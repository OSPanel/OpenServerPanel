Nuosavų meniu punktų kūrimas

  1. Pridėkite naują sekciją su unikaliu identifikatoriumi [ID]
  2. Išdėstykite sekcijas norima tvarka — tai nulems punktų tvarką meniu
  3. Išsaugokite pakeitimus ir paleiskite Open Server Panel iš naujo, kad pakeitimai įsigaliotų

Svarbi informacija

Kuriant nuosavus meniu punktus užtikrinkite, kad sekcijų identifikatoriai nesikartotų. Tai gali sukelti meniu veikimo konfliktus.

Meniu punktų nustatymai

Rikiavimo tvarka: Meniu punktai rikiuojami ta pačia tvarka, kuria atitinkamos sekcijos yra išdėstytos šablone.

caption Meniu punkto antraštė. Palaiko kalbines konstantas formatu {lang_xxx}.

Pagal numatymą: nenurodyta
category

Nustato meniu punkto vietą hierarchijoje. Palaikomas vienas įdėjimo lygis (pvz., "Mano Žymės\Darbas").

Specialios kategorijos:

  • projects, modules, addons - prideda punktą į atitinkamą veiksmų meniu
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - prideda punktą konkrečiam elementui

Jei kategorija nenurodyta, punktas sukuriamas šakniniame meniu.

Pagal numatymą: nenurodyta
command Komanda, vykdoma aktyvavus meniu punktą. Punktai be komandos ignoruojami.

Pagal numatymą: nenurodyta
enabled Įjungia/išjungia meniu punkto rodymą.

Pagal numatymą: on | Reikšmės: on, off
hide Valdo kviečiamos programos lango matomumą. Nedaro įtakos dukteriniams procesams.

Pagal numatymą: off | Reikšmės: on, off
hr_after Prideda horizontalų skirtuką po meniu punktu.

Pagal numatymą: off | Reikšmės: on, off
hr_before Prideda horizontalų skirtuką prieš meniu punktą.

Pagal numatymą: off | Reikšmės: on, off
icon Piktograma iš Font Awesome Free (Solid/Regular/Brands) rinkinio.

Pagal numatymą: nenurodyta
need_alias Rodo meniu punktą tik domeno pseudonimui. Meniu šablone gali būti tik vienas punktas su need_alias=on!
Taikoma kategorijoms: projects

Pagal numatymą: nenurodyta | Reikšmės: on, off
need_category

Riboja meniu punkto rodymą tik tam tikros kategorijos moduliais/papildiniais.

Palaikomi formatai:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Pagal numatymą: nenurodyta
need_module_shell Rodo meniu punktą priklausomai nuo shell/cli buvimo tėviniame modulyje.
Taikoma kategorijoms: modules, modules\<имя_модуля>

Pagal numatymą: nenurodyta | Reikšmės: on, off
need_state Rodo meniu punktą priklausomai nuo tėvinio modulio būsenos.
Taikoma kategorijoms: modules, modules\<имя_модуля>

Pagal numatymą: nenurodyta | Reikšmės: on, off
need_start_cmd Rodo meniu punktą, jei projekto nustatymuose yra paleidimo komanda.
Taikoma kategorijoms: projects, projects\<имя_домена>

Pagal numatymą: nenurodyta | Reikšmės: on, off
need_use_wt Rodo meniu punktą priklausomai nuo Windows Terminal naudojimo nustatymo Open Server Panel.

Pagal numatymą: nenurodyta | Reikšmės: on, off
work_directory Darbinis katalogas komandos vykdymui. Gali keistis komandų vykdymo metu.

Pagal numatymą: {root_dir}

Šabloniniai kintamieji

Parametruose "command" ir "work_directory" galima naudoti šiuos šabloninius kintamuosius:

Bendrieji kintamieji

Kintamasis Aprašymas
{date_time} Dabartinė data/laikas (kintamasis pasiekiamas tik parametrui "command")
{root_dir} Open Server Panel šakninė direktorija (pilnas kelias)
{root_drive} Šakninės direktorijos diskas
{root_path} Kelias į Open Server Panel šakninę direktoriją
{web_panel_url} Žiniatinklio sąsajos URL adresas

Specialūs kintamieji (tik projects ir projects\<имя_домена>)

Kintamasis Aprašymas
{base_dir} Projekto bazinis katalogas
{host} Domeno pavadinimas (Punycode)
{host_decoded} Matomas domeno pavadinimas (be Punycode)
{host_scheme} Užklausos į projektą schema ("http" arba "https", priklauso nuo TLS parametro projekto nustatymuose)
{http_port} Užklausos į projektą HTTP protokolu prievadas
{https_port} Užklausos į projektą HTTPS protokolu prievadas
{menu_caption} Meniu punkto antraštė (tik kategorijai projects su need_alias=ON)
{http_engine} HTTP variklis
{node_engine} Node.js variklis
{php_engine} PHP variklis
{project_root} Projekto šakninė direktorija
{base_url} Projekto URL
{web_root} Projekto viešasis katalogas
{scheme_port} Projekto užklausos prievadas (":{http_port}" arba ":{https_port}", priklauso nuo TLS parametro projekto nustatymuose). Jei {http_port} arba {https_port} turi numatytąją reikšmę 80 ar 443, tuomet {scheme_port} bus tuščias.
{app_start_command} Projekto programos paleidimo komanda (jei nustatyta)
{terminal_codepage} Konsolės koduotė

Specialūs kintamieji (tik addons ir addons\<имя_дополнения>)

Kintamasis Aprašymas
{addon_name} Papildinio pavadinimas
{terminal_codepage} Konsolės koduotė

Specialūs kintamieji (tik modules ir modules\<имя_модуля>)

Kintamasis Aprašymas
{ip} Modulio IP adresas
{log_level} Klaidų žurnalinimo lygis
{module_name} Modulio pavadinimas
{port} Modulio prievadas
{profile_name} Dabartinio modulio nustatymų profilio pavadinimas
{query_log_level} Užklausų žurnalinimo lygis
{shell_command} Modulio shell/cli aplinkos paleidimo komanda (jei nustatyta)
{terminal_codepage} Konsolės koduotė
{time_zone} Laiko juosta

Specialios komandų reikšmės

Komanda Aprašymas
command_open_logs_viewer Atidaryti žurnalų peržiūros langą
command_open_idn_converter Atidaryti IDN konverterį
command_open_options Atidaryti programos nustatymų langą

Be šabloninių kintamųjų, galima naudoti bet kokius Windows aplinkos kintamuosius, pvz.: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% ir t. t.

Naudojimo pavyzdys

[bookmark_1]

caption  = Google
category = Mano Žymės\Paieškos sistemos
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE parinktys

  • /c: Vykdyti komandą ir uždaryti terminalą.
  • /k: Vykdyti komandą ir palikti terminalą atvirą.
