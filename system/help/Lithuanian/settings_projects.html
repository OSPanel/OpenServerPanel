Globalūs projektų nustatymai

Parametrai, nurodyti šiame skyriuje, naudojami tuo atveju, jei projekto nustatymuose nenurodyta kitų reikšmių.

HTTP
Nustato naudojamą žiniatinklio serverio modulį projektams.
NODE
Nurodo Node.js variklį Node.js programoms paleisti.

Node.js įdiegimas: Iš anksto įdiekite reikiamą Node.js versiją komanda osp node <latest|lts|номер>.
PHP
Nustato naudojamą PHP modulį PHP failams apdoroti.
Įjungti
Nustato numatytąją projekto būseną (įjungtas arba išjungtas).
Terminalo koduotė
Terminalo koduotė dirbant projekto aplinkoje.

Specialios reikšmės:
- system: Naudojama sisteminė koduotė.

Svarbu: Jei reikšmė nenurodyta, formuojant galutinę projekto aplinką terminalo koduotė bus nustatyta paskutinės prijungtos aplinkos, kurioje ji nurodyta, pavyzdžiui, PHP modulio aplinkos.
IP
Nurodo IP adresą(-us), naudojamą visiems projektams be individualių nustatymų.

Apribojimas: Projektai, naudojantys tą patį IP adresą, turi veikti toje pačioje PHP versijoje.

Kelių IP palaikymas: Galima nurodyti kelis IP adresus per tarpą, įskaitant IPv6. HOSTS faile domenams bus priskirtas pirmasis nurodytas IP.

Automatinis priskyrimas: Jei lauką paliksite tuščią, IP adresas bus priskiriamas automatiškai.

Rekomendacijos:
  • Automatinis IP adresų valdymas rekomenduojamas daugumai naudotojų.
  • Rankinį IP adreso nurodymą naudokite tik esant specifiniams tinklo konfigūracijos reikalavimams.
HTTP
Nustato prievadą ryšiams per HTTP.
HTTPS
Nustato prievadą ryšiams per HTTPS.
TLS
Įjungia arba išjungia TLS palaikymą.
Sertifikato failas
Nurodo kelią į TLS sertifikato failą. Galima naudoti šabloninius kintamuosius.

Leistini simboliai: A-Za-z0-9-+_.\:

Rekomendacija: Palikite lauką tuščią, kad sertifikatai būtų generuojami automatiškai.
Rakto failas
Nurodo kelią į TLS rakto failą. Galima naudoti šabloninius kintamuosius.

Leistini simboliai: A-Za-z0-9-+_.\:

Rekomendacija: Palikite lauką tuščią, kad raktas būtų generuojamas automatiškai.
IP adresas (backend)
Nurodo IP adresą, kuriuo vykdomas prisijungimas prie serverinės dalies (Backend).
Prievadas (backend)
Nustato prievado numerį prisijungimui prie serverinės dalies (Backend).
Įjungti (backend)
Leidžia automatiškai nukreipti visą įeinantį projekto srautą (HTTP ir HTTPS) į serverinę dalį (Backend). Naudinga testuojant ar kuriant, kai frontendas ir backendas yra atskirti.
Projekto katalogas
Nurodo projekto šakninį katalogą. Perėjimas į šį katalogą atliekamas komanda osp project <DOMAIN> kartu su projekto aplinkos aktyvavimu. Galima naudoti šabloninius kintamuosius.

Leistini simboliai: A-Za-z0-9-+_.\:
Viešasis katalogas
Nustato projekto viešąjį katalogą. Galima naudoti šabloninius kintamuosius.

Leistini simboliai: A-Za-z0-9-+_.\:
Pseudonimai
Nurodo papildomus projekto domenų vardus (aliasus) per tarpą. Galima naudoti šabloninius kintamuosius.

Apribojimas: Simbolis "*" Windows HOSTS faile nepalaikomas ir reikalauja DNS konfigūracijos.
Projekto aplinka
Papildinių ir modulių sąrašas (per tarpą), formuojantis projekto aplinką.

HTTP, NODE ir PHP: Šių variklių aplinkos prijungiamos visada (jei nurodytos domenui) ir nereikalauja nurodymo šiame parametre.
Projekto paleidimo komanda
Nustato projekto paleidimo komandą (pavyzdžiui, nodemon app.js). Galima naudoti šabloninius kintamuosius.
Projekto URL
URL, naudojamas atidarant projektą Meniu→Projektas→Atidaryti naršyklėje, taip pat atidarant projekto domenų pseudonimus (aliasus). Galima naudoti šabloninius kintamuosius.

Taikymas: Galima nurodyti CMS administravimo skydelio URL.

Šabloniniai kintamieji

Kintamasis Aprašymas
{backend_ip} IP adresas prisijungimui prie serverinės dalies (Backend)
{backend_port} Prievadas prisijungimui prie serverinės dalies (Backend)
{base_dir} Projekto šakninė direktorija (kur yra katalogas .osp)
{date_time} Dabartinė data/laikas (kintamasis prieinamas tik projekto programos paleidimo komandai)
{host} Domeno vardas (tarptautiniams domenams naudojamas Punycode)
{host_decoded} Matomas domeno vardas (be Punycode)
{host_scheme} Užklausos į projektą schema ("http" arba "https", priklauso nuo TLS parametro projekto nustatymuose)
{http_port} Užklausos į projektą per HTTP prievadas
{https_port} Užklausos į projektą per HTTPS prievadas
{http_engine} HTTP variklis
{node_engine} NODE variklis
{php_engine} PHP variklis
{project_root} Projekto šakninė direktorija
{web_root} Projekto viešasis katalogas
{scheme_port} Užklausos į projektą prievadas (":{http_port}" arba ":{https_port}", priklauso nuo TLS parametro projekto nustatymuose).

Jei {http_port} arba {https_port} turi standartinę reikšmę 80 arba 443, tuomet {scheme_port} bus tuščias.
{root_dir} Open Server Panel šakninė direktorija (pilnas kelias)
{root_drive} Šakninio katalogo diskas
{root_path} Kelias į Open Server Panel šakninę direktoriją
{terminal_codepage} Konsolės koduotė
