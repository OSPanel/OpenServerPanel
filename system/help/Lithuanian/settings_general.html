Programos nustatymai

Paleisti kartu su Windows
Įjungti Open Server Panel automatinį paleidimą įkrovus operacinę sistemą.
Uždelsimas
Programos paleidimo uždelsimas (sekundėmis, nuo 0 iki 60).

Leidžia atidėti programos startą įkrovos metu kartu su Windows, kad sumažintumėte bendrą sistemos apkrovą. Tai ypač naudinga, jei reikia palaukti, kol pilnai inicializuosis trečiųjų šalių servisai ar tinklo sąsajos.
Tikrinti, ar yra naujų versijų
Įjungti Open Server Panel atnaujinimų tikrinimą (reikalingas prisijungimas prie interneto).
Įjungti užduočių planuoklę
Aktyvuoti integruotą užduočių planuoklę. Jei parametras išjungtas, jokios suplanuotos užduotys nebus vykdomos, nepriklausomai nuo jų būsenos.
Naudoti HOSTS failą
Įjungti domenų vardų rašymą į HOSTS failą.

Rekomendacijos, kai organizacijoje ribota prieiga prie HOSTS failo:

1. SuKonfigūruokite visus reikiamus modulius ir projektus.
2. Kreipkitės į sistemų administratorių, kad atrakintų HOSTS ir užfiksuotų jo būseną.
3. Po administratoriaus atliktų pakeitimų fiksavimo šią parinktį galima išjungti.

Svarbu: Neišjunkite šio parametro, jei nesate tikri dėl pasekmių!
Paleisti modulius su projekto profiliu
Paleisti modulius kartu aktyvuojant profilį, kurio pavadinimas sutampa su projekto vardu.

Naudojama pasirinkus meniu punktą „Įjungti projekto modulius“, kad automatiškai būtų aktyvuotas profilis tokiu pačiu pavadinimu kaip ir esamas projektas, jei toks yra.
Neišjungti paslėptų projektų modulių
Neišjungti paslėptų projektų modulių pasirinkus meniu punktą „Išjungti visus modulius“. „Paslėpti“ reiškia tuos projektus, kuriems nustatyta kategorija „hidden“.

Pagal numatymą komanda „Išjungti visus modulius“ sustabdo absoliučiai visų modulių darbą, įskaitant tuos, kuriuos naudoja paslėpti tarnybiniai projektai (pavyzdžiui, PHPMyAdmin). Ši parinktis leidžia išsaugoti paslėptų tarnybinių projektų veikimą neišjungiant jiems būtinų modulių, tuo tarpu visi kiti moduliai bus išjungti.
Sąsajos kalba
Open Server Panel naudotojo sąsajos kalba.

Jei lokalizacijos failas nėra arba jame yra klaidų, bus naudojama anglų kalba.
API domenas
Vietinis domenas API ir žiniatinklio sąsajai (kuriama)

Rekomendacija: Jei naudojamas VPN arba proxy, pridėkite šį domeną į išimtis.
API IP adresas
IPv4 adresas API ir žiniatinklio sąsajai (kuriama).

Rekomendacija: Jei naudojamas VPN arba proxy, pridėkite šį IP adresą į išimtis.
API prievadas
Prievadas, naudojamas API ir žiniatinklio sąsajai (kuriama). Open Server Panel nepavyks paleisti, jei nurodytą prievadą jau naudoja kita programa.
Naudoti Windows Terminal
Įjungti Windows Terminal naudojimą vietoje standartinės komandų sąsajos.

Reikalavimai: Windows Terminal turi būti įdiegtas sistemoje ir įrašytas į aplinkos kintamąjį PATH.

Windows Terminal kaip cmd.exe: Windows Terminal gali pakeisti cmd.exe ir būti įrašytas į aplinkos kintamąjį %COMSPEC% naujose Windows versijose. Jei taip yra, palikite šią parinktį įjungtą.

Nauji Windows Terminal egzemplioriai: Jei Windows Terminal atidaro naujus langus vietoje kortelių, sukonfigūruokite jį taip: Nustatymai→Paleidimas→Naujo egzemplioriaus elgsena→Prijungti prie paskutinio naudoto lango.
Trumpas projekto antraštės tekstas
Įjungus šią parinktį terminalo lango antraštėje bus rodomas tik projekto pavadinimas vietoje išsamaus aplinkos aprašymo.
Įtraukti sisteminę aplinką į projekto aplinką
Naudoti sistemos (System) aplinką terminale, net jei ji nenustatyta projekto nustatymuose. Sisteminė aplinka leidžia naudoti sistemoje įdiegtas programas (pavyzdžiui, git.exe arba ssh.exe).

Išjunkite šią parinktį tik kilus konfliktams su sistemine programine įranga.
ANSI palaikymas
Įjungti ANSI kodų palaikymą spalvų valdymui terminale.

Režimas „Automatiškai“ (pagal numatymą):
- Pataisa taikoma tik Windows 10 iki 1903 versijos imtinai. Naujesnėse Windows versijose ANSI kodų palaikymas jau yra integruotas.
- Pataisa netaikoma terminalams, kurie pagal numatymą palaiko ANSI (pavyzdžiui, Windows Terminal).
Katalogai projektų paieškai
Katalogų sąrašas, kuriuose Open Server Panel ieškos projektų. Kelius atskirkite kabliataškiu (;).

Išimtys: Paanalėjai node_modules ir vendor ignoruojami.
Gylis
Didžiausias katalogų įdėjimo gylis ieškant projektų.

Padidinus šią reikšmę, Open Server Panel paleidimas gali sulėtėti, jei nurodytuose kataloguose yra daug pakatalogių.
Maksimalus žurnalo failo dydis
Maksimalus žurnalo failo dydis megabaitais. Viršijus nurodytą reikšmę, žurnalo failas bus iš naujo sukurtas kitą kartą paleidus programą.

Nustatykite reikšmę 0, kad žurnalai būtų išvalomi kiekvieną kartą paleidžiant programą.

Nustatykite reikšmę 100 MB, kad visiškai išjungtumėte žurnalų valymą.
