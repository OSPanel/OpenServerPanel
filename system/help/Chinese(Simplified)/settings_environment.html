模块环境的全局变量

在本节中可以为模块设置全局环境变量。

这些变量仅在模块环境中生效，不会影响系统变量或项目环境。

值中允许使用模板变量。

如果某个变量存在于系统环境中，但不应在模块环境中使用，请使用专用过滤器（参见 模块→允许的系统变量）或通过将其设为空值从环境中删除该变量。

模板变量

变量 说明
{root_dir} Open Server Panel 根目录（完整路径）
{root_drive} 根目录所在的磁盘
{root_path} Open Server Panel 根目录路径
{terminal_codepage} 终端编码（参见 模块→终端编码）
{time_zone} Etc/GMT 格式的时区（参见 模块→时区）

除了模板变量外，还可以使用任意 Windows 环境变量，例如：%SYSTEMROOT%、%SYSTEMDRIVE%、%USERNAME%、%PATH% 等。
