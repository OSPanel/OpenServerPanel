模块全局设置

在此部分中设置的参数适用于当特定模块的相应选项设置为 auto（默认）时的情况。

静默模式
关闭来自 Windows Error Reporting 和模块自身的错误弹窗。

建议： 仅在需要对模块进行问题诊断时才关闭此模式。
在日志文件中添加标题
启用在每次启动模块时自动向日志文件添加标题。对关闭自动清理日志以区分工作会话很有用。
最大连续启动失败次数
确定在模块进入“错误”状态之前，允许的连续启动失败次数。
模块健康检查时间
确定模块成功启动后进行健康性测试的时间周期。

起始点： 自模块成功启动之时起。

进入“错误”状态： 如果模块在试用期内异常退出，它将不会被自动重启，并会进入“错误”状态。这也适用于模块无法在系统层面启动的情况。

关闭检查： 值为 0 将关闭试用期，模块在故障时将始终被重启。

建议： 不要设置为 0 或过短的周期（少于 30 秒），否则可能导致无限重启循环。
模块关闭的等待时间
确定允许模块完成其工作的最长期限。

强制结束： 如果模块未在指定期限内结束，将被强制停止。

关闭等待： 值为 0 将关闭等待期。程序将无限期等待模块结束。

警告： 强制停止模块可能导致数据损坏、未保存更改丢失或进程异常结束。请谨慎使用该设置。
日志文件的最大大小
日志文件的最大大小（以 MB 为单位）。超过指定值时，日志文件将在下次启动模块时被重新创建。

设置为 0 可在每次启动模块时清理日志。

设置为 100 MB 可完全关闭日志清理。
终端编码
模块环境交互时的终端编码。

特殊值：
- system: 使用系统编码。
时区
以 Etc/GMT 格式（例如，Etc/GMT-3）设置模块的时区。

特殊值：
- system: 使用系统时区。

重要： Etc/GMT 格式相对于 UTC 具有反向偏移（例如，Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow）。
使用的附加组件环境
指定附加组件列表（以空格分隔），其环境（如果有）将附加到模块环境。终端中的信息指示器不会显示这些附加环境。

警告： 仅在完全理解其用途时才使用此选项。
允许的系统变量
指定要传递到模块环境的 Windows 环境变量列表（以空格分隔）。

用途： 允许将模块的工作环境与系统中安装的同类软件隔离。

警告： 未充分理解其影响而更改此列表，可能导致模块工作不稳定。
