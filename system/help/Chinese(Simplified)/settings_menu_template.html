创建自定义菜单项

  1. 添加一个具有唯一标识符 [ID] 的新节
  2. 按所需顺序排列各节——这将决定菜单项的顺序
  3. 保存更改并重启 Open Server Panel 以应用更改

重要信息

在创建自定义菜单项时，请确保各节的标识符不重复。否则可能导致菜单运行冲突。

菜单项设置

排序顺序： 菜单项按照模板中对应各节的排列顺序进行排序。

caption 菜单项标题。支持 {lang_xxx} 格式的语言常量。

默认：未指定
category

确定菜单项在层级中的位置。支持一级嵌套（例如，“我的书签\工作”）。

特殊类别：

  • projects, modules, addons - 将项目添加到相应的操作菜单
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - 为特定元素添加项目

如果未指定类别，项目将在根菜单中创建。

默认：未指定
command 激活菜单项时执行的命令。没有命令的项目将被忽略。

默认：未指定
enabled 启用/禁用菜单项的显示。

默认：on | 取值：on, off
hide 控制被调用应用程序窗口的可见性。不影响子进程。

默认：off | 取值：on, off
hr_after 在菜单项之后添加水平分隔符。

默认：off | 取值：on, off
hr_before 在菜单项之前添加水平分隔符。

默认：off | 取值：on, off
icon 来自 Font Awesome Free (Solid/Regular/Brands) 的图标。

默认：未指定
need_alias 仅对域别名显示该菜单项。菜单模板中只能有一个 need_alias=on 的项目！
适用类别：projects

默认：未指定 | 取值：on, off
need_category

按特定类别的模块/插件限制菜单项的显示。

支持的格式：

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
默认：未指定
need_module_shell 根据父模块是否具有 shell/cli 显示菜单项。
适用类别：modules, modules\<имя_модуля>

默认：未指定 | 取值：on, off
need_state 根据父模块的状态显示菜单项。
适用类别：modules, modules\<имя_модуля>

默认：未指定 | 取值：on, off
need_start_cmd 当项目设置中存在启动命令时显示菜单项。
适用类别：projects, projects\<имя_домена>

默认：未指定 | 取值：on, off
need_use_wt 根据 Open Server Panel 中使用 Windows Terminal 的设置显示菜单项。

默认：未指定 | 取值：on, off
work_directory 执行命令的工作目录。可在执行过程中变更。

默认：{root_dir}

模板变量

在参数“command”和“work_directory”中可以使用以下模板变量：

通用变量

变量 说明
{date_time} 当前日期/时间（仅对参数“command”可用）
{root_dir} Open Server Panel 的根目录（完整路径）
{root_drive} 根目录所在磁盘
{root_path} Open Server Panel 根目录的路径
{web_panel_url} Web 界面的 URL 地址

特殊变量（仅用于 projects 和 projects\<имя_домена>）

变量 说明
{base_dir} 项目基础目录
{host} 域名（Punycode）
{host_decoded} 可见域名（非 Punycode）
{host_scheme} 项目请求的方案（“http” 或 “https”，取决于项目设置中的 TLS 参数）
{http_port} 通过 HTTP 协议请求项目的端口
{https_port} 通过 HTTPS 协议请求项目的端口
{menu_caption} 菜单项标题（仅用于类别 projects 且 need_alias=ON）
{http_engine} HTTP 引擎
{node_engine} Node.js 引擎
{php_engine} PHP 引擎
{project_root} 项目根目录
{base_url} 项目 URL
{web_root} 项目公共目录
{scheme_port} 项目请求端口（“:{http_port}” 或 “:{https_port}”，取决于项目设置中的 TLS 参数）。如果 {http_port} 或 {https_port} 的标准值为 80 或 443，则 {scheme_port} 将为空。
{app_start_command} 项目应用的启动命令（如果已配置）
{terminal_codepage} 控制台编码

特殊变量（仅用于 addons 和 addons\<имя_дополнения>）

变量 说明
{addon_name} 插件名称
{terminal_codepage} 控制台编码

特殊变量（仅用于 modules 和 modules\<имя_модуля>）

变量 说明
{ip} 模块 IP 地址
{log_level} 错误日志记录级别
{module_name} 模块名称
{port} 模块端口
{profile_name} 模块当前配置文件名称
{query_log_level} 请求日志记录级别
{shell_command} 模块的 shell/cli 启动命令（如果已配置）
{terminal_codepage} 控制台编码
{time_zone} 时区

特殊命令值

命令 说明
command_open_logs_viewer 打开日志查看器窗口
command_open_idn_converter 打开 IDN 转换器
command_open_options 打开程序设置窗口

除了模板变量外，还可以使用任何 Windows 环境变量，例如：%SYSTEMROOT%、%SYSTEMDRIVE%、%USERNAME%、%PATH% 等。

使用示例

[bookmark_1]

caption  = Google
category = 我的书签\搜索引擎
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE 选项

  • /c: 执行命令并关闭终端。
  • /k: 执行命令并保持终端打开。
