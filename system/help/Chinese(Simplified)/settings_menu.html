菜单设置

主题样式
菜单图标的主题样式。
字体大小
菜单的字体大小（像素）。该选项允许独立于系统设置来设置菜单字体大小。

将滑块设置为最小值 12px 可关闭字体大小控制功能（将使用系统大小）。
在通知区域显示图标
在 Windows 通知区域显示程序图标。

关闭： 如果您使用的是不需要 Windows 用户登录的自动启动类型（Windows 任务计划程序→计算机启动时运行），请关闭此选项。
为菜单项显示图标
在程序菜单中显示图标。启用系统渲染时不显示图标。
启用系统渲染
仅在需要与屏幕阅读器等无障碍程序兼容时启用此选项。

注意！ 启用系统渲染时，菜单中的图标不会显示。
显示垂直分隔符
启用该选项后，程序菜单中的图标将以垂直分隔符分隔。
不对仅有一个元素的列表进行分组
不对仅包含一个元素的列表进行分组。
项目：显示
显示项目管理菜单。
项目：分组
在菜单中按域名后缀对项目进行分组。
项目：嵌套菜单
在单独的子菜单中显示项目菜单。
项目：显示分隔符
在项目菜单后显示分隔线。
模块：显示
显示模块管理菜单。
模块：分组
在菜单中对模块进行分组。
模块：嵌套菜单
在单独的子菜单中显示模块菜单。
模块：显示分隔符
在模块菜单后显示分隔线。
扩展：显示
显示扩展菜单。
扩展：分组
在菜单中对扩展进行分组。
扩展：嵌套菜单
在单独的子菜单中显示扩展菜单。
扩展：显示分隔符
在扩展菜单后显示分隔线。
