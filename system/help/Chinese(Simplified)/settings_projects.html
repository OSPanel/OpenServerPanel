项目全局设置

在本节中指定的参数将在项目设置未指定其他值时使用。

HTTP
定义用于项目的Web服务器模块。
NODE
指定用于运行Node.js应用的Node.js引擎。

安装 Node.js： 请先使用命令 osp node <latest|lts|номер> 安装所需版本的 Node.js。
PHP
定义用于处理PHP文件的PHP模块。
启用
定义项目的默认状态（启用或禁用）。
终端编码
项目环境工作时的终端编码。

特殊值：
- system: 使用系统编码。

重要： 如果未设置该值，则在生成项目最终环境时，终端编码将由最后加载且设置了编码的环境确定，例如PHP模块环境。
IP
设置供所有未进行单独配置的项目使用的IP地址。

限制： 使用同一IP地址的项目必须运行在同一版本的PHP上。

支持多个IP： 可通过空格指定多个IP地址，包括IPv6。在HOSTS文件中，域名将被分配为第一个指定的IP。

自动分配： 如果留空，IP地址将自动分配。

建议：
  • 大多数用户建议使用IP地址的自动管理。
  • 仅在特定网络配置需求下使用手动指定IP地址。
HTTP
定义HTTP连接的端口。
HTTPS
定义HTTPS连接的端口。
TLS
启用或禁用TLS支持。
证书文件
指定TLS证书文件路径。可使用模板变量。

允许的字符： A-Za-z0-9-+_.\:

建议： 留空以自动生成证书。
密钥文件
指定TLS密钥文件路径。可使用模板变量。

允许的字符： A-Za-z0-9-+_.\:

建议： 留空以自动生成密钥。
IP地址（backend）
指定连接到后端（Backend）的IP地址。
端口（backend）
定义连接到后端（Backend）的端口号。
启用（backend）
允许将项目的所有入站流量（HTTP 和 HTTPS）自动转发到后端（Backend）。在前端与后端分离的测试或开发场景中很有用。
项目目录
指定项目根目录。执行 osp project <DOMAIN> 命令时将切换到此目录并同时激活项目环境。可使用模板变量。

允许的字符： A-Za-z0-9-+_.\:
公共目录
定义项目的公共目录。可使用模板变量。

允许的字符： A-Za-z0-9-+_.\:
别名
指定项目的额外域名（别名，以空格分隔）。可使用模板变量。

限制： 符号“*”在Windows的HOSTS文件中不受支持，需要配置DNS。
项目环境
组成项目环境的扩展与模块列表（以空格分隔）。

HTTP、NODE 和 PHP： 这些引擎的环境在为域名设置时将始终加载，无需在此参数中指定。
项目启动命令
定义项目的启动命令（例如，nodemon app.js）。可使用模板变量。
项目URL
在 菜单→项目→在浏览器中打开 打开项目时使用的URL，以及打开项目域别名时使用的URL。可使用模板变量。

用法： 可指定CMS管理面板的URL。

模板变量

变量 描述
{backend_ip} 连接到后端（Backend）的IP地址
{backend_port} 连接到后端（Backend）的端口
{base_dir} 项目根目录（.osp 目录所在位置）
{date_time} 当前日期/时间（仅在项目应用启动命令中可用）
{host} 域名（对国际化域名使用 Punycode）
{host_decoded} 可见的域名（不含 Punycode）
{host_scheme} 对项目的请求方案（"http" 或 "https"，取决于项目设置中的 TLS 参数）
{http_port} 通过 HTTP 协议请求项目的端口
{https_port} 通过 HTTPS 协议请求项目的端口
{http_engine} HTTP 引擎
{node_engine} NODE 引擎
{php_engine} PHP 引擎
{project_root} 项目根目录
{web_root} 项目公共目录
{scheme_port} 对项目的请求端口（":{http_port}" 或 ":{https_port}"，取决于项目设置中的 TLS 参数）。

如果 {http_port} 或 {https_port} 为标准值 80 或 443，则 {scheme_port} 为空。
{root_dir} Open Server Panel 根目录（完整路径）
{root_drive} 根目录所在磁盘
{root_path} Open Server Panel 根目录路径
{terminal_codepage} 控制台编码
