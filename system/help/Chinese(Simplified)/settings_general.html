程序设置

随 Windows 启动
在操作系统启动时启用 Open Server Panel 的自动启动。
延迟
程序启动延迟（以秒为单位，0 到 60）。

允许在随 Windows 启动时推迟应用程序的启动，以降低系统的总体负载。这在需要等待第三方服务或网络接口完全初始化时尤其有用。
检查新版本
启用 Open Server Panel 的更新检查（需要连接互联网）。
启用任务计划程序
激活内置任务计划程序。如果该参数被禁用，则无论任务状态如何，都不会执行任何计划任务。
使用 HOSTS 文件
启用将域名写入 HOSTS 文件。

组织中对 HOSTS 文件访问受限时的建议：

1. 配置所有必要的模块和项目。
2. 联系系统管理员以解锁 HOSTS 并固定其状态。
3. 管理员固定更改后，可关闭此选项。

重要： 如果不确定后果，请不要关闭此参数！
按项目配置文件启动模块
启动模块的同时激活与项目名称相同的配置文件。

在选择“启用项目模块”菜单项时使用，以便如果存在与当前项目同名的配置文件，则自动激活该配置文件。
不关闭隐藏项目的模块
在选择“关闭所有模块”菜单项时，不关闭隐藏项目的模块。这里的“隐藏”指设置了类别“hidden”的项目。

默认情况下，“关闭所有模块”命令会停止所有模块的运行，包括被隐藏的服务性项目使用的模块（例如，PHPMyAdmin）。该选项允许在关闭其他所有模块的同时，保持隐藏的服务性项目所需的模块继续运行。
界面语言
Open Server Panel 的用户界面语言。

如果缺少本地化文件或其中存在错误，将使用英语。
API 域名
用于 API 和 Web 界面的本地域名（开发中）

建议： 如果使用 VPN 或代理，请将该域名加入例外。
API IP 地址
用于 API 和 Web 界面的 IPv4 地址（开发中）。

建议： 如果使用 VPN 或代理，请将该 IP 地址加入例外。
API 端口
用于 API 和 Web 界面的端口（开发中）。如果所指定端口已被其他应用程序占用，Open Server Panel 将无法启动。
使用 Windows Terminal
启用使用 Windows Terminal 代替标准命令界面。

要求： 系统中必须安装 Windows Terminal，并在环境变量 PATH 中配置。

Windows Terminal 作为 cmd.exe： Windows Terminal 可替代 cmd.exe，并在新版本 Windows 中配置到环境变量 %COMSPEC%。如果是这样，请保持此选项开启。

Windows Terminal 新实例： 如果 Windows Terminal 打开新窗口而非新标签，请按以下方式进行设置：设置→启动→新实例行为→附加到最后使用的窗口。
简短项目标题
启用该选项后，终端窗口标题将仅显示项目名称，而非环境的详细描述。
在项目环境中包含系统环境
在终端中使用系统环境（System），即使它未在项目设置中指定。系统环境允许使用系统中安装的程序（例如，git.exe 或 ssh.exe）。

仅在与系统软件发生冲突时才关闭此选项。
ANSI 支持
启用用于控制终端颜色的 ANSI 代码支持。

“自动”模式（默认）：
- 仅对包含 Windows 10 1903 及更早版本应用修复。在更新版本的 Windows 中已内置对 ANSI 代码的支持。
- 对默认支持 ANSI 的终端（例如，Windows Terminal）不应用修复。
项目搜索目录
Open Server Panel 搜索项目的目录列表。请用分号（;）分隔路径。

排除项： 将忽略子目录 node_modules 和 vendor。
深度
搜索项目时目录嵌套的最大深度。

如果指定目录中包含大量子目录，增大该值可能会减慢 Open Server Panel 的启动速度。
日志文件最大大小
日志文件的最大大小（MB）。当超过指定值时，日志文件将在下次程序启动时重新创建。

设置为 0，可在每次程序启动时清空日志。

设置为 100 MB，可完全禁用日志清理。
