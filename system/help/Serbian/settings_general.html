Подешавања програма

Покретати заједно са Windows
Омогући аутоматско покретање Open Server Panel при учитавању оперативног система.
Задршка
Задршка покретања програма (у секундама, од 0 до 60).

Омогућава одлагање старта апликације током учитавања заједно са Windows, како би се смањило укупно оптерећење система. Ово је посебно корисно ако је потребно сачекати потпуну иницијализацију спољних сервиса или мрежних интерфејса.
Проверавати доступност нових верзија
Омогући проверу ажурирања Open Server Panel (потребна интернет веза).
Омогућити планер задатака
Активирати уграђени планер задатака. Ако је параметар искључен, ниједан заказани задатак неће бити извршен, без обзира на његов статус.
Користити HOSTS датотеку
Омогући упис доменских имена у HOSTS датотеку.

Препоруке у случају ограниченог приступа HOSTS датотеци у организацији:

1. Подесите све потребне модуле и пројекте.
2. Обратите се систем администратору ради откључавања HOSTS и фиксирања његовог стања.
3. Након фиксирања измена од стране администратора можете искључити ову опцију.

Важно: Не искључујте овај параметар ако нисте сигурни у последице!
Покретати модуле са профилом пројекта
Покретати модуле уз истовремену активацију профила који се поклапа са именом пројекта.

Користи се при избору ставке менија «Укључи модуле пројекта», како би се аутоматски активирао профил са истим именом као и код текућег пројекта, ако такав постоји.
Не искључивати модуле скривених пројеката
Не искључивати модуле скривених пројеката при избору ставке менија «Искључи све модуле». Под "скривеним" се подразумевају они пројекти за које је задата категорија "hidden".

Подразумевано команда «Искључи све модуле» зауставља рад апсолутно свих модула, укључујући и оне које користе скривени сервисни пројекти (на пример, PHPMyAdmin). Дата опција омогућава да се очува функционалност скривених сервисних пројеката, без искључивања модула неопходних за њих, док ће сви остали модули бити искључени.
Језик интерфејса
Језик корисничког интерфејса Open Server Panel.

Ако локализациона датотека недостаје или садржи грешке, користиће се енглески језик.
Домен API
Локални домен за API и веб-интерфејс (у развоју)

Препорука: Ако се користи VPN или прокси, додајте овај домен у изузеће.
IP адреса API
IPv4 адреса за API и веб-интерфејс (у развоју).

Препорука: Ако се користи VPN или прокси, додајте ову IP адресу у изузеће.
Порт API
Порт који се користи за API и веб-интерфејс (у развоју). Open Server Panel неће моћи да се покрене ако наведени порт већ користи нека друга апликација.
Користити Windows Terminal
Омогућити коришћење Windows Terminal уместо стандардног командног интерфејса.

Захтеви: Windows Terminal мора бити инсталиран у систему и наведен у променљивој окружења PATH.

Windows Terminal као cmd.exe: Windows Terminal може да замени cmd.exe и буде наведен у променљивој окружења %COMSPEC% у новијим верзијама Windows. Ако је тако, оставите ову опцију укљученом.

Нови примерци Windows Terminal: Ако Windows Terminal отвара нове прозоре уместо језичака, подесите га овако: Подешавања→Покретање→Понашање новог примерка→Придружити последњем коришћеном прозору.
Кратак наслов пројекта
При активирању ове опције у наслову прозора терминала биће приказано само име пројекта уместо детаљног описа окружења.
Укључивати системско окружење у окружење пројекта
Користити окружење система (System) у терминалу, чак и ако није задато у подешавањима пројекта. Системско окружење омогућава коришћење програма инсталираних у систему (на пример, git.exe или ssh.exe).

Искључујте ову опцију само у случају конфликата са системским софтвером.
Подршка ANSI
Омогућити подршку за ANSI кодове за управљање бојама у терминалу.

Режим "Аутоматски" (подразумевано):
- Исправка се примењује само на Windows 10 до верзије 1903 укључиво. У новијим верзијама Windows подршка за ANSI кодове је већ уграђена.
- Исправка се не примењује за терминале који подразумевано подржавају ANSI (на пример, Windows Terminal).
Каталози за претрагу пројеката
Списак каталога у којима ће Open Server Panel тражити пројекте. Раздвајајте путање тачком и запетом (;).

Искључења: Подкаталози node_modules и vendor се игноришу.
Дубина
Максимална дубина угнежђивања каталога при претрази пројеката.

Повећање ове вредности може успорити покретање Open Server Panel, ако у наведеним каталозима има велики број подкаталога.
Максимална величина датотеке дневника
Максимална величина датотеке дневника у мегабајтима. При премашењу наведене вредности лог датотека ће бити поново креирана при следећем покретању програма.

Поставите вредност 0 да бисте чистили дневнике при сваком покретању програма.

Поставите вредност 100 MB да бисте у потпуности онемогућили чишћење дневника.
