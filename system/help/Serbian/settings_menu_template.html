Креирање сопствених ставки менија

  1. Додајте нови одељак са јединственим идентификатором [ID]
  2. Поставите одељке у жељеном редоследу — то ће одредити редослед ставки у менију
  3. Сачувајте измене и поново покрените Open Server Panel да бисте применили измене

Важне информације

Приликом креирања сопствених ставки менија водите рачуна да се идентификатори одељака не понављају. То може довести до конфликата у раду менија.

Подешавања ставки менија

Редослед сортирања: Ставке менија се сортирају истим редоследом као и одговарајући одељци у шаблону.

caption Наслов ставке менија. Подржава језичке константе у формату {lang_xxx}.

Подразумевано: није задато
category

Одређује распоред ставке менија у хијерархији. Подржава један ниво угнежђености (на пример, "Моје Обележиваче\Посао").

Специјалне категорије:

  • projects, modules, addons - додаје ставку у одговарајући мени радњи
  • projects\<име_домена>, modules\<име_модула>, addons\<име_додатка> - додаје ставку за конкретан елемент

Ако категорија није наведена, ставка се креира у кореном менију.

Подразумевано: није задато
command Команда за извршавање при активирању ставке менија. Ставке без команде се игноришу.

Подразумевано: није задато
enabled Укључује/искључује приказ ставке менија.

Подразумевано: on | Вредности: on, off
hide Управља видљивошћу прозора покренуте апликације. Не утиче на дочерне процесе.

Подразумевано: off | Вредности: on, off
hr_after Додаје хоризонтални раздвајач после ставке менија.

Подразумевано: off | Вредности: on, off
hr_before Додаје хоризонтални раздвајач пре ставке менија.

Подразумевано: off | Вредности: on, off
icon Иконица из скупа Font Awesome Free (Solid/Regular/Brands).

Подразумевано: није задато
need_alias Приказује ставку менија само за доменски алијас. У шаблону менија може бити само једна ставка са need_alias=on!
Применљиво за категорије: projects

Подразумевано: није задато | Вредности: on, off
need_category

Ограничава приказ ставке менија модулима/додацима одређене категорије.

Подржани формати:

  • modules, addons
  • modules\<име_модула>, addons\<име_додатка>
Подразумевано: није задато
need_module_shell Приказује ставку менија у зависности од постојања shell/cli код матичног модула.
Применљиво за категорије: modules, modules\<име_модула>

Подразумевано: није задато | Вредности: on, off
need_state Приказује ставку менија у зависности од стања матичног модула.
Применљиво за категорије: modules, modules\<име_модула>

Подразумевано: није задато | Вредности: on, off
need_start_cmd Приказује ставку менија ако постоји команда покретања у подешавањима пројекта.
Применљиво за категорије: projects, projects\<име_домена>

Подразумевано: није задато | Вредности: on, off
need_use_wt Приказује ставку менија у зависности од подешавања коришћења Windows Terminal у Open Server Panel.

Подразумевано: није задато | Вредности: on, off
work_directory Радни директоријум за извршавање команде. Може се мењати током извршавања команди.

Подразумевано: {root_dir}

Шаблонске променљиве

У параметрима "command" и "work_directory" можете користити следеће шаблонске променљиве:

Опште променљиве

Променљива Опис
{date_time} Тренутни датум/време (променљива доступна само за параметар "command")
{root_dir} Корени директоријум Open Server Panel (пуна путања)
{root_drive} Диск кореног директоријума
{root_path} Путања до кореног директоријума Open Server Panel
{web_panel_url} URL адреса веб-интерфејса

Посебне променљиве (само за projects и projects\<име_домена>)

Променљива Опис
{base_dir} Базни директоријум пројекта
{host} Име домена (Punycode)
{host_decoded} Видљиво име домена (без Punycode)
{host_scheme} Шема захтева ка пројекту ("http" или "https", зависи од параметра TLS у подешавањима пројекта)
{http_port} Порт захтева ка пројекту путем протокола HTTP
{https_port} Порт захтева ка пројекту путем протокола HTTPS
{menu_caption} Наслов ставке менија (само за категорију projects са need_alias=ON)
{http_engine} HTTP енџин
{node_engine} Node.js енџин
{php_engine} PHP енџин
{project_root} Корени директоријум пројекта
{base_url} URL пројекта
{web_root} Публични директоријум пројекта
{scheme_port} Порт захтева ка пројекту (":{http_port}" или ":{https_port}", зависи од параметра TLS у подешавањима пројекта). Ако {http_port} или {https_port} има стандардну вредност 80 или 443, онда ће {scheme_port} бити празан.
{app_start_command} Команда покретања апликације пројекта (ако је подешена)
{terminal_codepage} Кодирање конзоле

Посебне променљиве (само за addons и addons\<име_додатка>)

Променљива Опис
{addon_name} Име додатка
{terminal_codepage} Кодирање конзоле

Посебне променљиве (само за modules и modules\<име_модула>)

Променљива Опис
{ip} IP адреса модула
{log_level} Ниво евидентирања грешака
{module_name} Име модула
{port} Порт модула
{profile_name} Име тренутног профила подешавања модула
{query_log_level} Ниво евидентирања захтева
{shell_command} Команда покретања shell/cli љуске модула (ако је подешена)
{terminal_codepage} Кодирање конзоле
{time_zone} Временска зона

Посебне вредности команди

Команда Опис
command_open_logs_viewer Отвори прозор за преглед дневника
command_open_idn_converter Отвори IDN конвертер
command_open_options Отвори прозор подешавања програма

Поред шаблонских променљивих, можете користити било које Windows променљиве окружења, на пример: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% итд.

Пример употребе

[bookmark_1]

caption  = Google
category = Моје Обележиваче\Претраживачи
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Опције CMD.EXE

  • /c: Изврши команду и затвори терминал.
  • /k: Изврши команду и остави терминал отвореним.
