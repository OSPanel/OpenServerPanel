Globalna podešavanja projekata

Parametri zadati u ovom odeljku koriste se ako u podešavanjima projekta nisu navedene druge vrednosti.

HTTP
Određuje korišćeni modul veb-servera za projekte.
NODE
Navodi engine Node.js za pokretanje Node.js aplikacija.

Instalacija Node.js: Prethodno instalirajte potrebnu verziju Node.js pomoću komande osp node <latest|lts|номер>.
PHP
Određuje korišćeni PHP modul za obradu PHP fajlova.
Uključiti
Određuje podrazumevano stanje projekta (uključen ili isključen).
Kodiranje terminala
Kodiranje terminala pri radu sa okruženjem projekta.

Specijalne vrednosti:
- system: Koristi se sistemsko kodiranje.

Važno: Ako vrednost nije zadana, pri formiranju konačnog okruženja projekta kodiranje terminala biće postavljeno poslednjim priključenim okruženjem u kom je zadato, na primer okruženjem PHP modula.
IP
Zadaje IP adresu(e) koju koriste svi projekti bez individualnih podešavanja.

Ograničenje: Projekti koji koriste istu IP adresu moraju raditi na jednoj verziji PHP.

Podrška za više IP: Možete navesti više IP adresa razdvojenih razmakom, uključujući IPv6. U fajlu HOSTS domenima će biti dodeljena prva navedena IP.

Automatsko dodeljivanje: Ako ostavite polje praznim, IP adresa će biti dodeljena automatski.

Preporuke:
  • Automatsko upravljanje IP adresama preporučuje se većini korisnika.
  • Ručno zadavanje IP adrese koristite samo pri specifičnim zahtevima mrežne konfiguracije.
HTTP
Određuje port za veze preko HTTP.
HTTPS
Određuje port za veze preko HTTPS.
TLS
Uključuje ili isključuje podršku za TLS.
Fajl sertifikata
Navodi putanju do fajla TLS sertifikata. Mogu se koristiti šablonske promenljive.

Dozvoljeni simboli: A-Za-z0-9-+_.\:

Preporuka: Ostavite polje praznim za automatsko generisanje sertifikata.
Fajl ključa
Navodi putanju do fajla TLS ključa. Mogu se koristiti šablonske promenljive.

Dozvoljeni simboli: A-Za-z0-9-+_.\:

Preporuka: Ostavite polje praznim za automatsko generisanje ključa.
IP adresa (backend)
Navodi IP adresu preko koje se ostvaruje povezivanje sa serverskim delom (Backend).
Port (backend)
Određuje broj porta za povezivanje sa serverskim delom (Backend).
Uključiti (backend)
Omogućava automatsko preusmeravanje celog dolaznog saobraćaja (HTTP i HTTPS) projekta na serverski deo (Backend). Korisno za testiranje ili razvoj kada su frontend i backend odvojeni.
Katalog projekta
Navodi korenski katalog projekta. Prelazak u ovaj katalog vrši se komandom osp project <DOMAIN> istovremeno sa aktivacijom okruženja projekta. Mogu se koristiti šablonske promenljive.

Dozvoljeni simboli: A-Za-z0-9-+_.\:
Javni katalog
Određuje javni katalog projekta. Mogu se koristiti šablonske promenljive.

Dozvoljeni simboli: A-Za-z0-9-+_.\:
Pseudonimi
Navodi dodatna imena domena (aliasi) za projekat (razdvojena razmakom). Mogu se koristiti šablonske promenljive.

Ograničenje: Simbol "*" nije podržan u Windows fajlu HOSTS i zahteva podešavanje DNS-a.
Okruženje projekta
Spisak dodataka i modula (razdvojenih razmakom) koji formiraju okruženje projekta.

HTTP, NODE i PHP: Okruženja ovih engine-a se uvek priključuju (ako su zadati za domen) i ne zahtevaju navođenje u ovom parametru.
Komanda za pokretanje projekta
Određuje komandu za pokretanje projekta (na primer, nodemon app.js). Mogu se koristiti šablonske promenljive.
URL projekta
URL koji se koristi pri otvaranju projekta Meni→Projekat→Otvori u pregledaču, kao i pri otvaranju domenih pseudonima projekta (aliasa). Mogu se koristiti šablonske promenljive.

Primena: Možete zadati URL admin panela CMS-a.

Šablonske promenljive

Promenljiva Opis
{backend_ip} IP adresa povezivanja sa serverskim delom (Backend)
{backend_port} Port povezivanja sa serverskim delom (Backend)
{base_dir} Korenski katalog projekta (gde se nalazi katalog .osp)
{date_time} Trenutni datum/vreme (promenljiva dostupna samo za komandu pokretanja aplikacije projekta)
{host} Ime domena (za internacionalizovane domene koristi se Punycode)
{host_decoded} Vidljivo ime domena (bez Punycode)
{host_scheme} Šema zahteva ka projektu ("http" ili "https", zavisi od parametra TLS u podešavanjima projekta)
{http_port} Port zahteva ka projektu preko protokola HTTP
{https_port} Port zahteva ka projektu preko protokola HTTPS
{http_engine} Engine HTTP
{node_engine} Engine NODE
{php_engine} Engine PHP
{project_root} Korenski katalog projekta
{web_root} Javni katalog projekta
{scheme_port} Port zahteva ka projektu (":{http_port}" ili ":{https_port}", zavisi od parametra TLS u podešavanjima projekta).

Ako {http_port} ili {https_port} ima standardnu vrednost 80 ili 443, tada {scheme_port} će biti prazan.
{root_dir} Korenski katalog Open Server Panel (puna putanja)
{root_drive} Disk korenskog kataloga
{root_path} Putanja do korenskog kataloga Open Server Panel
{terminal_codepage} Kodiranje konzole
