Moodulite globaalsed keskkonnamuutujad

Selles jaotises saab määrata moodulite globaalsed keskkonnamuutujad.

Need muutujad kehtivad ainult moodulite keskkonnas ega mõjuta süsteemimuutujaid ega projektide keskkonda.

Väärtustes on lubatud kasutada mallmuutujaid.

Kui muutuja on süsteemi keskkonnas olemas, kuid seda ei tohi moodulite keskkonnas kasutada, kasutage spetsiaalset filtrit (vt Moodulid→Lubatud süsteemimuutujad) või eemaldage muutuja keskkonnast, määrates selle väärtuseks tühja stringi.

Mallmuutujad

Muutuja Kirjeldus
{root_dir} Open Server Paneli juurkataloog (täielik rada)
{root_drive} Juurkataloogi kettaseade
{root_path} Open Server Paneli juurkataloogi rada
{terminal_codepage} Kodeering terminalis (vt Moodulid→Kodeering terminalis)
{time_zone} Ajavöönd vormingus Etc/GMT (vt Moodulid→Ajavöönd)

Lisaks mallmuutujatele võib kasutada mis tahes Windowsi keskkonnamuutujaid, näiteks: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% jne.
