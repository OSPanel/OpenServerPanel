Programmi seaded

Käivita koos Windowsiga
Luba Open Server Paneli automaatne käivitamine operatsioonisüsteemi laadimisel.
Viivitus
Programmi käivitamise viivitus (sekundites, 0 kuni 60).

Võimaldab edasi lükata rakenduse käivitamist Windowsi laadimise ajal, et vähendada süsteemi üldist koormust. See on eriti kasulik, kui on vaja oodata kolmandate osapoolte teenuste või võrguliideste täielikku initsialiseerimist.
Kontrolli uute versioonide olemasolu
Luba Open Server Paneli värskenduste kontroll (vajalik Interneti-ühendus).
Luba ülesannete ajastaja
Aktiveeri sisseehitatud ülesannete ajastaja. Kui parameeter on välja lülitatud, ei käivitata ühtegi plaanitud ülesannet, sõltumata nende olekust.
Kasuta HOSTS-faili
Luba domeeninimede kirjutamine HOSTS-faili.

Soovitused, kui organisatsioonis on juurdepääs HOSTS-failile piiratud:

1. Seadistage kõik vajalikud moodulid ja projektid.
2. Pöörduge süsteemiadministraatori poole, et HOSTS avada ja selle olek fikseerida.
3. Pärast muudatuste fikseerimist administraatori poolt võib selle valiku välja lülitada.

Tähtis: Ärge lülitage seda parameetrit välja, kui te ei ole tagajärgedes kindel!
Käivita moodulid projekti profiiliga
Käivita moodulid samaaegse profiili aktiveerimisega, mis langeb kokku projekti nimega.

Kasutatakse menüüpunkti „Luba projekti moodulid” valimisel, et automaatselt aktiveerida profiil sama nimega nagu praegusel projektil, kui see on olemas.
Ära lõpeta peidetud projektide mooduleid
Ära lõpeta peidetud projektide mooduleid menüüpunkti „Lülita kõik moodulid välja” valimisel. „Peidetud” all peetakse silmas projekte, millele on määratud kategooria „hidden”.

Vaikimisi peatab käsk „Lülita kõik moodulid välja” absoluutselt kõik moodulid, kaasa arvatud need, mida kasutavad peidetud teenindusprojektid (näiteks PHPMyAdmin). See valik võimaldab säilitada peidetud teenindusprojektide töövõime, ilma et nende jaoks vajalikud moodulid välja lülitataks, samal ajal kui kõik teised moodulid lülitatakse välja.
Kasutajaliidese keel
Open Server Paneli kasutajaliidese keel.

Kui lokaliseerimisfail puudub või sisaldab vigu, kasutatakse inglise keelt.
API domeen
Kohalik domeen API ja veebi-liidese jaoks (arendamisel)

Soovitus: Kui kasutatakse VPN-i või proksit, lisage see domeen eranditesse.
API IP-aadress
IPv4-aadress API ja veebi-liidese jaoks (arendamisel).

Soovitus: Kui kasutatakse VPN-i või proksit, lisage see IP-aadress eranditesse.
API port
Port, mida kasutatakse API ja veebi-liidese jaoks (arendamisel). Open Server Panel ei saa käivituda, kui määratud porti kasutab juba mõni muu rakendus.
Kasuta Windows Terminali
Luba Windows Terminali kasutamine standardses käsuliideses asemel.

Nõuded: Windows Terminal peab olema süsteemi paigaldatud ja lisatud keskkonnamuutujasse PATH.

Windows Terminal kui cmd.exe: Windows Terminal võib asendada cmd.exe ja olla määratud keskkonnamuutujas %COMSPEC% Windowsi uuemates versioonides. Kui see nii on, jätke see valik sisse.

Windows Terminali uued isendid: Kui Windows Terminal avab uued aknad sakkide asemel, seadistage see nii: Sätted→Käivitamine→Uue isendi käitumine→Liitu viimati kasutatud aknaga.
Lühike projekti pealkiri
Selle valiku aktiveerimisel kuvatakse terminaliakna pealkirjas ainult projekti nimi üksikasjaliku keskkonnakirjelduse asemel.
Lisa süsteemikeskkond projekti keskkonda
Kasuta süsteemi (System) keskkonda terminalis isegi siis, kui see pole projekti seadetes määratud. Süsteemikeskkond võimaldab kasutada süsteemi paigaldatud programme (näiteks git.exe või ssh.exe).

Lülitage see valik välja ainult siis, kui tekivad konfliktid süsteemitarkvaraga.
ANSI tugi
Luba ANSI-koodide tugi värvide juhtimiseks terminalis.

Režiim „Automaatne” (vaikimisi):
- Parandus rakendub ainult Windows 10-le kuni versioonini 1903 (kaasa arvatud). Uuemates Windowsi versioonides on ANSI-koodide tugi juba sisseehitatud.
- Parandust ei rakendata terminalidele, mis toetavad ANSI-t vaikimisi (näiteks Windows Terminal).
Kataloogid projektide otsimiseks
Kataloogide loend, kust Open Server Panel otsib projekte. Eristage teed semikooloniga (;).

Erandid: Alamkataloogid node_modules ja vendor jäetakse vahele.
Sügavus
Kataloogide maksimaalne pesastatuse sügavus projektide otsimisel.

Selle väärtuse suurendamine võib aeglustada Open Server Paneli käivitamist, kui määratud kataloogides on suur hulk alamkatalooge.
Maksimaalne logifaili suurus
Logifaili maksimaalne suurus megabaitides. Kui määratud väärtus ületatakse, luuakse logifail programmi järgmisel käivitamisel uuesti.

Määrake väärtus 0, et puhastada logid iga programmi käivitamise korral.

Määrake väärtus 100 MB, et logide puhastamine täielikult välja lülitada.
