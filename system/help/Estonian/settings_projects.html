Projektide globaalsed sätted

Selles jaotises määratud parameetreid kasutatakse juhul, kui projekti sätetes ei ole määratud teisi väärtusi.

HTTP
Määrab projektide jaoks kasutatava veebiserveri mooduli.
NODE
Määrab Node.js mootori Node.js-rakenduste käivitamiseks.

Node.js paigaldus: Paigaldage eelnevalt soovitud Node.js versioon käsuga osp node <latest|lts|номер>.
PHP
Määrab PHP-failide töötlemiseks kasutatava PHP mooduli.
Luba
Määrab projekti vaikeseisundi (lubatud või keelatud).
Terminali koodileht
Terminali koodileht projekti keskkonnas töötamisel.

Spetsiaalsed väärtused:
- system: Kasutatakse süsteemi koodilehte.

Tähtis: Kui väärtust ei ole määratud, siis projekti lõpliku keskkonna moodustamisel määratakse terminali koodileht viimase ühendatud keskkonna poolt, kus see on määratud, näiteks PHP mooduli keskkonna poolt.
IP
Määrab IP-aadressi(d), mida kasutavad kõik projektid ilma individuaalsete säteteta.

Piirang: Projektid, mis kasutavad sama IP-aadressi, peavad töötama sama PHP versiooniga.

Mitme IP tugi: Saab määrata mitu IP-aadressi tühikuga eraldatult, sh IPv6. HOSTS-failis määratakse domeenidele esimene loetletud IP.

Automaatne määramine: Kui jätta väli tühjaks, määratakse IP-aadress automaatselt.

Soovitused:
  • IP-aadresside automaatne haldus on soovitatav enamikele kasutajatele.
  • Käsitsi IP määramist tuleks kasutada ainult spetsiifiliste võrgu konfiguratsiooni nõuete korral.
HTTP
Määrab HTTP-ühenduste pordi.
HTTPS
Määrab HTTPS-ühenduste pordi.
TLS
Lülitab TLS toe sisse või välja.
Sertifikaadifail
Määrab tee TLS-sertifikaadi failini. Võib kasutada mallimuutujaid.

Lubatud sümbolid: A-Za-z0-9-+_.\:

Soovitus: Jätke väli tühjaks sertifikaatide automaatseks genereerimiseks.
Võtmefail
Määrab tee TLS-võtme failini. Võib kasutada mallimuutujaid.

Lubatud sümbolid: A-Za-z0-9-+_.\:

Soovitus: Jätke väli tühjaks võtme automaatseks genereerimiseks.
IP-aadress (backend)
Määrab IP-aadressi, mille kaudu toimub ühendus serveripoolse osaga (Backend).
Port (backend)
Määrab pordi numbri ühenduseks serveripoolse osaga (Backend).
Luba (backend)
Võimaldab automaatselt suunata kogu projekti sissetuleva liikluse (HTTP ja HTTPS) serveripoolsesse ossa (Backend). Kasulik testimisel või arendamisel, kui frontend ja backend on eraldatud.
Projekti kataloog
Määrab projekti juurkataloogi. Sellesse kataloogi liigutakse käsuga osp project <DOMAIN> samaaegselt projekti keskkonna aktiveerimisega. Võib kasutada mallimuutujaid.

Lubatud sümbolid: A-Za-z0-9-+_.\:
Avalik kataloog
Määrab projekti avaliku kataloogi. Võib kasutada mallimuutujaid.

Lubatud sümbolid: A-Za-z0-9-+_.\:
Pseudonüümid
Määrab projekti täiendavad domeeninimed (alias'ed) tühikuga eraldatult. Võib kasutada mallimuutujaid.

Piirang: Sümbolit "*" ei toeta Windowsi HOSTS-fail ja see nõuab DNS-i seadistamist.
Projekti keskkond
Loetelu lisadest ja moodulitest (tühikuga eraldatult), mis moodustavad projekti keskkonna.

HTTP, NODE ja PHP: Nende mootorite keskkonnad ühendatakse alati (kui need on domeeni jaoks määratud) ega vaja selles parameetris eraldi märkimist.
Projekti käivituskäsk
Määrab käsu projekti käivitamiseks (näiteks nodemon app.js). Võib kasutada mallimuutujaid.
Projekti URL
URL, mida kasutatakse projekti avamisel Menüü→Projekt→Ava brauseris, samuti projekti domeenialiaste avamisel. Võib kasutada mallimuutujaid.

Kasutus: Saab määrata CMS-i halduspaneeli URL-i.

Mallimuutujad

Muutuja Kirjeldus
{backend_ip} Ühenduse IP-aadress serveripoolse osaga (Backend)
{backend_port} Ühenduse port serveripoolse osaga (Backend)
{base_dir} Projekti juurkataloog (kust leitakse kataloog .osp)
{date_time} Praegune kuupäev/kellaaeg (muutuja on saadaval ainult projekti rakenduse käivituskorralduses)
{host} Domeeni nimi (rahvusvahelistatud domeenide puhul kasutatakse Punycode'i)
{host_decoded} Nähtav domeeni nimi (ilma Punycode'ita)
{host_scheme} Päringu skeem projektile ("http" või "https", sõltub TLS parameetrist projekti sätetes)
{http_port} Projekti päringu port HTTP protokolli kaudu
{https_port} Projekti päringu port HTTPS protokolli kaudu
{http_engine} HTTP mootor
{node_engine} NODE mootor
{php_engine} PHP mootor
{project_root} Projekti juurkataloog
{web_root} Projekti avalik kataloog
{scheme_port} Projekti päringu port (":{http_port}" või ":{https_port}", sõltub TLS parameetrist projekti sätetes).

Kui {http_port} või {https_port} on vaikimisi väärtusega 80 või 443, siis {scheme_port} on tühi.
{root_dir} Open Server Paneli juurkataloog (täielik tee)
{root_drive} Juurkataloogi kettaseade
{root_path} Tee Open Server Paneli juurkataloogi
{terminal_codepage} Konsooli koodileht
