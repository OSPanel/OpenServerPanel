Oma menüüpunktide loomine

  1. Lisage uus sektsioon unikaalse identifikaatoriga [ID]
  2. Paigutage sektsioonid soovitud järjekorda — see määrab menüüpunktide järjestuse menüüs
  3. Salvestage muudatused ja taaskäivitage Open Server Panel, et muudatused rakenduksid

Tähtis teave

Oma menüüpunktide loomisel veenduge, et sektsioonide identifikaatorid ei korduks. See võib põhjustada konflikte menüü töös.

Menüüpunktide sätted

Sorteerimise järjekord: Menüüpunktid sorditakse samas järjekorras, nagu vastavad sektsioonid on paigutatud mallis.

caption Menüüpunkti pealkiri. Toetab keelekonstante formaadis {lang_xxx}.

Vaikimisi: määramata
category

Määrab menüüpunkti asukoha hierarhias. Toetab ühte pesastustasandit (näiteks "Minu Järjehoidjad\Töö").

Spetsiaalsed kategooriad:

  • projects, modules, addons - lisab punkti vastavasse toimingute menüüsse
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - lisab punkti konkreetse elemendi jaoks

Kui kategooriat pole määratud, luuakse punkt juurmenüüs.

Vaikimisi: määramata
command Käsk, mida täita menüüpunkti aktiveerimisel. Käsuta punktid jäetakse tähelepanuta.

Vaikimisi: määramata
enabled Lülitab menüüpunkti nähtavuse sisse/välja.

Vaikimisi: on | Väärtused: on, off
hide Juhtib käivitatava rakenduse akna nähtavust. Ei mõjuta alamprotsesse.

Vaikimisi: off | Väärtused: on, off
hr_after Lisab menüüpunkti järele horisontaalse eraldaja.

Vaikimisi: off | Väärtused: on, off
hr_before Lisab menüüpunkti ette horisontaalse eraldaja.

Vaikimisi: off | Väärtused: on, off
icon Ikoon komplektist Font Awesome Free (Solid/Regular/Brands).

Vaikimisi: määramata
need_alias Kuvab menüüpunkti ainult domeenialiaasile. Menüü mallis võib olla ainult üks punkt väärtusega need_alias=on!
Kehtib kategooriatele: projects

Vaikimisi: määramata | Väärtused: on, off
need_category

Piirab menüüpunkti kuvamist kindla kategooria moodulite/täiendustega.

Toetatavad formaadid:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Vaikimisi: määramata
need_module_shell Kuvab menüüpunkti sõltuvalt vanemmooduli shell/cli olemasolust.
Kehtib kategooriatele: modules, modules\<имя_модуля>

Vaikimisi: määramata | Väärtused: on, off
need_state Kuvab menüüpunkti sõltuvalt vanemmooduli olekust.
Kehtib kategooriatele: modules, modules\<имя_модуля>

Vaikimisi: määramata | Väärtused: on, off
need_start_cmd Kuvab menüüpunkti, kui projekti sätetes on olemas käivituskäsk.
Kehtib kategooriatele: projects, projects\<имя_домена>

Vaikimisi: määramata | Väärtused: on, off
need_use_wt Kuvab menüüpunkti sõltuvalt Windows Terminali kasutamise sätetest Open Server Panelis.

Vaikimisi: määramata | Väärtused: on, off
work_directory Töökataloog käsu täitmiseks. Võib muutuda käskude täitmise ajal.

Vaikimisi: {root_dir}

Mallimuutujad

Parameetrites "command" ja "work_directory" saab kasutada järgmisi mallimuutujaid:

Üldised muutujad

Muutuja Kirjeldus
{date_time} Praegune kuupäev/kellaaeg (muutuja on saadaval ainult parameetri "command" jaoks)
{root_dir} Open Server Paneli juurkataloog (täielik tee)
{root_drive} Juurkataloogi ketas
{root_path} Tee Open Server Paneli juurkataloogi
{web_panel_url} Veebiliidese URL-aadress

Eri muutujad (ainult projects ja projects\<имя_домена> jaoks)

Muutuja Kirjeldus
{base_dir} Projekti baasikataloog
{host} Domeeninimi (Punycode)
{host_decoded} Nähtav domeeninimi (ilma Punycode'ita)
{host_scheme} Päringu skeem projekti juurde ("http" või "https", sõltub projekti sätetes olevast TLS parameetrist)
{http_port} HTTP-protokolli päringu port projekti juurde
{https_port} HTTPS-protokolli päringu port projekti juurde
{menu_caption} Menüüpunkti pealkiri (ainult kategooria projects puhul, kui need_alias=ON)
{http_engine} HTTP mootor
{node_engine} Node.js mootor
{php_engine} PHP mootor
{project_root} Projekti juurkataloog
{base_url} Projekti URL
{web_root} Projekti avalik kataloog
{scheme_port} Projekti päringu port (":{http_port}" või ":{https_port}", sõltub projekti sätetes olevast TLS parameetrist). Kui {http_port} või {https_port} on vaikeväärtus 80 või 443, on {scheme_port} tühi.
{app_start_command} Projekti rakenduse käivituskäsk (kui on seadistatud)
{terminal_codepage} Konsooli koodileht

Eri muutujad (ainult addons ja addons\<имя_дополнения> jaoks)

Muutuja Kirjeldus
{addon_name} Täienduse nimi
{terminal_codepage} Konsooli koodileht

Eri muutujad (ainult modules ja modules\<имя_модуля> jaoks)

Muutuja Kirjeldus
{ip} Mooduli IP-aadress
{log_level} Vealogi taseme tase
{module_name} Mooduli nimi
{port} Mooduli port
{profile_name} Mooduli aktiivse seadistusprofiili nimi
{query_log_level} Päringulogimise tase
{shell_command} Mooduli shell/cli kesta käivituskäsk (kui on seadistatud)
{terminal_codepage} Konsooli koodileht
{time_zone} Ajavöönd

Eri käsuväärtused

Käsk Kirjeldus
command_open_logs_viewer Ava logivaaturi aken
command_open_idn_converter Ava IDN-konverter
command_open_options Ava programmi sätete aken

Lisaks mallimuutujatele saab kasutada mis tahes Windowsi keskkonnamuutujaid, näiteks: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% jne.

Kasutamise näide

[bookmark_1]

caption  = Google
category = Minu Järjehoidjad\Otsingumootorid
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE valikud

  • /c: Täida käsk ja sule terminal.
  • /k: Täida käsk ja jäta terminal avatuks.
