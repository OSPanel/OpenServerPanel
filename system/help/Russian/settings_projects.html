Глобальные настройки проектов

Параметры, заданные в данном разделе, используются в случае, если в настройках проекта не указаны другие значения.

Nginx
Определяет используемую версию веб-сервера Nginx для проектов.
Node
Указывает движок Node.js для запуска Node.js-приложений.

Установка Node.js: Предварительно установите нужную версию Node.js с помощью дополнения NVM.
PHP
Определяет используемый движок PHP для обработки PHP-файлов.

Важно: Модули PHP без префикса FCGI представляют собой интегрированные модули Apache+PHP.
Включить
Определяет состояние проекта по умолчанию (включен или выключен).
Кодировка терминала
Кодировка терминала при работе со средой проекта.

Специальные значения:
- system: Используется системная кодировка.

Важно: Если значение не задано, при формировании итоговой среды проекта кодировка терминала будет установлена последней подключённой средой, в которой она задана, например, средой модуля PHP.
IP
Задает IP-адрес(а), используемый всеми проектами без индивидуальных настроек.

Ограничение: Проекты, использующие один и тот же IP-адрес, должны работать на одной версии PHP.

Поддержка нескольких IP: Можно указать несколько IP-адресов через пробел, включая IPv6. В файле HOSTS доменам будет назначен первый указанный IP.

Автоматическое назначение: Если оставить поле пустым, IP-адрес будет назначаться автоматически.

Рекомендации:
  • Автоматическое управление IP-адресами рекомендуется большинству пользователей.
  • Ручное задание IP-адреса следует использовать только при специфических требованиях сетевой конфигурации.
HTTP
Определяет порт для соединений по HTTP.
HTTPS
Определяет порт для соединений по HTTPS.
SSL
Включает или отключает поддержку SSL для проектов без индивидуальных настроек.
Файл сертификата
Указывает путь к файлу SSL-сертификата. Можно использовать шаблонные переменные.

Допустимые символы: A-Za-z0-9-+_.\:

Рекомендация: Оставьте поле пустым для автоматической генерации сертификатов.
Файл ключа
Указывает путь к файлу SSL-ключа. Можно использовать шаблонные переменные.

Допустимые символы: A-Za-z0-9-+_.\:

Рекомендация: Оставьте поле пустым для автоматической генерации ключа.
Каталог проекта
Указывает корневой каталог проекта. Переход в этот каталог осуществляется по команде osp project <DOMAIN> одновременно с активацией среды проекта. Можно использовать шаблонные переменные.

Разрешённые символы: A-Za-z0-9-+_.\:
Публичный каталог
Определяет публичный каталог проекта. Можно использовать шаблонные переменные.

Разрешённые символы: A-Za-z0-9-+_.\:
Псевдонимы
Указывает дополнительные доменные имена (алиасы) для проекта (через пробел). Можно использовать шаблонные переменные.

Поддомены: Если псевдоним не содержит точку, он рассматривается как поддомен (например, "www" -> "www.test.local").

Ограничение: Символ "*" не поддерживается в Windows файлом HOSTS и требует настройки DNS.
Среда проекта
Перечень дополнений и модулей (через пробел), формирующих окружение проекта.

Модули PHP/Nginx/Node.js: Среды этих модулей подключаются всегда (если заданы для домена) и не требуют указания в этом параметре.
Команда запуска проекта
Определяет команду для запуска проекта (например, nodemon app.js). Можно использовать шаблонные переменные.
URL проекта
URL, открываемый при выборе Открыть проект в браузере в Open Server Panel. Можно использовать шаблонные переменные.

Применение: Можно задать URL панели администрирования CMS.

Шаблонные переменные

Переменная Описание
{base_dir} Корневой каталог проекта (где находится каталог .osp)
{host} Имя домена (для интернационализированных доменов используется Punycode)
{host_decoded} Видимое имя домена (без Punycode)
{host_scheme} Схема запроса к проекту ("http" или "https", зависит от параметра SSL в настройках проекта)
{http_port} Порт запроса к проекту по протоколу HTTP
{https_port} Порт запроса к проекту по протоколу HTTPS
{nginx_engine} Движок Nginx
{node_engine} Движок Node.js
{php_engine} Движок PHP
{project_dir} Корневой каталог проекта
{public_dir} Публичный каталог проекта
{scheme_port} Порт запроса к проекту (":{http_port}" или ":{https_port}", зависит от параметра SSL в настройках проекта).

Если {http_port} или {https_port} имеет стандартное значение 80 или 443, то {scheme_port} будет пустым.
{root_dir} Корневой каталог Open Server Panel (полный путь)
{root_drive} Диск корневого каталога
{root_path} Путь к корневому каталогу Open Server Panel
{terminal_codepage} Кодировка консоли
