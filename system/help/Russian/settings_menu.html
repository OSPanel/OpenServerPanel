Настройки меню

Тема оформления
Тема оформления для иконок меню.
Размер шрифта
Размер шрифта меню в пикселях. Опция позволяет задать размер шрифта меню независимо от системных настроек.

Установите ползунок в минимальное значение 12px для отключения функции контроля размера шрифта (будет использован системный размер).
Показывать значок в области уведомлений
Показывать значок программы в области уведомлений Windows.

Отключение: Отключите эту опцию, если вы запускаете Open Server Panel в среде Windows Server Core или используете тип автозапуска, не требующий входа пользователя Windows (Планировщик заданий Windows→Запуск при загрузке компьютера).
Показывать значки для пунктов меню
Показывать значки в меню программы. Значки не отображаются если включена системная отрисовка.
Включить системную отрисовку
Включайте данную опцию только при необходимости обеспечения совместимости с программами экранного доступа (скрин-ридерами).
Показывать вертикальный разделитель
При включении данной опции иконки в меню программы будут отделены вертикальным разделителем.
Не группировать списки из одного элемента
Не группировать списки, содержащие только один элемент.
