Настройки программы

Запускать вместе с Windows
Включить автозапуск Open Server Panel при загрузке операционной системы.
Задержка
Задержка запуска программы (в секундах, от 0 до 60).

Позволяет отложить старт приложения, чтобы уменьшить нагрузку на систему при запуске. Это особенно полезно, если нужно дождаться полной инициализации сторонних сервисов или сетевых интерфейсов.
Проверять наличие новых версий
Включить проверку обновлений Open Server Panel (требуется подключение к Интернету).
Включить планировщик заданий
Активировать встроенный планировщик задач. Если параметр отключен, никакие запланированные задания не будут выполняться, независимо от их статуса.
Использовать файл HOSTS
Включить запись доменных имен в файл HOSTS.

Рекомендации при ограниченном доступе к файлу HOSTS в организации:

1. Настройте все необходимые модули и проекты.
2. Обратитесь к системному администратору для разблокировки HOSTS и фиксации его состояния.
3. После фиксации изменений администратором можно отключить эту опцию.

Важно: Не отключайте этот параметр, если не уверены в последствиях!
Запускать модули с профилем проекта
Запускать модули с одновременной активацией профиля, совпадающего с именем проекта.

Используется при выборе пункта меню «Включить модули проекта», чтобы автоматически активировать профиль с тем же именем, что и у текущего проекта, если таковой существует.
Не выключать модули скрытых проектов
Не отключать модули скрытых проектов при выборе пункта меню «Выключить все модули». Под "скрытыми" подразумеваются те проекты, для которых задана категория "hidden".

По умолчанию команда «Выключить все модули» останавливает работу абсолютно всех модулей, включая те, которые используются скрытыми служебными проектами (например, PHPMyAdmin). Данная опция позволяет сохранить работоспособность скрытых служебных проектов, не отключая необходимые для них модули, в то время как все остальные модули будут выключены.
Язык интерфейса
Язык пользовательского интерфейса Open Server Panel.

Если файл локализации отсутствует или содержит ошибки, будет использоваться английский язык.
Домен API
Локальный домен для API и веб-интерфейса (в разработке)

Рекомендация: Если используется VPN или прокси, добавьте этот домен в исключения.
IP-адрес API
IPv4-адрес для API и веб-интерфейса (в разработке).

Рекомендация: Если используется VPN или прокси, добавьте этот IP-адрес в исключения.
Порт API
Порт, используемый для API и веб-интерфейса (в разработке). Open Server Panel не сможет запуститься, если указанный порт уже используется другим приложением.
Использовать Windows Terminal
Включить использование Windows Terminal вместо стандартного командного интерфейса.

Требования: Windows Terminal должен быть установлен в системе и прописан в переменной окружения PATH.

Windows Terminal как cmd.exe: Windows Terminal может заменять собой cmd.exe и быть прописан в переменной окружения %COMSPEC% в новых версиях Windows. Если это так, оставьте эту опцию включенной.

Новые экземпляры Windows Terminal: Если Windows Terminal открывает новые окна вместо вкладок, настройте его так: Параметры→Запуск→Поведение нового экземпляра→Присоединять к последнему использованному окну.
Короткий заголовок проекта
При активации этой опции в заголовке окна терминала будет отображаться только имя проекта вместо подробного описания.
Включать системную среду в окружение проекта
Использовать среду системы (System) в терминале, даже если она не задана в настройках проекта. Системная среда позволяет использовать программы, установленные в системе (например, git.exe или ssh.exe).

Отключайте эту опцию только при возникновении конфликтов с системным ПО.
Поддержка ANSI
Включить поддержку ANSI-кодов для управления цветами в терминале.

Режим "Автоматически" (по умолчанию):
- Исправление применяется только к Windows 7, 8 и Windows 10 (до версии 1903 включительно). В более новых версиях Windows поддержка ANSI-кодов уже встроена.
- Исправление не применяется для терминалов, поддерживающих ANSI по умолчанию (например, Windows Terminal).
Каталоги для поиска проектов
Список директорий, в которых Open Server Panel будет искать проекты. Разделяйте пути точкой с запятой (;).

Исключения: Подкаталоги node_modules и vendor игнорируются.
Глубина
Максимальная глубина вложенности каталогов при поиске проектов.

Увеличение этого значения может замедлить запуск Open Server Panel, если в указанных каталогах содержится большое количество подкаталогов.
Максимальный размер файла журнала
Максимальный размер файла журнала в мегабайтах. При превышении указанного значения лог-файл будет пересоздан при следующем запуске программы.

Установите значение 0, чтобы очищать лог-файлы при каждом запуске программы.

Установите значение 100 МБ, чтобы полностью отключить очистку лог-файлов.
