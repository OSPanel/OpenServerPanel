Создание собственных пунктов меню

  1. Добавьте новую секцию с уникальным идентификатором [ID]
  2. Расположите секции в желаемом порядке — это определит порядок пунктов в меню
  3. Сохраните изменения и перезапустите Open Server Panel для применения изменений

Важная информация

При создании собственных пунктов меню следите за тем, чтобы идентификаторы секций не повторялись. Это может привести к конфликтам в работе меню.

Настройки пунктов меню

Порядок сортировки: Пункты меню сортируются в том же порядке, в котором расположены соответствующие секции в шаблоне.

caption Заголовок пункта меню. Поддерживает языковые константы в формате {lang_xxx}.

По умолчанию: не задано
category

Определяет расположение пункта меню в иерархии. Поддерживает один уровень вложенности (например, "Мои Закладки\Работа").

Специальные категории:

  • projects, modules, addons - добавляет пункт в соответствующее меню действий
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - добавляет пункт для конкретного элемента

Если категория не указана, пункт создается в корневом меню.

По умолчанию: не задано
command Команда для выполнения при активации пункта меню. Пункты без команды игнорируются.

По умолчанию: не задано
enabled Включает/отключает отображение пункта меню.

По умолчанию: on | Значения: on, off
hide Управляет видимостью окна вызываемого приложения. Не влияет на дочерние процессы.

По умолчанию: off | Значения: on, off
hr_after Добавляет горизонтальный разделитель после пункта меню.

По умолчанию: off | Значения: on, off
hr_before Добавляет горизонтальный разделитель перед пунктом меню.

По умолчанию: off | Значения: on, off
icon Иконка из набора Font Awesome Free (Solid/Regular/Brands).

По умолчанию: не задано
need_alias Отображает пункт меню только для доменного псевдонима. В шаблоне меню может быть только один пункт с need_alias=on!
Применимо для категорий: projects

По умолчанию: не задано | Значения: on, off
need_category

Ограничивает отображение пункта меню модулями/дополнениями определенной категории.

Поддерживаемые форматы:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
По умолчанию: не задано
need_module_shell Отображает пункт меню в зависимости от наличия shell/cli у родительского модуля.
Применимо для категорий: modules, modules\<имя_модуля>

По умолчанию: не задано | Значения: on, off
need_state Отображает пункт меню в зависимости от состояния родительского модуля.
Применимо для категорий: modules, modules\<имя_модуля>

По умолчанию: не задано | Значения: on, off
need_start_cmd Отображает пункт меню при наличии команды запуска в настройках проекта.
Применимо для категорий: projects, projects\<имя_домена>

По умолчанию: не задано | Значения: on, off
need_use_wt Отображает пункт меню в зависимости от настройки использования Windows Terminal в Open Server Panel.

По умолчанию: не задано | Значения: on, off
work_directory Рабочая директория для выполнения команды. Может изменяться во время выполнения команд.

По умолчанию: {root_dir}

Шаблонные переменные

В параметрах "command" и "work_directory" можно использовать следующие шаблонные переменные:

Общие переменные

Переменная Описание
{root_dir} Корневой каталог Open Server Panel (полный путь)
{root_drive} Диск корневого каталога
{root_path} Путь к корневому каталогу Open Server Panel
{web_panel_url} URL-адрес веб-интерфейса

Особые переменные (только для projects и projects\<имя_домена>)

Переменная Описание
{base_dir} Базовый каталог проекта
{host} Имя домена (Punycode)
{host_decoded} Видимое имя домена (без Punycode)
{host_scheme} Схема запроса к проекту ("http" или "https", зависит от параметра SSL в настройках проекта)
{http_port} Порт запроса к проекту по протоколу HTTP
{https_port} Порт запроса к проекту по протоколу HTTPS
{menu_caption} Заголовок пункта меню (только для категории projects с need_alias=ON)
{nginx_engine} Движок Nginx
{node_engine} Движок Node.js
{php_engine} Движок PHP
{project_dir} Корневой каталог проекта
{project_url} URL проекта
{public_dir} Публичный каталог проекта
{scheme_port} Порт запроса к проекту (":{http_port}" или ":{https_port}", зависит от параметра SSL в настройках проекта). Если {http_port} или {https_port} имеет стандартное значение 80 или 443, то {scheme_port} будет пустым.
{start_command} Команда запуска проекта (если настроена)
{terminal_codepage} Кодировка консоли

Особые переменные (только для addons и addons\<имя_дополнения>)

Переменная Описание
{addon_name} Имя дополнения
{terminal_codepage} Кодировка консоли

Особые переменные (только для modules и modules\<имя_модуля>)

Переменная Описание
{ip} IP-адрес модуля
{log_level} Уровень журналирования ошибок
{module_name} Имя модуля
{port} Порт модуля
{profile_name} Имя текущего профиля настроек модуля
{query_log_level} Уровень журналирования запросов
{shell_command} Команда запуска shell/cli оболочки модуля (если настроена)
{terminal_codepage} Кодировка консоли
{time_zone} Часовой пояс

Особые значения команд

Команда Описание
command_open_logs_viewer Открыть окно просмотра журналов
command_open_idn_converter Открыть IDN-конвертер
command_open_options Открыть окно настроек программы

Помимо шаблонных переменных, можно использовать любые переменные среды Windows, например: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH% и т.д.

Примеры использования

[21]

caption  = Открыть в PhpStorm
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = Мои Закладки\Поисковые системы
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Опции `cmd.exe`

  • /c: Выполнить команду и закрыть терминал.
  • /k: Выполнить команду и оставить терминал открытым.
