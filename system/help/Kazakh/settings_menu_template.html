Өз меню тармақтарын жасау

  1. Бірегей идентификаторы [ID] бар жаңа секция қосыңыз
  2. Секцияларды қалаған ретпен орналастырыңыз — бұл менюдегі тармақтардың ретін анықтайды
  3. Өзгерістерді сақтап, өзгерістерді қолдану үшін Open Server Panel-ді қайта іске қосыңыз

Маңызды ақпарат

Өз меню тармақтарын жасағанда, секция идентификаторларының қайталанбайтынына назар аударыңыз. Бұл меню жұмысының қайшылықтарына әкелуі мүмкін.

Меню тармақтарының баптаулары

Сұрыптау реті: Меню тармақтары шаблондағы сәйкес секциялардың ретіне сай сұрыпталады.

caption Меню тармағының тақырыбы. {lang_xxx} форматындағы тілдік константаларды қолдайды.

Әдепкі: көрсетілмеген
category

Меню тармағының иерархиядағы орналасуын анықтайды. Бір деңгейлі ішіне салуды қолдайды (мысалы, "Менің Бетбелгілерім\Жұмыс").

Арнайы санаттар:

  • projects, modules, addons - тиісті әрекеттер менюіне тармақ қосады
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - нақты элемент үшін тармақ қосады

Егер санат көрсетілмесе, тармақ түбір менюде жасалады.

Әдепкі: көрсетілмеген
command Меню тармағын белсендіру кезінде орындалатын команда. Командасы жоқ тармақтар еленбейді.

Әдепкі: көрсетілмеген
enabled Меню тармағын көрсету/жасыруды қосады/сөндіреді.

Әдепкі: on | Мәндері: on, off
hide Шақырылатын қосымшаның терезесінің көрінуін басқарады. Еншілес процестерге әсер етпейді.

Әдепкі: off | Мәндері: on, off
hr_after Меню тармағынан кейін көлденең бөлгіш қосады.

Әдепкі: off | Мәндері: on, off
hr_before Меню тармағының алдына көлденең бөлгіш қосады.

Әдепкі: off | Мәндері: on, off
icon Font Awesome Free (Solid/Regular/Brands) жинағынан белгіше.

Әдепкі: көрсетілмеген
need_alias Меню тармағын тек домендік бүркеншік ат үшін көрсетеді. Меню шаблонында need_alias=on бар тек бір тармақ болуы керек!
Қолданылуы мүмкін санаттар: projects

Әдепкі: көрсетілмеген | Мәндері: on, off
need_category

Меню тармағын белгілі бір санаттағы модульдер/қосымшалармен шектеп көрсетеді.

Қолданылатын форматтар:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Әдепкі: көрсетілмеген
need_module_shell Меню тармағын ата-модульде shell/cli бар-жоғына байланысты көрсетеді.
Қолданылуы мүмкін санаттар: modules, modules\<имя_модуля>

Әдепкі: көрсетілмеген | Мәндері: on, off
need_state Меню тармағын ата-модульдің күйіне байланысты көрсетеді.
Қолданылуы мүмкін санаттар: modules, modules\<имя_модуля>

Әдепкі: көрсетілмеген | Мәндері: on, off
need_start_cmd Жоба баптауларында іске қосу командасы бар кезде меню тармағын көрсетеді.
Қолданылуы мүмкін санаттар: projects, projects\<имя_домена>

Әдепкі: көрсетілмеген | Мәндері: on, off
need_use_wt Меню тармағын Open Server Panel-дегі Windows Terminal пайдалану баптауына байланысты көрсетеді.

Әдепкі: көрсетілмеген | Мәндері: on, off
work_directory Команданы орындауға арналған жұмыс каталогы. Командалар орындалу барысында өзгеруі мүмкін.

Әдепкі: {root_dir}

Шаблон айнымалылары

"command" және "work_directory" параметрлерінде келесі шаблон айнымалыларын қолдануға болады:

Жалпы айнымалылар

Айнымалы Сипаттамасы
{date_time} Ағымдағы күн/уақыт ("command" параметрі үшін ғана қолжетімді айнымалы)
{root_dir} Open Server Panel түбір каталогы (толық жол)
{root_drive} Түбір каталогының дискі
{root_path} Open Server Panel түбір каталогына жол
{web_panel_url} Веб-интерфейс URL-мекенжайы

Арнайы айнымалылар (тек projects және projects\<имя_домена> үшін)

Айнымалы Сипаттамасы
{base_dir} Жобаның базалық каталогы
{host} Домен атауы (Punycode)
{host_decoded} Көрінетін домен атауы (Punycodeсыз)
{host_scheme} Жобаға сұрау сұлбасы ("http" немесе "https", жобаның TLS параметріне байланысты)
{http_port} Жобаға HTTP протоколы бойынша сұрау порты
{https_port} Жобаға HTTPS протоколы бойынша сұрау порты
{menu_caption} Меню тармағының тақырыбы (тек need_alias=ON бар projects санаты үшін)
{http_engine} HTTP қозғалтқышы
{node_engine} Node.js қозғалтқышы
{php_engine} PHP қозғалтқышы
{project_root} Жобаның түбір каталогы
{base_url} Жобаның URL-ы
{web_root} Жобаның жалпыға қолжетімді каталогы
{scheme_port} Жобаға сұрау порты (":{http_port}" немесе ":{https_port}", жобаның TLS параметріне байланысты). Егер {http_port} немесе {https_port} стандартты 80 не 443 болса, {scheme_port} бос болады.
{app_start_command} Жоба қосымшасын іске қосу командасы (егер бапталған болса)
{terminal_codepage} Консоль кодтамасы

Арнайы айнымалылар (тек addons және addons\<имя_дополнения> үшін)

Айнымалы Сипаттамасы
{addon_name} Қосымшаның атауы
{terminal_codepage} Консоль кодтамасы

Арнайы айнымалылар (тек modules және modules\<имя_модуля> үшін)

Айнымалы Сипаттамасы
{ip} Модульдің IP-мекенжайы
{log_level} Қателерді журналдау деңгейі
{module_name} Модуль атауы
{port} Модуль порты
{profile_name} Модуль баптауларының ағымдағы профилі атауы
{query_log_level} Сұрауларды журналдау деңгейі
{shell_command} Модульдің shell/cli қабығын іске қосу командасы (егер бапталған болса)
{terminal_codepage} Консоль кодтамасы
{time_zone} Уақыт белдеуі

Арнайы командалар мәндері

Команда Сипаттамасы
command_open_logs_viewer Журналдарды қарау терезесін ашу
command_open_idn_converter IDN-конвертерін ашу
command_open_options Бағдарлама баптаулары терезесін ашу

Шаблон айнымалыларынан бөлек, кез келген Windows орта айнымалыларын пайдалануға болады, мысалы: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% және т.б.

Пайдалану мысалы

[bookmark_1]

caption  = Google
category = Менің Бетбелгілерім\Іздеу жүйелері
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE опциялары

  • /c: Команданы орындап, терминалды жабу.
  • /k: Команданы орындап, терминалды ашық қалдыру.
