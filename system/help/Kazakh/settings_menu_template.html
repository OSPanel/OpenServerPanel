Жеке мәзір тармақтарын құру

  1. Бірегей идентификаторы бар [ID] жаңа секцияны қосыңыз
  2. Секцияларды қалаған ретпен орналастырыңыз — бұл мәзірдегі тармақтардың ретін анықтайды
  3. Өзгерістерді сақтаңыз және өзгерістерді қолдану үшін Open Server Panel бағдарламасын қайта іске қосыңыз

Маңызды ақпарат

Жеке мәзір тармақтарын құру кезінде секциялардың идентификаторлары қайталанбауын қадағалаңыз. Бұл мәзірдің жұмысында қақтығыстарға әкелуі мүмкін.

Мәзір тармақтарының параметрлері

Сұрыптау реті: Мәзір тармақтары сәйкес секциялар үлгіде орналасқан реттілікпен сұрыпталады.

caption Мәзір тармағының тақырыбы. {lang_xxx} форматындағы тіл константаларын қолдайды.

Әдепкі бойынша: орнатылмаған
category

Мәзір тармағының иерархиядағы орнын анықтайды. Бір деңгейлі ішкі қатарды қолдайды (мысалы, "Менің Бетбелгілерім\Жұмыс").

Арнайы санаттар:

  • projects, modules, addons - тармақты сәйкес әрекеттер мәзіріне қосады
  • projects\<домен_аты>, modules\<модуль_аты>, addons\<қосымша_аты> - нақты элемент үшін тармақ қосады

Егер санат көрсетілмесе, тармақ түбірлік мәзірде жасалады.

Әдепкі бойынша: орнатылмаған
command Мәзір тармағы белсендірілген кезде орындалатын команда. Командасы жоқ тармақтар еленбейді.

Әдепкі бойынша: орнатылмаған
enabled Мәзір тармағының көрсетілуін қосады/өшіреді.

Әдепкі бойынша: on | Мәндері: on, off
hide Шақырылатын қолданбаның терезесінің көрінуін басқарады. Еншілес процестерге әсер етпейді.

Әдепкі бойынша: off | Мәндері: on, off
hr_after Мәзір тармағынан кейін көлденең бөлгіш қосады.

Әдепкі бойынша: off | Мәндері: on, off
hr_before Мәзір тармағынан бұрын көлденең бөлгіш қосады.

Әдепкі бойынша: off | Мәндері: on, off
icon Font Awesome Free (Solid/Regular/Brands) жиынтығынан белгіше.

Әдепкі бойынша: орнатылмаған
need_alias Мәзір тармағын тек домен бүркеншік аты үшін көрсетеді. Мәзір үлгісінде need_alias=on мәні бар тек бір тармақ болуы мүмкін!
Келесі санаттарға қолданылады: projects

need_category

Мәзір тармағының көрсетілуін белгілі бір санаттағы модульдермен/қосымшалармен шектейді.

Қолдау көрсетілетін форматтар:

  • modules, addons
  • modules\<модуль_аты>, addons\<қосымша_аты>
Әдепкі бойынша: орнатылмаған
need_module_shell Мәзір тармағын ата-аналық модульде shell/cli болуына байланысты көрсетеді.
Келесі санаттарға қолданылады: modules, modules\<модуль_аты>

Әдепкі бойынша: орнатылмаған | Мәндері: on, off
need_state Мәзір тармағын ата-аналық модульдің күйіне байланысты көрсетеді.

Әдепкі бойынша: орнатылмаған | Мәндері: on, off

need_use_wt Мәзір тармағының көрсетілуін Open Server Panel-де Windows Terminal қолдану параметріне байланысты көрсетеді.

Әдепкі бойынша: орнатылмаған | Мәндері: on, off
work_directory Команданы орындау үшін жұмыс каталогы. Командаларды орындау кезінде өзгертілуі мүмкін.

Әдепкі бойынша: {root_dir}

Үлгі айнымалылары

"command" және "work_directory" параметрлерінде келесі үлгі айнымалыларын қолдануға болады:

Жалпы айнымалылар

Айнымалы Сипаттама
{root_dir} Open Server Panel түбірлік каталогы (толық жол)
{root_drive} Түбірлік каталог дискісі
{root_path} Open Server Panel түбірлік каталогына жол
{web_panel_url} Веб-интерфейстің URL-мекенжайы

Арнайы айнымалылар (тек projects және projects\<домен_аты> үшін)

Айнымалы Сипаттама
{base_dir} Жобаның базалық каталогы
{host} Домен атауы (Punycode)
{host_decoded} Көрінетін домен атауы (Punycode-сыз)
{host_scheme} Жобаға сұраныс схемасы ("http" немесе "https", жоба параметрлеріндегі SSL параметріне байланысты)
{http_port} HTTP протоколы бойынша жобаға сұраныс порты
{https_port} HTTPS протоколы бойынша жобаға сұраныс порты
{menu_caption} Мәзір тармағының тақырыбы (тек need_alias=ON мәні бар projects санаты үшін)
{nginx_engine} Nginx қозғалтқышы
{node_engine} Node.js қозғалтқышы
{php_engine} PHP қозғалтқышы
{project_dir} Жобаның түбірлік каталогы
{project_url} Жоба URL
{public_dir} Жобаның жария каталогы
{scheme_port} Жобаға сұраныс порты (":{http_port}" немесе ":{https_port}", жоба параметрлеріндегі SSL параметріне байланысты). Егер {http_port} немесе {https_port} стандартты 80 немесе 443 мәніне ие болса, онда {scheme_port} бос болады.
{start_command} Жобаны іске қосу командасы (егер баптаулар жасалған болса)
{terminal_codepage} Консоль кодировкасы

Арнайы айнымалылар (тек addons және addons\<қосымша_аты> үшін)

Айнымалы Сипаттама
{addon_name} Қосымша атауы
{terminal_codepage} Консоль кодировкасы

Арнайы айнымалылар (тек modules және modules\<модуль_аты> үшін)

Айнымалы Сипаттама
{ip} Модульдің IP-мекенжайы
{log_level} Қателерді журналдау деңгейі
{module_name} Модуль атауы
{port} Модуль порты
{profile_name} Модульдің ағымдағы параметрлер профилінің атауы
{query_log_level} Сұраныстарды журналдау деңгейі
{shell_command} Модульдің shell/cli қабығын іске қосу командасы (егер баптаулар жасалған болса)
{terminal_codepage} Консоль кодировкасы
{time_zone} Уақыт белдеуі

Командалардың арнайы мәндері

Команда Сипаттама
command_open_logs_viewer Журналдарды қарау терезесін ашу
command_open_idn_converter IDN-конвертерін ашу
command_open_options Бағдарлама параметрлері терезесін ашу

Үлгі айнымалыларынан бөлек, кез келген Windows орта айнымалыларын қолдануға болады, мысалы: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH% және т.б.

`cmd.exe` опциялары

  • /k: Команданы орындап, терминалды ашық қалдыру.
