Бағдарлама параметрлері

Windows-пен бірге іске қосу
Операциялық жүйе жүктелген кезде Open Server Panel автоматты іске қосылуын қосу.
Кідіріс
Бағдарламаны іске қосуды кідірту (секундпен, 0-ден 60-қа дейін).

Бұл жүйеге түсетін жүктемені азайту үшін қолданбаның басталуын кейінге қалдыруға мүмкіндік береді. Бұл әсіресе сыртқы қызметтердің немесе желілік интерфейстердің толық инициализациясын күту қажет болған жағдайда пайдалы.
Жаңа нұсқалардың бар-жоғын тексеру
Open Server Panel жаңартуларын тексеруді қосу (Интернетке қосылу қажет).
Тапсырмалар жоспарлаушысын қосу
Кіріктірілген тапсырмалар жоспарлаушысын іске қосу. Егер бұл параметр өшірілген болса, күйіне қарамастан жоспарланған тапсырмалардың ешқайсысы орындалмайды.
HOSTS файлын пайдалану
HOSTS файлына домен атауларын жазуды қосу.

Ұйымда HOSTS файлына шектеулі қол жеткізу кезіндегі ұсыныстар:

1. Барлық қажетті модульдер мен жобаларды баптаңыз.
2. HOSTS бұғаттауын алып тастау және оның күйін бекіту үшін жүйелік әкімшіге хабарласыңыз.
3. Әкімші өзгерістерді бекіткеннен кейін бұл опцияны өшіруге болады.

Маңызды: Салдарына сенімді болмасаңыз, бұл параметрді өшірмеңіз!
Модульдерді жоба профилімен іске қосу
Модульдерді жоба атауымен сәйкес келетін профильді бір уақытта белсендірумен іске қосу.

«Жоба модульдерін қосу» мәзір тармағын таңдаған кезде, егер мұндай профиль болса, ағымдағы жобамен бірдей атаулы профильді автоматты түрде белсендіру үшін қолданылады.
Жасырын жобалардың модульдерін өшірмеу
«Барлық модульдерді өшіру» мәзір тармағын таңдаған кезде жасырын жобалардың модульдерін өшірмеу. "Жасырын" дегеніміз - "hidden" санаты тағайындалған жобалар.

Әдепкі бойынша, «Барлық модульдерді өшіру» командасы жасырын қызметтік жобалар (мысалы, PHPMyAdmin) пайдаланатын модульдерді қоса алғанда, барлық модульдердің жұмысын тоқтатады. Бұл опция басқа барлық модульдер өшірілген кезде, жасырын қызметтік жобалардың жұмыс қабілеттілігін сақтап, олар үшін қажетті модульдерді өшірмеуге мүмкіндік береді.
Интерфейс тілі
Open Server Panel пайдаланушы интерфейсінің тілі.

Егер локализация файлы жоқ болса немесе қателер бар болса, ағылшын тілі қолданылады.
API домені
API және веб-интерфейс үшін жергілікті домен (әзірлеу кезеңінде)

Ұсыныс: VPN немесе прокси пайдаланылса, бұл доменді ерекше жағдайларға қосыңыз.
API IP-мекенжайы
API және веб-интерфейс үшін IPv4-мекенжайы (әзірлеу кезеңінде).

Ұсыныс: VPN немесе прокси пайдаланылса, бұл IP-мекенжайды ерекше жағдайларға қосыңыз.
API порты
API және веб-интерфейс үшін қолданылатын порт (әзірлеу кезеңінде). Егер көрсетілген порт басқа қолданбамен пайдаланылып жатса, Open Server Panel іске қосыла алмайды.
Windows Terminal пайдалану
Стандартты командалық интерфейс орнына Windows Terminal пайдалануды қосу.

Талаптар: Windows Terminal жүйеде орнатылған және PATH орта айнымалысында тіркелген болуы керек.

Windows Terminal cmd.exe ретінде: Windows Terminal cmd.exe орнына пайдаланылуы және Windows жаңа нұсқаларында %COMSPEC% ортасының айнымалысына жазылуы мүмкін. Егер бұл солай болса, бұл опцияны қосулы қалдырыңыз.

Windows Terminal жаңа экземплярлары: Егер Windows Terminal қойындылар орнына жаңа терезелер ашса, оны келесідей баптаңыз: Параметрлер→Іске қосу→Жаңа экземпляр әрекеті→Соңғы қолданылған терезеге қосылу.
Жобаның қысқа тақырыбы
Бұл опцияны белсендіргенде, терминал терезесінің тақырыбында толық сипаттама орнына тек жоба атауы көрсетіледі.
Жүйелік ортаны жоба ортасына қосу
Жоба параметрлерінде көрсетілмесе де, терминалда жүйе (System) ортасын пайдалану. Жүйелік орта жүйеде орнатылған бағдарламаларды (мысалы, git.exe немесе ssh.exe) пайдалануға мүмкіндік береді.

Бұл опцияны жүйелік БҚ-мен қақтығыстар туындаған жағдайда ғана өшіріңіз.
ANSI қолдауы
Терминалда түстерді басқару үшін ANSI-кодтарын қолдауды қосу.

"Автоматты" режимі (әдепкі бойынша):
- Түзету тек Windows 7, 8 және Windows 10 (1903 нұсқасына дейін қоса) нұсқаларына қолданылады. Windows жаңа нұсқаларында ANSI-кодтарын қолдау бұрыннан кіріктірілген.
- Түзету ANSI-ны әдепкі бойынша қолдайтын терминалдарға (мысалы, Windows Terminal) қолданылмайды.
Жобаларды іздеу каталогтары
Open Server Panel жобаларды іздейтін каталогтар тізімі. Жолдарды нүктелі үтірмен (;) бөліңіз.

Ерекшеліктер: node_modules және vendor ішкі каталогтары еленбейді.
Тереңдік
Жобаларды іздеу кезіндегі каталогтардың максималды ішкі ену тереңдігі.

Егер көрсетілген каталогтарда көптеген ішкі каталогтар болса, бұл мәнді арттыру Open Server Panel іске қосылуын баяулатуы мүмкін.
Журнал файлының максималды өлшемі
Мегабайттағы журнал файлының максималды өлшемі. Көрсетілген мән асып кеткен кезде, бағдарлама келесі рет іске қосылған кезде лог-файл қайта құрылады.

Бағдарлама әр іске қосылған сайын лог-файлдарды тазарту үшін 0 мәнін орнатыңыз.

Лог-файлдарды тазалауды толығымен өшіру үшін 100 МБ мәнін орнатыңыз.
