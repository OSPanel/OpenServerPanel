Бағдарлама баптаулары

Windows-пен бірге іске қосу
Операциялық жүйе жүктелген кезде Open Server Panel автожүктеуін қосу.
Кідіріс
Бағдарламаны іске қосудың кідірісі (секундпен, 0-ден 60-қа дейін).

Windows-пен бірге жүктелу кезінде қолданбаны іске қосуды шегеруге мүмкіндік береді, бұл жүйеге түсетін жалпы жүктемені азайтады. Бұл әсіресе үшінші тарап сервистері немесе желілік интерфейстер толық инициализацияланғанын күту қажет болғанда пайдалы.
Жаңа нұсқалардың бар-жоғын тексеру
Open Server Panel жаңартуларын тексеруді қосу (Интернетке қосылу қажет).
Тапсырмалар жоспарлағышын қосу
Құрамдастырылған тапсырмалар жоспарлағышын белсендіру. Параметр өшірілсе, олардың күйіне қарамастан ешбір жоспарланған тапсырма орындалмайды.
HOSTS файлын пайдалану
Домендік атауларды HOSTS файлына жазуды қосу.

Ұйымда HOSTS файлына қолжетімдік шектеулі болғандағы ұсыныстар:

1. Барлық қажетті модульдер мен жобаларды баптаңыз.
2. HOSTS-ты бұғаттан шығарып, оның күйін бекіту үшін жүйелік әкімшіге жүгініңіз.
3. Әкімші өзгерістерді бекіткеннен кейін бұл опцияны өшіруге болады.

Маңызды: Салдарын білмесеңіз, бұл параметрді өшірмеңіз!
Модульдерді жоба профилімен іске қосу
Жоба атауымен сәйкес келетін профильді бір уақытта белсендіріп, модульдерді іске қосу.

«Жоба модульдерін қосу» мәзір тармағы таңдалғанда, егер бар болса, ағымдағы жоба атауымен бірдей атаудағы профиль автоматты түрде белсендірілсін.
Жасырын жобалардың модульдерін сөндірмеу
«Барлық модульдерді сөндіру» мәзір тармағы таңдалғанда жасырын жобалардың модульдерін сөндірмеу. «Жасырын» дегеніміз санаты «hidden» болып белгіленген жобалар.

Әдепкіде «Барлық модульдерді сөндіру» командасы барлық модульдердің жұмысын тоқтатады, жасырын қызметтік жобалар (мысалы, PHPMyAdmin) пайдаланатындарын қоса. Бұл опция жасырын қызметтік жобалардың жұмысқа қабілеттілігін сақтай отырып, олар үшін қажетті модульдерді сөндірмей, қалған барлық модульдерді сөндіруге мүмкіндік береді.
Интерфейс тілі
Open Server Panel пайдаланушы интерфейсінің тілі.

Локализация файлы жоқ немесе қателер болса, ағылшын тілі қолданылады.
API домені
API және веб-интерфейс үшін жергілікті домен (әзірлеуде)

Ұсыныс: Егер VPN немесе прокси қолданылса, бұл доменді ерекшеліктер тізіміне қосыңыз.
API IP-мекенжайы
API және веб-интерфейс үшін IPv4-мекенжай (әзірлеуде).

Ұсыныс: Егер VPN немесе прокси қолданылса, бұл IP-мекенжайды ерекшеліктер тізіміне қосыңыз.
API порты
API және веб-интерфейс үшін қолданылатын порт (әзірлеуде). Егер көрсетілген портты басқа қолданба пайдаланып тұрса, Open Server Panel іске қосыла алмайды.
Windows Terminal пайдалану
Стандартты командалық интерфейстің орнына Windows Terminal пайдалануды қосу.

Талаптар: Windows Terminal жүйеде орнатылған және PATH орта айнымалысына тіркелген болуы керек.

cmd.exe ретінде Windows Terminal: Windows Terminal өзін cmd.exe-нің орнына қолдана алады және Windows-тың жаңа нұсқаларында %COMSPEC% орта айнымалысына тіркелуі мүмкін. Егер солай болса, бұл опцияны қосулы қалдырыңыз.

Windows Terminal жаңа даналары: Егер Windows Terminal қойындылардың орнына жаңа терезелер ашса, былай баптаңыз: Параметрлер→Іске қосу→Жаңа нұсқаның мінез-құлқы→Соңғы пайдаланылған терезеге тіркеу.
Жобаның қысқа тақырыбы
Бұл опция белсендірілсе, терминал терезесінің тақырыбында орта туралы егжей-тегжейлі сипаттаманың орнына тек жоба атауы көрсетіледі.
Жобаның ортасына жүйелік ортаны қосу
Терминалда, жоба баптауларында көрсетілмесе де, жүйелік ортаны (System) пайдалану. Жүйелік орта жүйеде орнатылған бағдарламаларды пайдалануға мүмкіндік береді (мысалы, git.exe немесе ssh.exe).

Бұл опцияны тек жүйелік БҚ-пен қақтығыстар туындаған жағдайда өшіріңіз.
ANSI қолдауы
Терминалда түстерді басқаруға арналған ANSI-кодтарын қолдауды қосу.

«Автоматты» режимі (әдепкі):
- Түзету Windows 10 1903 нұсқасына қоса дейін ғана қолданылады. Windows-тың одан жаңа нұсқаларында ANSI-кодтарға қолдау ендірілген.
- ANSI-ді әдепкіде қолдайтын терминалдар үшін түзету қолданылмайды (мысалы, Windows Terminal).
Жобаларды іздеу каталогтары
Open Server Panel жобаларды іздейтін каталогтар тізімі. Жолдарды нүктелі үтірмен (;) бөліңіз.

Ерекшеліктер: node_modules және vendor ішкі каталогтары еленбейді.
Тереңдік
Жобаларды іздеу кезінде каталогтар ұяласуының максималды тереңдігі.

Бұл мәнді ұлғайту, көрсетілген каталогтарда ішкі каталогтар көп болса, Open Server Panel іске қосылуын баяулатуы мүмкін.
Журнал файлының максималды өлшемі
Журнал файлының мегабайтпен максималды өлшемі. Көрсетілген мәннен асқан жағдайда лог-файл бағдарлама келесі іске қосылғанда қайта жасалады.

Бағдарлама әр іске қосылған сайын журналдарды тазарту үшін 0 мәнін орнатыңыз.

Журналдарды тазартуды толық өшіру үшін 100 МБ мәнін орнатыңыз.
