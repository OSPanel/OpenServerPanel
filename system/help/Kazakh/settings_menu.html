Мәзір параметрлері

Безендіру тақырыбы
Мәзір белгішелері үшін безендіру тақырыбы.
Қаріп өлшемі
Пиксельдегі мәзір қаріпінің өлшемі. Опция жүйелік параметрлерге қарамастан мәзір қаріпінің өлшемін орнатуға мүмкіндік береді.

Қаріп өлшемін бақылау функциясын өшіру үшін жүгірткіні минималды мәнге 12px қойыңыз (жүйелік өлшем қолданылады).
Хабарландыру аймағында белгішені көрсету
Windows хабарландыру аймағында бағдарлама белгішесін көрсету.

Өшіру: Windows Server Core ортасында Open Server Panel іске қосатын болсаңыз немесе Windows пайдаланушысының кіруін қажет етпейтін автоматты іске қосу түрін қолдансаңыз (Windows тапсырмалар жоспарлаушысы→Компьютер жүктелген кезде іске қосу), бұл опцияны өшіріңіз.
Мәзір элементтері үшін белгішелерді көрсету
Бағдарлама мәзірінде белгішелерді көрсету. Жүйелік сызу қосылған болса, белгішелер көрсетілмейді.
Жүйелік сызуды қосу
Бұл опцияны тек экрандық қол жеткізу бағдарламаларымен (скрин-ридерлермен) үйлесімділікті қамтамасыз ету қажет болған жағдайда ғана қосыңыз.
Тік бөлгішті көрсету
Бұл опцияны қосқан кезде бағдарлама мәзіріндегі белгішелер тік бөлгішпен бөлінеді.
Бір элементтен тұратын тізімдерді топтастырмау
Тек бір элементтен тұратын тізімдерді топтастырмау.
Жобалар: көрсету
Жобаларды басқару мәзірін көрсету.
Жобалар: топтастыру
Мәзірде жобаларды домен аймағы бойынша топтастыру.
Жобалар: ішкі мәзір
Жобалар мәзірін жеке ішкі мәзірде көрсету.
Жобалар: бөлгішті көрсету
Жобалар мәзірінен кейін бөлу сызығын көрсету.
Модульдер: көрсету
Модульдерді басқару мәзірін көрсету.
Модульдер: топтастыру
Мәзірде модульдерді топтастыру.
Модульдер: ішкі мәзір
Модульдер мәзірін жеке ішкі мәзірде көрсету.
Модульдер: бөлгішті көрсету

Қосымшалар: топтастыру
