Жобалардың ғаламдық баптаулары

Осы бөлімде берілген параметрлер жоба баптауларында басқа мәндер көрсетілмесе қолданылады.

HTTP
Жобалар үшін қолданылатын веб-сервер модулін анықтайды.
NODE
Node.js-қолданбаларын іске қосу үшін қолданылатын Node.js қозғалтқышын көрсетеді.

Node.js орнату: Қажетті Node.js нұсқасын алдын ала osp node <latest|lts|нөмір> пәрмені арқылы орнатыңыз.
PHP
PHP-файлдарды өңдеу үшін қолданылатын PHP модулін анықтайды.
Қосу
Жобаның әдепкі күйін (қосулы немесе өшірулі) анықтайды.
Терминал кодировкасы
Жоба ортасымен жұмыс істеу кезіндегі терминал кодировкасы.

Арнайы мәндер:
- system: Жүйелік кодировка қолданылады.

Маңызды: Егер мән берілмесе, жоба ортасының соңғы түрлендірілуі кезінде терминал кодировкасы оны орнатқан соңғы қосылған орта бойынша қойылады, мысалы, PHP модулі ортасы.
IP
Жеке баптаулары жоқ барлық жобалар қолданатын IP-мекенжай(лар)ын қояды.

Шектеу: Бірдей IP-мекенжайды қолданатын жобалар бір PHP нұсқасында жұмыс істеуі керек.

Көп IP қолдауы: Бірнеше IP-мекенжайды бос орын арқылы көрсетуге болады, IPv6 қоса алғанда. HOSTS файлында домендерге бірінші көрсетілген IP тағайындалады.

Автоматты тағайындау: Егер өрісті бос қалдырсаңыз, IP-мекенжай автоматты түрде тағайындалады.

Ұсынымдар:
  • IP-мекенжайларды автоматты басқару көпшілік пайдаланушыларға ұсынылады.
  • IP-мекенжайды қолмен тағайындауды тек желілік конфигурацияның ерекше талаптары болғанда қолданыңыз.
HTTP
HTTP бойынша қосылымдарға арналған портты анықтайды.
HTTPS
HTTPS бойынша қосылымдарға арналған портты анықтайды.
TLS
TLS қолдауын қосады немесе өшіреді.
Сертификат файлы
TLS-сертификат файлының жолын көрсетеді. Шаблондық айнымалыларды қолдануға болады.

Жарамды таңбалар: A-Za-z0-9-+_.\:

Ұсыныс: Сертификаттарды автоматты генерациялау үшін өрісті бос қалдырыңыз.
Кілт файлы
TLS-кілт файлының жолын көрсетеді. Шаблондық айнымалыларды қолдануға болады.

Жарамды таңбалар: A-Za-z0-9-+_.\:

Ұсыныс: Кілтті автоматты генерациялау үшін өрісті бос қалдырыңыз.
IP-мекенжай (backend)
Серверлік бөлікке (Backend) қосылу жүзеге асырылатын IP-мекенжайды көрсетеді.
Порт (backend)
Серверлік бөлікке (Backend) қосылу үшін порт нөмірін анықтайды.
Қосу (backend)
Жобаның барлық кіріс трафигін (HTTP және HTTPS) автоматты түрде серверлік бөлікке (Backend) бағыттауға мүмкіндік береді. Фронтенд пен бэкенд бөлінген кезде тестілеу немесе әзірлеу үшін пайдалы.
Жоба каталогы
Жобаның түбір каталогын көрсетеді. Осы каталогқа өту osp project <DOMAIN> пәрменімен бір мезгілде жоба ортасын белсендірумен орындалады. Шаблондық айнымалыларды қолдануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:
Публичный каталог
Жобаның жария каталогын анықтайды. Шаблондық айнымалыларды қолдануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:
Псевдонимы
Жоба үшін қосымша домендік атауларды (алиастарды) көрсетеді (бос орын арқылы). Шаблондық айнымалыларды қолдануға болады.

Шектеу: "*" таңбасы Windows жүйесіндегі HOSTS файлында қолдау таппайды және DNS баптауды талап етеді.
Жоба ортасы
Жоба ортасын қалыптастыратын толықтырулар мен модульдердің тізімі (бос орын арқылы).

HTTP, NODE және PHP: Осы қозғалтқыштардың ортасы әрқашан қосылады (егер домен үшін берілсе) және бұл параметрде көрсетуді талап етпейді.
Жобаны іске қосу пәрмені
Жобаны іске қосу пәрменін анықтайды (мысалы, nodemon app.js). Шаблондық айнымалыларды қолдануға болады.
Жоба URL-ы
Жобаны Мәзір→Жоба→Браузерде ашу арқылы ашқанда қолданылатын, сондай-ақ жоба домендік алиастарын ашқанда қолданылатын URL. Шаблондық айнымалыларды қолдануға болады.

Қолдану: CMS әкімшілік панелінің URL-ын көрсетуге болады.

Шаблондық айнымалылар

Айнымалы Сипаттама
{backend_ip} Серверлік бөлікке (Backend) қосылу IP-мекенжайы
{backend_port} Серверлік бөлікке (Backend) қосылу порты
{base_dir} Жобаның түбір каталогы (.osp каталоги орналасқан жер)
{date_time} Ағымдағы күн/уақыты (айнымалы тек жоба қолданбасын іске қосу пәрмені үшін қолжетімді)
{host} Домен атауы (интернационалдандырылған домендер үшін Punycode қолданылады)
{host_decoded} Көрінетін домен атауы (Punycode-сыз)
{host_scheme} Жобаға сұрау сызбасы ("http" немесе "https", жоба баптауларындағы TLS параметріне байланысты)
{http_port} Жобаға HTTP протоколы бойынша сұраудың порты
{https_port} Жобаға HTTPS протоколы бойынша сұраудың порты
{http_engine} HTTP қозғалтқышы
{node_engine} NODE қозғалтқышы
{php_engine} PHP қозғалтқышы
{project_root} Жобаның түбір каталогы
{web_root} Жобаның жария каталогы
{scheme_port} Жобаға сұраудың порты (":{http_port}" немесе ":{https_port}", жоба баптауларындағы TLS параметріне байланысты).

Егер {http_port} немесе {https_port} стандартты 80 немесе 443 мәніне ие болса, {scheme_port} бос болады.
{root_dir} Open Server Panel түбір каталогы (толық жол)
{root_drive} Түбір каталогының дискі
{root_path} Open Server Panel түбір каталогына жол
{terminal_codepage} Консоль кодировкасы
