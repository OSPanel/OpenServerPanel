Жобалардың жаһандық параметрлері

Бұл бөлімде орнатылған параметрлер, жоба параметрлерінде басқа мәндер көрсетілмеген жағдайда қолданылады.

Nginx
Жобалар үшін қолданылатын Nginx веб-серверінің нұсқасын анықтайды.
Node
Node.js-қосымшаларын іске қосу үшін Node.js қозғалтқышын көрсетеді.

Node.js орнату: Алдын ала NVM қосымшасы арқылы қажетті Node.js нұсқасын орнатыңыз.
PHP
PHP-файлдарын өңдеу үшін қолданылатын PHP қозғалтқышын анықтайды.

Маңызды: FCGI префиксі жоқ PHP модульдері Apache+PHP интеграцияланған модульдері болып табылады.
Қосу
Жобаның әдепкі күйін анықтайды (қосулы немесе өшірулі).
Терминал кодировкасы
Жоба ортасымен жұмыс істеу кезіндегі терминал кодировкасы.

Арнайы мәндер:
- system: Жүйелік кодировка қолданылады.

Маңызды: Егер мән берілмесе, жобаның соңғы ортасын қалыптастыру кезінде терминал кодировкасы оны көрсеткен соңғы қосылған ортамен орнатылады, мысалы, PHP модулінің ортасымен.
IP
Жеке параметрлері жоқ барлық жобалармен қолданылатын IP-мекенжай(лар)ды орнатады.

Шектеу: Бір IP-мекенжайын қолданатын жобалар бір PHP нұсқасында жұмыс істеуі керек.

Бірнеше IP қолдауы: IPv6 қоса, бос орын арқылы бірнеше IP-мекенжайларын көрсетуге болады. HOSTS файлында домендерге алғашқы көрсетілген IP тағайындалады.

Автоматты тағайындау: Егер өрісті бос қалдырсаңыз, IP-мекенжай автоматты түрде тағайындалады.

Ұсыныстар:
  • IP-мекенжайларын автоматты басқару көптеген пайдаланушыларға ұсынылады.
  • IP-мекенжайды қолмен орнатуды тек желілік конфигурацияның арнайы талаптары болған жағдайда ғана қолдану керек.
HTTP
HTTP байланыстары үшін портты анықтайды.
HTTPS
HTTPS байланыстары үшін портты анықтайды.
SSL
Жеке параметрлері жоқ жобалар үшін SSL қолдауын қосады немесе өшіреді.
Сертификат файлы
SSL-сертификат файлына жолды көрсетеді. Үлгі айнымалыларын қолдануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:

Ұсыныс: Сертификаттарды автоматты түрде жасау үшін өрісті бос қалдырыңыз.
Кілт файлы
SSL-кілт файлына жолды көрсетеді. Үлгі айнымалыларын қолдануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:

Ұсыныс: Кілтті автоматты түрде жасау үшін өрісті бос қалдырыңыз.
IP-мекенжай (backend)
Серверлік бөлікке (Backend) қосылу жүзеге асырылатын IP-мекенжайды көрсетеді.
Порт (backend)
Backend-ке қосылу үшін порт нөмірін анықтайды.
Қосу (backend)
Жобаның барлық кіріс трафигін (HTTP және HTTPS) автоматты түрде серверлік бөлікке (Backend) бағыттауға мүмкіндік береді. Фронтенд пен бэкенд бөлек болған кезде тестілеу немесе әзірлеу үшін пайдалы.
Жоба каталогы
Жобаның түбірлік каталогын көрсетеді. Бұл каталогқа өту osp project <DOMAIN> командасы арқылы жоба ортасын белсендірумен бір уақытта жүзеге асырылады. Үлгі айнымалыларын қолдануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:
Жария каталог
Жобаның жария каталогын анықтайды. Үлгі айнымалыларын қолдануға болады.

Рұқсат етілген таңбалар: A-Za-z0-9-+_.\:
Бүркеншік атаулар
Жоба үшін қосымша домен атауларын (бүркеншік атаулар) көрсетеді (бос орын арқылы). Үлгі айнымалыларын қолдануға болады.

Субдомендер: Егер бүркеншік атауда нүкте болмаса, ол субдомен ретінде қарастырылады (мысалы, "www" -> "www.test.local").

Шектеу: "*" таңбасы Windows HOSTS файлында қолданылмайды және DNS баптауын қажет етеді.
Жоба ортасы
Жоба ортасын қалыптастыратын қосымшалар мен модульдер тізімі (бос орын арқылы).

PHP/Nginx/Node.js модульдері: Бұл модульдердің орталары әрқашан қосылады (егер домен үшін орнатылған болса) және бұл параметрде көрсетуді қажет етпейді.
Жобаны іске қосу командасы
Жобаны іске қосу үшін команданы анықтайды (мысалы, nodemon app.js). Үлгі айнымалыларын қолдануға болады.
Жоба URL
Open Server Panel-де Жобаны браузерде ашу таңдалған кезде ашылатын URL. Үлгі айнымалыларын қолдануға болады.

Қолдану: CMS әкімшілік панелінің URL-ін орнатуға болады.

Үлгі айнымалылары

Айнымалы Сипаттама
{backend_ip} Серверлік бөлікке (Backend) қосылу IP-мекенжайы
{backend_port} Серверлік бөлікке (Backend) қосылу порты
{base_dir} Жобаның түбірлік каталогы (.osp каталогы орналасқан жер)
{host} Домен атауы (интернационалдандырылған домендер үшін Punycode қолданылады)
{host_decoded} Көрінетін домен атауы (Punycode-сыз)
{host_scheme} Жобаға сұраныс схемасы ("http" немесе "https", жоба параметрлеріндегі SSL параметріне байланысты)
{http_port} HTTP протоколы бойынша жобаға сұраныс порты
{https_port} HTTPS протоколы бойынша жобаға сұраныс порты
{nginx_engine} Nginx қозғалтқышы
{node_engine} Node.js қозғалтқышы
{php_engine} PHP қозғалтқышы
{project_dir} Жобаның түбірлік каталогы
{public_dir} Жобаның жария каталогы
{scheme_port} Жобаға сұраныс порты (":{http_port}" немесе ":{https_port}", жоба параметрлеріндегі SSL параметріне байланысты).

Егер {http_port} немесе {https_port} стандартты 80 немесе 443 мәніне ие болса, онда {scheme_port} бос болады.
{root_dir} Open Server Panel түбірлік каталогы (толық жол)
{root_drive} Түбірлік каталог дискісі
{root_path} Open Server Panel түбірлік каталогына жол
{terminal_codepage} Консоль кодировкасы
