Модульдердің жаһандық орта айнымалылары

Бұл бөлімде модульдер үшін жаһандық орта айнымалыларын орнатуға болады.

Бұл айнымалылар тек модульдер ортасында әрекет етеді және жүйелік айнымалыларға немесе жобалар ортасына әсер етпейді.

Мәндерде үлгі айнымалыларын пайдалануға болады.

Егер айнымалы жүйелік ортада бар, бірақ модульдер ортасында пайдаланылмауы керек болса, арнайы сүзгіні қолданыңыз (Модульдер→Рұқсат етілген жүйелік айнымалылар бөлімін қараңыз) немесе бос мән беріп айнымалыны ортадан жойыңыз.

Үлгі айнымалылары

Айнымалы Сипаттама
{root_dir} Open Server Panel түбірлік каталогы (толық жол)
{root_drive} Түбірлік каталог дискісі
{root_path} Open Server Panel түбірлік каталогына жол
{terminal_codepage} Терминалдағы кодировка (Модульдер→Терминалдағы кодировка бөлімін қараңыз)
{time_zone} Etc/GMT форматындағы уақыт белдеуі (Модульдер→Уақыт белдеуі бөлімін қараңыз)

Үлгі айнымалыларынан бөлек, кез келген Windows орта айнымалыларын қолдануға болады, мысалы: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH% және т.б.
