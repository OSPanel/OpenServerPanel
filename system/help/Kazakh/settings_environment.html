Модульдік ортаның жаһандық айнымалылары

Осы бөлімде модульдер үшін жаһандық орта айнымалыларын орнатуға болады.

Бұл айнымалылар тек модульдік ортада әрекет етеді және жүйелік айнымалыларға немесе жобалар ортасына әсер етпейді.

Мәндерде үлгілік айнымалыларды қолдануға болады.

Егер айнымалы жүйелік ортада бар болса, бірақ модульдік ортада қолданылмауы тиіс болса, арнайы сүзгіні пайдаланыңыз (қараңыз: Модульдер→Рұқсат етілген жүйелік айнымалылар) немесе айнымалыға бос мән беріп, оны ортадан алып тастаңыз.

Үлгілік айнымалылар

Айнымалы Сипаттама
{root_dir} Open Server Panel түбірлік каталогы (толық жол)
{root_drive} Түбірлік каталог орналасқан диск
{root_path} Open Server Panel түбірлік каталогына жол
{terminal_codepage} Терминалдағы кодировка (қараңыз: Модульдер→Терминалдағы кодировка)
{time_zone} Etc/GMT форматындағы уақыт белдеуі (қараңыз: Модульдер→Уақыт белдеуі)

Үлгілік айнымалылардан бөлек, Windows ортасының кез келген айнымалыларын қолдануға болады, мысалы: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% және т.б.
