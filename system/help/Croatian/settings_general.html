Postavke programa

Pokretati zajedno s Windows
Omogućiti automatsko pokretanje Open Server Panel pri učitavanju operativnog sustava.
Odgoda
Odgoda pokretanja programa (u sekundama, od 0 do 60).

Omogućuje odgodu pokretanja aplikacije tijekom učitavanja zajedno s Windows kako bi se smanjilo ukupno opterećenje sustava. To je posebno korisno ako je potrebno pričekati potpunu inicijalizaciju vanjskih servisa ili mrežnih sučelja.
Provjeravati dostupnost novih verzija
Omogućiti provjeru ažuriranja Open Server Panel (potrebna je veza s internetom).
Omogućiti planer zadataka
Aktivirati ugrađeni planer zadataka. Ako je parametar onemogućen, nijedan zakazani zadatak neće se izvršavati, bez obzira na njihov status.
Koristiti datoteku HOSTS
Omogućiti zapisivanje domena u datoteku HOSTS.

Preporuke pri ograničenom pristupu datoteci HOSTS u organizaciji:

1. Konfigurirajte sve potrebne module i projekte.
2. Obratite se sistemskom administratoru radi deblokade HOSTS i fiksiranja njegovog stanja.
3. Nakon što administrator fiksira promjene, ovu opciju možete isključiti.

Važno: Ne isključujte ovaj parametar ako niste sigurni u posljedice!
Pokretati module s profilom projekta
Pokrenuti module uz istovremenu aktivaciju profila koji se podudara s imenom projekta.

Koristi se pri odabiru stavke izbornika «Omogućiti module projekta» kako bi se automatski aktivirao profil s istim imenom kao i trenutni projekt, ako takav postoji.
Ne isključivati module skrivenih projekata
Ne isključivati module skrivenih projekata pri odabiru stavke izbornika «Isključiti sve module». Pod "skrivenim" podrazumijevaju se oni projekti za koje je postavljena kategorija "hidden".

Prema zadanim postavkama naredba «Isključiti sve module» zaustavlja rad apsolutno svih modula, uključujući i one koje koriste skriveni servisni projekti (na primjer, PHPMyAdmin). Ova opcija omogućuje očuvanje funkcionalnosti skrivenih servisnih projekata, ne isključujući potrebne module za njih, dok će svi ostali moduli biti isključeni.
Jezik sučelja
Jezik korisničkog sučelja Open Server Panel.

Ako datoteka lokalizacije nedostaje ili sadrži pogreške, koristit će se engleski jezik.
Domena API-ja
Lokalna domena za API i web-sučelje (u razvoju)

Preporuka: Ako se koristi VPN ili proxy, dodajte ovu domenu u iznimke.
IP adresa API-ja
IPv4 adresa za API i web-sučelje (u razvoju).

Preporuka: Ako se koristi VPN ili proxy, dodajte ovu IP adresu u iznimke.
Port API-ja
Port koji se koristi za API i web-sučelje (u razvoju). Open Server Panel neće se moći pokrenuti ako je navedeni port već zauzet drugim programom.
Koristiti Windows Terminal
Omogućiti korištenje Windows Terminal umjesto standardnog komandnog sučelja.

Zahtjevi: Windows Terminal mora biti instaliran u sustavu i naveden u varijabli okruženja PATH.

Windows Terminal kao cmd.exe: Windows Terminal može zamijeniti cmd.exe i biti naveden u varijabli okruženja %COMSPEC% u novijim verzijama Windows. Ako je tako, ostavite ovu opciju uključenom.

Novi primjerci Windows Terminal: Ako Windows Terminal otvara nove prozore umjesto kartica, podesite ga ovako: Postavke→Pokretanje→Ponašanje novog primjerka→Pridruži se zadnje korištenom prozoru.
Kratki naslov projekta
Kada je ova opcija aktivirana, u naslovu prozora terminala prikazivat će se samo ime projekta umjesto detaljnog opisa okruženja.
Uključivati sistemsko okruženje u okruženje projekta
Koristiti okruženje sustava (System) u terminalu, čak i ako nije zadano u postavkama projekta. Sistemsko okruženje omogućuje korištenje programa instaliranih u sustavu (na primjer, git.exe ili ssh.exe).

Isključite ovu opciju samo u slučaju konflikata sa sistemskim softverom.
Podrška za ANSI
Omogućiti podršku za ANSI kodove za upravljanje bojama u terminalu.

Način "Automatski" (prema zadanim postavkama):
- Ispravak se primjenjuje samo na Windows 10 do verzije 1903 uključivo. U novijim verzijama Windows podrška za ANSI kodove već je ugrađena.
- Ispravak se ne primjenjuje na terminale koji podržavaju ANSI prema zadanim postavkama (na primjer, Windows Terminal).
Direktoriji za pretraživanje projekata
Popis direktorija u kojima će Open Server Panel tražiti projekte. Putanje odvajajte točkom sa zarezom (;).

Iznimke: Poddirektoriji node_modules i vendor se ignoriraju.
Dubina
Maksimalna dubina ugniježđivanja direktorija pri pretraživanju projekata.

Povećanje ove vrijednosti može usporiti pokretanje Open Server Panel ako navedeni direktoriji sadrže velik broj poddirektorija.
Maksimalna veličina datoteke dnevnika
Maksimalna veličina datoteke dnevnika u megabajtima. Pri prekoračenju navedene vrijednosti log-datoteka bit će ponovno stvorena pri sljedećem pokretanju programa.

Postavite vrijednost 0 kako biste čistili dnevnike pri svakom pokretanju programa.

Postavite vrijednost 100 MB kako biste u potpunosti onemogućili čišćenje dnevnika.
