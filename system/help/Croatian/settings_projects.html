Globalne postavke projekata

Parametri navedeni u ovom odjeljku koriste se ako u postavkama projekta nisu navedene druge vrijednosti.

HTTP
Određuje korišteni modul web-poslužitelja za projekte.
NODE
Navodi engine Node.js za pokretanje Node.js-aplikacija.

Instalacija Node.js: Prethodno instalirajte željenu verziju Node.js pomoću naredbe osp node <latest|lts|номер>.
PHP
Određuje korišteni modul PHP za obradu PHP-datoteka.
Omogući
Određuje zadano stanje projekta (uključen ili isključen).
Kodiranje terminala
Kodiranje terminala pri radu s okruženjem projekta.

Posebne vrijednosti:
- system: Koristi se sistemsko kodiranje.

Važno: Ako vrijednost nije zadana, pri formiranju konačnog okruženja projekta kodiranje terminala bit će postavljeno posljednjim priključenim okruženjem u kojem je zadano, na primjer, okruženjem modula PHP.
IP
Zadaje IP-adresu(e) koju koriste svi projekti bez individualnih postavki.

Ograničenje: Projekti koji koriste istu IP-adresu moraju raditi na jednoj verziji PHP-a.

Podrška za više IP-ova: Možete navesti više IP-adresa odvojenih razmakom, uključujući IPv6. U datoteci HOSTS domenama će biti dodijeljena prva navedena IP-adresa.

Automatsko dodjeljivanje: Ako ostavite polje prazno, IP-adresa će se dodjeljivati automatski.

Preporuke:
  • Automatsko upravljanje IP-adresama preporučuje se većini korisnika.
  • Ručno zadavanje IP-adrese koristite samo pri specifičnim zahtjevima mrežne konfiguracije.
HTTP
Određuje port za veze putem HTTP-a.
HTTPS
Određuje port za veze putem HTTPS-a.
TLS
Omogućuje ili onemogućuje podršku za TLS.
Datoteka certifikata
Navodi put do datoteke TLS-certifikata. Mogu se koristiti predložne varijable.

Dozvoljeni znakovi: A-Za-z0-9-+_.\:

Preporuka: Ostavite polje prazno za automatsko generiranje certifikata.
Datoteka ključa
Navodi put do datoteke TLS-ključa. Mogu se koristiti predložne varijable.

Dozvoljeni znakovi: A-Za-z0-9-+_.\:

Preporuka: Ostavite polje prazno za automatsko generiranje ključa.
IP-adresa (backend)
Navodi IP-adresu putem koje se ostvaruje povezivanje s poslužiteljskim dijelom (Backend).
Port (backend)
Određuje broj porta za povezivanje s poslužiteljskim dijelom (Backend).
Omogući (backend)
Omogućuje automatsko preusmjeravanje cjelokupnog dolaznog prometa (HTTP i HTTPS) projekta na poslužiteljski dio (Backend). Korisno za testiranje ili razvoj kada su frontend i backend odvojeni.
Katalog projekta
Navodi korijenski katalog projekta. Prelazak u ovaj katalog vrši se naredbom osp project <DOMAIN> istovremeno s aktivacijom okruženja projekta. Mogu se koristiti predložne varijable.

Dozvoljeni znakovi: A-Za-z0-9-+_.\:
Javni katalog
Određuje javni katalog projekta. Mogu se koristiti predložne varijable.

Dozvoljeni znakovi: A-Za-z0-9-+_.\:
Pseudonimi
Navodi dodatna naziva domena (aliasi) za projekt (odvojeni razmakom). Mogu se koristiti predložne varijable.

Ograničenje: Znak "*" nije podržan u Windows datoteci HOSTS i zahtijeva DNS konfiguraciju.
Okruženje projekta
Popis dodataka i modula (odvojeni razmakom) koji formiraju okruženje projekta.

HTTP, NODE i PHP: Okruženja ovih enginea priključuju se uvijek (ako su zadana za domenu) i ne zahtijevaju navođenje u ovom parametru.
Naredba za pokretanje projekta
Određuje naredbu za pokretanje projekta (npr. nodemon app.js). Mogu se koristiti predložne varijable.
URL projekta
URL koji se koristi pri otvaranju projekta Izbornik→Projekt→Otvori u pregledniku, kao i pri otvaranju domenih pseudonima projekta (aliase). Mogu se koristiti predložne varijable.

Primjena: Može se zadati URL administracijske ploče CMS-a.

Predložne varijable

Varijabla Opis
{backend_ip} IP-adresa povezivanja s poslužiteljskim dijelom (Backend)
{backend_port} Port povezivanja s poslužiteljskim dijelom (Backend)
{base_dir} Korijenski katalog projekta (gdje se nalazi katalog .osp)
{date_time} Trenutni datum/vrijeme (varijabla dostupna samo za naredbu pokretanja aplikacije projekta)
{host} Naziv domene (za internacionalizirane domene koristi se Punycode)
{host_decoded} Vidljivo ime domene (bez Punycodea)
{host_scheme} Shema zahtjeva prema projektu ("http" ili "https", ovisi o parametru TLS u postavkama projekta)
{http_port} Port zahtjeva prema projektu putem protokola HTTP
{https_port} Port zahtjeva prema projektu putem protokola HTTPS
{http_engine} Engine HTTP
{node_engine} Engine NODE
{php_engine} Engine PHP
{project_root} Korijenski katalog projekta
{web_root} Javni katalog projekta
{scheme_port} Port zahtjeva prema projektu (":{http_port}" ili ":{https_port}", ovisi o parametru TLS u postavkama projekta).

Ako {http_port} ili {https_port} ima standardnu vrijednost 80 ili 443, tada će {scheme_port} biti prazan.
{root_dir} Korijenski katalog Open Server Panel (puna putanja)
{root_drive} Disk korijenskog kataloga
{root_path} Put do korijenskog kataloga Open Server Panel
{terminal_codepage} Kodiranje konzole
