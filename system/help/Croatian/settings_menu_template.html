Stvaranje vlastitih stavki izbornika

  1. Dodajte novu sekciju s jedinstvenim identifikatorom [ID]
  2. Rasporedite sekcije željenim redoslijedom — to će odrediti redoslijed stavki u izborniku
  3. Spremite promjene i ponovno pokrenite Open Server Panel za primjenu promjena

Važne informacije

Prilikom stvaranja vlastitih stavki izbornika pazite da se identifikatori sekcija ne ponavljaju. To može dovesti do sukoba u radu izbornika.

Postavke stavki izbornika

Redoslijed sortiranja: Stavke izbornika sortiraju se istim redoslijedom kojim su raspoređene odgovarajuće sekcije u predlošku.

caption Naslov stavke izbornika. Podržava jezične konstante u formatu {lang_xxx}.

Zadano: nije postavljeno
category

Određuje položaj stavke izbornika u hijerarhiji. Podržava jednu razinu ugniježđenja (npr. "Moje Zabilješke\Posao").

Posebne kategorije:

  • projects, modules, addons - dodaje stavku u odgovarajući izbornik radnji
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - dodaje stavku za određeni element

Ako kategorija nije navedena, stavka se stvara u korijenskom izborniku.

Zadano: nije postavljeno

Zadano: nije postavljeno

Zadano: on | Vrijednosti: on, off

icon Ikona iz skupa Font Awesome Free (Solid/Regular/Brands).

Predlošci varijabli

U parametrima "command" i "work_directory" mogu se koristiti sljedeće predloške varijable:

Opće varijable

Varijabla Opis
{date_time} Trenutni datum/vrijeme (varijabla je dostupna samo za parametar "command")
{root_dir} Korijenski direktorij Open Server Panel (puna putanja)
{root_drive} Disk korijenskog direktorija
{root_path} Put do korijenskog direktorija Open Server Panel
{web_panel_url} URL adresa web-sučelja

Posebne varijable (samo za projects i projects\<имя_домена>)

Varijabla Opis
{base_dir} Osnovni direktorij projekta
{host} Naziv domene (Punycode)
{host_decoded} Vidljivo ime domene (bez Punycode)
{host_scheme} Shema zahtjeva prema projektu ("http" ili "https", ovisi o parametru TLS u postavkama projekta)
{http_port} Port zahtjeva prema projektu putem HTTP protokola
{https_port} Port zahtjeva prema projektu putem HTTPS protokola
{menu_caption} Naslov stavke izbornika (samo za kategoriju projects s need_alias=ON)
{http_engine} HTTP engine
{node_engine} Node.js engine
{php_engine} PHP engine
{project_root} Korijenski direktorij projekta
{base_url} URL projekta
{web_root} Javni direktorij projekta
{scheme_port} Port zahtjeva prema projektu (":{http_port}" ili ":{https_port}", ovisi o parametru TLS u postavkama projekta). Ako {http_port} ili {https_port} ima standardnu vrijednost 80 ili 443, tada {scheme_port} će biti prazan.
{app_start_command} Naredba za pokretanje aplikacije projekta (ako je postavljena)
{terminal_codepage} Kodna stranica konzole

Posebne varijable (samo za addons i addons\<имя_дополнения>)

Varijabla Opis
{addon_name} Naziv dodatka
{terminal_codepage} Kodna stranica konzole

Posebne varijable (samo za modules i modules\<имя_модуля>)

Varijabla Opis
{ip} IP adresa modula
{log_level} Razina zapisivanja grešaka
{module_name} Naziv modula
{port} Port modula
{profile_name} Naziv trenutačnog profila postavki modula
{query_log_level} Razina zapisivanja upita
{shell_command} Naredba pokretanja shell/cli ljuske modula (ako je postavljena)
{terminal_codepage} Kodna stranica konzole
{time_zone} Vremenska zona

Posebne vrijednosti naredbi

Naredba Opis
command_open_logs_viewer Otvoriti prozor za pregled dnevnika
command_open_idn_converter Otvoriti IDN pretvarač
command_open_options Otvoriti prozor postavki programa

Osim predložaka varijabli, mogu se koristiti bilo koje Windows varijable okruženja, na primjer: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% itd.

Primjer uporabe

[bookmark_1]

caption  = Google
category = Moje Zabilješke\Pretraživači
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opcije CMD.EXE

  • /c: Izvršiti naredbu i zatvoriti terminal.
  • /k: Izvršiti naredbu i ostaviti terminal otvorenim.
