Projektek globális beállításai

A jelen szakaszban megadott paraméterek akkor kerülnek felhasználásra, ha a projekt beállításaiban nincsenek más értékek megadva.

HTTP
Meghatározza a projektekhez használt webszerver-modult.
NODE
Megadja a Node.js engine-t a Node.js alkalmazások futtatásához.

Node.js telepítése: Előzetesen telepítse a szükséges Node.js verziót az osp node <latest|lts|номер> paranccsal.
PHP
Meghatározza a PHP-fájlok feldolgozásához használt PHP modult.
Engedélyezés
Meghatározza a projekt alapértelmezett állapotát (engedélyezve vagy letiltva).
Terminál kódolása
A terminál kódolása a projekt környezetében végzett munka során.

Speciális értékek:
- system: A rendszer kódolása kerül használatra.

Fontos: Ha az érték nincs megadva, a projekt végső környezetének kialakításakor a terminál kódolását az utoljára csatlakoztatott környezet állítja be, amelyben meg van adva, például a PHP modul környezete.
IP
Megadja az IP-címet/címeket, amelyet minden egyedi beállítás nélküli projekt használ.

Korlátozás: Az azonos IP-címet használó projekteknek ugyanazon a PHP verzión kell futniuk.

Több IP támogatása: Megadható több IP-cím szóközzel elválasztva, beleértve az IPv6-ot is. A HOSTS fájlban a domainekhez az első megadott IP kerül hozzárendelésre.

Automatikus hozzárendelés: Ha a mezőt üresen hagyja, az IP-cím automatikusan lesz hozzárendelve.

Ajánlások:
  • Az IP-címek automatikus kezelése a felhasználók többségének ajánlott.
  • Kézi IP-cím megadását csak speciális hálózati konfigurációs követelmények esetén használja.
HTTP
Meghatározza a HTTP kapcsolatok portját.
HTTPS
Meghatározza a HTTPS kapcsolatok portját.
TLS
Engedélyezi vagy letiltja a TLS támogatást.
Tanúsítvány fájl
Megadja a TLS tanúsítvány fájl elérési útját. Sablonváltozók használhatók.

Megengedett karakterek: A-Za-z0-9-+_.\:

Ajánlás: Hagyja üresen a mezőt a tanúsítványok automatikus generálásához.
Kulcs fájl
Megadja a TLS kulcs fájl elérési útját. Sablonváltozók használhatók.

Megengedett karakterek: A-Za-z0-9-+_.\:

Ajánlás: Hagyja üresen a mezőt a kulcs automatikus generálásához.
IP-cím (backend)
Megadja azt az IP-címet, amelyen a szerveroldali részhez (Backend) történik a csatlakozás.
Port (backend)
Meghatározza a port számát a szerveroldali részhez (Backend) való csatlakozáshoz.
Engedélyezés (backend)
Lehetővé teszi az összes bejövő projektforgalom (HTTP és HTTPS) automatikus továbbítását a szerveroldali részhez (Backend). Hasznos teszteléshez vagy fejlesztéshez, amikor a frontend és a backend szét van választva.
Projekt könyvtár
Megadja a projekt gyökérkönyvtárát. Ebbe a könyvtárba történik az átlépés az osp project <DOMAIN> paranccsal a projekt környezetének aktiválásával egyidejűleg. Sablonváltozók használhatók.

Engedélyezett karakterek: A-Za-z0-9-+_.\:
Nyilvános könyvtár
Megadja a projekt nyilvános könyvtárát. Sablonváltozók használhatók.

Engedélyezett karakterek: A-Za-z0-9-+_.\:
Aliasok
Megadja a projekthez tartozó további domain neveket (aliasok, szóközzel elválasztva). Sablonváltozók használhatók.

Korlátozás: A "*" karaktert a Windows HOSTS fájl nem támogatja, és DNS beállítást igényel.
Projekt környezete
Kiegészítők és modulok felsorolása (szóközzel elválasztva), amelyek a projekt környezetét alkotják.

HTTP, NODE és PHP: E motorok környezetei mindig csatlakoznak (ha meg vannak adva a domainhez), és nem szükséges megadni ebben a paraméterben.
A projekt indítási parancsa
Meghatározza a projekt indításához használt parancsot (például nodemon app.js). Sablonváltozók használhatók.
A projekt URL-je
Az URL, amelyet a projekt megnyitásakor használ a Menü→Projekt→Megnyitás a böngészőben, valamint a projekt domain aliasainak megnyitásakor. Sablonváltozók használhatók.

Alkalmazás: Megadható például egy CMS adminisztrációs panel URL-je.

Sablonváltozók

Változó Leírás
{backend_ip} IP-cím a szerveroldali részhez (Backend) való csatlakozáshoz
{backend_port} Port a szerveroldali részhez (Backend) való csatlakozáshoz
{base_dir} A projekt gyökérkönyvtára (ahol a .osp könyvtár található)
{date_time} Aktuális dátum/idő (a változó csak a projekt alkalmazásindító parancsához érhető el)
{host} Domain név (nemzetközi domaineknél Punycode kerül használatra)
{host_decoded} Látható domain név (Punycode nélkül)
{host_scheme} A projekthez intézett kérés sémája ("http" vagy "https", a projekt beállításaiban szereplő TLS paramétertől függ)
{http_port} Port a projekthez intézett HTTP protokollú kéréshez
{https_port} Port a projekthez intézett HTTPS protokollú kéréshez
{http_engine} HTTP engine
{node_engine} NODE engine
{php_engine} PHP engine
{project_root} A projekt gyökérkönyvtára
{web_root} A projekt nyilvános könyvtára
{scheme_port} A projekthez intézett kérés portja (":{http_port}" vagy ":{https_port}", a projekt beállításaiban szereplő TLS paramétertől függ).

Ha a {http_port} vagy {https_port} standard értéke 80 vagy 443, akkor a {scheme_port} üres lesz.
{root_dir} Az Open Server Panel gyökérkönyvtára (teljes elérési út)
{root_drive} A gyökérkönyvtár meghajtója
{root_path} Az Open Server Panel gyökérkönyvtárának elérési útja
{terminal_codepage} Konzol kódolása
