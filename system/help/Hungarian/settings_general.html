Programbeállítások

Indítás a Windowszal együtt
Az Open Server Panel automatikus indításának engedélyezése az operációs rendszer betöltésekor.
Késleltetés
A program indításának késleltetése (másodpercben, 0-tól 60-ig).

Lehetővé teszi az alkalmazás indításának elhalasztását a Windowszal együtt történő betöltés során, hogy csökkentse a rendszer általános terhelését. Különösen hasznos, ha meg kell várni a külső szolgáltatások vagy hálózati interfészek teljes inicializálását.
Új verziók ellenőrzése
Az Open Server Panel frissítéseinek ellenőrzésének engedélyezése (Internetkapcsolat szükséges).
Feladatütemező engedélyezése
A beépített feladatütemező aktiválása. Ha a paraméter ki van kapcsolva, semmilyen ütemezett feladat nem fog végrehajtódni, függetlenül az állapotuktól.
HOSTS fájl használata
Domainnevek írásának engedélyezése a HOSTS fájlba.

Ajánlások, ha a szervezetben korlátozott a hozzáférés a HOSTS fájlhoz:

1. Állítson be minden szükséges modult és projektet.
2. Forduljon a rendszergazdához a HOSTS feloldásához és az állapotának rögzítéséhez.
3. A rendszergazda általi módosításrögzítés után ez az opció kikapcsolható.

Fontos: Ne kapcsolja ki ezt a paramétert, ha nem biztos a következményekben!
Modulok indítása a projekt profiljával
Modulok indítása a projektnévvel megegyező profil egyidejű aktiválásával.

A „Projekt moduljainak bekapcsolása” menüpont használatakor automatikusan aktiválja az aktuális projekttel azonos nevű profilt, ha létezik ilyen.
Rejtett projektek moduljainak ne kikapcsolása
Ne kapcsolja ki a rejtett projektek moduljait a „Minden modul kikapcsolása” menüpont kiválasztásakor. „Rejtett” alatt azokat a projekteket értjük, amelyeknél a kategória „hidden”.

Alapértelmezetten a „Minden modul kikapcsolása” parancs minden modult leállít, beleértve azokat is, amelyeket rejtett szolgáltató projektek használnak (például PHPMyAdmin). Ez az opció lehetővé teszi a rejtett szolgáltató projektek működőképességének megőrzését azáltal, hogy nem kapcsolja ki a számukra szükséges modulokat, miközben az összes többi modul ki lesz kapcsolva.
Felhasználói felület nyelve
Az Open Server Panel felhasználói felületének nyelve.

Ha a lokalizációs fájl hiányzik vagy hibákat tartalmaz, az angol nyelv kerül használatra.
API domain
Helyi domain az API-hoz és a webes felülethez (fejlesztés alatt)

Ajánlás: Ha VPN-t vagy proxy-t használ, adja hozzá ezt a domaint a kivételekhez.
API IP-címe
IPv4-cím az API-hoz és a webes felülethez (fejlesztés alatt).

Ajánlás: Ha VPN-t vagy proxy-t használ, adja hozzá ezt az IP-címet a kivételekhez.
API port
Az API és a webes felület számára használt port (fejlesztés alatt). Az Open Server Panel nem tud elindulni, ha a megadott portot már egy másik alkalmazás használja.
Windows Terminal használata
A Windows Terminal használatának engedélyezése az alapértelmezett parancsinterfész helyett.

Követelmények: A Windows Terminalnak telepítve kell lennie a rendszerben, és szerepelnie kell a PATH környezeti változóban.

Windows Terminal mint cmd.exe: A Windows Terminal helyettesítheti a cmd.exe-t, és bekerülhet a %COMSPEC% környezeti változóba a Windows újabb verzióiban. Ha így van, hagyja ezt az opciót bekapcsolva.

Windows Terminal új példányai: Ha a Windows Terminal új ablakokat nyit fülek helyett, állítsa be így: Beállítások→Indítás→Új példány viselkedése→Csatlakozás az utoljára használt ablakhoz.
Rövid projektcím
Ennek az opciónak az aktiválásakor a terminálablak címében csak a projekt neve jelenik meg a környezet részletes leírása helyett.
A rendszerkörnyezet bevonása a projekt környezetébe
A rendszer (System) környezetének használata a terminálban akkor is, ha az nincs megadva a projekt beállításaiban. A rendszerkörnyezet lehetővé teszi a rendszerben telepített programok használatát (például git.exe vagy ssh.exe).

Csak akkor kapcsolja ki ezt az opciót, ha ütközések lépnek fel a rendszer szoftverével.
ANSI támogatás
ANSI-kódok támogatásának engedélyezése a terminál színkezeléséhez.

„Automatikus” mód (alapértelmezett):
- A javítás csak a Windows 10 1903-as verziójáig bezárólag kerül alkalmazásra. Az újabb Windows verziókban az ANSI-kódok támogatása már be van építve.
- A javítás nem kerül alkalmazásra azokra a terminálokra, amelyek alapértelmezetten támogatják az ANSI-t (például Windows Terminal).
Projektkeresési könyvtárak
Azoknak a könyvtáraknak a listája, amelyekben az Open Server Panel projekteket fog keresni. Az elérési utakat pontosvesszővel (;) válassza el.

Kivételek: A node_modules és a vendor alkönyvtárak figyelmen kívül lesznek hagyva.
Mélység
A projektkeresés során a könyvtárak maximális beágyazási mélysége.

Ennek az értéknek a növelése lelassíthatja az Open Server Panel indítását, ha a megadott könyvtárakban nagy számú alkönyvtár található.
Naplófájl maximális mérete
A naplófájl maximális mérete megabájtban. Ha a megadott érték túllépésre kerül, a naplófájl a program következő indításakor újralétrejön.

Állítson be 0 értéket a naplók minden programindításkor történő törléséhez.

Állítson be 100 MB-ot a naplók törlésének teljes kikapcsolásához.
