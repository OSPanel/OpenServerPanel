Глобальні налаштування проєктів

Параметри, задані в цьому розділі, використовуються у випадку, якщо в налаштуваннях проєкту не вказані інші значення.

Nginx
Визначає використовувану версію веб-сервера Nginx для проєктів.
Node
Вказує рушій Node.js для запуску Node.js-додатків.

Встановлення Node.js: Попередньо встановіть потрібну версію Node.js за допомогою додатка NVM.
PHP
Визначає використовуваний рушій PHP для обробки PHP-файлів.

Важливо: Модулі PHP без префікса FCGI являють собою інтегровані модулі Apache+PHP.
Увімкнути
Визначає стан проєкту за замовчуванням (увімкнений чи вимкнений).
Кодування терміналу
Кодування терміналу при роботі з середовищем проєкту.

Спеціальні значення:
- system: Використовується системне кодування.

Важливо: Якщо значення не задано, при формуванні підсумкового середовища проєкту кодування терміналу буде встановлено останнім підключеним середовищем, в якому воно задано, наприклад, середовищем модуля PHP.
IP
Задає IP-адресу(и), що використовується всіма проєктами без індивідуальних налаштувань.

Обмеження: Проєкти, що використовують одну й ту саму IP-адресу, повинні працювати на одній версії PHP.

Підтримка кількох IP: Можна вказати кілька IP-адрес через пробіл, включаючи IPv6. У файлі HOSTS доменам буде призначено перший вказаний IP.

Автоматичне призначення: Якщо залишити поле порожнім, IP-адреса буде призначатися автоматично.

Рекомендації:
  • Автоматичне керування IP-адресами рекомендується більшості користувачів.
  • Ручне задання IP-адреси слід використовувати лише при специфічних вимогах мережевої конфігурації.
HTTP
Визначає порт для з'єднань по HTTP.
HTTPS
Визначає порт для з'єднань по HTTPS.
SSL
Вмикає або вимикає підтримку SSL для проєктів без індивідуальних налаштувань.
Файл сертифіката
Вказує шлях до файлу SSL-сертифіката. Можна використовувати шаблонні змінні.

Допустимі символи: A-Za-z0-9-+_.\:

Рекомендація: Залиште поле порожнім для автоматичної генерації сертифікатів.
Файл ключа
Вказує шлях до файлу SSL-ключа. Можна використовувати шаблонні змінні.

Допустимі символи: A-Za-z0-9-+_.\:

Рекомендація: Залиште поле порожнім для автоматичної генерації ключа.
IP-адреса (backend)
Вказує IP-адресу, за якою здійснюється підключення до серверної частини (Backend).
Порт (backend)
Визначає номер порту для підключення до Backend.
Увімкнути (backend)
Дозволяє автоматично направляти весь вхідний трафік (HTTP і HTTPS) проєкту на серверну частину (Backend). Корисно для тестування або розробки, коли фронтенд і бекенд розділені.
Каталог проєкту
Вказує кореневий каталог проєкту. Перехід у цей каталог здійснюється за командою osp project <DOMAIN> одночасно з активацією середовища проєкту. Можна використовувати шаблонні змінні.

Дозволені символи: A-Za-z0-9-+_.\:
Публічний каталог
Визначає публічний каталог проєкту. Можна використовувати шаблонні змінні.

Дозволені символи: A-Za-z0-9-+_.\:
Псевдоніми
Вказує додаткові доменні імена (аліаси) для проєкту (через пробіл). Можна використовувати шаблонні змінні.

Піддомени: Якщо псевдонім не містить крапку, він розглядається як піддомен (наприклад, "www" -> "www.test.local").

Обмеження: Символ "*" не підтримується у Windows файлом HOSTS і вимагає налаштування DNS.
Середовище проєкту
Перелік додатків і модулів (через пробіл), що формують оточення проєкту.

Модулі PHP/Nginx/Node.js: Середовища цих модулів підключаються завжди (якщо задані для домену) і не потребують вказівки в цьому параметрі.
Команда запуску проєкту
Визначає команду для запуску проєкту (наприклад, nodemon app.js). Можна використовувати шаблонні змінні.
URL проєкту
URL, що відкривається при виборі Відкрити проєкт у браузері в Open Server Panel. Можна використовувати шаблонні змінні.

Застосування: Можна задати URL панелі адміністрування CMS.

Шаблонні змінні

Змінна Опис
{backend_ip} IP-адреса підключення до серверної частини (Backend)
{backend_port} Порт підключення до серверної частини (Backend)
{base_dir} Кореневий каталог проєкту (де знаходиться каталог .osp)
{host} Ім'я домену (для інтернаціоналізованих доменів використовується Punycode)
{host_decoded} Видиме ім'я домену (без Punycode)
{host_scheme} Схема запиту до проєкту ("http" або "https", залежить від параметра SSL у налаштуваннях проєкту)
{http_port} Порт запиту до проєкту за протоколом HTTP
{https_port} Порт запиту до проєкту за протоколом HTTPS
{nginx_engine} Рушій Nginx
{node_engine} Рушій Node.js
{php_engine} Рушій PHP
{project_dir} Кореневий каталог проєкту
{public_dir} Публічний каталог проєкту
{scheme_port} Порт запиту до проєкту (":{http_port}" або ":{https_port}", залежить від параметра SSL у налаштуваннях проєкту).

Якщо {http_port} або {https_port} має стандартне значення 80 або 443, то {scheme_port} буде порожнім.
{root_dir} Кореневий каталог Open Server Panel (повний шлях)
{root_drive} Диск кореневого каталогу
{root_path} Шлях до кореневого каталогу Open Server Panel
{terminal_codepage} Кодування консолі
