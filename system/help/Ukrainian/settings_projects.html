Глобальні налаштування проектів

Параметри, зазначені в даному розділі, використовуються у випадку, якщо в налаштуваннях проекту не вказані інші значення.

Nginx
Визначає використовувану версію веб-сервера Nginx для проектів.
Node
Вказує рушій Node.js для запуску Node.js-додатків.

Встановлення Node.js: Попередньо встановіть потрібну версію Node.js за допомогою доповнення NVM.
PHP
Визначає використовуваний рушій PHP для обробки PHP-файлів.

Важливо: Модулі PHP без префіксу FCGI являють собою інтегровані модулі Apache+PHP.
Увімкнути
Визначає стан проекту за замовчуванням (увімкнений або вимкнений).
Кодування терміналу
Кодування терміналу при роботі з середовищем проекту.

Спеціальні значення:
- system: Використовується системне кодування.
- (порожнє значення): Кодування терміналу залишається незмінним.

Важливо: Якщо значення не задано, при формуванні підсумкового середовища проекту кодування терміналу буде встановлено останнім підключеним середовищем, в якому воно задано, наприклад, середовищем модуля PHP.
IP
Задає IP-адресу(и), що використовується всіма проектами без індивідуальних налаштувань.

Обмеження: Проекти, що використовують одну й ту ж IP-адресу, повинні працювати на одній версії PHP.

Підтримка кількох IP: Можна вказати кілька IP-адрес через пробіл, включаючи IPv6. У файлі HOSTS доменам буде призначено перший вказаний IP.

Автоматичне призначення: Якщо залишити поле порожнім, IP-адреса буде призначатися автоматично.

Рекомендації:
  • Автоматичне керування IP-адресами рекомендується більшості користувачів.
  • Ручне задання IP-адреси слід використовувати тільки при специфічних вимогах мережевої конфігурації.
HTTP
Визначає порт для з'єднань по HTTP.
HTTPS
Визначає порт для з'єднань по HTTPS.
SSL
Вмикає або вимикає підтримку SSL для проектів без індивідуальних налаштувань.
Файл сертифіката
Вказує шлях до файлу SSL-сертифіката. Можна використовувати шаблонні змінні.

Допустимі символи: A-Za-z0-9-+_.\:

Рекомендація: Залиште поле порожнім для автоматичної генерації сертифікатів.
Файл ключа
Вказує шлях до файлу SSL-ключа. Можна використовувати шаблонні змінні.

Допустимі символи: A-Za-z0-9-+_.\:

Рекомендація: Залиште поле порожнім для автоматичної генерації ключа.
Каталог проекту
Вказує кореневий каталог проекту. Перехід у цей каталог здійснюється за командою osp project <DOMAIN> одночасно з активацією середовища проекту. Можна використовувати шаблонні змінні.

Дозволені символи: A-Za-z0-9-+_.\:
Публічний каталог
Визначає публічний каталог проекту. Можна використовувати шаблонні змінні.

Дозволені символи: A-Za-z0-9-+_.\:
Псевдоніми
Вказує додаткові доменні імена (аліаси) для проекту (через пробіл). Можна використовувати шаблонні змінні.

Піддомени: Якщо псевдонім не містить крапку, він розглядається як піддомен (наприклад, "www" -> "www.test.local").

Обмеження: Символ "*" не підтримується у Windows файлом HOSTS і вимагає налаштування DNS.
Середовище проекту
Перелік доповнень і модулів (через пробіл), що формують оточення проекту.

Модулі PHP/Nginx/Node.js: Середовища цих модулів підключаються завжди (якщо задані для домену) і не вимагають зазначення в цьому параметрі.
Команда запуску проекту
Визначає команду для запуску проекту (наприклад, nodemon app.js). Можна використовувати шаблонні змінні.
URL проекту
URL, що відкривається при виборі Відкрити проект у браузері в Open Server Panel. Можна використовувати шаблонні змінні.

Застосування: Можна задати URL панелі адміністрування CMS.

Шаблонні змінні

Змінна Опис
{base_dir} Кореневий каталог проекту (де знаходиться каталог .osp)
{host} Ім'я домену (для інтернаціоналізованих доменів використовується Punycode)
{host_decoded} Видиме ім'я домену (без Punycode)
{host_scheme} Схема запиту до проекту ("http" або "https", залежить від параметра SSL в налаштуваннях проекту)
{http_port} Порт запиту до проекту за протоколом HTTP
{https_port} Порт запиту до проекту за протоколом HTTPS
{nginx_engine} Рушій Nginx
{node_engine} Рушій Node.js
{php_engine} Рушій PHP
{project_dir} Кореневий каталог проекту
{public_dir} Публічний каталог проекту
{scheme_port} Порт запиту до проекту (":{http_port}" або ":{https_port}", залежить від параметра SSL в налаштуваннях проекту).

Якщо {http_port} або {https_port} має стандартне значення 80 або 443, то {scheme_port} буде порожнім.
{root_dir} Кореневий каталог Open Server Panel (повний шлях)
{root_drive} Диск кореневого каталогу
{root_path} Шлях до кореневого каталогу Open Server Panel
{terminal_codepage} Кодування консолі
