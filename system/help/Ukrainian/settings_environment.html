Глобальні змінні середовища модулів

У цьому розділі можна задати глобальні змінні середовища для модулів.

Ці змінні діють лише в середовищі модулів і не впливають на системні змінні або середовище проєктів.

У значеннях дозволяється використання шаблонних змінних.

Якщо змінна присутня в системному середовищі, але не повинна використовуватися в середовищі модулів, скористайтеся спеціальним фільтром (див. Модулі→Дозволені системні змінні) або видаліть змінну із середовища, задавши їй порожнє значення.

Шаблонні змінні

Змінна Опис
{root_dir} Кореневий каталог Open Server Panel (повний шлях)
{root_drive} Диск кореневого каталогу
{root_path} Шлях до кореневого каталогу Open Server Panel
{terminal_codepage} Кодування в терміналі (див. Модулі→Кодування в терміналі)
{time_zone} Часовий пояс у форматі Etc/GMT (див. Модулі→Часовий пояс)

Окрім шаблонних змінних, можна використовувати будь-які змінні середовища Windows, наприклад: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% тощо.
