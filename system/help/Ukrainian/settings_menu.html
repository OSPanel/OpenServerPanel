Налаштування меню

Тема оформлення
Тема оформлення для іконок меню.
Розмір шрифту
Розмір шрифту меню в пікселях. Опція дозволяє задати розмір шрифту меню незалежно від системних налаштувань.

Встановіть повзунок у мінімальне значення 12px для вимкнення функції контролю розміру шрифту (буде використано системний розмір).
Показувати значок в області сповіщень
Показувати значок програми в області сповіщень Windows.

Вимкнення: Вимкніть цю опцію, якщо ви запускаєте Open Server Panel в середовищі Windows Server Core або використовуєте тип автозапуску, що не вимагає входу користувача Windows (Планувальник завдань Windows→Запуск при завантаженні комп'ютера).
Показувати значки для пунктів меню
Показувати значки в меню програми. Значки не відображаються якщо увімкнена системна відрисовка.
Увімкнути системну відрисовку
Вмикайте дану опцію тільки при необхідності забезпечення сумісності з програмами екранного доступу (скрін-рідерами).
Показувати вертикальний роздільник
При увімкненні даної опції іконки в меню програми будуть відокремлені вертикальним роздільником.
Не групувати списки з одного елемента
Не групувати списки, що містять тільки один елемент.
Доповнення: показувати
Показувати меню доповнень.
Доповнення: групувати
Групувати доповнення в меню.
Доповнення: вкладене меню
Показувати меню доповнень в окремому підменю.
Доповнення: показувати роздільник
Показувати роздільну лінію після меню доповнень.
Модулі: показувати
Показувати меню керування модулями.
Модулі: групувати
Групувати модулі в меню.
Модулі: вкладене меню
Показувати меню модулів в окремому підменю.
Модулі: показувати роздільник
Показувати роздільну лінію після меню модулів.
Проекти: показувати
Показувати меню керування проектами.
Проекти: групувати
Групувати проекти за доменною зоною в меню.
Проекти: вкладене меню
Показувати меню проектів в окремому підменю.
Проекти: показувати роздільник
Показувати роздільну лінію після меню проектів.
