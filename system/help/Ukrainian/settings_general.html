Налаштування програми

Запускати разом з Windows
Увімкнути автозапуск Open Server Panel при завантаженні операційної системи.
Перевіряти наявність нових версій
Увімкнути перевірку оновлень Open Server Panel (потрібне підключення до Інтернету).
Увімкнути планувальник завдань
Активувати вбудований планувальник завдань. Якщо параметр вимкнений, жодні заплановані завдання не будуть виконуватися, незалежно від їх статусу.
Використовувати файл HOSTS
Увімкнути запис доменних імен у файл HOSTS.

Рекомендації при обмеженому доступі до файлу HOSTS в організації:

1. Налаштуйте всі необхідні модулі та проекти.
2. Зверніться до системного адміністратора для розблокування HOSTS і фіксації його стану.
3. Після фіксації змін адміністратором можна вимкнути цю опцію.

Важливо: Не вимикайте цей параметр, якщо не впевнені в наслідках!
Мова інтерфейсу
Мова користувацького інтерфейсу Open Server Panel.

Якщо файл локалізації відсутній або містить помилки, буде використовуватися англійська мова.
Домен API
Локальний домен для API та веб-інтерфейсу (в розробці)

Рекомендація: Якщо використовується VPN або проксі, додайте цей домен у винятки.
IP-адреса API
IPv4-адреса для API та веб-інтерфейсу (в розробці).

Рекомендація: Якщо використовується VPN або проксі, додайте цю IP-адресу у винятки.
Порт API
Порт, що використовується для API та веб-інтерфейсу (в розробці). Open Server Panel не запуститься, якщо вказаний порт уже зайнятий.
Використовувати Windows Terminal
Увімкнути використання Windows Terminal замість стандартного командного інтерфейсу.

Вимоги: Windows Terminal повинен бути встановлений у системі і прописаний у змінній середовища PATH.

Windows Terminal як cmd.exe: У нових версіях Windows термінал Windows Terminal може замінювати cmd.exe і бути прописаним у змінній середовища %COMSPEC%. Якщо це так, залиште цю опцію увімкненою.

Нові екземпляри Windows Terminal: Якщо Windows Terminal відкриває нові вікна замість вкладок, налаштуйте його так: Параметри→Запуск→Поведінка нового екземпляра→Приєднувати до останнього використаного вікна.
Короткий заголовок проекту
При активації цієї опції в заголовку вікна терміналу буде відображатися тільки ім'я проекту замість детального опису.
Використовувати системне середовище для проектів
Використовувати середовище системи (System) в терміналі, навіть якщо воно не задане в налаштуваннях проекту. Системне середовище дозволяє використовувати програми, встановлені в системі (наприклад, git.exe або ssh.exe).

Вимикайте цю опцію тільки при виникненні конфліктів із системним ПЗ.
Підтримка ANSI
Увімкнути підтримку ANSI-кодів для керування кольорами в терміналі.

Режим "Автоматично" (за замовчуванням):
- Виправлення застосовується тільки до Windows 7, 8 і Windows 10 (до версії 1903 включно). У новіших версіях Windows підтримка ANSI-кодів уже вбудована.
- Виправлення не застосовується для терміналів, що підтримують ANSI за замовчуванням (наприклад, Windows Terminal).
Каталоги для пошуку проектів
Список директорій, в яких Open Server Panel шукатиме проекти. Розділяйте шляхи крапкою з комою (;).

Винятки: Підкаталоги node_modules і vendor ігноруються.
Глибина
Максимальна глибина вкладеності каталогів при пошуку проектів.

Збільшення цього значення може сповільнити запуск Open Server Panel, якщо в зазначених каталогах міститься велика кількість підкаталогів.
Максимальний розмір файлу журналу
Максимальний розмір файлу журналу в мегабайтах. При перевищенні зазначеного значення лог-файл буде пересотворений при наступному запуску програми.

Встановіть значення 0, щоб очищати лог-файли при кожному запуску програми.

Встановіть значення 100 МБ, щоб повністю вимкнути очищення лог-файлів.
