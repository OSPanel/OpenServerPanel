Налаштування програми

Запускати разом з Windows
Увімкнути автозапуск Open Server Panel при завантаженні операційної системи.
Затримка
Затримка запуску програми (в секундах, від 0 до 60).

Дозволяє відкласти старт додатка, щоб зменшити навантаження на систему при запуску. Це особливо корисно, якщо потрібно дочекатися повної ініціалізації сторонніх сервісів або мережевих інтерфейсів.
Перевіряти наявність нових версій
Увімкнути перевірку оновлень Open Server Panel (потрібне підключення до Інтернету).
Увімкнути планувальник завдань
Активувати вбудований планувальник завдань. Якщо параметр вимкнено, жодні заплановані завдання не будуть виконуватися, незалежно від їхнього статусу.
Використовувати файл HOSTS
Увімкнути запис доменних імен у файл HOSTS.

Рекомендації при обмеженому доступі до файлу HOSTS в організації:

1. Налаштуйте всі необхідні модулі та проекти.
2. Зверніться до системного адміністратора для розблокування HOSTS та фіксації його стану.
3. Після фіксації змін адміністратором можна вимкнути цю опцію.

Важливо: Не вимикайте цей параметр, якщо не впевнені в наслідках!
Запускати модулі з профілем проекту
Запускати модулі з одночасною активацією профілю, що збігається з іменем проекту.

Використовується при виборі пункту меню «Увімкнути модулі проекту», щоб автоматично активувати профіль з тим самим іменем, що й у поточного проекту, якщо такий існує.
Не вимикати модулі прихованих проектів
Не відключати модулі прихованих проектів при виборі пункту меню "Вимкнути всі модулі".

За замовчуванням команда "Вимкнути всі модулі" зупиняє роботу абсолютно всіх модулів, включаючи ті, які використовуються службовими проектами (наприклад, PHPMyAdmin). Дана опція дозволяє зберегти працездатність прихованих службових проектів, не відключаючи необхідні для них модулі, в той час як всі інші модулі будуть вимкнені.
Мова інтерфейсу
Мова користувацького інтерфейсу Open Server Panel.

Якщо файл локалізації відсутній або містить помилки, буде використовуватися англійська мова.
Домен API
Локальний домен для API та веб-інтерфейсу (в розробці)

Рекомендація: Якщо використовується VPN або проксі, додайте цей домен до винятків.
IP-адреса API
IPv4-адреса для API та веб-інтерфейсу (в розробці).

Рекомендація: Якщо використовується VPN або проксі, додайте цю IP-адресу до винятків.
Порт API
Порт, що використовується для API та веб-інтерфейсу (в розробці). Open Server Panel не зможе запуститися, якщо вказаний порт вже використовується іншим додатком.
Використовувати Windows Terminal
Увімкнути використання Windows Terminal замість стандартного командного інтерфейсу.

Вимоги: Windows Terminal має бути встановлений у системі та вказаний у змінній середовища PATH.

Windows Terminal як cmd.exe: Windows Terminal може замінювати собою cmd.exe і бути вказаним у змінній середовища %COMSPEC% у нових версіях Windows. Якщо це так, залиште цю опцію увімкненою.

Нові екземпляри Windows Terminal: Якщо Windows Terminal відкриває нові вікна замість вкладок, налаштуйте його так: Параметри→Запуск→Поведінка нового екземпляра→Приєднувати до останнього використаного вікна.
Короткий заголовок проекту
При активації цієї опції в заголовку вікна терміналу відображатиметься лише ім'я проекту замість детального опису.
Включати системне середовище в оточення проекту
Використовувати середовище системи (System) в терміналі, навіть якщо воно не задане в налаштуваннях проекту. Системне середовище дозволяє використовувати програми, встановлені в системі (наприклад, git.exe або ssh.exe).

Вимикайте цю опцію лише при виникненні конфліктів із системним ПЗ.
Підтримка ANSI
Увімкнути підтримку ANSI-кодів для керування кольорами в терміналі.

Режим "Автоматично" (за замовчуванням):
- Виправлення застосовується тільки до Windows 7, 8 та Windows 10 (до версії 1903 включно). У новіших версіях Windows підтримка ANSI-кодів вже вбудована.
- Виправлення не застосовується для терміналів, що підтримують ANSI за замовчуванням (наприклад, Windows Terminal).
Каталоги для пошуку проектів
Список директорій, в яких Open Server Panel буде шукати проекти. Розділяйте шляхи крапкою з комою (;).

Виключення: Підкаталоги node_modules і vendor ігноруються.
Глибина
Максимальна глибина вкладеності каталогів при пошуку проектів.

Збільшення цього значення може уповільнити запуск Open Server Panel, якщо у вказаних каталогах міститься велика кількість підкаталогів.
Максимальний розмір файлу журналу
Максимальний розмір файлу журналу в мегабайтах. При перевищенні вказаного значення лог-файл буде перестворено при наступному запуску програми.

Встановіть значення 0, щоб очищати лог-файли при кожному запуску програми.

Встановіть значення 100 МБ, щоб повністю вимкнути очищення лог-файлів.
