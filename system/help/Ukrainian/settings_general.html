Налаштування програми

Запускати разом із Windows
Увімкнути автозапуск Open Server Panel під час завантаження операційної системи.
Затримка
Затримка запуску програми (у секундах, від 0 до 60).

Дозволяє відкласти старт застосунку під час завантаження разом із Windows, щоб зменшити загальне навантаження на систему. Це особливо корисно, якщо потрібно дочекатися повної ініціалізації сторонніх сервісів або мережевих інтерфейсів.
Перевіряти наявність нових версій
Увімкнути перевірку оновлень Open Server Panel (потрібне підключення до Інтернету).
Увімкнути планувальник завдань
Активувати вбудований планувальник завдань. Якщо параметр вимкнено, жодні заплановані завдання не виконуватимуться, незалежно від їхнього статусу.
Використовувати файл HOSTS
Увімкнути запис доменних імен у файл HOSTS.

Рекомендації за обмеженого доступу до файлу HOSTS в організації:

1. Налаштуйте всі необхідні модулі та проєкти.
2. Зверніться до системного адміністратора для розблокування HOSTS і фіксації його стану.
3. Після фіксації змін адміністратором можна вимкнути цю опцію.

Важливо: Не вимикайте цей параметр, якщо не впевнені в наслідках!
Запускати модулі з профілем проєкту
Запускати модулі з одночасною активацією профілю, що збігається з назвою проєкту.

Використовується під час вибору пункту меню «Увімкнути модулі проєкту», щоб автоматично активувати профіль із такою ж назвою, як у поточного проєкту, якщо такий існує.
Не вимикати модулі прихованих проєктів
Не вимикати модулі прихованих проєктів під час вибору пункту меню «Вимкнути всі модулі». Під "прихованими" маються на увазі ті проєкти, для яких задано категорію "hidden".

Типово команда «Вимкнути всі модулі» зупиняє роботу абсолютно всіх модулів, включно з тими, які використовуються прихованими службовими проєктами (наприклад, PHPMyAdmin). Ця опція дозволяє зберегти працездатність прихованих службових проєктів, не вимикаючи необхідні для них модулі, тоді як усі інші модулі будуть вимкнені.
Мова інтерфейсу
Мова користувацького інтерфейсу Open Server Panel.

Якщо файл локалізації відсутній або містить помилки, буде використовуватися англійська мова.
Домен API
Локальний домен для API та веб-інтерфейсу (в розробці)

Рекомендація: Якщо використовується VPN або проксі, додайте цей домен до винятків.
IP-адреса API
IPv4-адреса для API та веб-інтерфейсу (в розробці).

Рекомендація: Якщо використовується VPN або проксі, додайте цю IP-адресу до винятків.
Порт API
Порт, що використовується для API та веб-інтерфейсу (в розробці). Open Server Panel не зможе запуститися, якщо вказаний порт уже використовується іншим застосунком.
Використовувати Windows Terminal
Увімкнути використання Windows Terminal замість стандартного командного інтерфейсу.

Вимоги: Windows Terminal має бути встановлений у системі та прописаний у змінній середовища PATH.

Windows Terminal як cmd.exe: Windows Terminal може заміщувати cmd.exe та бути прописаним у змінній середовища %COMSPEC% у нових версіях Windows. Якщо це так, залиште цю опцію увімкненою.

Нові екземпляри Windows Terminal: Якщо Windows Terminal відкриває нові вікна замість вкладок, налаштуйте його так: Параметри→Запуск→Поведінка нового екземпляра→Приєднувати до останнього використаного вікна.
Короткий заголовок проєкту
Під час активації цієї опції в заголовку вікна термінала відображатиметься лише назва проєкту замість докладного опису середовища.
Включати системне середовище в оточення проєкту
Використовувати середовище системи (System) у терміналі, навіть якщо воно не задане в налаштуваннях проєкту. Системне середовище дозволяє використовувати програми, встановлені в системі (наприклад, git.exe або ssh.exe).

Вимикайте цю опцію лише у разі виникнення конфліктів із системним ПЗ.
Підтримка ANSI
Увімкнути підтримку ANSI-кодів для керування кольорами в терміналі.

Режим "Автоматично" (типово):
- Виправлення застосовується лише до Windows 10 до версії 1903 включно. У новіших версіях Windows підтримка ANSI-кодів уже вбудована.
- Виправлення не застосовується для терміналів, що підтримують ANSI типово (наприклад, Windows Terminal).
Каталоги для пошуку проєктів
Список каталогів, у яких Open Server Panel шукатиме проєкти. Розділяйте шляхи крапкою з комою (;).

Винятки: Підкаталоги node_modules і vendor ігноруються.
Глибина
Максимальна глибина вкладеності каталогів під час пошуку проєктів.

Збільшення цього значення може сповільнити запуск Open Server Panel, якщо в указаних каталогах міститься велика кількість підкаталогів.
Максимальний розмір файлу журналу
Максимальний розмір файлу журналу в мегабайтах. Після перевищення вказаного значення лог-файл буде пересотворено під час наступного запуску програми.

Встановіть значення 0, щоб очищати журнали під час кожного запуску програми.

Встановіть значення 100 МБ, щоб повністю вимкнути очищення журналів.
