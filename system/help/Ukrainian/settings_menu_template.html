Створення власних пунктів меню

  1. Додайте нову секцію з унікальним ідентифікатором [ID]
  2. Розташуйте секції в бажаному порядку — це визначить порядок пунктів у меню
  3. Збережіть зміни та перезапустіть Open Server Panel для застосування змін

Важлива інформація

При створенні власних пунктів меню слідкуйте за тим, щоб ідентифікатори секцій не повторювались. Це може призвести до конфліктів у роботі меню.

Налаштування пунктів меню

Порядок сортування: Пункти меню сортуються в тому ж порядку, в якому розташовані відповідні секції в шаблоні.

caption Заголовок пункту меню. Підтримує мовні константи у форматі {lang_xxx}.

За замовчуванням: не задано
category

Визначає розташування пункту меню в ієрархії. Підтримує один рівень вкладеності (наприклад, "Мої Закладки\Робота").

Спеціальні категорії:

  • projects, modules, addons - додає пункт у відповідне меню дій
  • projects\<ім'я_домену>, modules\<ім'я_модуля>, addons\<ім'я_доповнення> - додає пункт для конкретного елемента

Якщо категорія не вказана, пункт створюється в кореневому меню.

За замовчуванням: не задано
command Команда для виконання при активації пункту меню. Пункти без команди ігноруються.

За замовчуванням: не задано
enabled Вмикає/вимикає відображення пункту меню.

За замовчуванням: on | Значення: on, off
hide Керує видимістю вікна програми, що викликається. Не впливає на дочірні процеси.

За замовчуванням: off | Значення: on, off
hr_after Додає горизонтальний роздільник після пункту меню.

За замовчуванням: off | Значення: on, off
hr_before Додає горизонтальний роздільник перед пунктом меню.

За замовчуванням: off | Значення: on, off
icon Іконка з набору Font Awesome Free (Solid/Regular/Brands).

За замовчуванням: не задано
need_alias Відображає пункт меню тільки для доменного псевдоніма. У шаблоні меню може бути тільки один пункт з need_alias=on!
Застосовно для категорій: projects

За замовчуванням: не встановлено | Значення: on, off
need_category

Обмежує відображення пункту меню модулями/доповненнями певної категорії.

Підтримувані формати:

  • modules, addons
  • modules\<ім'я_модуля>, addons\<ім'я_доповнення>
За замовчуванням: не задано
need_module_shell Відображає пункт меню в залежності від наявності shell/cli у батьківського модуля.
Застосовується для категорій: modules, modules\<ім'я_модуля>

За замовчуванням: не задано | Значення: on, off
need_state Відображає пункт меню в залежності від стану батьківського модуля.
Застосовується для категорій: modules, modules\<ім'я_модуля>

За замовчуванням: не задано | Значення: on, off
need_start_cmd Відображає пункт меню при наявності команди запуску в налаштуваннях проекту.
Застосовується для категорій: projects, projects\<ім'я_домену>

За замовчуванням: не задано | Значення: on, off
need_use_wt Відображає пункт меню в залежності від налаштування використання Windows Terminal в Open Server Panel.

За замовчуванням: не задано | Значення: on, off
work_directory Робоча директорія для виконання команди. Може змінюватися під час виконання команд.

За замовчуванням: {root_dir}

Шаблонні змінні

В параметрах "command" і "work_directory" можна використовувати такі шаблонні змінні:

Загальні змінні

Змінна Опис
{root_dir} Кореневий каталог Open Server Panel (повний шлях)
{root_drive} Диск кореневого каталогу
{root_path} Шлях до кореневого каталогу Open Server Panel
{web_panel_url} URL-адреса веб-інтерфейсу

Особливі змінні (тільки для projects і projects\<ім'я_домену>)

Змінна Опис
{base_dir} Базовий каталог проекту
{host} Ім'я домену (Punycode)
{host_decoded} Видиме ім'я домену (без Punycode)
{menu_caption} Заголовок пункту меню (тільки для категорії projects з need_alias=ON)
{nginx_engine} Рушій Nginx
{node_engine} Рушій Node.js
{php_engine} Рушій PHP
{project_dir} Кореневий каталог проекту
{project_url} URL проекту
{public_dir} Публічний каталог проекту
{start_command} Команда запуску проекту (якщо налаштована)
{terminal_codepage} Кодування консолі

Особливі змінні (тільки для addons і addons\<ім'я_доповнення>)

Змінна Опис
{addon_name} Ім'я доповнення
{terminal_codepage} Кодування консолі

Особливі змінні (тільки для modules і modules\<ім'я_модуля>)

Змінна Опис
{ip} IP-адреса модуля
{log_level} Рівень журналювання помилок
{module_name} Ім'я модуля
{port} Порт модуля
{profile_name} Ім'я поточного профілю налаштувань модуля
{query_log_level} Рівень журналювання запитів
{shell_command} Команда запуску shell/cli оболонки модуля (якщо налаштована)
{terminal_codepage} Кодування консолі
{time_zone} Часовий пояс

Особливі значення команд

Команда Опис
command_open_logs_viewer Відкрити вікно перегляду журналів
command_open_idn_converter Відкрити IDN-конвертер
command_open_options Відкрити вікно налаштувань програми
command_restart Перезапустити програму
command_exit Завершити роботу програми

Окрім шаблонних змінних, можна використовувати будь-які змінні середовища Windows, наприклад: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH% тощо.

Приклади використання

[21]

caption  = Відкрити в PhpStorm
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = Мої Закладки\Пошукові системи
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Опції `cmd.exe`

  • /c: Виконати команду і закрити термінал.
  • /k: Виконати команду і залишити термінал відкритим.
