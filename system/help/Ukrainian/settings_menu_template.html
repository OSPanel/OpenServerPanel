Створення власних пунктів меню

  1. Додайте нову секцію з унікальним ідентифікатором [ID]
  2. Розташуйте секції в бажаному порядку — це визначить порядок пунктів у меню
  3. Збережіть зміни та перезапустіть Open Server Panel для застосування змін

Важлива інформація

Під час створення власних пунктів меню слідкуйте за тим, щоб ідентифікатори секцій не повторювалися. Це може призвести до конфліктів у роботі меню.

Налаштування пунктів меню

Порядок сортування: Пункти меню сортуються в тому самому порядку, в якому розташовані відповідні секції в шаблоні.

caption Заголовок пункту меню. Підтримує мовні константи у форматі {lang_xxx}.

За замовчуванням: не задано
category

Визначає розташування пункту меню в ієрархії. Підтримує один рівень вкладеності (наприклад, "Мої Закладки\Робота").

Спеціальні категорії:

  • projects, modules, addons - додає пункт у відповідне меню дій
  • projects\<ім'я_домена>, modules\<ім'я_модуля>, addons\<ім'я_доповнення> - додає пункт для конкретного елемента

Якщо категорія не вказана, пункт створюється в кореневому меню.

За замовчуванням: не задано
command Команда для виконання під час активації пункту меню. Пункти без команди ігноруються.

За замовчуванням: не задано
enabled Вмикає/вимикає відображення пункту меню.

За замовчуванням: on | Значення: on, off
hide Керує видимістю вікна викликаного застосунку. Не впливає на дочірні процеси.

За замовчуванням: off | Значення: on, off
hr_after Додає горизонтальний розділювач після пункту меню.

За замовчуванням: off | Значення: on, off
hr_before Додає горизонтальний розділювач перед пунктом меню.

За замовчуванням: off | Значення: on, off
icon Іконка з набору Font Awesome Free (Solid/Regular/Brands).

За замовчуванням: не задано
need_alias Відображає пункт меню лише для доменного псевдоніма. У шаблоні меню може бути лише один пункт з need_alias=on!
Застосовно для категорій: projects

За замовчуванням: не задано | Значення: on, off
need_category

Обмежує відображення пункту меню модулями/доповненнями певної категорії.

Підтримувані формати:

  • modules, addons
  • modules\<ім'я_модуля>, addons\<ім'я_доповнення>
За замовчуванням: не задано
need_module_shell Відображає пункт меню залежно від наявності shell/cli у батьківського модуля.
Застосовно для категорій: modules, modules\<ім'я_модуля>

За замовчуванням: не задано | Значення: on, off
need_state Відображає пункт меню залежно від стану батьківського модуля.
Застосовно для категорій: modules, modules\<ім'я_модуля>

За замовчуванням: не задано | Значення: on, off
need_start_cmd Відображає пункт меню за наявності команди запуску в налаштуваннях проєкту.
Застосовно для категорій: projects, projects\<ім'я_домена>

За замовчуванням: не задано | Значення: on, off
need_use_wt Відображає пункт меню залежно від налаштування використання Windows Terminal в Open Server Panel.

За замовчуванням: не задано | Значення: on, off
work_directory Робоча директорія для виконання команди. Може змінюватися під час виконання команд.

За замовчуванням: {root_dir}

Шаблонні змінні

У параметрах "command" і "work_directory" можна використовувати такі шаблонні змінні:

Загальні змінні

Змінна Опис
{date_time} Поточна дата/час (змінна доступна лише для параметра "command")
{root_dir} Кореневий каталог Open Server Panel (повний шлях)
{root_drive} Диск кореневого каталогу
{root_path} Шлях до кореневого каталогу Open Server Panel
{web_panel_url} URL-адреса веб-інтерфейсу

Особливі змінні (тільки для projects і projects\<ім'я_домена>)

Змінна Опис
{base_dir} Базовий каталог проєкту
{host} Ім'я домена (Punycode)
{host_decoded} Видиме ім'я домена (без Punycode)
{host_scheme} Схема запиту до проєкту ("http" або "https", залежить від параметра TLS у налаштуваннях проєкту)
{http_port} Порт запиту до проєкту за протоколом HTTP
{https_port} Порт запиту до проєкту за протоколом HTTPS
{menu_caption} Заголовок пункту меню (тільки для категорії projects з need_alias=ON)
{http_engine} Движок HTTP
{node_engine} Движок Node.js
{php_engine} Движок PHP
{project_root} Кореневий каталог проєкту
{base_url} URL проєкту
{web_root} Публічний каталог проєкту
{scheme_port} Порт запиту до проєкту (":{http_port}" або ":{https_port}", залежить від параметра TLS у налаштуваннях проєкту). Якщо {http_port} або {https_port} має стандартне значення 80 або 443, то {scheme_port} буде порожнім.
{app_start_command} Команда запуску застосунку проєкту (якщо налаштована)
{terminal_codepage} Кодування консолі

Особливі змінні (тільки для addons і addons\<ім'я_доповнення>)

Змінна Опис
{addon_name} Ім'я доповнення
{terminal_codepage} Кодування консолі

Особливі змінні (тільки для modules і modules\<ім'я_модуля>)

Змінна Опис
{ip} IP-адреса модуля
{log_level} Рівень журналювання помилок
{module_name} Ім'я модуля
{port} Порт модуля
{profile_name} Ім'я поточного профілю налаштувань модуля
{query_log_level} Рівень журналювання запитів
{shell_command} Команда запуску shell/cli оболонки модуля (якщо налаштована)
{terminal_codepage} Кодування консолі
{time_zone} Часовий пояс

Особливі значення команд

Команда Опис
command_open_logs_viewer Відкрити вікно перегляду журналів
command_open_idn_converter Відкрити IDN-конвертер
command_open_options Відкрити вікно налаштувань програми

Окрім шаблонних змінних, можна використовувати будь-які змінні середовища Windows, наприклад: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% тощо.

Приклад використання

[bookmark_1]

caption  = Google
category = Мої Закладки\Пошукові системи
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Опції CMD.EXE

  • /c: Виконати команду і закрити термінал.
  • /k: Виконати команду і залишити термінал відкритим.
