Глобальні налаштування модулів

Параметри, зазначені в цьому розділі, застосовуються у випадках, коли в налаштуваннях конкретного модуля для відповідної опції встановлено значення auto (за замовчуванням).

Тихий режим роботи
Вимикає спливаючі повідомлення про помилки від Windows Error Reporting і самого модуля.

Рекомендація: Вимикайте цей режим тільки при необхідності діагностики проблем у роботі модуля.
Додавати заголовок у файл журналу
Вмикає автоматичне додавання заголовка у файл журналу при кожному запуску модуля. Корисно при вимкненому автоматичному очищенні логів для розділення сесій роботи.
Максимальна кількість невдалих запусків
Визначає, скільки послідовних невдалих запусків модуля допускається перед тим, як він перейде в стан «Помилка».
Час перевірки працездатності модуля
Визначає період тестування працездатності модуля після його успішного запуску.

Початок відліку: З моменту успішного запуску модуля.

Перехід у стан «Помилка»: Якщо модуль аварійно завершить роботу протягом випробувального терміну, він не буде автоматично перезапущений і перейде в стан «Помилка». Це також стосується випадків, коли модуль не вдається запустити на рівні системи.

Вимкнення перевірки: Значення 0 вимикає випробувальний термін, і модуль завжди буде перезапускатися при збої.

Рекомендація: Не встановлюйте значення 0 або занадто короткий період (менше 30 секунд), оскільки це може призвести до нескінченних циклів перезапуску.
Час очікування завершення роботи модуля
Визначає граничний час, протягом якого модулю дозволено завершувати свою роботу.

Примусове завершення: Якщо модуль не завершить роботу в зазначений термін, він буде примусово зупинений.

Вимкнення очікування: Значення 0 вимикає період очікування. Програма буде очікувати завершення роботи модуля необмежений час.

Попередження: Примусова зупинка модуля може призвести до пошкодження даних, втрати незбережених змін або некоректного завершення процесів. Використовуйте це налаштування з обережністю.
Максимальний розмір файлу журналу
Максимальний розмір файлу журналу в мегабайтах. При перевищенні зазначеного значення лог-файл буде пересотворений при наступному запуску модуля.

Встановіть значення 0, щоб очищати лог-файли при кожному запуску модуля.

Встановіть значення 100 МБ, щоб повністю вимкнути очищення лог-файлів.
Кодування терміналу
Кодування терміналу при роботі з середовищем модуля.

Спеціальні значення:
- system: Використовується системне кодування.
Часовий пояс
Визначає часову зону модуля у форматі Etc/GMT (наприклад, Etc/GMT-3).

Спеціальні значення:
- system: Використовується системний часовий пояс.

Важливо: Формат Etc/GMT має зворотне зміщення відносно UTC (наприклад, Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Використовувані середовища доповнень
Визначає список доповнень (вказуються через пробіл), середовища яких (якщо такі є) приєднуються до середовища модуля. Інформаційні індикатори в терміналі не відображають ці додаткові середовища.

Попередження: Використовуйте цю опцію тільки при повному розумінні її призначення.
Дозволені системні змінні
Визначає перелік змінних середовища Windows (вказуються через пробіл), які передаються в середовище модуля.

Призначення: Дозволяє ізолювати робоче середовище модуля від аналогічного встановленого в системі ПЗ.

Попередження: Зміна цього списку без повного розуміння його впливу може призвести до нестабільної роботи модуля.
