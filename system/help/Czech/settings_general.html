Nastavení programu

Spouštět spolu s Windows
Povolit automatické spuštění Open Server Panel při načítání operačního systému.
Zpoždění
Zpoždění spuštění programu (v sekundách, od 0 do 60).

Umožňuje odložit start aplikace během spouštění spolu s Windows, aby se snížilo celkové zatížení systému. Je to obzvlášť užitečné, pokud je potřeba vyčkat na plnou inicializaci cizích služeb nebo síťových rozhraní.
Kontrolovat dostupnost nových verzí
Povolit kontrolu aktualizací Open Server Panel (vyžaduje připojení k internetu).
Zapnout plánovač úloh
Aktivovat vestavěný plánovač úloh. Pokud je parametr vypnut, žádné naplánované úlohy nebudou prováděny bez ohledu na jejich stav.
Používat soubor HOSTS
Povolit zápis doménových jmen do souboru HOSTS.

Doporučení při omezeném přístupu k souboru HOSTS v organizaci:

1. Nastavte všechny potřebné moduly a projekty.
2. Obraťte se na systémového administrátora kvůli odblokování HOSTS a fixaci jeho stavu.
3. Po fixaci změn administrátorem lze tuto volbu vypnout.

Důležité: Nevypínejte tento parametr, pokud si nejste jisti následky!
Spouštět moduly s profilem projektu
Spouštět moduly se současnou aktivací profilu, který se shoduje se jménem projektu.

Používá se při volbě položky menu «Zapnout moduly projektu», aby se automaticky aktivoval profil se stejným názvem jako aktuální projekt, pokud takový existuje.
Nevypínat moduly skrytých projektů
Nevypínat moduly skrytých projektů při volbě položky menu «Vypnout všechny moduly». Pod „skrytými“ se rozumí projekty, pro které je nastavena kategorie "hidden".

Ve výchozím nastavení příkaz «Vypnout všechny moduly» zastaví práci naprosto všech modulů, včetně těch, které používají skryté servisní projekty (například PHPMyAdmin). Tato volba umožňuje zachovat funkčnost skrytých servisních projektů, aniž by se vypínaly pro ně potřebné moduly, zatímco všechny ostatní moduly budou vypnuty.
Jazyk rozhraní
Jazyk uživatelského rozhraní Open Server Panel.

Pokud soubor lokalizace chybí nebo obsahuje chyby, bude použit anglický jazyk.
Doména API
Lokální doména pro API a webové rozhraní (ve vývoji)

Doporučení: Pokud používáte VPN nebo proxy, přidejte tuto doménu do výjimek.
IP adresa API
IPv4 adresa pro API a webové rozhraní (ve vývoji).

Doporučení: Pokud používáte VPN nebo proxy, přidejte tuto IP adresu do výjimek.
Port API
Port používaný pro API a webové rozhraní (ve vývoji). Open Server Panel nebude moci být spuštěn, pokud je uvedený port již používán jinou aplikací.
Používat Windows Terminal
Povolit použití Windows Terminal místo standardního příkazového rozhraní.

Požadavky: Windows Terminal musí být nainstalován v systému a uveden v proměnné prostředí PATH.

Windows Terminal jako cmd.exe: Windows Terminal může nahrazovat cmd.exe a být uveden v proměnné prostředí %COMSPEC% v nových verzích Windows. Pokud je tomu tak, ponechte tuto volbu zapnutou.

Nové instance Windows Terminal: Pokud Windows Terminal otevírá nová okna místo karet, nastavte jej takto: Nastavení→Spuštění→Chování nové instance→Připojit k poslednímu použitému oknu.
Krátký titul projektu
Při aktivaci této volby bude v záhlaví okna terminálu zobrazováno pouze jméno projektu místo podrobného popisu prostředí.
Zahrnout systémové prostředí do prostředí projektu
Používat prostředí systému (System) v terminálu, i když není zadáno v nastaveních projektu. Systémové prostředí umožňuje používat programy nainstalované v systému (například git.exe nebo ssh.exe).

Vypínejte tuto volbu pouze při vzniku konfliktů se systémovým softwarem.
Podpora ANSI
Povolit podporu ANSI kódů pro správu barev v terminálu.

Režim „Automaticky“ (ve výchozím nastavení):
- Oprava se uplatní pouze na Windows 10 do verze 1903 včetně. V novějších verzích Windows je podpora ANSI kódů již zabudována.
- Oprava se neuplatní pro terminály, které podporují ANSI ve výchozím nastavení (například Windows Terminal).
Adresáře pro vyhledávání projektů
Seznam adresářů, ve kterých bude Open Server Panel hledat projekty. Cesty oddělujte středníkem (;).

Výjimky: Podadresáře node_modules a vendor jsou ignorovány.
Hloubka
Maximální hloubka vnoření adresářů při vyhledávání projektů.

Zvýšení této hodnoty může zpomalit spuštění Open Server Panel, pokud uvedené adresáře obsahují velké množství podadresářů.
Maximální velikost souboru protokolu
Maximální velikost souboru protokolu v megabajtech. Při překročení uvedené hodnoty bude log soubor znovu vytvořen při příštím spuštění programu.

Nastavte hodnotu 0 pro čištění protokolů při každém spuštění programu.

Nastavte hodnotu 100 MB pro úplné vypnutí čištění protokolů.
