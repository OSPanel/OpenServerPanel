Globální nastavení projektů

Parametry zadané v této části se používají v případě, že v nastavení projektu nejsou uvedeny jiné hodnoty.

HTTP
Určuje použitý modul webového serveru pro projekty.
NODE
Určuje engine Node.js pro spuštění aplikací Node.js.

Instalace Node.js: Předem nainstalujte požadovanou verzi Node.js pomocí příkazu osp node <latest|lts|номер>.
PHP
Určuje použitý modul PHP pro zpracování PHP souborů.
Zapnout
Určuje výchozí stav projektu (zapnuto nebo vypnuto).
Kódování terminálu
Kódování terminálu při práci s prostředím projektu.

Speciální hodnoty:
- system: Použije se systémové kódování.

Důležité: Pokud hodnota není zadána, při formování výsledného prostředí projektu bude kódování terminálu nastaveno posledním připojeným prostředím, ve kterém je zadáno, například prostředím modulu PHP.
IP
Určuje IP adresu(y), použitou všemi projekty bez individuálního nastavení.

Omezení: Projekty používající stejnou IP adresu musí běžet na jedné verzi PHP.

Podpora více IP: Lze zadat více IP adres oddělených mezerou, včetně IPv6. V souboru HOSTS bude doménám přiřazena první uvedená IP.

Automatické přiřazení: Pokud pole ponecháte prázdné, IP adresa bude přiřazena automaticky.

Doporučení:
  • Automatické řízení IP adres se doporučuje většině uživatelů.
  • Ruční zadání IP adresy používejte pouze při specifických požadavcích síťové konfigurace.
HTTP
Určuje port pro připojení přes HTTP.
HTTPS
Určuje port pro připojení přes HTTPS.
TLS
Zapíná nebo vypíná podporu TLS.
Soubor certifikátu
Určuje cestu k souboru TLS certifikátu. Lze použít šablonové proměnné.

Povolené znaky: A-Za-z0-9-+_.\:

Doporučení: Ponechte pole prázdné pro automatické generování certifikátů.
Soubor klíče
Určuje cestu k souboru TLS klíče. Lze použít šablonové proměnné.

Povolené znaky: A-Za-z0-9-+_.\:

Doporučení: Ponechte pole prázdné pro automatické generování klíče.
IP adresa (backend)
Určuje IP adresu, na které se realizuje připojení k serverové části (Backend).
Port (backend)
Určuje číslo portu pro připojení k serverové části (Backend).
Zapnout (backend)
Umožňuje automaticky směrovat veškerý příchozí provoz (HTTP a HTTPS) projektu na serverovou část (Backend). Užitečné pro testování nebo vývoj, když jsou frontend a backend odděleny.
Adresář projektu
Určuje kořenový adresář projektu. Přechod do tohoto adresáře se provádí příkazem osp project <DOMAIN> současně s aktivací prostředí projektu. Lze použít šablonové proměnné.

Povolené znaky: A-Za-z0-9-+_.\:
Veřejný adresář
Určuje veřejný adresář projektu. Lze použít šablonové proměnné.

Povolené znaky: A-Za-z0-9-+_.\:
Alias
Určuje další doménová jména (aliasy) pro projekt (oddělené mezerou). Lze použít šablonové proměnné.

Omezení: Symbol "*" není ve Windows v souboru HOSTS podporován a vyžaduje nastavení DNS.
Prostředí projektu
Seznam doplňků a modulů (oddělených mezerou), které tvoří prostředí projektu.

HTTP, NODE a PHP: Prostředí těchto engine se připojují vždy (pokud jsou pro doménu zadány) a není nutné je uvádět v tomto parametru.
Příkaz pro spuštění projektu
Určuje příkaz pro spuštění projektu (například nodemon app.js). Lze použít šablonové proměnné.
URL projektu
URL používané při otevření projektu Menu→Projekt→Otevřít v prohlížeči, stejně jako při otevírání doménových aliasů projektu. Lze použít šablonové proměnné.

Použití: Lze zadat URL administračního panelu CMS.

Šablonové proměnné

Proměnná Popis
{backend_ip} IP adresa připojení k serverové části (Backend)
{backend_port} Port připojení k serverové části (Backend)
{base_dir} Kořenový adresář projektu (kde se nachází adresář .osp)
{date_time} Aktuální datum/čas (proměnná je dostupná pouze pro příkaz spuštění aplikace projektu)
{host} Název domény (pro internacionalizované domény se používá Punycode)
{host_decoded} Viditelný název domény (bez Punycode)
{host_scheme} Schéma požadavku k projektu ("http" nebo "https", závisí na parametru TLS v nastavení projektu)
{http_port} Port požadavku k projektu přes protokol HTTP
{https_port} Port požadavku k projektu přes protokol HTTPS
{http_engine} Engine HTTP
{node_engine} Engine NODE
{php_engine} Engine PHP
{project_root} Kořenový adresář projektu
{web_root} Veřejný adresář projektu
{scheme_port} Port požadavku k projektu (":{http_port}" nebo ":{https_port}", závisí na parametru TLS v nastavení projektu).

Pokud má {http_port} nebo {https_port} standardní hodnotu 80 nebo 443, bude {scheme_port} prázdné.
{root_dir} Kořenový adresář Open Server Panel (plná cesta)
{root_drive} Disk kořenového adresáře
{root_path} Cesta ke kořenovému adresáři Open Server Panel
{terminal_codepage} Kódování konzole
