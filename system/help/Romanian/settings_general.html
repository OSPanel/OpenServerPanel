Setările programului

Pornește împreună cu Windows
Activează auto-pornirea Open Server Panel la încărcarea sistemului de operare.
Întârziere
Întârzierea pornirii programului (în secunde, de la 0 la 60).

Permite amânarea startului aplicației în timpul încărcării împreună cu Windows, pentru a reduce încărcarea generală a sistemului. Este util în special dacă este nevoie să așteptați inițializarea completă a serviciilor terțe sau a interfețelor de rețea.
Verifică existența noilor versiuni
Activează verificarea actualizărilor Open Server Panel (este necesară conexiune la Internet).
Activează Planificatorul de sarcini
Activează planificatorul de sarcini integrat. Dacă parametrul este dezactivat, nicio sarcină programată nu va fi executată, indiferent de statusul acesteia.
Folosește fișierul HOSTS
Activează scrierea numelor de domeniu în fișierul HOSTS.

Recomandări în cazul accesului limitat la fișierul HOSTS în organizație:

1. Configurați toate modulele și proiectele necesare.
2. Contactați administratorul de sistem pentru deblocarea HOSTS și fixarea stării acestuia.
3. După fixarea modificărilor de către administrator, puteți dezactiva această opțiune.

Important: Nu dezactivați acest parametru dacă nu sunteți sigur de consecințe!
Pornește modulele cu profilul proiectului
Pornește modulele cu activarea simultană a profilului care coincide cu numele proiectului.

Se utilizează la selectarea elementului de meniu „Activează modulele proiectului”, pentru a activa automat profilul cu același nume ca al proiectului curent, dacă există.
Nu opri modulele proiectelor ascunse
Nu opri modulele proiectelor ascunse la selectarea elementului de meniu „Oprește toate modulele”. Prin „ascunse” se înțeleg acele proiecte pentru care este setată categoria „hidden”.

În mod implicit, comanda „Oprește toate modulele” oprește funcționarea absolut tuturor modulelor, inclusiv pe cele utilizate de proiectele de serviciu ascunse (de exemplu, PHPMyAdmin). Această opțiune permite menținerea funcționării proiectelor de serviciu ascunse, fără a dezactiva modulele necesare pentru ele, în timp ce toate celelalte module vor fi oprite.
Limba interfeței
Limba interfeței utilizator Open Server Panel.

Dacă fișierul de localizare lipsește sau conține erori, va fi utilizată limba engleză.
Domeniul API
Domeniul local pentru API și interfața web (în dezvoltare)

Recomandare: Dacă se utilizează VPN sau proxy, adăugați acest domeniu la excepții.
Adresa IP a API
Adresa IPv4 pentru API și interfața web (în dezvoltare).

Recomandare: Dacă se utilizează VPN sau proxy, adăugați această adresă IP la excepții.
Portul API
Portul utilizat pentru API și interfața web (în dezvoltare). Open Server Panel nu va putea porni dacă portul specificat este deja utilizat de o altă aplicație.
Folosește Windows Terminal
Activează utilizarea Windows Terminal în locul interfeței standard de comandă.

Cerințe: Windows Terminal trebuie să fie instalat în sistem și prezent în variabila de mediu PATH.

Windows Terminal ca cmd.exe: Windows Terminal poate înlocui cmd.exe și poate fi setat în variabila de mediu %COMSPEC% în versiunile noi de Windows. Dacă este cazul, lăsați această opțiune activată.

Instanțe noi Windows Terminal: Dacă Windows Terminal deschide ferestre noi în loc de file, configurați-l astfel: Settings→Startup→New instance behavior→Attach to the most recently used window.
Titlu scurt al proiectului
La activarea acestei opțiuni, în titlul ferestrei terminalului va fi afișat doar numele proiectului în locul descrierii detaliate a mediului.
Include mediul sistemului în mediul proiectului
Utilizează mediul sistemului (System) în terminal, chiar dacă nu este setat în setările proiectului. Mediul sistemului permite utilizarea programelor instalate în sistem (de exemplu, git.exe sau ssh.exe).

Dezactivați această opțiune doar în cazul apariției conflictelor cu software-ul de sistem.
Suport ANSI
Activează suportul pentru codurile ANSI pentru controlul culorilor în terminal.

Modul „Automat” (implicit):
- Corecția se aplică doar pentru Windows 10 până la versiunea 1903 inclusiv. În versiunile mai noi de Windows suportul pentru codurile ANSI este deja integrat.
- Corecția nu se aplică pentru terminalele care suportă ANSI în mod implicit (de exemplu, Windows Terminal).
Directoare pentru căutarea proiectelor
Lista de directoare în care Open Server Panel va căuta proiecte. Separați căile cu punct și virgulă (;).

Excepții: Subdirectoarele node_modules și vendor sunt ignorate.
Adâncime
Adâncimea maximă de imbricare a directoarelor la căutarea proiectelor.

Creșterea acestei valori poate încetini pornirea Open Server Panel, dacă în directoarele indicate există un număr mare de subdirectoare.
Dimensiunea maximă a fișierului jurnal
Dimensiunea maximă a fișierului jurnal în megabytes. La depășirea valorii specificate, fișierul de log va fi recreat la următoarea pornire a programului.

Setați valoarea 0 pentru a curăța jurnalele la fiecare pornire a programului.

Setați valoarea 100 MB pentru a dezactiva complet curățarea jurnalelor.
