Crearea propriilor elemente de meniu

  1. Adăugați o secțiune nouă cu un identificator [ID] unic
  2. Aranjați secțiunile în ordinea dorită — aceasta va determina ordinea elementelor în meniu
  3. Salvați modificările și reporniți Open Server Panel pentru a aplica modificările

Informații importante

Atunci când creați propriile elemente de meniu, asigurați-vă că identificatorii secțiunilor nu se repetă. Acest lucru poate duce la conflicte în funcționarea meniului.

Setări ale elementelor de meniu

Ordinea de sortare: Elementele de meniu sunt sortate în aceeași ordine în care sunt plasate secțiunile corespunzătoare în șablon.

caption Titlul elementului de meniu. Acceptă constante lingvistice în formatul {lang_xxx}.

Implicit: nu este setat
category

Determină plasarea elementului de meniu în ierarhie. Acceptă un singur nivel de imbricare (de exemplu, "Marcajele mele\Muncă").

Categorii speciale:

  • projects, modules, addons - adaugă elementul în meniul de acțiuni corespunzător
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - adaugă elementul pentru un anumit element

Dacă categoria nu este specificată, elementul este creat în meniul rădăcină.

Implicit: nu este setat
command Comanda de executat la activarea elementului de meniu. Elementele fără comandă sunt ignorate.

Implicit: nu este setat
enabled Activează/dezactivează afișarea elementului de meniu.

Implicit: on | Valori: on, off
hide Controlează vizibilitatea ferestrei aplicației apelate. Nu afectează procesele copil.

Implicit: off | Valori: on, off
hr_after Adaugă un separator orizontal după elementul de meniu.

Implicit: off | Valori: on, off
hr_before Adaugă un separator orizontal înaintea elementului de meniu.

Implicit: off | Valori: on, off
icon Pictogramă din setul Font Awesome Free (Solid/Regular/Brands).

Implicit: nu este setat
need_alias Afișează elementul de meniu doar pentru un alias de domeniu. În șablonul meniului poate exista un singur element cu need_alias=on!
Aplicabil pentru categoriile: projects

Implicit: nu este setat | Valori: on, off
need_category

Restricționează afișarea elementului de meniu la module/addons dintr-o anumită categorie.

Formate acceptate:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Implicit: nu este setat
need_module_shell Afișează elementul de meniu în funcție de existența shell/cli la modulul părinte.
Aplicabil pentru categoriile: modules, modules\<имя_модуля>

Implicit: nu este setat | Valori: on, off
need_state Afișează elementul de meniu în funcție de starea modulului părinte.
Aplicabil pentru categoriile: modules, modules\<имя_модуля>

Implicit: nu este setat | Valori: on, off
need_start_cmd Afișează elementul de meniu dacă există o comandă de pornire în setările proiectului.
Aplicabil pentru categoriile: projects, projects\<имя_домена>

Implicit: nu este setat | Valori: on, off
need_use_wt Afișează elementul de meniu în funcție de setarea utilizării Windows Terminal în Open Server Panel.

Implicit: nu este setat | Valori: on, off
work_directory Directorul de lucru pentru executarea comenzii. Poate fi modificat în timpul executării comenzilor.

Implicit: {root_dir}

Variabile de șablon

În parametrii "command" și "work_directory" puteți utiliza următoarele variabile de șablon:

Variabile generale

Variabilă Descriere
{date_time} Data/ora curentă (variabila este disponibilă doar pentru parametrul "command")
{root_dir} Directorul rădăcină Open Server Panel (cale completă)
{root_drive} Unitatea directorului rădăcină
{root_path} Calea către directorul rădăcină Open Server Panel
{web_panel_url} URL-ul interfeței web

Variabile speciale (numai pentru projects și projects\<имя_домена>)

Variabilă Descriere
{base_dir} Directorul de bază al proiectului
{host} Numele domeniului (Punycode)
{host_decoded} Numele vizibil al domeniului (fără Punycode)
{host_scheme} Schematica cererii către proiect ("http" sau "https", depinde de parametrul TLS din setările proiectului)
{http_port} Portul cererii către proiect prin protocolul HTTP
{https_port} Portul cererii către proiect prin protocolul HTTPS
{menu_caption} Titlul elementului de meniu (numai pentru categoria projects cu need_alias=ON)
{http_engine} Motorul HTTP
{node_engine} Motorul Node.js
{php_engine} Motorul PHP
{project_root} Directorul rădăcină al proiectului
{base_url} URL-ul proiectului
{web_root} Directorul public al proiectului
{scheme_port} Portul cererii către proiect (":{http_port}" sau ":{https_port}", depinde de parametrul TLS din setările proiectului). Dacă {http_port} sau {https_port} are valoarea standard 80 sau 443, atunci {scheme_port} va fi gol.
{app_start_command} Comanda de pornire a aplicației proiectului (dacă este configurată)
{terminal_codepage} Setul de caractere al consolei

Variabile speciale (numai pentru addons și addons\<имя_дополнения>)

Variabilă Descriere
{addon_name} Numele addon-ului
{terminal_codepage} Setul de caractere al consolei

Variabile speciale (numai pentru modules și modules\<имя_модуля>)

Variabilă Descriere
{ip} Adresa IP a modulului
{log_level} Nivelul de jurnalizare a erorilor
{module_name} Numele modulului
{port} Portul modulului
{profile_name} Numele profilului curent de setări al modulului
{query_log_level} Nivelul de jurnalizare a interogărilor
{shell_command} Comanda de lansare a shell/cli a modulului (dacă este configurată)
{terminal_codepage} Setul de caractere al consolei
{time_zone} Fus orar

Valori speciale ale comenzilor

Comandă Descriere
command_open_logs_viewer Deschide fereastra de vizualizare a jurnalelor
command_open_idn_converter Deschide convertorul IDN
command_open_options Deschide fereastra de setări a programului

Pe lângă variabilele de șablon, se pot utiliza orice variabile de mediu Windows, de exemplu: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% etc.

Exemplu de utilizare

[bookmark_1]

caption  = Google
category = Marcajele mele\Sisteme de căutare
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opțiuni CMD.EXE

  • /c: Execută comanda și închide terminalul.
  • /k: Execută comanda și lasă terminalul deschis.
