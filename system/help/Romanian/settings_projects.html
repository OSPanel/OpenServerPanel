Setări globale ale proiectelor

Parametrii specificați în această secțiune sunt utilizați dacă în setările proiectului nu sunt indicate alte valori.

HTTP
Determină modulul serverului web utilizat pentru proiecte.
NODE
Indică engine-ul Node.js pentru rularea aplicațiilor Node.js.

Instalarea Node.js: Instalați în prealabil versiunea necesară de Node.js folosind comanda osp node <latest|lts|номер>.
PHP
Determină modulul PHP utilizat pentru procesarea fișierelor PHP.
Activare
Determină starea implicită a proiectului (activat sau dezactivat).
Codare terminal
Codarea terminalului la lucrul cu mediul proiectului.

Valori speciale:
- system: Se utilizează codarea sistemului.

Important: Dacă valoarea nu este setată, la formarea mediului final al proiectului codarea terminalului va fi stabilită de ultimul mediu conectat în care este setată, de exemplu de mediul modulului PHP.
IP
Setează adresa(le) IP utilizată(e) de toate proiectele fără setări individuale.

Limitare: Proiectele care folosesc aceeași adresă IP trebuie să ruleze pe aceeași versiune de PHP.

Suport pentru mai multe IP-uri: Puteți specifica mai multe adrese IP separate prin spațiu, inclusiv IPv6. În fișierul HOSTS domeniilor le va fi atribuit primul IP indicat.

Atribuire automată: Dacă lăsați câmpul gol, adresa IP va fi atribuită automat.

Recomandări:
  • Gestionarea automată a adreselor IP este recomandată pentru majoritatea utilizatorilor.
  • Setarea manuală a adresei IP trebuie utilizată doar în cazul unor cerințe specifice de configurare a rețelei.
HTTP
Determină portul pentru conexiunile HTTP.
HTTPS
Determină portul pentru conexiunile HTTPS.
TLS
Activează sau dezactivează suportul TLS.
Fișier certificat
Indică calea către fișierul certificatului TLS. Puteți utiliza variabile șablon.

Caractere permise: A-Za-z0-9-+_.\:

Recomandare: Lăsați câmpul gol pentru generarea automată a certificatelor.
Fișier cheie
Indică calea către fișierul cheii TLS. Puteți utiliza variabile șablon.

Caractere permise: A-Za-z0-9-+_.\:

Recomandare: Lăsați câmpul gol pentru generarea automată a cheii.
Adresă IP (backend)
Indică adresa IP prin care se realizează conectarea la partea de server (Backend).
Port (backend)
Determină numărul portului pentru conectarea la partea de server (Backend).
Activare (backend)
Permite redirecționarea automată a întregului trafic de intrare (HTTP și HTTPS) al proiectului către partea de server (Backend). Util pentru testare sau dezvoltare, când frontend-ul și backend-ul sunt separate.
Directorul proiectului
Indică directorul rădăcină al proiectului. Se face trecerea în acest director prin comanda osp project <DOMAIN> simultan cu activarea mediului proiectului. Puteți utiliza variabile șablon.

Caractere permise: A-Za-z0-9-+_.\:
Director public
Determină directorul public al proiectului. Puteți utiliza variabile șablon.

Caractere permise: A-Za-z0-9-+_.\:
Pseudonime
Indică nume de domeniu suplimentare (aliasuri) pentru proiect (separate prin spațiu). Puteți utiliza variabile șablon.

Limitare: Caracterul "*" nu este suportat în Windows de fișierul HOSTS și necesită configurarea DNS.
Mediul proiectului
Lista de add-on-uri și module (separate prin spațiu) care formează mediul proiectului.

HTTP, NODE și PHP: Mediile acestor engine-uri sunt conectate întotdeauna (dacă sunt setate pentru domeniu) și nu necesită specificare în acest parametru.
Comanda de pornire a proiectului
Determină comanda pentru pornirea proiectului (de exemplu, nodemon app.js). Puteți utiliza variabile șablon.
URL-ul proiectului
URL-ul utilizat la deschiderea proiectului Meniu→Proiect→Deschide în browser, precum și la deschiderea aliasurilor de domeniu ale proiectului. Puteți utiliza variabile șablon.

Aplicare: Puteți seta URL-ul panoului de administrare al CMS.

Variabile șablon

Variabilă Descriere
{backend_ip} Adresa IP pentru conectarea la partea de server (Backend)
{backend_port} Portul de conectare la partea de server (Backend)
{base_dir} Directorul rădăcină al proiectului (unde se află directorul .osp)
{date_time} Data/ora curentă (variabila este disponibilă doar pentru comanda de pornire a aplicației proiectului)
{host} Numele domeniului (pentru domeniile internaționalizate se utilizează Punycode)
{host_decoded} Numele vizibil al domeniului (fără Punycode)
{host_scheme} Schematica cererii către proiect ("http" sau "https", depinde de parametrul TLS din setările proiectului)
{http_port} Portul cererii către proiect prin protocolul HTTP
{https_port} Portul cererii către proiect prin protocolul HTTPS
{http_engine} Engine-ul HTTP
{node_engine} Engine-ul NODE
{php_engine} Engine-ul PHP
{project_root} Directorul rădăcină al proiectului
{web_root} Directorul public al proiectului
{scheme_port} Portul cererii către proiect (":{http_port}" sau ":{https_port}", depinde de parametrul TLS din setările proiectului).

Dacă {http_port} sau {https_port} are valoarea standard 80 sau 443, atunci {scheme_port} va fi gol.
{root_dir} Directorul rădăcină Open Server Panel (cale completă)
{root_drive} Unitatea directorului rădăcină
{root_path} Calea către directorul rădăcină Open Server Panel
{terminal_codepage} Codarea consolei
