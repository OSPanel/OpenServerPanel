Setări meniu

Temă de afișare
Tema de afișare pentru pictogramele meniului.
Mărimea fontului
Mărimea fontului meniului în pixeli. Opțiunea permite setarea mărimii fontului meniului independent de setările sistemului.

Setați glisorul la valoarea minimă de 12px pentru a dezactiva funcția de control al mărimii fontului (va fi folosită mărimea sistemului).
Afișează pictograma în zona de notificări
Afișează pictograma programului în zona de notificări Windows.

Dezactivare: Dezactivați această opțiune dacă folosiți un tip de auto-pornire care nu necesită autentificarea utilizatorului Windows (Planificator de activități Windows→Pornire la încărcarea computerului).
Afișează pictograme pentru elementele meniului
Afișează pictograme în meniul programului. Pictogramele nu sunt afișate dacă este activată randarea sistem.
Activează randarea sistem
Activați această opțiune doar atunci când este necesară compatibilitatea cu programe de acces la ecran (screen reader-e).

Atenție! Pictogramele din meniu nu sunt afișate dacă este activată randarea sistem.
Afișează separator vertical
Când această opțiune este activată, pictogramele din meniul programului vor fi separate de un separator vertical.
Nu grupa listele dintr-un singur element
Nu grupa listele care conțin un singur element.
