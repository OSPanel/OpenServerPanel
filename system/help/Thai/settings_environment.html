ตัวแปรสภาพแวดล้อมแบบโกลบอลของโมดูล

ในส่วนนี้คุณสามารถกำหนดตัวแปรสภาพแวดล้อมแบบโกลบอลสำหรับโมดูลได้

ตัวแปรเหล่านี้มีผลเฉพาะในสภาพแวดล้อมของโมดูล และไม่ส่งผลต่อระบบหรือสภาพแวดล้อมของโปรเจ็กต์

สามารถใช้ตัวแปรแม่แบบในค่าได้

หากตัวแปรมีอยู่ในสภาพแวดล้อมของระบบ แต่ไม่ควรถูกใช้ในสภาพแวดล้อมของโมดูล ให้ใช้ตัวกรองพิเศษ (ดูที่ โมดูล→ตัวแปรระบบที่อนุญาต) หรือเอาตัวแปรออกจากสภาพแวดล้อมโดยกำหนดค่าเป็นค่าว่าง

ตัวแปรแม่แบบ

ตัวแปร คำอธิบาย
{root_dir} ไดเรกทอรีรากของ Open Server Panel (พาธแบบเต็ม)
{root_drive} ไดรฟ์ของไดเรกทอรีราก
{root_path} พาธไปยังไดเรกทอรีรากของ Open Server Panel
{terminal_codepage} การเข้ารหัสในเทอร์มินัล (ดูที่ โมดูล→การเข้ารหัสในเทอร์มินัล)
{time_zone} โซนเวลาในรูปแบบ Etc/GMT (ดูที่ โมดูล→โซนเวลา)

นอกเหนือจากตัวแปรแม่แบบแล้ว ยังสามารถใช้ตัวแปรสภาพแวดล้อมของ Windows ใดๆ ได้ เช่น: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% เป็นต้น
