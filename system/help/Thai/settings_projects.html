การตั้งค่าโปรเจกต์แบบโกลบอล

พารามิเตอร์ที่กำหนดในส่วนนี้จะถูกใช้ในกรณีที่ไม่ได้ระบุค่าอื่นไว้ในการตั้งค่าของโปรเจกต์

HTTP
กำหนดโมดูลเว็บเซิร์ฟเวอร์ที่ใช้สำหรับโปรเจกต์
NODE
ระบุเอนจิน Node.js สำหรับรันแอปพลิเคชัน Node.js

การติดตั้ง Node.js: ติดตั้งเวอร์ชัน Node.js ที่ต้องการล่วงหน้าด้วยคำสั่ง osp node <latest|lts|номер>.
PHP
กำหนดโมดูล PHP ที่ใช้สำหรับประมวลผลไฟล์ PHP
เปิดใช้งาน
กำหนดสถานะเริ่มต้นของโปรเจกต์ (เปิดหรือปิด)
การเข้ารหัสของเทอร์มินัล
การเข้ารหัสของเทอร์มินัลเมื่อทำงานกับสภาพแวดล้อมของโปรเจกต์

ค่าเฉพาะ:
- system: ใช้การเข้ารหัสของระบบ

สำคัญ: หากไม่ได้กำหนดค่าไว้ เมื่อตอนสร้างสภาพแวดล้อมสุดท้ายของโปรเจกต์ การเข้ารหัสของเทอร์มินัลจะถูกตั้งค่าตามสภาพแวดล้อมที่เชื่อมต่อเป็นลำดับสุดท้ายที่มีการกำหนดไว้ เช่น สภาพแวดล้อมของโมดูล PHP
IP
กำหนดที่อยู่ IP ที่ใช้โดยทุกโปรเจกต์ที่ไม่มีการตั้งค่าเฉพาะของตนเอง

ข้อจำกัด: โปรเจกต์ที่ใช้ที่อยู่ IP เดียวกันต้องทำงานบน PHP เวอร์ชันเดียวกัน

รองรับหลาย IP: สามารถระบุหลายที่อยู่ IP ได้โดยคั่นด้วยช่องว่าง รวมถึง IPv6 ในไฟล์ HOSTS จะกำหนด IP ตัวแรกให้กับโดเมน

การกำหนดอัตโนมัติ: หากปล่อยว่างไว้ IP จะถูกกำหนดโดยอัตโนมัติ

คำแนะนำ:
  • การจัดการ IP แบบอัตโนมัติแนะนำสำหรับผู้ใช้ส่วนใหญ่
  • การกำหนด IP ด้วยตนเองควรใช้เมื่อมีข้อกำหนดเฉพาะของการตั้งค่าเครือข่าย
HTTP
กำหนดพอร์ตสำหรับการเชื่อมต่อผ่าน HTTP
HTTPS
กำหนดพอร์ตสำหรับการเชื่อมต่อผ่าน HTTPS
TLS
เปิดหรือปิดการรองรับ TLS
ไฟล์ใบรับรอง
ระบุเส้นทางไปยังไฟล์ใบรับรอง TLS สามารถใช้ตัวแปรเทมเพลตได้

อักขระที่อนุญาต: A-Za-z0-9-+_.\:

คำแนะนำ: ปล่อยว่างไว้เพื่อให้สร้างใบรับรองอัตโนมัติ
ไฟล์คีย์
ระบุเส้นทางไปยังไฟล์คีย์ TLS สามารถใช้ตัวแปรเทมเพลตได้

อักขระที่อนุญาต: A-Za-z0-9-+_.\:

คำแนะนำ: ปล่อยว่างไว้เพื่อให้สร้างคีย์อัตโนมัติ
ที่อยู่ IP (backend)
ระบุที่อยู่ IP ที่ใช้เชื่อมต่อกับส่วนเซิร์ฟเวอร์ (Backend)
พอร์ต (backend)
กำหนดหมายเลขพอร์ตสำหรับการเชื่อมต่อกับส่วนเซิร์ฟเวอร์ (Backend)
เปิดใช้งาน (backend)
ช่วยให้สามารถเปลี่ยนเส้นทางทราฟฟิกขาเข้า (HTTP และ HTTPS) ทั้งหมดของโปรเจกต์ไปยังส่วนเซิร์ฟเวอร์ (Backend) โดยอัตโนมัติ มีประโยชน์สำหรับการทดสอบหรือการพัฒนาเมื่อแยก frontend และ backend ออกจากกัน
ไดเรกทอรีของโปรเจกต์
ระบุไดเรกทอรีรากของโปรเจกต์ การเข้าสู่ไดเรกทอรีนี้ทำได้ด้วยคำสั่ง osp project <DOMAIN> พร้อมกับการเปิดใช้งานสภาพแวดล้อมของโปรเจกต์ สามารถใช้ตัวแปรเทมเพลตได้

อักขระที่อนุญาต: A-Za-z0-9-+_.\:
ไดเรกทอรีสาธารณะ
กำหนดไดเรกทอรีสาธารณะของโปรเจกต์ สามารถใช้ตัวแปรเทมเพลตได้

อักขระที่อนุญาต: A-Za-z0-9-+_.\:
นามแฝง
ระบุชื่อโดเมนเพิ่มเติม (alias) สำหรับโปรเจกต์ (คั่นด้วยช่องว่าง) สามารถใช้ตัวแปรเทมเพลตได้

ข้อจำกัด: อักขระ "*" ไม่รองรับใน Windows โดยไฟล์ HOSTS และต้องตั้งค่า DNS
สภาพแวดล้อมของโปรเจกต์
รายการส่วนเสริมและโมดูล (คั่นด้วยช่องว่าง) ที่ประกอบกันเป็นสภาพแวดล้อมของโปรเจกต์

HTTP, NODE และ PHP: สภาพแวดล้อมของเอนจินเหล่านี้จะถูกเชื่อมต่อเสมอ (หากกำหนดไว้สำหรับโดเมน) และไม่จำเป็นต้องระบุในพารามิเตอร์นี้
คำสั่งเริ่มต้นโปรเจกต์
กำหนดคำสั่งสำหรับการเริ่มต้นโปรเจกต์ (เช่น nodemon app.js) สามารถใช้ตัวแปรเทมเพลตได้
URL ของโปรเจกต์
URL ที่ใช้เมื่อเปิดโปรเจกต์ผ่าน เมนู→โปรเจกต์→เปิดในเบราว์เซอร์ รวมถึงเมื่อเปิดนามแฝงโดเมนของโปรเจกต์ สามารถใช้ตัวแปรเทมเพลตได้

การใช้งาน: สามารถกำหนด URL ของแผงผู้ดูแลระบบของ CMS ได้

ตัวแปรเทมเพลต

ตัวแปร คำอธิบาย
{backend_ip} ที่อยู่ IP สำหรับเชื่อมต่อกับส่วนเซิร์ฟเวอร์ (Backend)
{backend_port} พอร์ตสำหรับเชื่อมต่อกับส่วนเซิร์ฟเวอร์ (Backend)
{base_dir} ไดเรกทอรีรากของโปรเจกต์ (ตำแหน่งที่อยู่ของไดเรกทอรี .osp)
{date_time} วันที่/เวลา ปัจจุบัน (ตัวแปรนี้ใช้ได้เฉพาะสำหรับคำสั่งเริ่มต้นแอปของโปรเจกต์)
{host} ชื่อโดเมน (สำหรับโดเมนที่เป็นภาษาต่างประเทศใช้ Punycode)
{host_decoded} ชื่อโดเมนที่มองเห็นได้ (ไม่มี Punycode)
{host_scheme} สคีมาของคำขอไปยังโปรเจกต์ ("http" หรือ "https" ขึ้นกับพารามิเตอร์ TLS ในการตั้งค่าโปรเจกต์)
{http_port} พอร์ตของคำขอไปยังโปรเจกต์ผ่านโปรโตคอล HTTP
{https_port} พอร์ตของคำขอไปยังโปรเจกต์ผ่านโปรโตคอล HTTPS
{http_engine} เอนจิน HTTP
{node_engine} เอนจิน NODE
{php_engine} เอนจิน PHP
{project_root} ไดเรกทอรีรากของโปรเจกต์
{web_root} ไดเรกทอรีสาธารณะของโปรเจกต์
{scheme_port} พอร์ตของคำขอไปยังโปรเจกต์ (":{http_port}" หรือ ":{https_port}" ขึ้นกับพารามิเตอร์ TLS ในการตั้งค่าโปรเจกต์)

หาก {http_port} หรือ {https_port} มีค่าเริ่มต้นเป็น 80 หรือ 443 ค่า {scheme_port} จะว่าง
{root_dir} ไดเรกทอรีรากของ Open Server Panel (เส้นทางเต็ม)
{root_drive} ไดรฟ์ของไดเรกทอรีราก
{root_path} เส้นทางไปยังไดเรกทอรีรากของ Open Server Panel
{terminal_codepage} การเข้ารหัสของคอนโซล
