การสร้างรายการเมนูของคุณเอง

  1. เพิ่มเซกชันใหม่พร้อมตัวระบุ [ID] ที่ไม่ซ้ำกัน
  2. จัดวางเซกชันตามลำดับที่ต้องการ — สิ่งนี้จะกำหนดลำดับของรายการในเมนู
  3. บันทึกการเปลี่ยนแปลงและรีสตาร์ท Open Server Panel เพื่อให้การเปลี่ยนแปลงมีผล

ข้อมูลสำคัญ

เมื่อสร้างรายการเมนูของคุณเอง โปรดตรวจสอบให้แน่ใจว่า ID ของเซกชันไม่ซ้ำกัน หากซ้ำกันอาจทำให้เกิดความขัดแย้งในการทำงานของเมนูได้

การตั้งค่ารายการเมนู

ลำดับการจัดเรียง: รายการเมนูจะถูกจัดเรียงตามลำดับเดียวกับที่เซกชันที่เกี่ยวข้องถูกจัดวางไว้ในเทมเพลต

caption ชื่อของรายการเมนู รองรับคงที่ภาษาในรูปแบบ {lang_xxx}.

ค่าเริ่มต้น: ไม่ได้กำหนด
category

กำหนดตำแหน่งของรายการเมนูในลำดับชั้น รองรับการซ้อนระดับเดียว (เช่น "บุ๊กมาร์กของฉัน\งาน").

หมวดพิเศษ:

  • projects, modules, addons - เพิ่มรายการในเมนูการกระทำที่สอดคล้องกัน
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - เพิ่มรายการสำหรับองค์ประกอบเฉพาะ

หากไม่ได้ระบุหมวด รายการจะถูกสร้างในเมนูราก

ค่าเริ่มต้น: ไม่ได้กำหนด
command คำสั่งที่จะทำงานเมื่อเปิดใช้งานรายการเมนู รายการที่ไม่มีคำสั่งจะถูกเพิกเฉย

ค่าเริ่มต้น: ไม่ได้กำหนด
enabled เปิด/ปิดการแสดงผลของรายการเมนู

ค่าเริ่มต้น: on | ค่าที่รองรับ: on, off
hide ควบคุมการมองเห็นของหน้าต่างแอปที่ถูกเรียก ใช้ไม่ได้กับโพรเซสลูก

ค่าเริ่มต้น: off | ค่าที่รองรับ: on, off
hr_after เพิ่มเส้นคั่นแนวนอนหลังรายการเมนู

ค่าเริ่มต้น: off | ค่าที่รองรับ: on, off
hr_before เพิ่มเส้นคั่นแนวนอนก่อนรายการเมนู

ค่าเริ่มต้น: off | ค่าที่รองรับ: on, off
icon ไอคอนจากชุด Font Awesome Free (Solid/Regular/Brands).

ค่าเริ่มต้น: ไม่ได้กำหนด
need_alias แสดงรายการเมนูเฉพาะสำหรับโดเมน alias ในเทมเพลตเมนูสามารถมีได้เพียงรายการเดียวที่มี need_alias=on!
ใช้ได้กับหมวด: projects

ค่าเริ่มต้น: ไม่ได้กำหนด | ค่าที่รองรับ: on, off
need_category

จำกัดการแสดงรายการเมนูด้วย modules/addons ของหมวดที่กำหนด

รูปแบบที่รองรับ:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
ค่าเริ่มต้น: ไม่ได้กำหนด
need_module_shell แสดงรายการเมนูขึ้นอยู่กับการมี shell/cli ของโมดูลหลัก
ใช้ได้กับหมวด: modules, modules\<имя_модуля>

ค่าเริ่มต้น: ไม่ได้กำหนด | ค่าที่รองรับ: on, off
need_state แสดงรายการเมนูขึ้นอยู่กับสถานะของโมดูลหลัก
ใช้ได้กับหมวด: modules, modules\<имя_модуля>

ค่าเริ่มต้น: ไม่ได้กำหนด | ค่าที่รองรับ: on, off
need_start_cmd แสดงรายการเมนูเมื่อมีคำสั่งเริ่มต้นในการตั้งค่าโปรเจกต์
ใช้ได้กับหมวด: projects, projects\<имя_домена>

ค่าเริ่มต้น: ไม่ได้กำหนด | ค่าที่รองรับ: on, off
need_use_wt แสดงรายการเมนูขึ้นอยู่กับการตั้งค่าการใช้งาน Windows Terminal ใน Open Server Panel

ค่าเริ่มต้น: ไม่ได้กำหนด | ค่าที่รองรับ: on, off
work_directory ไดเรกทอรีทำงานสำหรับการรันคำสั่ง สามารถเปลี่ยนแปลงได้ระหว่างการรันคำสั่ง

ค่าเริ่มต้น: {root_dir}

ตัวแปรเทมเพลต

ในพารามิเตอร์ "command" และ "work_directory" สามารถใช้ตัวแปรเทมเพลตต่อไปนี้ได้:

ตัวแปรทั่วไป

ตัวแปร คำอธิบาย
{date_time} วันที่/เวลา ปัจจุบัน (ตัวแปรนี้ใช้ได้เฉพาะกับพารามิเตอร์ "command")
{root_dir} ไดเรกทอรีรากของ Open Server Panel (พาธแบบเต็ม)
{root_drive} ไดรฟ์ของไดเรกทอรีราก
{root_path} พาธไปยังไดเรกทอรีรากของ Open Server Panel
{web_panel_url} ที่อยู่ URL ของเว็บอินเทอร์เฟซ

ตัวแปรพิเศษ (สำหรับ projects และ projects\<имя_домена> เท่านั้น)

ตัวแปร คำอธิบาย
{base_dir} ไดเรกทอรีฐานของโปรเจกต์
{host} ชื่อโดเมน (Punycode)
{host_decoded} ชื่อโดเมนที่มองเห็นได้ (ไม่ใช่ Punycode)
{host_scheme} สคีมของการเรียกโปรเจกต์ ("http" หรือ "https" ขึ้นอยู่กับพารามิเตอร์ TLS ในการตั้งค่าโปรเจกต์)
{http_port} พอร์ตสำหรับเรียกโปรเจกต์ผ่านโปรโตคอล HTTP
{https_port} พอร์ตสำหรับเรียกโปรเจกต์ผ่านโปรโตคอล HTTPS
{menu_caption} ชื่อของรายการเมนู (เฉพาะสำหรับหมวด projects เมื่อ need_alias=ON)
{http_engine} เอนจิน HTTP
{node_engine} เอนจิน Node.js
{php_engine} เอนจิน PHP
{project_root} ไดเรกทอรีรากของโปรเจกต์
{base_url} URL ของโปรเจกต์
{web_root} ไดเรกทอรีสาธารณะของโปรเจกต์
{scheme_port} พอร์ตสำหรับเรียกโปรเจกต์ (":{http_port}" หรือ ":{https_port}" ขึ้นอยู่กับพารามิเตอร์ TLS ในการตั้งค่าโปรเจกต์) หาก {http_port} หรือ {https_port} มีค่าเริ่มต้นเป็น 80 หรือ 443 แล้ว {scheme_port} จะว่างเปล่า
{app_start_command} คำสั่งเริ่มต้นแอปของโปรเจกต์ (หากมีการตั้งค่า)
{terminal_codepage} รหัสหน้า ของคอนโซล

ตัวแปรพิเศษ (สำหรับ addons และ addons\<имя_дополнения> เท่านั้น)

ตัวแปร คำอธิบาย
{addon_name} ชื่อของส่วนเสริม
{terminal_codepage} รหัสหน้า ของคอนโซล

ตัวแปรพิเศษ (สำหรับ modules และ modules\<имя_модуля> เท่านั้น)

ตัวแปร คำอธิบาย
{ip} ที่อยู่ IP ของโมดูล
{log_level} ระดับการบันทึกข้อผิดพลาด
{module_name} ชื่อของโมดูล
{port} พอร์ตของโมดูล
{profile_name} ชื่อโปรไฟล์การตั้งค่าปัจจุบันของโมดูล
{query_log_level} ระดับการบันทึกคำขอ
{shell_command} คำสั่งเริ่มต้น shell/cli ของโมดูล (หากมีการตั้งค่า)
{terminal_codepage} รหัสหน้า ของคอนโซล
{time_zone} เขตเวลา

ค่าคำสั่งพิเศษ

คำสั่ง คำอธิบาย
command_open_logs_viewer เปิดหน้าต่างดูบันทึก
command_open_idn_converter เปิด IDN converter
command_open_options เปิดหน้าต่างการตั้งค่าโปรแกรม

นอกเหนือจากตัวแปรเทมเพลตแล้ว ยังสามารถใช้ตัวแปรสภาพแวดล้อมของ Windows ใดๆ ได้ เช่น: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% เป็นต้น

ตัวอย่างการใช้งาน

[bookmark_1]

caption  = Google
category = บุ๊กมาร์กของฉัน\เครื่องมือค้นหา
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

ตัวเลือกของ CMD.EXE

  • /c: รันคำสั่งแล้วปิดเทอร์มินัล
  • /k: รันคำสั่งแล้วคงเทอร์มินัลไว้
