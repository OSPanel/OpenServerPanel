การตั้งค่าทั่วไปของโมดูล

พารามิเตอร์ที่กำหนดในส่วนนี้จะถูกใช้เมื่อในการตั้งค่าของโมดูลเฉพาะมีค่าเป็น auto (ค่าเริ่มต้น) สำหรับออปชันที่สอดคล้องกัน

โหมดการทำงานแบบเงียบ
ปิดการแสดงข้อความป๊อปอัปเกี่ยวกับข้อผิดพลาดจาก Windows Error Reporting และจากตัวโมดูลเอง

คำแนะนำ: ปิดโหมดนี้เฉพาะเมื่อจำเป็นต้องวินิจฉัยปัญหาในการทำงานของโมดูล
เพิ่มส่วนหัวในไฟล์บันทึก
เปิดการเพิ่มส่วนหัวลงในไฟล์บันทึกโดยอัตโนมัติทุกครั้งที่เริ่มโมดูล มีประโยชน์เมื่อปิดการล้างบันทึกอัตโนมัติเพื่อแยกเซสชันการทำงาน
จำนวนครั้งสูงสุดของการเริ่มล้มเหลว
กำหนดจำนวนครั้งของการเริ่มโมดูลที่ล้มเหลวติดต่อกันที่อนุญาตก่อนที่โมดูลจะเข้าสู่สถานะ “ข้อผิดพลาด”
เวลาตรวจสอบความพร้อมใช้งานของโมดูล
กำหนดช่วงเวลาทดสอบความพร้อมใช้งานของโมดูลหลังจากเริ่มทำงานสำเร็จ

เวลาเริ่มนับ: นับตั้งแต่ช่วงเวลาที่โมดูลเริ่มทำงานสำเร็จ

การเข้าสู่สถานะ “ข้อผิดพลาด”: หากโมดูลหยุดทำงานอย่างไม่คาดคิดภายในระยะทดสอบ จะไม่ถูกเริ่มใหม่โดยอัตโนมัติและจะเข้าสู่สถานะ “ข้อผิดพลาด” ซึ่งรวมถึงกรณีที่ไม่สามารถเริ่มโมดูลได้ในระดับระบบด้วย

การปิดการตรวจสอบ: ค่า 0 จะปิดระยะทดสอบ และโมดูลจะถูกเริ่มใหม่เสมอเมื่อเกิดข้อขัดข้อง

คำแนะนำ: อย่ากำหนดค่าเป็น 0 หรือช่วงเวลาที่สั้นเกินไป (น้อยกว่า 30 วินาที) เนื่องจากอาจทำให้เกิดลูปการเริ่มใหม่ไม่สิ้นสุด
เวลาในการรอการปิดการทำงานของโมดูล
กำหนดเวลาสูงสุดที่อนุญาตให้โมดูลปิดการทำงานของตนเอง

การปิดแบบบังคับ: หากโมดูลไม่ปิดการทำงานภายในเวลาที่กำหนด จะถูกหยุดแบบบังคับ

การปิดการรอ: ค่า 0 จะปิดช่วงเวลาการรอ โปรแกรมจะรอการปิดการทำงานของโมดูลโดยไม่จำกัดเวลา

คำเตือน: การหยุดโมดูลแบบบังคับอาจทำให้ข้อมูลเสียหาย สูญเสียการเปลี่ยนแปลงที่ยังไม่บันทึก หรือจบกระบวนการอย่างไม่ถูกต้อง ใช้การตั้งค่านี้ด้วยความระมัดระวัง
ขนาดสูงสุดของไฟล์บันทึก
ขนาดสูงสุดของไฟล์บันทึกเป็นเมกะไบต์ เมื่อเกินค่าที่ระบุ ไฟล์บันทึกจะถูกสร้างใหม่เมื่อเริ่มโมดูลครั้งถัดไป

ตั้งค่า 0 เพื่อทำความสะอาดบันทึกทุกครั้งที่เริ่มโมดูล

ตั้งค่า 100 MB เพื่อปิดการทำความสะอาดบันทึกโดยสมบูรณ์
การเข้ารหัสของเทอร์มินัล
การเข้ารหัสของเทอร์มินัลเมื่อทำงานกับสภาพแวดล้อมของโมดูล

ค่าพิเศษ:
- system: ใช้การเข้ารหัสของระบบ
เขตเวลา
กำหนดเขตเวลาของโมดูลในรูปแบบ Etc/GMT (เช่น Etc/GMT-3)

ค่าพิเศษ:
- system: ใช้เขตเวลาของระบบ

สำคัญ: รูปแบบ Etc/GMT มีการชดเชยกลับด้านเมื่อเทียบกับ UTC (เช่น Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow)
สภาพแวดล้อมของส่วนเสริมที่ใช้
กำหนดรายการของส่วนเสริม (ระบุคั่นด้วยช่องว่าง) ที่สภาพแวดล้อมของส่วนเสริมเหล่านั้น (ถ้ามี) จะถูกแนบเข้ากับสภาพแวดล้อมของโมดูล ตัวบ่งชี้ข้อมูลในเทอร์มินัลจะไม่แสดงสภาพแวดล้อมเพิ่มเติมเหล่านี้

คำเตือน: ใช้ออปชันนี้เฉพาะเมื่อเข้าใจวัตถุประสงค์ของมันอย่างถ่องแท้
ตัวแปรระบบที่อนุญาต
กำหนดรายการตัวแปรสภาพแวดล้อมของ Windows (ระบุคั่นด้วยช่องว่าง) ที่จะถูกส่งต่อไปยังสภาพแวดล้อมของโมดูล

วัตถุประสงค์: ช่วยแยกสภาพแวดล้อมการทำงานของโมดูลออกจากซอฟต์แวร์ที่ติดตั้งในระบบซึ่งมีลักษณะคล้ายกัน

คำเตือน: การเปลี่ยนแปลงรายการนี้โดยไม่เข้าใจผลกระทบอย่างถ่องแท้อาจทำให้การทำงานของโมดูลไม่เสถียร
