การตั้งค่าโปรแกรม

เปิดพร้อมกับ Windows
เปิดใช้งานการเริ่มต้นอัตโนมัติของ Open Server Panel เมื่อระบบปฏิบัติการบูต
หน่วงเวลา
หน่วงเวลาในการเริ่มโปรแกรม (เป็นวินาที ตั้งแต่ 0 ถึง 60).

ช่วยเลื่อนการเริ่มแอปในระหว่างบูตร่วมกับ Windows เพื่อลดภาระโดยรวมของระบบ เหมาะอย่างยิ่งเมื่อจำเป็นต้องรอให้บริการภายนอกหรืออินเทอร์เฟซเครือข่ายเริ่มทำงานสมบูรณ์
ตรวจสอบเวอร์ชันใหม่
เปิดใช้งานการตรวจสอบอัปเดต Open Server Panel (ต้องเชื่อมต่ออินเทอร์เน็ต)
เปิดใช้งานตัวจัดตารางงาน
เปิดใช้งานตัวจัดตารางงานแบบในตัว หากปิดพารามิเตอร์นี้ งานที่กำหนดเวลาไว้จะไม่ถูกรัน ไม่ว่ามันจะมีสถานะใดก็ตาม
ใช้ไฟล์ HOSTS
เปิดการเขียนชื่อโดเมนลงในไฟล์ HOSTS

คำแนะนำเมื่อมีการเข้าถึงไฟล์ HOSTS แบบจำกัดในองค์กร:

1. ตั้งค่ามอดูลและโปรเจกต์ที่จำเป็นทั้งหมด
2. ติดต่อผู้ดูแลระบบเพื่อปลดบล็อก HOSTS และยืนยันสถานะของมัน
3. หลังจากผู้ดูแลระบบยืนยันการเปลี่ยนแปลงแล้ว สามารถปิดตัวเลือกนี้ได้

สำคัญ: อย่าปิดพารามิเตอร์นี้ หากไม่มั่นใจในผลที่ตามมา!
เริ่มมอดูลด้วยโปรไฟล์ของโปรเจกต์
เริ่มมอดูลพร้อมเปิดใช้งานโปรไฟล์ที่มีชื่อเดียวกับโปรเจกต์

ใช้เมื่อเลือกเมนู «เปิดใช้งานมอดูลของโปรเจกต์» เพื่อเปิดใช้งานโปรไฟล์ที่มีชื่อเดียวกับโปรเจกต์ปัจจุบันโดยอัตโนมัติ หากมีอยู่
ไม่ปิดมอดูลของโปรเจกต์ที่ซ่อนอยู่
ไม่ปิดมอดูลของโปรเจกต์ที่ซ่อนอยู่เมื่อเลือกเมนู «ปิดมอดูลทั้งหมด» คำว่า "ซ่อน" หมายถึงโปรเจกต์ที่กำหนดหมวดหมู่ "hidden"

โดยค่าเริ่มต้น คำสั่ง «ปิดมอดูลทั้งหมด» จะหยุดการทำงานของมอดูลทุกตัว รวมถึงมอดูลที่ถูกใช้โดยโปรเจกต์บริการที่ซ่อนอยู่ (เช่น PHPMyAdmin) ตัวเลือกนี้ช่วยคงความสามารถในการทำงานของโปรเจกต์บริการที่ซ่อนอยู่ โดยไม่ปิดมอดูลที่จำเป็นสำหรับมัน ในขณะที่มอดูลอื่น ๆ ทั้งหมดจะถูกปิด
ภาษาของอินเทอร์เฟซ
ภาษาของอินเทอร์เฟซผู้ใช้ Open Server Panel

หากไม่มีไฟล์การแปลหรือไฟล์มีข้อผิดพลาด จะใช้ภาษาอังกฤษ
โดเมน API
โดเมนภายในเครื่องสำหรับ API และเว็บอินเทอร์เฟซ (กำลังพัฒนา)

คำแนะนำ: หากใช้ VPN หรือพร็อกซี ให้เพิ่มโดเมนนี้ในรายการยกเว้น
ที่อยู่ IP ของ API
ที่อยู่ IPv4 สำหรับ API และเว็บอินเทอร์เฟซ (กำลังพัฒนา)

คำแนะนำ: หากใช้ VPN หรือพร็อกซี ให้เพิ่มที่อยู่ IP นี้ในรายการยกเว้น
พอร์ต API
พอร์ตที่ใช้สำหรับ API และเว็บอินเทอร์เฟซ (กำลังพัฒนา) Open Server Panel จะไม่สามารถเริ่มได้ หากพอร์ตที่ระบุถูกใช้งานโดยแอปพลิเคชันอื่นอยู่แล้ว
ใช้ Windows Terminal
เปิดใช้งานการใช้ Windows Terminal แทนอินเทอร์เฟซคำสั่งมาตรฐาน

ข้อกำหนด: ต้องติดตั้ง Windows Terminal ในระบบและระบุไว้ในตัวแปรสภาพแวดล้อม PATH

Windows Terminal เป็น cmd.exe: Windows Terminal สามารถแทนที่ cmd.exe และถูกระบุในตัวแปรสภาพแวดล้อม %COMSPEC% ใน Windows รุ่นใหม่ หากเป็นเช่นนั้น ให้คงเปิดใช้งานตัวเลือกนี้ไว้

อินสแตนซ์ใหม่ของ Windows Terminal: หาก Windows Terminal เปิดหน้าต่างใหม่แทนแท็บ ให้ตั้งค่า: การตั้งค่า→การเริ่มต้น→พฤติกรรมของอินสแตนซ์ใหม่→แนบกับหน้าต่างที่ใช้ล่าสุด
ชื่อหัวข้อโปรเจกต์แบบสั้น
เมื่อเปิดใช้งานตัวเลือกนี้ ในชื่อหน้าต่างของเทอร์มินัลจะแสดงเฉพาะชื่อโปรเจกต์แทนคำอธิบายสภาพแวดล้อมโดยละเอียด
รวมสภาพแวดล้อมของระบบไว้ในสภาพแวดล้อมของโปรเจกต์
ใช้สภาพแวดล้อมของระบบ (System) ในเทอร์มินัล แม้ว่าจะไม่ได้กำหนดไว้ในการตั้งค่าของโปรเจกต์ สภาพแวดล้อมของระบบช่วยให้ใช้โปรแกรมที่ติดตั้งในระบบได้ (เช่น git.exe หรือ ssh.exe)

ปิดตัวเลือกนี้เฉพาะเมื่อเกิดความขัดแย้งกับซอฟต์แวร์ของระบบ
การรองรับ ANSI
เปิดใช้งานการรองรับโค้ด ANSI สำหรับการจัดการสีในเทอร์มินัล

โหมด "อัตโนมัติ" (ค่าเริ่มต้น):
- การแก้ไขจะถูกใช้เฉพาะกับ Windows 10 จนถึงเวอร์ชัน 1903 รวมด้วย ใน Windows เวอร์ชันใหม่กว่ามีการรองรับ ANSI ในตัวแล้ว
- จะไม่ใช้การแก้ไขสำหรับเทอร์มินัลที่รองรับ ANSI ตามค่าเริ่มต้น (เช่น Windows Terminal)
ไดเรกทอรีสำหรับค้นหาโปรเจกต์
รายการไดเรกทอรีที่ Open Server Panel จะค้นหาโปรเจกต์ คั่นเส้นทางด้วยเครื่องหมายอัฒภาค (;)

ข้อยกเว้น: จะละเว้นโฟลเดอร์ย่อย node_modules และ vendor
ความลึก
ความลึกสูงสุดของการซ้อนโฟลเดอร์เมื่อค้นหาโปรเจกต์

การเพิ่มค่านี้อาจทำให้การเริ่ม Open Server Panel ช้าลง หากในไดเรกทอรีที่ระบุมีโฟลเดอร์ย่อยจำนวนมาก
ขนาดสูงสุดของไฟล์บันทึก
ขนาดสูงสุดของไฟล์บันทึกเป็นเมกะไบต์ เมื่อเกินค่าที่กำหนด ไฟล์บันทึกจะถูกสร้างใหม่เมื่อเริ่มโปรแกรมครั้งถัดไป

ตั้งค่าเป็น 0 เพื่อเคลียร์บันทึกทุกครั้งที่เริ่มโปรแกรม

ตั้งค่าเป็น 100 MB เพื่อปิดการเคลียร์บันทึกอย่างสมบูรณ์
