Creazione di voci di menu personalizzate

  1. Aggiungi una nuova sezione con un identificatore univoco [ID]
  2. Disponi le sezioni nell’ordine desiderato: questo determinerà l’ordine delle voci nel menu
  3. Salva le modifiche e riavvia Open Server Panel per applicarle

Informazioni importanti

Quando crei voci di menu personalizzate, assicurati che gli identificatori delle sezioni non si ripetano. Ciò può causare conflitti nel funzionamento del menu.

Impostazioni delle voci di menu

Ordine di ordinamento: Le voci di menu vengono ordinate nello stesso ordine in cui sono disposte le sezioni corrispondenti nel template.

caption Titolo della voce di menu. Supporta le costanti di lingua nel formato {lang_xxx}.

Predefinito: non impostato
category

Determina la posizione della voce di menu nella gerarchia. Supporta un livello di annidamento (ad esempio, "I miei Segnalibri\Lavoro").

Categorie speciali:

  • projects, modules, addons - aggiunge la voce al corrispondente menu delle azioni
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - aggiunge la voce per un elemento specifico

Se la categoria non è specificata, la voce viene creata nel menu principale.

Predefinito: non impostato
command Comando da eseguire all’attivazione della voce di menu. Le voci senza comando vengono ignorate.

Predefinito: non impostato
enabled Abilita/disabilita la visualizzazione della voce di menu.

Predefinito: on | Valori: on, off
hide Controlla la visibilità della finestra dell’applicazione richiamata. Non influisce sui processi figlio.

Predefinito: off | Valori: on, off
hr_after Aggiunge un separatore orizzontale dopo la voce di menu.

Predefinito: off | Valori: on, off
hr_before Aggiunge un separatore orizzontale prima della voce di menu.

Predefinito: off | Valori: on, off
icon Icona dal set Font Awesome Free (Solid/Regular/Brands).

Predefinito: non impostato
need_alias Mostra la voce di menu solo per un alias di dominio. Nel template del menu può esserci solo una voce con need_alias=on!
Applicabile per le categorie: projects

Predefinito: non impostato | Valori: on, off
need_category

Limita la visualizzazione della voce di menu a modules/addons di una determinata categoria.

Formati supportati:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Predefinito: non impostato
need_module_shell Mostra la voce di menu a seconda della presenza di shell/cli nel modulo padre.
Applicabile per le categorie: modules, modules\<имя_модуля>

Predefinito: non impostato | Valori: on, off
need_state Mostra la voce di menu a seconda dello stato del modulo padre.
Applicabile per le categorie: modules, modules\<имя_модуля>

Predefinito: non impostato | Valori: on, off
need_start_cmd Mostra la voce di menu se è presente un comando di avvio nelle impostazioni del progetto.
Applicabile per le categorie: projects, projects\<имя_домена>

Predefinito: non impostato | Valori: on, off
need_use_wt Mostra la voce di menu in base all’impostazione sull’uso di Windows Terminal in Open Server Panel.

Predefinito: non impostato | Valori: on, off
work_directory Directory di lavoro per l’esecuzione del comando. Può cambiare durante l’esecuzione dei comandi.

Predefinito: {root_dir}

Variabili del template

Nei parametri "command" e "work_directory" è possibile utilizzare le seguenti variabili del template:

Variabili generali

Variabile Descrizione
{date_time} Data/ora corrente (variabile disponibile solo per il parametro "command")
{root_dir} Directory radice di Open Server Panel (percorso completo)
{root_drive} Unità della directory radice
{root_path} Percorso alla directory radice di Open Server Panel
{web_panel_url} URL dell’interfaccia web

Variabili speciali (solo per projects e projects\<имя_домена>)

Variabile Descrizione
{base_dir} Directory base del progetto
{host} Nome del dominio (Punycode)
{host_decoded} Nome visibile del dominio (senza Punycode)
{host_scheme} Schema della richiesta al progetto ("http" o "https", dipende dal parametro TLS nelle impostazioni del progetto)
{http_port} Porta della richiesta al progetto tramite HTTP
{https_port} Porta della richiesta al progetto tramite HTTPS
{menu_caption} Titolo della voce di menu (solo per la categoria projects con need_alias=ON)
{http_engine} Motore HTTP
{node_engine} Motore Node.js
{php_engine} Motore PHP
{project_root} Directory radice del progetto
{base_url} URL del progetto
{web_root} Directory pubblica del progetto
{scheme_port} Porta della richiesta al progetto (":{http_port}" o ":{https_port}", dipende dal parametro TLS nelle impostazioni del progetto). Se {http_port} o {https_port} ha il valore standard 80 o 443, allora {scheme_port} sarà vuota.
{app_start_command} Comando di avvio dell’applicazione del progetto (se impostato)
{terminal_codepage} Codifica della console

Variabili speciali (solo per addons e addons\<имя_дополнения>)

Variabile Descrizione
{addon_name} Nome dell’addon
{terminal_codepage} Codifica della console

Variabili speciali (solo per modules e modules\<имя_модуля>)

Variabile Descrizione
{ip} Indirizzo IP del modulo
{log_level} Livello di registrazione degli errori
{module_name} Nome del modulo
{port} Porta del modulo
{profile_name} Nome del profilo di impostazioni corrente del modulo
{query_log_level} Livello di registrazione delle query
{shell_command} Comando di avvio della shell/cli del modulo (se impostato)
{terminal_codepage} Codifica della console
{time_zone} Fuso orario

Valori speciali dei comandi

Comando Descrizione
command_open_logs_viewer Apri la finestra di visualizzazione dei log
command_open_idn_converter Apri l’IDN-converter
command_open_options Apri la finestra delle impostazioni del programma

Oltre alle variabili del template, è possibile utilizzare qualsiasi variabile d’ambiente di Windows, ad esempio: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, ecc.

Esempio di utilizzo

[bookmark_1]

caption  = Google
category = I miei Segnalibri\Motori di ricerca
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opzioni di CMD.EXE

  • /c: Eseguire il comando e chiudere il terminale.
  • /k: Eseguire il comando e lasciare il terminale aperto.
