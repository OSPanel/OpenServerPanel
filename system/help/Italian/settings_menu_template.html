Creazione di voci di menu personalizzate

  1. Aggiungere una nuova sezione con un identificatore univoco [ID]
  2. Disporre le sezioni nell'ordine desiderato — questo determinerà l'ordine delle voci nel menu
  3. Salvare le modifiche e riavviare Open Server Panel per applicare le modifiche

Informazioni importanti

Quando si creano voci di menu personalizzate, assicurarsi che gli identificatori delle sezioni non siano duplicati. Questo può portare a conflitti nella funzionalità del menu.

Impostazioni delle voci di menu

Ordine di ordinamento: Le voci del menu vengono ordinate nello stesso ordine delle sezioni corrispondenti nel modello.

caption Titolo della voce di menu. Supporta costanti di lingua nel formato {lang_xxx}.

Predefinito: non impostato
category

Determina la posizione della voce nella gerarchia del menu. Supporta un livello di nidificazione (ad esempio, "I miei Segnalibri\Lavoro").

Categorie speciali:

  • projects, modules, addons - aggiunge la voce al menu azioni corrispondente
  • projects\, modules\, addons\ - aggiunge una voce per un elemento specifico

Se la categoria non è specificata, la voce viene creata nel menu radice.

Predefinito: non impostato
command Comando da eseguire quando la voce di menu viene attivata. Le voci senza comando vengono ignorate.

Predefinito: non impostato
enabled Attiva/disattiva la visualizzazione della voce di menu.

Predefinito: on | Valori: on, off
hide Controlla la visibilità della finestra dell'applicazione chiamata. Non influisce sui processi figli.

Predefinito: off | Valori: on, off
hr_after Aggiunge un separatore orizzontale dopo la voce di menu.

Predefinito: off | Valori: on, off
hr_before Aggiunge un separatore orizzontale prima della voce di menu.

Predefinito: off | Valori: on, off
icon Icona dal set Font Awesome Free (Solid/Regular/Brands).

Predefinito: non impostato
need_alias Visualizza la voce di menu solo per un alias di dominio. Il modello di menu può avere solo una voce con need_alias=on!
Applicabile per categorie: projects

Predefinito: non impostato | Valori: on, off
need_category

Limita la visualizzazione della voce di menu a moduli/componenti aggiuntivi di una specifica categoria.

Formati supportati:

  • modules, addons
  • modules\, addons\
Predefinito: non impostato
need_module_shell Visualizza la voce di menu in base alla presenza di shell/cli nel modulo principale.
Applicabile per categorie: modules, modules\

Predefinito: non impostato | Valori: on, off
need_state Visualizza la voce di menu in base allo stato del modulo principale.
Applicabile per categorie: modules, modules\

Predefinito: non impostato | Valori: on, off
need_start_cmd Visualizza la voce di menu se è presente un comando di avvio nelle impostazioni del progetto.
Applicabile per categorie: projects, projects\

Predefinito: non impostato | Valori: on, off
need_use_wt Visualizza la voce di menu in base all'impostazione di utilizzo di Windows Terminal in Open Server Panel.

Predefinito: non impostato | Valori: on, off
work_directory Directory di lavoro per l'esecuzione del comando. Può essere modificata durante l'esecuzione del comando.

Predefinito: {root_dir}

Variabili del modello

Le seguenti variabili del modello possono essere utilizzate nei parametri "command" e "work_directory":

Variabili generali

Variabile Descrizione
{root_dir} Directory radice di Open Server Panel (percorso completo)
{root_drive} Unità della directory radice
{root_path} Percorso della directory radice di Open Server Panel
{web_panel_url} URL dell'interfaccia web

Variabili speciali (solo per projects e projects\<nome_dominio>)

Variabile Descrizione
{base_dir} Directory base del progetto
{host} Nome di dominio (Punycode)
{host_decoded} Nome di dominio visibile (senza Punycode)
{host_scheme} Schema di richiesta del progetto ("http" o "https", dipende dal parametro SSL nelle impostazioni del progetto)
{http_port} Porta di richiesta del protocollo HTTP per il progetto
{https_port} Porta di richiesta del protocollo HTTPS per il progetto
{menu_caption} Titolo della voce di menu (solo per la categoria projects con need_alias=ON)
{nginx_engine} Motore Nginx
{node_engine} Motore Node.js
{php_engine} Motore PHP
{project_dir} Directory radice del progetto
{project_url} URL del progetto
{public_dir} Directory pubblica del progetto
{scheme_port} Porta di richiesta del progetto (":{http_port}" o ":{https_port}", dipende dal parametro SSL nelle impostazioni del progetto). Se {http_port} o {https_port} ha un valore standard di 80 o 443, allora {scheme_port} sarà vuoto.
{start_command} Comando di avvio del progetto (se configurato)
{terminal_codepage} Codifica della console

Variabili speciali (solo per addons e addons\<nome_componente_aggiuntivo>)

Variabile Descrizione
{addon_name} Nome del componente aggiuntivo
{terminal_codepage} Codifica della console

Variabili speciali (solo per modules e modules\<nome_modulo>)

Variabile Descrizione
{ip} Indirizzo IP del modulo
{log_level} Livello di registrazione degli errori
{module_name} Nome del modulo
{port} Porta del modulo
{profile_name} Nome del profilo di impostazioni corrente del modulo
{query_log_level} Livello di registrazione delle query
{shell_command} Comando di avvio della shell/cli del modulo (se configurato)
{terminal_codepage} Codifica della console
{time_zone} Fuso orario

Valori speciali dei comandi

Comando Descrizione
command_open_logs_viewer Apri la finestra di visualizzazione dei log
command_open_idn_converter Apri il convertitore IDN
command_open_options Apri la finestra delle impostazioni del programma

Oltre alle variabili del modello, è possibile utilizzare qualsiasi variabile di ambiente Windows, come: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, ecc.

Esempi di utilizzo

[21]

caption  = Apri in PhpStorm
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = I miei Segnalibri\Motori di ricerca
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opzioni `cmd.exe`

  • /c: Esegui il comando e chiudi il terminale.
  • /k: Esegui il comando e mantieni il terminale aperto.
