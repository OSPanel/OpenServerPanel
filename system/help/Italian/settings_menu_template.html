Creazione di voci di menu personalizzate

  1. Aggiungi una nuova sezione con un identificatore univoco [ID]
  2. Posiziona le sezioni nell'ordine desiderato — questo determinerà l'ordine delle voci nel menu
  3. Salva le modifiche e riavvia Open Server Panel per applicare le modifiche

Informazioni importanti

Quando crei voci di menu personalizzate, assicurati che gli identificatori delle sezioni non si ripetano. Ciò potrebbe causare conflitti nel funzionamento del menu.

Impostazioni delle voci di menu

Ordine di ordinamento: Le voci di menu sono ordinate nello stesso ordine in cui le sezioni corrispondenti sono posizionate nel modello.

caption Intestazione della voce di menu. Supporta costanti linguistiche nel formato {lang_xxx}.

Predefinito: non specificato
category

Determina la posizione della voce di menu nella gerarchia. Supporta un livello di nidificazione (ad esempio, "I Miei Segnalibri\Lavoro").

Categorie speciali:

  • projects, modules, addons - aggiunge la voce nel menu azioni corrispondente
  • projects\, modules\, addons\ - aggiunge la voce per l'elemento specifico

Se la categoria non è specificata, la voce viene creata nel menu principale.

Predefinito: non specificato
command Comando da eseguire quando si attiva la voce di menu. Le voci senza comando vengono ignorate.

Predefinito: non specificato
enabled Attiva/disattiva la visualizzazione della voce di menu.

Predefinito: on | Valori: on, off
hide Controlla la visibilità della finestra dell'applicazione richiamata. Non influisce sui processi figlio.

Predefinito: off | Valori: on, off
hr_after Aggiunge un separatore orizzontale dopo la voce di menu.

Predefinito: off | Valori: on, off
hr_before Aggiunge un separatore orizzontale prima della voce di menu.

Predefinito: off | Valori: on, off
icon Icona dal set Font Awesome Free (Solid/Regular/Brands).

Predefinito: non specificato
need_alias Visualizza la voce di menu solo per l'alias di dominio. Nel template del menu può esserci solo una voce con need_alias=on!
Applicabile per le categorie: projects

Predefinito: non specificato | Valori: on, off
need_category

Limita la visualizzazione della voce di menu ai moduli/componenti aggiuntivi di una determinata categoria.

Formati supportati:

  • modules, addons
  • modules\, addons\
Predefinito: non specificato
need_module_shell Visualizza la voce di menu in base alla presenza di shell/cli nel modulo principale.
Applicabile per categorie: modules, modules\

Predefinito: non specificato | Valori: on, off
need_state Visualizza la voce di menu in base allo stato del modulo principale.
Applicabile per categorie: modules, modules\

Predefinito: non specificato | Valori: on, off
need_start_cmd Visualizza la voce di menu quando è presente un comando di avvio nelle impostazioni del progetto.
Applicabile per categorie: projects, projects\

Predefinito: non specificato | Valori: on, off
need_use_wt Visualizza la voce di menu in base all'impostazione dell'utilizzo di Windows Terminal in Open Server Panel.

Predefinito: non specificato | Valori: on, off
work_directory Directory di lavoro per l'esecuzione del comando. Può essere modificata durante l'esecuzione dei comandi.

Predefinito: {root_dir}

Variabili di modello

Nei parametri "command" e "work_directory" è possibile utilizzare le seguenti variabili di modello:

Variabili generali

Variabile Descrizione
{root_dir} Directory principale di Open Server Panel (percorso completo)
{root_drive} Unità della directory principale
{root_path} Percorso alla directory principale di Open Server Panel
{web_panel_url} URL dell'interfaccia web

Variabili speciali (solo per projects e projects\<nome_dominio>)

Variabile Descrizione
{base_dir} Directory base del progetto
{host} Nome di dominio (Punycode)
{host_decoded} Nome di dominio visibile (senza Punycode)
{host_scheme} Schema della richiesta al progetto ("http" o "https", dipende dal parametro SSL nelle impostazioni del progetto)
{menu_caption} Titolo della voce di menu (solo per la categoria projects con need_alias=ON)
{nginx_engine} Motore Nginx
{node_engine} Motore Node.js
{php_engine} Motore PHP
{project_dir} Directory principale del progetto
{project_url} URL del progetto
{public_dir} Directory pubblica del progetto
{start_command} Comando di avvio del progetto (se configurato)
{terminal_codepage} Codifica della console

Variabili speciali (solo per addons e addons\<nome_componente>)

Variabile Descrizione
{addon_name} Nome del componente aggiuntivo
{terminal_codepage} Codifica della console

Variabili speciali (solo per modules e modules\<nome_modulo>)

Variabile Descrizione
{ip} Indirizzo IP del modulo
{log_level} Livello di registrazione degli errori
{module_name} Nome del modulo
{port} Porta del modulo
{profile_name} Nome del profilo di impostazioni corrente del modulo
{query_log_level} Livello di registrazione delle query
{shell_command} Comando di avvio della shell/cli del modulo (se configurato)
{terminal_codepage} Codifica della console
{time_zone} Fuso orario

Valori speciali dei comandi

Comando Descrizione
command_open_logs_viewer Apri la finestra di visualizzazione dei registri
command_open_idn_converter Apri il convertitore IDN
command_open_options Apri la finestra delle impostazioni del programma

Oltre alle variabili di modello, è possibile utilizzare qualsiasi variabile dell'ambiente Windows, ad esempio: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, ecc.

Esempi di utilizzo

[21]

caption  = Apri in PhpStorm
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = I Miei Segnalibri\Motori di ricerca
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opzioni `cmd.exe`

  • /c: Esegui il comando e chiudi il terminale.
  • /k: Esegui il comando e mantieni il terminale aperto.
