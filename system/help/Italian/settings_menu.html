Impostazioni del menu

Tema
Tema per le icone del menu.
Dimensione del carattere
Dimensione del carattere del menu in pixel. L'opzione consente di impostare la dimensione del carattere del menu indipendentemente dalle impostazioni di sistema.

Imposta il cursore sul valore minimo di 12px per disattivare la funzione di controllo della dimensione del carattere (verrà utilizzata la dimensione di sistema).
Mostra icona nell'area di notifica
Mostra l'icona del programma nell'area di notifica di Windows.

Disattivazione: Disattiva questa opzione se esegui Open Server Panel in un ambiente Windows Server Core o utilizzi un tipo di avvio automatico che non richiede l'accesso dell'utente Windows (Pianificatore attività di Windows→Avvio all'avvio del computer).
Mostra icone per le voci di menu
Mostra icone nel menu del programma. Le icone non vengono visualizzate se è attivato il rendering di sistema.
Attiva rendering di sistema
Attiva questa opzione solo quando è necessario garantire la compatibilità con i programmi di accesso allo schermo (screen reader).
Mostra separatore verticale
Quando questa opzione è attiva, le icone nel menu del programma saranno separate da un separatore verticale.
Non raggruppare liste con un solo elemento
Non raggruppare liste che contengono un solo elemento.
