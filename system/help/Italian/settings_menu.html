Impostazioni del menu

Tema dell'interfaccia
Tema dell'interfaccia per le icone del menu.
Dimensione del carattere
Dimensione del carattere del menu in pixel. L'opzione consente di impostare la dimensione del carattere del menu indipendentemente dalle impostazioni di sistema.

Impostare il cursore al valore minimo di 12px per disattivare la funzione di controllo della dimensione del carattere (verrà utilizzata la dimensione di sistema).
Mostrare l'icona nell'area di notifica
Mostrare l'icona del programma nell'area di notifica di Windows.

Disattivazione: Disattivate questa opzione se utilizzate un tipo di avvio automatico che non richiede l'accesso dell'utente Windows (Pianificatore attività di Windows→Avvio all'avvio del computer).
Mostrare le icone per le voci di menu
Mostrare le icone nel menu del programma. Le icone non vengono visualizzate se è abilitato il rendering di sistema.
Abilitare il rendering di sistema
Abilitare questa opzione solo se necessario per garantire la compatibilità con i programmi di accesso allo schermo (screen reader).

Attenzione! Le icone nel menu non vengono visualizzate se è abilitato il rendering di sistema.
Mostrare il separatore verticale
Quando questa opzione è abilitata, le icone nel menu del programma saranno separate da un separatore verticale.
Non raggruppare gli elenchi di un solo elemento
Non raggruppare gli elenchi contenenti un solo elemento.
