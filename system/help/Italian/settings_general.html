Impostazioni del programma

Avvia con Windows
Abilita l'avvio automatico di Open Server Panel all'avvio del sistema operativo.
Ritardo
Ritardo all'avvio del programma (in secondi, da 0 a 60).

Consente di posticipare l'avvio dell'applicazione per ridurre il carico sul sistema durante l'avvio. Questo è particolarmente utile se è necessario attendere la completa inizializzazione di servizi di terze parti o interfacce di rete.
Verifica la presenza di nuove versioni
Abilita il controllo degli aggiornamenti per Open Server Panel (richiede connessione a Internet).
Abilita pianificatore attività
Attiva il pianificatore di attività integrato. Se questo parametro è disabilitato, nessuna attività pianificata verrà eseguita indipendentemente dal suo stato.
Usa file HOSTS
Abilita la scrittura di nomi di dominio nel file HOSTS.

Raccomandazioni per l'accesso limitato al file HOSTS nelle organizzazioni:

1. Configurare tutti i moduli e progetti necessari.
2. Contattare l'amministratore di sistema per sbloccare il file HOSTS e fissarne lo stato.
3. Dopo che l'amministratore ha fissato le modifiche, è possibile disabilitare questa opzione.

Importante: Non disabilitare questo parametro se non sei sicuro delle conseguenze!
Avvia moduli con profilo progetto
Avvia i moduli con attivazione simultanea di un profilo corrispondente al nome del progetto.

Utilizzato quando si seleziona la voce di menu "Abilita moduli del progetto" per attivare automaticamente un profilo con lo stesso nome del progetto corrente, se esiste.
Non disattivare i moduli dei progetti nascosti
Non disattivare i moduli dei progetti nascosti quando si seleziona l'opzione di menu "Disattiva tutti i moduli". Per impostazione predefinita, il comando "Disattiva tutti i moduli" interrompe il funzionamento di tutti i moduli, inclusi quelli utilizzati dai progetti di servizio (ad esempio PHPMyAdmin). Questa opzione consente di mantenere la funzionalità dei progetti di servizio nascosti senza disattivare i moduli necessari per essi, mentre tutti gli altri moduli verranno disattivati.
Lingua dell'interfaccia
Lingua dell'interfaccia utente per Open Server Panel.

Se il file di localizzazione è mancante o contiene errori, verrà utilizzato l'inglese.
Dominio API
Dominio locale per API e interfaccia web (in sviluppo)

Raccomandazione: Se si utilizza VPN o proxy, aggiungere questo dominio alle eccezioni.
Indirizzo IP API
Indirizzo IPv4 per API e interfaccia web (in sviluppo).

Raccomandazione: Se si utilizza VPN o proxy, aggiungere questo indirizzo IP alle eccezioni.
Porta API
Porta utilizzata per API e interfaccia web (in sviluppo). Open Server Panel non sarà in grado di avviarsi se la porta specificata è già in uso da un'altra applicazione.
Usa Windows Terminal
Abilita l'utilizzo di Windows Terminal invece dell'interfaccia a riga di comando standard.

Requisiti: Windows Terminal deve essere installato nel sistema e definito nella variabile di ambiente PATH.

Windows Terminal come cmd.exe: Windows Terminal può sostituire cmd.exe ed essere definito nella variabile di ambiente %COMSPEC% nelle versioni più recenti di Windows. In questo caso, mantieni questa opzione abilitata.

Nuove istanze di Windows Terminal: Se Windows Terminal apre nuove finestre invece di schede, configuralo come segue: Impostazioni→Avvio→Comportamento nuova istanza→Collega alla finestra utilizzata più di recente.
Titolo breve del progetto
Quando questa opzione è attivata, nel titolo della finestra del terminale verrà visualizzato solo il nome del progetto invece di una descrizione dettagliata.
Includi ambiente di sistema nell'ambiente del progetto
Usa l'ambiente di sistema (System) nel terminale anche se non è specificato nelle impostazioni del progetto. L'ambiente di sistema consente l'uso di programmi installati nel sistema (come git.exe o ssh.exe).

Disabilita questa opzione solo in caso di conflitti con il software di sistema.
Supporto ANSI
Abilita il supporto per i codici ANSI per controllare i colori nel terminale.

Modalità "Automatica" (predefinita):
- La correzione viene applicata solo a Windows 7, 8 e Windows 10 (fino alla versione 1903 inclusa). Nelle versioni più recenti di Windows, il supporto per i codici ANSI è già integrato.
- La correzione non viene applicata ai terminali che supportano ANSI per impostazione predefinita (ad esempio, Windows Terminal).
Directory di ricerca progetti
Elenco delle directory in cui Open Server Panel cercherà i progetti. Separare i percorsi con punto e virgola (;).

Esclusioni: Le sottodirectory node_modules e vendor vengono ignorate.
Profondità
Profondità massima di annidamento delle directory durante la ricerca dei progetti.

Aumentare questo valore può rallentare l'avvio di Open Server Panel se le directory specificate contengono un gran numero di sottodirectory.
Dimensione massima file di registro
Dimensione massima del file di registro in megabyte. Quando viene superato il valore specificato, il file di registro verrà ricreato al prossimo avvio del programma.

Impostare il valore su 0 per cancellare i file di registro a ogni avvio del programma.

Impostare il valore su 100 MB per disabilitare completamente la pulizia dei file di registro.
