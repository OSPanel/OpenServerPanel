Impostazioni del programma

Avviare insieme a Windows
Abilitare l'avvio automatico di Open Server Panel all'avvio del sistema operativo.
Ritardo
Ritardo di avvio del programma (in secondi, da 0 a 60).

Consente di posticipare l'avvio dell'applicazione durante l'avvio insieme a Windows, per ridurre il carico complessivo sul sistema. È particolarmente utile se è necessario attendere la completa inizializzazione di servizi di terze parti o interfacce di rete.
Controllare la disponibilità di nuove versioni
Abilitare il controllo degli aggiornamenti di Open Server Panel (è necessaria la connessione a Internet).
Abilitare il pianificatore di attività
Attivare il pianificatore di attività integrato. Se il parametro è disabilitato, nessuna attività pianificata verrà eseguita, indipendentemente dal loro stato.
Utilizzare il file HOSTS
Abilitare la registrazione dei nomi di dominio nel file HOSTS.

Raccomandazioni in caso di accesso limitato al file HOSTS nell'organizzazione:

1. Configurare tutti i moduli e i progetti necessari.
2. Contattare l'amministratore di sistema per sbloccare HOSTS e fissarne lo stato.
3. Dopo la fissazione delle modifiche da parte dell'amministratore, è possibile disattivare questa opzione.

Importante: Non disattivare questo parametro se non si è sicuri delle conseguenze!
Avviare i moduli con il profilo del progetto
Avviare i moduli con l'attivazione simultanea del profilo che coincide con il nome del progetto.

Viene utilizzato quando si seleziona la voce di menu «Abilitare i moduli del progetto», per attivare automaticamente il profilo con lo stesso nome del progetto corrente, se esiste.
Non spegnere i moduli dei progetti nascosti
Non spegnere i moduli dei progetti nascosti quando si seleziona la voce di menu «Spegnere tutti i moduli». Per "nascosti" si intendono quei progetti per i quali è impostata la categoria "hidden".

Per impostazione predefinita, il comando «Spegnere tutti i moduli» arresta il funzionamento di tutti i moduli, inclusi quelli utilizzati da progetti di servizio nascosti (ad esempio, PHPMyAdmin). Questa opzione consente di mantenere la funzionalità dei progetti di servizio nascosti, senza disattivare i moduli necessari per essi, mentre tutti gli altri moduli verranno disattivati.
Lingua dell'interfaccia
Lingua dell'interfaccia utente di Open Server Panel.

Se il file di localizzazione è assente o contiene errori, verrà utilizzata la lingua inglese.
Dominio API
Dominio locale per API e interfaccia web (in sviluppo)

Raccomandazione: Se si utilizza una VPN o un proxy, aggiungere questo dominio alle eccezioni.
Indirizzo IP dell'API
Indirizzo IPv4 per API e interfaccia web (in sviluppo).

Raccomandazione: Se si utilizza una VPN o un proxy, aggiungere questo indirizzo IP alle eccezioni.
Porta API
Porta utilizzata per API e interfaccia web (in sviluppo). Open Server Panel non potrà avviarsi se la porta specificata è già utilizzata da un'altra applicazione.
Utilizzare Windows Terminal
Abilitare l'uso di Windows Terminal al posto dell'interfaccia a riga di comando standard.

Requisiti: Windows Terminal deve essere installato nel sistema e presente nella variabile d'ambiente PATH.

Windows Terminal come cmd.exe: Windows Terminal può sostituire cmd.exe ed essere presente nella variabile d'ambiente %COMSPEC% nelle nuove versioni di Windows. Se è così, lasciare questa opzione abilitata.

Nuove istanze di Windows Terminal: Se Windows Terminal apre nuove finestre invece delle schede, configurarlo così: Impostazioni→Avvio→Comportamento della nuova istanza→Allega all'ultima finestra utilizzata.
Titolo breve del progetto
Attivando questa opzione, nel titolo della finestra del terminale verrà visualizzato solo il nome del progetto invece della descrizione dettagliata dell'ambiente.
Includere l'ambiente di sistema nell'ambiente del progetto
Utilizzare l'ambiente di sistema (System) nel terminale, anche se non è impostato nelle impostazioni del progetto. L'ambiente di sistema consente di utilizzare i programmi installati nel sistema (ad esempio, git.exe o ssh.exe).

Disattivare questa opzione solo in caso di conflitti con il software di sistema.
Supporto ANSI
Abilitare il supporto dei codici ANSI per la gestione dei colori nel terminale.

Modalità "Automatico" (predefinita):
- La correzione viene applicata solo a Windows 10 fino alla versione 1903 inclusa. Nelle versioni più recenti di Windows, il supporto dei codici ANSI è già integrato.
- La correzione non viene applicata ai terminali che supportano ANSI per impostazione predefinita (ad esempio, Windows Terminal).
Cartelle per la ricerca dei progetti
Elenco delle cartelle in cui Open Server Panel cercherà i progetti. Separare i percorsi con un punto e virgola (;).

Eccezioni: Le sottocartelle node_modules e vendor vengono ignorate.
Profondità
Profondità massima di annidamento delle cartelle durante la ricerca dei progetti.

L'aumento di questo valore può rallentare l'avvio di Open Server Panel se nelle cartelle specificate sono presenti numerose sottocartelle.
Dimensione massima del file di log
Dimensione massima del file di log in megabyte. Al superamento del valore indicato, il file di log verrà ricreato al successivo avvio del programma.

Impostare il valore 0 per pulire i log a ogni avvio del programma.

Impostare il valore 100 MB per disattivare completamente la pulizia dei log.
