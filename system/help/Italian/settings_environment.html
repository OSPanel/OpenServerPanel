Variabili globali dell'ambiente dei moduli

In questa sezione è possibile definire variabili di ambiente globali per i moduli. Queste variabili vengono applicate esclusivamente nell'ambiente dei moduli e non influenzano le variabili di sistema o l'ambiente dei progetti. Nei valori è possibile utilizzare variabili di modello.

Se una variabile è presente nell'ambiente di sistema, ma non deve essere utilizzata nell'ambiente dei moduli, utilizzare un filtro speciale (vedi Moduli→Variabili di sistema consentite) o rimuovere la variabile dall'ambiente assegnandole un valore vuoto.

Variabili di modello

Variabile Descrizione
{root_dir} Directory principale di Open Server Panel (percorso completo)
{root_drive} Unità della directory principale
{root_path} Percorso alla directory principale di Open Server Panel
{terminal_codepage} Codifica nel terminale (vedi Moduli→Codifica nel terminale)
{time_zone} Fuso orario nel formato Etc/GMT (vedi Moduli→Fuso orario)

Oltre alle variabili di modello, è possibile utilizzare qualsiasi variabile dell'ambiente Windows, ad esempio: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, ecc.
