Variabili d'ambiente globali dei moduli

In questa sezione è possibile impostare le variabili d'ambiente globali per i moduli.

Queste variabili sono valide solo nell'ambiente dei moduli e non influiscono sulle variabili di sistema o sull'ambiente dei progetti.

Nei valori è consentito l'uso di variabili template.

Se una variabile è presente nell'ambiente di sistema ma non deve essere utilizzata nell'ambiente dei moduli, utilizzare un filtro speciale (vedi Moduli→Variabili di sistema consentite) oppure rimuovere la variabile dall'ambiente assegnandole un valore vuoto.

Variabili template

Variabile Descrizione
{root_dir} Directory radice di Open Server Panel (percorso completo)
{root_drive} Unità della directory radice
{root_path} Percorso alla directory radice di Open Server Panel
{terminal_codepage} Codifica nel terminale (vedi Moduli→Codifica nel terminale)
{time_zone} Fuso orario nel formato Etc/GMT (vedi Moduli→Fuso orario)

Oltre alle variabili template, è possibile utilizzare qualsiasi variabile d'ambiente di Windows, ad esempio: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% ecc.
