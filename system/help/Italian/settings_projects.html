Impostazioni globali dei progetti

I parametri definiti in questa sezione vengono utilizzati quando nelle impostazioni del progetto non sono specificati altri valori.

Attiva
Determina lo stato predefinito del progetto (attivato o disattivato).
Codifica del terminale
Codifica del terminale quando si lavora nell'ambiente del progetto.

Valori speciali:
- system: Viene utilizzata la codifica di sistema.
- (valore vuoto): La codifica del terminale rimane invariata.

Importante: Se il valore non è specificato, durante la formazione dell'ambiente finale del progetto, la codifica del terminale sarà impostata dall'ultimo ambiente collegato in cui è specificata, ad esempio, l'ambiente del modulo PHP.
Nginx
Determina la versione del server web Nginx utilizzata per i progetti.
Node
Specifica il motore Node.js per l'esecuzione delle applicazioni Node.js.

Installazione di Node.js: Installare preventivamente la versione desiderata di Node.js utilizzando il componente aggiuntivo NVM.
PHP
Determina il motore PHP utilizzato per l'elaborazione dei file PHP.

Importante: I moduli PHP senza il prefisso FCGI sono moduli integrati Apache+PHP.
IP
Imposta l'indirizzo/i IP utilizzato/i da tutti i progetti senza impostazioni individuali.

Limitazione: I progetti che utilizzano lo stesso indirizzo IP devono funzionare con la stessa versione di PHP.

Supporto per più IP: È possibile specificare più indirizzi IP separati da spazi, inclusi IPv6. Nel file HOSTS, ai domini verrà assegnato il primo IP specificato.

Assegnazione automatica: Lasciando il campo vuoto, l'indirizzo IP verrà assegnato automaticamente.

Raccomandazioni:
  • La gestione automatica degli indirizzi IP è consigliata per la maggior parte degli utenti.
  • L'impostazione manuale dell'indirizzo IP dovrebbe essere utilizzata solo in caso di requisiti specifici di configurazione di rete.
HTTP
Determina la porta per le connessioni HTTP.
HTTPS
Determina la porta per le connessioni HTTPS.
SSL
Attiva o disattiva il supporto SSL per i progetti senza impostazioni individuali.
File del certificato
Specifica il percorso al file del certificato SSL. È possibile utilizzare variabili di modello.

Caratteri consentiti: A-Za-z0-9-+_.\:

Raccomandazione: Lasciare il campo vuoto per la generazione automatica dei certificati.
File della chiave
Specifica il percorso al file della chiave SSL. È possibile utilizzare variabili di modello.

Caratteri consentiti: A-Za-z0-9-+_.\:

Raccomandazione: Lasciare il campo vuoto per la generazione automatica della chiave.
Directory del progetto
Specifica la directory principale del progetto. Il passaggio a questa directory avviene con il comando osp project <DOMAIN> contestualmente all'attivazione dell'ambiente del progetto. È possibile utilizzare variabili di modello.

Caratteri consentiti: A-Za-z0-9-+_.\:
Directory pubblica
Definisce la directory pubblica del progetto. È possibile utilizzare variabili di modello.

Caratteri consentiti: A-Za-z0-9-+_.\:
Alias
Specifica nomi di dominio aggiuntivi (alias) per il progetto (separati da spazi). È possibile utilizzare variabili di modello.

Sottodomini: Se un alias non contiene un punto, viene considerato come un sottodominio (ad esempio, "www" -> "www.test.local").

Limitazione: Il carattere "*" non è supportato nel file HOSTS di Windows e richiede la configurazione DNS.
Ambiente del progetto
Elenco di componenti aggiuntivi e moduli (separati da spazi) che formano l'ambiente del progetto.

Moduli PHP/Nginx/Node.js: Gli ambienti di questi moduli vengono sempre collegati (se specificati per il dominio) e non richiedono di essere indicati in questo parametro.
Comando di avvio del progetto
Definisce il comando per l'avvio del progetto (ad esempio, nodemon app.js). È possibile utilizzare variabili di modello.
URL del progetto
URL che si apre quando si seleziona Apri progetto nel browser in Open Server Panel. È possibile utilizzare variabili di modello.

Applicazione: È possibile impostare l'URL del pannello di amministrazione del CMS.

Variabili di modello

Variabile Descrizione
{base_dir} Directory principale del progetto (dove si trova la directory .osp)
{host} Nome di dominio (per i domini internazionalizzati viene utilizzato Punycode)
{host_decoded} Nome di dominio visibile (senza Punycode)
{root_dir} Directory principale di Open Server Panel (percorso completo)
{root_drive} Unità della directory principale
{root_path} Percorso alla directory principale di Open Server Panel
