Impostazioni globali dei progetti

I parametri definiti in questa sezione vengono utilizzati se nelle impostazioni del progetto non sono specificati altri valori.

HTTP
Determina il modulo del web server utilizzato per i progetti.
NODE
Indica il motore Node.js per l'esecuzione delle applicazioni Node.js.

Installazione di Node.js: Installa preliminarmente la versione necessaria di Node.js con il comando osp node <latest|lts|номер>.
PHP
Determina il modulo PHP utilizzato per l'elaborazione dei file PHP.
Abilita
Determina lo stato predefinito del progetto (attivato o disattivato).
Codifica del terminale
Codifica del terminale durante il lavoro con l'ambiente del progetto.

Valori speciali:
- system: Viene utilizzata la codifica di sistema.

Importante: Se il valore non è impostato, durante la formazione dell'ambiente finale del progetto la codifica del terminale sarà impostata dall'ultimo ambiente collegato in cui è definita, ad esempio dall'ambiente del modulo PHP.
IP
Imposta l'indirizzo IP utilizzato da tutti i progetti senza impostazioni individuali.

Limitazione: I progetti che utilizzano lo stesso indirizzo IP devono funzionare con la stessa versione di PHP.

Supporto multi-IP: È possibile specificare più indirizzi IP separati da uno spazio, inclusi IPv6. Nel file HOSTS ai domini verrà assegnato il primo IP indicato.

Assegnazione automatica: Se lasciato vuoto, l'indirizzo IP verrà assegnato automaticamente.

Raccomandazioni:
  • La gestione automatica degli indirizzi IP è consigliata alla maggior parte degli utenti.
  • L'assegnazione manuale dell'indirizzo IP va utilizzata solo in caso di requisiti specifici di configurazione di rete.
HTTP
Determina la porta per le connessioni HTTP.
HTTPS
Determina la porta per le connessioni HTTPS.
TLS
Abilita o disabilita il supporto TLS.
File del certificato
Indica il percorso al file del certificato TLS. È possibile utilizzare variabili template.

Caratteri consentiti: A-Za-z0-9-+_.\:

Raccomandazione: Lascia il campo vuoto per la generazione automatica dei certificati.
File della chiave
Indica il percorso al file della chiave TLS. È possibile utilizzare variabili template.

Caratteri consentiti: A-Za-z0-9-+_.\:

Raccomandazione: Lascia il campo vuoto per la generazione automatica della chiave.
Indirizzo IP (backend)
Indica l'indirizzo IP tramite il quale viene effettuata la connessione al Backend.
Porta (backend)
Determina il numero di porta per la connessione al Backend.
Abilita (backend)
Consente di reindirizzare automaticamente tutto il traffico in ingresso (HTTP e HTTPS) del progetto al Backend. Utile per test o sviluppo quando frontend e backend sono separati.
Directory del progetto
Indica la directory radice del progetto. L'accesso a questa directory viene effettuato con il comando osp project <DOMAIN> contestualmente all'attivazione dell'ambiente del progetto. È possibile utilizzare variabili template.

Caratteri consentiti: A-Za-z0-9-+_.\:
Directory pubblica
Determina la directory pubblica del progetto. È possibile utilizzare variabili template.

Caratteri consentiti: A-Za-z0-9-+_.\:
Alias
Indica nomi di dominio aggiuntivi (alias) per il progetto (separati da spazio). È possibile utilizzare variabili template.

Limitazione: Il simbolo "*" non è supportato in Windows dal file HOSTS e richiede la configurazione del DNS.
Ambiente del progetto
Elenco di add-on e moduli (separati da spazio) che costituiscono l'ambiente del progetto.

HTTP, NODE e PHP: Gli ambienti di questi motori vengono collegati sempre (se impostati per il dominio) e non richiedono di essere indicati in questo parametro.
Comando di avvio del progetto
Definisce il comando per avviare il progetto (ad esempio, nodemon app.js). È possibile utilizzare variabili template.
URL del progetto
URL utilizzato all'apertura del progetto Menu→Progetto→Apri nel browser, nonché all'apertura degli alias di dominio del progetto. È possibile utilizzare variabili template.

Applicazione: È possibile specificare l'URL del pannello di amministrazione della CMS.

Variabili template

Variabile Descrizione
{backend_ip} Indirizzo IP di connessione al Backend
{backend_port} Porta di connessione al Backend
{base_dir} Directory radice del progetto (dove si trova la directory .osp)
{date_time} Data/ora corrente (variabile disponibile solo per il comando di avvio dell'applicazione del progetto)
{host} Nome del dominio (per i domini internazionalizzati viene utilizzato Punycode)
{host_decoded} Nome visibile del dominio (senza Punycode)
{host_scheme} Schema della richiesta al progetto ("http" o "https", dipende dal parametro TLS nelle impostazioni del progetto)
{http_port} Porta della richiesta al progetto tramite protocollo HTTP
{https_port} Porta della richiesta al progetto tramite protocollo HTTPS
{http_engine} Motore HTTP
{node_engine} Motore NODE
{php_engine} Motore PHP
{project_root} Directory radice del progetto
{web_root} Directory pubblica del progetto
{scheme_port} Porta della richiesta al progetto (":{http_port}" o ":{https_port}", dipende dal parametro TLS nelle impostazioni del progetto).

Se {http_port} o {https_port} ha il valore standard 80 o 443, allora {scheme_port} sarà vuoto.
{root_dir} Directory radice di Open Server Panel (percorso completo)
{root_drive} Unità della directory radice
{root_path} Percorso alla directory radice di Open Server Panel
{terminal_codepage} Codifica della console
