Impostazioni Globali dei Progetti

I parametri impostati in questa sezione vengono utilizzati se nelle impostazioni del progetto non sono specificati altri valori.

Nginx
Determina la versione del server web Nginx utilizzata per i progetti.
Node
Specifica il motore Node.js per l'esecuzione delle applicazioni Node.js.

Installazione di Node.js: Preinstallare la versione desiderata di Node.js utilizzando l'estensione NVM.
PHP
Determina il motore PHP utilizzato per elaborare i file PHP.

Importante: I moduli PHP senza il prefisso FCGI sono moduli integrati Apache+PHP.
Abilitare
Determina lo stato predefinito del progetto (abilitato o disabilitato).
Codifica del Terminale
Codifica del terminale quando si lavora con l'ambiente del progetto.

Valori speciali:
- system: Viene utilizzata la codifica di sistema.

Importante: Se non viene specificato alcun valore, quando si forma l'ambiente finale del progetto, la codifica del terminale sarà impostata dall'ultimo ambiente connesso in cui è definita, ad esempio, dall'ambiente del modulo PHP.
IP
Imposta l'indirizzo/i IP utilizzato/i da tutti i progetti senza impostazioni individuali.

Limitazione: I progetti che utilizzano lo stesso indirizzo IP devono essere eseguiti sulla stessa versione di PHP.

Supporto di più IP: È possibile specificare più indirizzi IP separati da spazi, inclusi IPv6. Nel file HOSTS, ai domini verrà assegnato il primo IP specificato.

Assegnazione automatica: Se il campo viene lasciato vuoto, l'indirizzo IP verrà assegnato automaticamente.

Raccomandazioni:
  • La gestione automatica degli indirizzi IP è raccomandata per la maggior parte degli utenti.
  • L'assegnazione manuale dell'indirizzo IP dovrebbe essere utilizzata solo per requisiti specifici di configurazione di rete.
HTTP
Determina la porta per le connessioni HTTP.
HTTPS
Determina la porta per le connessioni HTTPS.
SSL
Abilita o disabilita il supporto SSL per i progetti senza impostazioni individuali.
File del Certificato
Specifica il percorso al file del certificato SSL. È possibile utilizzare variabili di template.

Caratteri consentiti: A-Za-z0-9-+_.\:

Raccomandazione: Lasciare il campo vuoto per la generazione automatica dei certificati.
File della Chiave
Specifica il percorso al file della chiave SSL. È possibile utilizzare variabili di template.

Caratteri consentiti: A-Za-z0-9-+_.\:

Raccomandazione: Lasciare il campo vuoto per la generazione automatica della chiave.
Indirizzo IP (backend)
Specifica l'indirizzo IP utilizzato per connettersi al Backend.
Porta (backend)
Determina il numero di porta per la connessione al Backend.
Abilitare (backend)
Permette di indirizzare automaticamente tutto il traffico in entrata del progetto (HTTP e HTTPS) al Backend. Utile per test o sviluppo quando frontend e backend sono separati.
Directory del Progetto
Specifica la directory root del progetto. Il passaggio a questa directory viene effettuato utilizzando il comando osp project <DOMAIN> mentre si attiva contemporaneamente l'ambiente del progetto. È possibile utilizzare variabili di template.

Caratteri consentiti: A-Za-z0-9-+_.\:
Directory Pubblica
Determina la directory pubblica del progetto. È possibile utilizzare variabili di template.

Caratteri consentiti: A-Za-z0-9-+_.\:
Alias
Specifica nomi di dominio aggiuntivi (alias) per il progetto (separati da spazi). È possibile utilizzare variabili di template.

Sottodomini: Se un alias non contiene un punto, viene trattato come un sottodominio (ad esempio, "www" -> "www.test.local").

Limitazione: Il carattere "*" non è supportato nel file HOSTS di Windows e richiede una configurazione DNS.
Ambiente del Progetto
Elenco delle estensioni e dei moduli (separati da spazi) che formano l'ambiente del progetto.

Moduli PHP/Nginx/Node.js: Gli ambienti di questi moduli sono sempre connessi (se impostati per il dominio) e non devono essere specificati in questo parametro.
Comando di Avvio del Progetto
Definisce il comando per avviare il progetto (ad esempio, nodemon app.js). È possibile utilizzare variabili di template.
URL del Progetto
URL aperto quando si seleziona Apri progetto nel browser in Open Server Panel. È possibile utilizzare variabili di template.

Applicazione: Può essere utilizzato per impostare l'URL del pannello di amministrazione CMS.

Variabili di Template

Variabile Descrizione
{backend_ip} Indirizzo IP per la connessione al Backend
{backend_port} Porta per la connessione al Backend
{base_dir} Directory root del progetto (dove si trova la directory .osp)
{host} Nome del dominio (per i domini internazionalizzati viene utilizzato Punycode)
{host_decoded} Nome del dominio visibile (senza Punycode)
{host_scheme} Schema di richiesta del progetto ("http" o "https", dipende dal parametro SSL nelle impostazioni del progetto)
{http_port} Porta per le richieste del progetto tramite il protocollo HTTP
{https_port} Porta per le richieste del progetto tramite il protocollo HTTPS
{nginx_engine} Motore Nginx
{node_engine} Motore Node.js
{php_engine} Motore PHP
{project_dir} Directory root del progetto
{public_dir} Directory pubblica del progetto
{scheme_port} Porta per le richieste del progetto (":{http_port}" o ":{https_port}", dipende dal parametro SSL nelle impostazioni del progetto).

Se {http_port} o {https_port} ha il valore standard di 80 o 443, allora {scheme_port} sarà vuoto.
{root_dir} Directory root di Open Server Panel (percorso completo)
{root_drive} Unità della directory root
{root_path} Percorso alla directory root di Open Server Panel
{terminal_codepage} Codifica della console
