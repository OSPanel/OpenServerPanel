Impostazioni globali dei moduli

I parametri definiti in questa sezione vengono applicati nei casi in cui nelle impostazioni di un modulo specifico è impostato il valore auto (predefinito) per l'opzione corrispondente.

Modalità silenziosa
Disattiva i messaggi popup di errore da Windows Error Reporting e dal modulo stesso.

Raccomandazione: Disattivare questa modalità solo quando è necessario diagnosticare problemi nel funzionamento del modulo.
Aggiungi intestazione al file di registro
Abilita l'aggiunta automatica di un'intestazione al file di registro ogni volta che il modulo viene avviato. Utile quando la pulizia automatica dei log è disattivata per separare le sessioni di lavoro.
Numero massimo di avvii falliti
Determina quanti avvii consecutivi falliti del modulo sono consentiti prima che passi allo stato "Errore".
Tempo di verifica del funzionamento del modulo
Determina il periodo di test del funzionamento del modulo dopo il suo avvio riuscito.

Inizio del conteggio: Dal momento dell'avvio riuscito del modulo.

Passaggio allo stato "Errore": Se il modulo termina in modo anomalo durante il periodo di prova, non verrà riavviato automaticamente e passerà allo stato "Errore". Questo vale anche per i casi in cui il modulo non può essere avviato a livello di sistema.

Disattivazione della verifica: Il valore 0 disattiva il periodo di prova, e il modulo verrà sempre riavviato in caso di fallimento.

Raccomandazione: Non impostare il valore su 0 o un periodo troppo breve (meno di 30 secondi), poiché ciò potrebbe causare cicli di riavvio infiniti.
Tempo di attesa per la terminazione del modulo
Determina il tempo massimo entro il quale il modulo è autorizzato a terminare il proprio funzionamento.

Terminazione forzata: Se il modulo non termina entro il tempo specificato, verrà arrestato forzatamente.

Disattivazione dell'attesa: Il valore 0 disattiva il periodo di attesa. Il programma attenderà indefinitamente il completamento del modulo.

Avvertenza: L'arresto forzato del modulo può portare a danni ai dati, perdita di modifiche non salvate o terminazione impropria dei processi. Utilizzare questa impostazione con cautela.
Dimensione massima del file di registro
Dimensione massima del file di registro in megabyte. Quando viene superato il valore specificato, il file di log verrà ricreato al successivo avvio del modulo.

Impostare il valore su 0 per cancellare i file di log ad ogni avvio del modulo.

Impostare il valore su 100 MB per disattivare completamente la pulizia dei file di log.
Codifica del terminale
Codifica del terminale quando si lavora con l'ambiente del modulo.

Valori speciali:
- system: Viene utilizzata la codifica di sistema.
- (valore vuoto): La codifica del terminale rimane invariata.
Fuso orario
Determina il fuso orario del modulo nel formato Etc/GMT (ad esempio, Etc/GMT-3).

Valori speciali:
- system: Viene utilizzato il fuso orario di sistema.

Importante: Il formato Etc/GMT ha uno spostamento inverso rispetto a UTC (ad esempio, Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Ambienti dei componenti aggiuntivi utilizzati
Determina l'elenco dei componenti aggiuntivi (separati da spazi) i cui ambienti (se esistenti) vengono uniti all'ambiente del modulo. Gli indicatori informativi nel terminale non mostrano questi ambienti aggiuntivi.

Avvertenza: Utilizzare questa opzione solo con una piena comprensione del suo scopo.
Variabili di sistema consentite
Determina l'elenco delle variabili dell'ambiente Windows (separate da spazi) che vengono trasferite all'ambiente del modulo.

Scopo: Consente di isolare l'ambiente di lavoro del modulo da software simile installato nel sistema.

Avvertenza: La modifica di questo elenco senza una piena comprensione della sua influenza può portare a un funzionamento instabile del modulo.
