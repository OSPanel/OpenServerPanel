Creating Custom Menu Items

  1. Add a new section with a unique identifier [ID]
  2. Arrange sections in the desired order — this will determine the order of items in the menu
  3. Save changes and restart Open Server Panel to apply changes

Important Information

When creating custom menu items, ensure that section identifiers are not duplicated. This can lead to conflicts in the menu functionality.

Menu Item Settings

Sort order: Menu items are sorted in the same order as their corresponding sections in the template.

caption Menu item title. Supports language constants in {lang_xxx} format.

Default: not set
category

Determines the item's position in the menu hierarchy. Supports one level of nesting (for example, "My Bookmarks\Work").

Special categories:

  • projects, modules, addons - adds the item to the corresponding action menu
  • projects\, modules\, addons\ - adds an item for a specific element

If the category is not specified, the item is created in the root menu.

Default: not set
command Command to execute when the menu item is activated. Items without a command are ignored.

Default: not set
enabled Enables/disables the display of the menu item.

Default: on | Values: on, off
hide Controls the visibility of the called application window. Does not affect child processes.

Default: off | Values: on, off
hr_after Adds a horizontal separator after the menu item.

Default: off | Values: on, off
hr_before Adds a horizontal separator before the menu item.

Default: off | Values: on, off
icon Icon from the Font Awesome Free set (Solid/Regular/Brands).

Default: not set
need_alias Displays the menu item only for a domain alias. The menu template can have only one item with need_alias=on!
Applicable for categories: projects

Default: not set | Values: on, off
need_category

Restricts the display of the menu item to modules/add-ons of a specific category.

Supported formats:

  • modules, addons
  • modules\, addons\
Default: not set
need_module_shell Displays the menu item depending on the presence of shell/cli in the parent module.
Applicable for categories: modules, modules\

Default: not set | Values: on, off
need_state Displays the menu item depending on the state of the parent module.
Applicable for categories: modules, modules\

Default: not set | Values: on, off
need_start_cmd Displays the menu item if a start command is present in the project settings.
Applicable for categories: projects, projects\

Default: not set | Values: on, off
need_use_wt Displays the menu item depending on the Windows Terminal usage setting in Open Server Panel.

Default: not set | Values: on, off
work_directory Working directory for command execution. Can be changed during command execution.

Default: {root_dir}

Template Variables

The following template variables can be used in the "command" and "work_directory" parameters:

General Variables

Variable Description
{root_dir} Open Server Panel root directory (full path)
{root_drive} Root directory drive
{root_path} Path to the Open Server Panel root directory
{web_panel_url} Web interface URL

Special Variables (only for projects and projects\<domain_name>)

Variable Description
{base_dir} Project base directory
{host} Domain name (Punycode)
{host_decoded} Visible domain name (without Punycode)
{host_scheme} Project request scheme ("http" or "https", depends on the SSL parameter in project settings)
{http_port} HTTP protocol request port for the project
{https_port} HTTPS protocol request port for the project
{menu_caption} Menu item title (only for projects category with need_alias=ON)
{nginx_engine} Nginx engine
{node_engine} Node.js engine
{php_engine} PHP engine
{project_dir} Project root directory
{project_url} Project URL
{public_dir} Project public directory
{scheme_port} Project request port (":{http_port}" or ":{https_port}", depends on the SSL parameter in project settings). If {http_port} or {https_port} has a standard value of 80 or 443, then {scheme_port} will be empty.
{start_command} Project start command (if configured)
{terminal_codepage} Console encoding

Special Variables (only for addons and addons\<addon_name>)

Variable Description
{addon_name} Addon name
{terminal_codepage} Console encoding

Special Variables (only for modules and modules\<module_name>)

Variable Description
{ip} Module IP address
{log_level} Error logging level
{module_name} Module name
{port} Module port
{profile_name} Current module settings profile name
{query_log_level} Query logging level
{shell_command} Module shell/cli launch command (if configured)
{terminal_codepage} Console encoding
{time_zone} Time zone

Special Command Values

Command Description
command_open_logs_viewer Open logs viewer window
command_open_idn_converter Open IDN converter
command_open_options Open program settings window

In addition to template variables, you can use any Windows environment variables, such as: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, etc.

Usage Examples

[21]

caption  = Open in PhpStorm
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = My Bookmarks\Search Engines
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

`cmd.exe` Options

  • /c: Execute the command and close the terminal.
  • /k: Execute the command and keep the terminal open.
