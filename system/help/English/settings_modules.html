Global module settings

The parameters specified in this section apply when the corresponding option in a specific module is set to auto (default).

Silent mode
Disables pop-up error messages from Windows Error Reporting and the module itself.

Recommendation: Disable this mode only when diagnostic troubleshooting of the module is required.
Add header to log file
Enables automatic addition of a header to the log file on each module start. Useful when automatic log cleanup is disabled to separate work sessions.
Maximum number of failed starts
Determines how many consecutive failed module starts are allowed before it switches to the “Error” state.
Module health check period
Defines the period for testing the module’s health after it starts successfully.

Start of countdown: From the moment the module starts successfully.

Transition to “Error” state: If the module crashes during the trial period, it will not be restarted automatically and will switch to the “Error” state. This also applies to cases when the module fails to start at the system level.

Disabling the check: A value of 0 disables the trial period, and the module will always be restarted on failure.

Recommendation: Do not set the value to 0 or too short a period (less than 30 seconds), as this may lead to infinite restart loops.
Module shutdown timeout
Defines the maximum time the module is allowed to complete its shutdown.

Forced termination: If the module does not stop within the specified time, it will be forcibly stopped.

Disabling the wait: A value of 0 disables the waiting period. The program will wait indefinitely for the module to stop.

Warning: Forcibly stopping the module may lead to data corruption, loss of unsaved changes, or improper termination of processes. Use this setting with caution.
Maximum log file size
Maximum log file size in megabytes. If the specified value is exceeded, the log file will be recreated at the next module start.

Set the value to 0 to clear logs at each module start.

Set the value to 100 MB to completely disable log cleanup.
Terminal encoding
Terminal encoding when working with the module environment.

Special values:
- system: The system encoding is used.
Time zone
Defines the module’s time zone in the Etc/GMT format (for example, Etc/GMT-3).

Special values:
- system: The system time zone is used.

Important: The Etc/GMT format has an offset reversed relative to UTC (for example, Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Add-on environments to use
Specifies the list of add-ons (separated by spaces) whose environments (if any) are attached to the module environment. Informational indicators in the terminal do not display these additional environments.

Warning: Use this option only if you fully understand its purpose.
Allowed system variables
Specifies the list of Windows environment variables (separated by spaces) that are passed into the module environment.

Purpose: Allows isolating the module’s working environment from similar software installed on the system.

Warning: Changing this list without fully understanding its impact may lead to unstable module operation.
