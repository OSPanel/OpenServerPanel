Global Module Settings

Parameters set in this section are applied when the corresponding option in the specific module settings is set to auto (default).

Silent Mode
Disables popup error messages from Windows Error Reporting and the module itself.

Recommendation: Disable this mode only when diagnosing module issues is necessary.
Add Header to Log File
Enables automatic header addition to the log file each time the module starts. Useful when automatic log cleanup is disabled to separate work sessions.
Maximum Number of Failed Starts
Defines how many consecutive failed module starts are allowed before the module transitions to the "Error" state.
Module Health Check Time
Defines the period for testing module health after its successful launch.

Countdown start: From the moment of successful module start.

Transition to "Error" state: If the module crashes during the test period, it will not be automatically restarted and will transition to the "Error" state. This also applies to cases when the module cannot be started at the system level.

Disabling the check: A value of 0 disables the test period, and the module will always be restarted upon failure.

Recommendation: Do not set the value to 0 or too short a period (less than 30 seconds) as this may lead to infinite restart loops.
Module Shutdown Timeout
Defines the maximum time during which the module is allowed to complete its work.

Forced termination: If the module does not complete its work within the specified time, it will be forcibly stopped.

Disabling timeout: A value of 0 disables the waiting period. The program will wait indefinitely for the module to complete its work.

Warning: Forced module termination can lead to data corruption, loss of unsaved changes, or incorrect process termination. Use this setting with caution.
Maximum Log File Size
Maximum log file size in megabytes. When this value is exceeded, the log file will be recreated the next time the module starts.

Set the value to 0 to clear log files each time the module starts.

Set the value to 100 MB to completely disable log file cleanup.
Terminal Encoding
Terminal encoding when working with the module environment.

Special values:
- system: Uses system encoding.
- (empty value): Terminal encoding remains unchanged.
Time Zone
Defines the module's time zone in Etc/GMT format (e.g., Etc/GMT-3).

Special values:
- system: Uses the system time zone.

Important: The Etc/GMT format has reverse offset relative to UTC (e.g., Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Addon Environments Used
Defines a list of addons (space-separated) whose environments (if any) are attached to the module environment. Information indicators in the terminal do not display these additional environments.

Warning: Use this option only when you fully understand its purpose.
Allowed System Variables
Defines the list of Windows environment variables (space-separated) that are passed to the module environment.

Purpose: Allows isolating the module's working environment from similar software installed in the system.

Warning: Changing this list without fully understanding its impact may lead to unstable module operation.
