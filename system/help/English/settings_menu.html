Menu settings

Theme
Theme for menu icons.
Font size
Menu font size in pixels. The option allows you to set the menu font size independently of the system settings.

Set the slider to the minimum value of 12px to disable the font size control feature (the system size will be used).
Show icon in the notification area
Show the program icon in the Windows notification area.

Disable: Disable this option if you are using an autorun type that does not require a Windows user to sign in (Windows Task Scheduler→Run at system startup).
Show icons for menu items
Show icons in the program menu. Icons are not displayed if system rendering is enabled.
Enable system rendering
Enable this option only when necessary to ensure compatibility with screen access programs (screen readers).

Attention! Icons in the menu are not displayed if system rendering is enabled.
Show vertical separator
When this option is enabled, icons in the program menu will be separated by a vertical separator.
Do not group lists with a single item
Do not group lists containing only one item.
Projects: show
Show the project management menu.
Projects: group
Group projects by domain zone in the menu.
Projects: nested menu
Show the projects menu in a separate submenu.
Projects: show separator
Show a separator line after the projects menu.
Modules: show
Show the modules management menu.
Modules: group
Group modules in the menu.
Modules: nested menu
Show the modules menu in a separate submenu.
Modules: show separator
Show a separator line after the modules menu.
Add-ons: show
Show the add-ons menu.
Add-ons: group
Group add-ons in the menu.
Add-ons: nested menu
Show the add-ons menu in a separate submenu.
Add-ons: show separator
Show a separator line after the add-ons menu.
