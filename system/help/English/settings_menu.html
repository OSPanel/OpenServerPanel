Menu Settings

Theme
Theme for menu icons.
Font Size
Menu font size in pixels. This option allows setting the menu font size independently of system settings.

Set the slider to the minimum value of 12px to disable font size control (system size will be used).
Show Icon in Notification Area
Show the program icon in the Windows notification area.

Disabling: Disable this option if you run Open Server Panel in Windows Server Core environment or use an autostart type that doesn't require Windows user login (Windows Task Scheduler→Start at computer boot).
Show Icons for Menu Items
Show icons in the program menu. Icons are not displayed if system rendering is enabled.
Enable System Rendering
Enable this option only when compatibility with screen readers is necessary.
Show Vertical Separator
When this option is enabled, icons in the program menu will be separated by a vertical separator.
Don't Group Lists with Single Item
Don't group lists containing only one item.
Addons: Show
Show the addons menu.
Addons: Group
Group addons in the menu.
Addons: Nested Menu
Show the addons menu in a separate submenu.
Addons: Show Separator
Show a separator line after the addons menu.
Modules: Show
Show the modules management menu.
Modules: Group
Group modules in the menu.
Modules: Nested Menu
Show the modules menu in a separate submenu.
Modules: Show Separator
Show a separator line after the modules menu.
Projects: Show
Show the projects management menu.
Projects: Group
Group projects by domain zone in the menu.
Projects: Nested Menu
Show the projects menu in a separate submenu.
Projects: Show Separator
Show a separator line after the projects menu.
