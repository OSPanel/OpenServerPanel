Program settings

Start with Windows
Enable Open Server Panel autorun when the operating system loads.
Delay
Program startup delay (in seconds, from 0 to 60).

Allows you to postpone the app start during Windows startup to reduce overall system load. This is especially useful if you need to wait for full initialization of third-party services or network interfaces.
Check for new versions
Enable Open Server Panel updates check (Internet connection required).
Enable task scheduler
Activate the built-in task scheduler. If this option is disabled, no scheduled tasks will be executed regardless of their status.
Use HOSTS file
Enable writing domain names to the HOSTS file.

Recommendations when access to the HOSTS file is restricted in your organization:

1. Configure all required modules and projects.
2. Contact your system administrator to unblock HOSTS and lock in its state.
3. After the administrator finalizes the changes, you can disable this option.

Important: Do not disable this option unless you are sure of the consequences!
Start modules with project profile
Start modules while simultaneously activating the profile that matches the project name.

Used when selecting the “Enable project modules” menu item to automatically activate the profile with the same name as the current project, if it exists.
Do not stop modules of hidden projects
Do not stop modules of hidden projects when selecting the “Disable all modules” menu item. By "hidden" we mean projects for which the "hidden" category is set.

By default, the “Disable all modules” command stops absolutely all modules, including those used by hidden service projects (for example, PHPMyAdmin). This option allows you to keep hidden service projects operational without disabling the modules they require, while all other modules will be turned off.
Interface language
The Open Server Panel user interface language.

If the localization file is missing or contains errors, English will be used.
API domain
Local domain for the API and web interface (in development)

Recommendation: If a VPN or proxy is used, add this domain to the exclusions.
API IP address
IPv4 address for the API and web interface (in development).

Recommendation: If a VPN or proxy is used, add this IP address to the exclusions.
API port
The port used for the API and web interface (in development). Open Server Panel will not be able to start if the specified port is already used by another application.
Use Windows Terminal
Enable using Windows Terminal instead of the standard command interface.

Requirements: Windows Terminal must be installed in the system and present in the PATH environment variable.

Windows Terminal as cmd.exe: Windows Terminal can replace cmd.exe and be set in the %COMSPEC% environment variable in newer versions of Windows. If so, leave this option enabled.

New Windows Terminal instances: If Windows Terminal opens new windows instead of tabs, configure it as follows: Settings→Startup→New instance behavior→Attach to most recently used window.
Short project title
When this option is enabled, only the project name will be shown in the terminal window title instead of a detailed environment description.
Include system environment in the project environment
Use the system (System) environment in the terminal even if it is not set in the project settings. The system environment allows you to use programs installed in the system (for example, git.exe or ssh.exe).

Disable this option only if conflicts with system software occur.
ANSI support
Enable ANSI code support for color control in the terminal.

"Automatic" mode (default):
- The fix is applied only to Windows 10 up to and including version 1903. In newer versions of Windows, ANSI code support is already built-in.
- The fix is not applied to terminals that support ANSI by default (for example, Windows Terminal).
Directories for searching projects
A list of directories where Open Server Panel will search for projects. Separate paths with a semicolon (;).

Exclusions: The node_modules and vendor subdirectories are ignored.
Depth
The maximum directory nesting depth when searching for projects.

Increasing this value may slow down the startup of Open Server Panel if the specified directories contain a large number of subdirectories.
Maximum log file size
The maximum log file size in megabytes. If the specified value is exceeded, the log file will be recreated at the next program startup.

Set the value to 0 to clear logs at every program startup.

Set the value to 100 MB to completely disable log clearing.
