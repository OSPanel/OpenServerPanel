Program Settings

Run with Windows
Enable automatic startup of Open Server Panel when the operating system loads.
Delay
Program startup delay (in seconds, from 0 to 60).

Allows postponing the application launch to reduce system load during startup. This is especially useful if you need to wait for full initialization of third-party services or network interfaces.
Check for new versions
Enable update checking for Open Server Panel (internet connection required).
Enable task scheduler
Activate the built-in task scheduler. If this parameter is disabled, no scheduled tasks will be executed regardless of their status.
Use HOSTS file
Enable writing domain names to the HOSTS file.

Recommendations for restricted access to HOSTS file in organizations:

1. Configure all necessary modules and projects.
2. Contact your system administrator to unblock HOSTS and fix its state.
3. After the administrator has fixed the changes, you can disable this option.

Important: Do not disable this parameter if you are unsure of the consequences!
Launch modules with project profile
Launch modules with simultaneous activation of a profile matching the project name.

Used when selecting the "Enable project modules" menu item to automatically activate a profile with the same name as the current project, if one exists.
Interface language
User interface language for Open Server Panel.

If the localization file is missing or contains errors, English will be used.
API Domain
Local domain for API and web interface (in development)

Recommendation: If using VPN or proxy, add this domain to exceptions.
API IP Address
IPv4 address for API and web interface (in development).

Recommendation: If using VPN or proxy, add this IP address to exceptions.
API Port
Port used for API and web interface (in development). Open Server Panel will not be able to start if the specified port is already in use by another application.
Use Windows Terminal
Enable using Windows Terminal instead of the standard command interface.

Requirements: Windows Terminal must be installed on the system and defined in the PATH environment variable.

Windows Terminal as cmd.exe: Windows Terminal can replace cmd.exe and be defined in the %COMSPEC% environment variable in newer versions of Windows. If this is the case, keep this option enabled.

New Windows Terminal instances: If Windows Terminal opens new windows instead of tabs, configure it as follows: Settings→Startup→New instance behavior→Attach to the most recently used window.
Short project title
When this option is activated, only the project name will be displayed in the terminal window title instead of a detailed description.
Include system environment in project environment
Use the system environment (System) in the terminal even if it is not specified in the project settings. System environment allows the use of programs installed on the system (such as git.exe or ssh.exe).

Disable this option only if conflicts with system software occur.
ANSI support
Enable support for ANSI codes to control colors in the terminal.

"Automatic" mode (default):
- The fix is applied only to Windows 7, 8, and Windows 10 (up to version 1903 inclusive). In newer Windows versions, ANSI code support is already built-in.
- The fix is not applied to terminals that support ANSI by default (e.g., Windows Terminal).
Project search directories
List of directories where Open Server Panel will search for projects. Separate paths with semicolons (;).

Exclusions: Subdirectories node_modules and vendor are ignored.
Depth
Maximum directory nesting depth when searching for projects.

Increasing this value may slow down the Open Server Panel startup if the specified directories contain a large number of subdirectories.
Maximum log file size
Maximum log file size in megabytes. When the specified value is exceeded, the log file will be recreated the next time the program starts.

Set the value to 0 to clear log files on each program start.

Set the value to 100 MB to completely disable log file cleaning.
