Global Project Settings

Parameters set in this section are used if no other values are specified in the project settings.

Nginx
Defines the Nginx web server version used for projects.
Node
Specifies the Node.js engine for running Node.js applications.

Installing Node.js: First install the required Node.js version using the NVM addon.
PHP
Defines the PHP engine used for processing PHP files.

Important: PHP modules without the FCGI prefix are integrated Apache+PHP modules.
Enable
Determines the default project state (enabled or disabled).
Terminal Encoding
Terminal encoding when working with the project environment.

Special values:
- system: Uses system encoding.
- (empty value): Terminal encoding remains unchanged.

Important: If the value is not set, when forming the final project environment, terminal encoding will be set by the last connected environment in which it is defined, for example, the PHP module environment.
IP
Sets the IP address(es) used by all projects without individual settings.

Limitation: Projects using the same IP address must work with the same PHP version.

Multiple IP support: You can specify multiple IP addresses separated by spaces, including IPv6. The first specified IP will be assigned to domains in the HOSTS file.

Automatic assignment: If left empty, the IP address will be assigned automatically.

Recommendations:
  • Automatic IP address management is recommended for most users.
  • Manual IP address assignment should be used only for specific network configuration requirements.
HTTP
Defines the port for HTTP connections.
HTTPS
Defines the port for HTTPS connections.
SSL
Enables or disables SSL support for projects without individual settings.
Certificate File
Specifies the path to the SSL certificate file. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:

Recommendation: Leave this field empty for automatic certificate generation.
Key File
Specifies the path to the SSL key file. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:

Recommendation: Leave this field empty for automatic key generation.
Project Directory
Specifies the root directory of the project. Switching to this directory is performed by the command osp project <DOMAIN> simultaneously with the activation of the project environment. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:
Public Directory
Defines the public directory of the project. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:
Aliases
Specifies additional domain names (aliases) for the project (space-separated). Template variables can be used.

Subdomains: If an alias does not contain a dot, it is considered a subdomain (e.g., "www" -> "www.test.local").

Limitation: The "*" character is not supported in Windows HOSTS file and requires DNS configuration.
Project Environment
List of add-ons and modules (space-separated) that form the project environment.

PHP/Nginx/Node.js modules: Environments of these modules are always connected (if set for the domain) and do not need to be specified in this parameter.
Project Start Command
Defines the command to start the project (e.g., nodemon app.js). Template variables can be used.
Project URL
URL opened when selecting Open project in browser in Open Server Panel. Template variables can be used.

Application: You can set the URL of the CMS admin panel.

Template Variables

Variable Description
{base_dir} Project root directory (where the .osp directory is located)
{host} Domain name (Punycode is used for internationalized domains)
{host_decoded} Visible domain name (without Punycode)
{root_dir} Open Server Panel root directory (full path)
{root_drive} Root directory drive
{root_path} Path to the Open Server Panel root directory
