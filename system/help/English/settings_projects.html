Global project settings

The parameters specified in this section are used if no other values are specified in the project settings.

HTTP
Defines the web server module used for projects.
NODE
Specifies the Node.js engine for running Node.js applications.

Installing Node.js: Pre-install the required Node.js version using the command osp node <latest|lts|number>.
PHP
Defines the PHP module used to process PHP files.
Enable
Defines the default project state (enabled or disabled).
Terminal encoding
Terminal encoding when working with the project environment.

Special values:
- system: The system encoding is used.

Important: If the value is not set, when forming the final project environment the terminal encoding will be set by the last connected environment in which it is specified, for example, the PHP module environment.
IP
Sets the IP address(es) used by all projects without individual settings.

Limitation: Projects using the same IP address must run on the same PHP version.

Multiple IP support: You can specify multiple IP addresses separated by spaces, including IPv6. In the HOSTS file, the first specified IP will be assigned to domains.

Automatic assignment: If you leave the field empty, the IP address will be assigned automatically.

Recommendations:
  • Automatic IP address management is recommended for most users.
  • Manual IP assignment should be used only for specific network configuration requirements.
HTTP
Defines the port for HTTP connections.
HTTPS
Defines the port for HTTPS connections.
TLS
Enables or disables TLS support.
Certificate file
Specifies the path to the TLS certificate file. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:

Recommendation: Leave the field empty for automatic certificate generation.
Key file
Specifies the path to the TLS key file. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:

Recommendation: Leave the field empty for automatic key generation.
IP address (backend)
Specifies the IP address used to connect to the Backend.
Port (backend)
Defines the port number for connecting to the Backend.
Enable (backend)
Allows automatically routing all incoming project traffic (HTTP and HTTPS) to the Backend. Useful for testing or development when the frontend and backend are separated.
Project directory
Specifies the project's root directory. You can switch to this directory with the osp project <DOMAIN> command simultaneously with activating the project environment. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:
Public directory
Defines the project's public directory. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:
Aliases
Specifies additional domain names (aliases) for the project (space-separated). Template variables can be used.

Limitation: The "*" character is not supported in Windows by the HOSTS file and requires DNS configuration.
Project environment
A list of addons and modules (space-separated) that form the project environment.

HTTP, NODE and PHP: The environments of these engines are always connected (if set for the domain) and do not need to be specified in this parameter.
Project start command
Defines the command to start the project (for example, nodemon app.js). Template variables can be used.
Project URL
The URL used when opening the project via Menu→Project→Open in browser, as well as when opening the project's domain aliases. Template variables can be used.

Usage: You can specify the URL of the CMS admin panel.

Template variables

Variable Description
{backend_ip} IP address for connecting to the Backend
{backend_port} Port for connecting to the Backend
{base_dir} Project root directory (where the .osp directory is located)
{date_time} Current date/time (variable available only for the project application's start command)
{host} Domain name (Punycode is used for internationalized domains)
{host_decoded} Visible domain name (without Punycode)
{host_scheme} Request scheme to the project ("http" or "https", depends on the TLS parameter in the project settings)
{http_port} HTTP request port to the project
{https_port} HTTPS request port to the project
{http_engine} HTTP engine
{node_engine} NODE engine
{php_engine} PHP engine
{project_root} Project root directory
{web_root} Project public directory
{scheme_port} Project request port (":{http_port}" or ":{https_port}", depends on the TLS parameter in the project settings).

If {http_port} or {https_port} has the standard value 80 or 443, then {scheme_port} will be empty.
{root_dir} Open Server Panel root directory (full path)
{root_drive} Root directory drive
{root_path} Path to the Open Server Panel root directory
{terminal_codepage} Console encoding
