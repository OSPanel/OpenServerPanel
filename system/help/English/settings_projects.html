Global Project Settings

Parameters set in this section are used if no other values are specified in the project settings.

Nginx
Determines the version of the Nginx web server used for projects.
Node
Specifies the Node.js engine for running Node.js applications.

Node.js Installation: Pre-install the desired Node.js version using the NVM extension.
PHP
Determines the PHP engine used for processing PHP files.

Important: PHP modules without the FCGI prefix are integrated Apache+PHP modules.
Enable
Determines the default state of the project (enabled or disabled).
Terminal Encoding
Terminal encoding when working with the project environment.

Special values:
- system: System encoding is used.

Important: If no value is specified, when forming the final project environment, the terminal encoding will be set by the last connected environment in which it is defined, for example, by the PHP module environment.
IP
Sets the IP address(es) used by all projects without individual settings.

Limitation: Projects using the same IP address must run on the same PHP version.

Multiple IP support: You can specify multiple IP addresses separated by spaces, including IPv6. In the HOSTS file, domains will be assigned the first specified IP.

Automatic assignment: If the field is left empty, the IP address will be assigned automatically.

Recommendations:
  • Automatic IP address management is recommended for most users.
  • Manual IP address assignment should only be used for specific network configuration requirements.
HTTP
Determines the port for HTTP connections.
HTTPS
Determines the port for HTTPS connections.
SSL
Enables or disables SSL support for projects without individual settings.
Certificate File
Specifies the path to the SSL certificate file. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:

Recommendation: Leave the field empty for automatic certificate generation.
Key File
Specifies the path to the SSL key file. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:

Recommendation: Leave the field empty for automatic key generation.
IP Address (backend)
Specifies the IP address used for connecting to the Backend.
Port (backend)
Determines the port number for connecting to the Backend.
Enable (backend)
Allows automatically directing all incoming project traffic (HTTP and HTTPS) to the Backend. Useful for testing or development when frontend and backend are separated.
Project Directory
Specifies the root directory of the project. Changing to this directory is done using the command osp project <DOMAIN> while simultaneously activating the project environment. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:
Public Directory
Determines the public directory of the project. Template variables can be used.

Allowed characters: A-Za-z0-9-+_.\:
Aliases
Specifies additional domain names (aliases) for the project (space-separated). Template variables can be used.

Subdomains: If an alias does not contain a dot, it is treated as a subdomain (e.g., "www" -> "www.test.local").

Limitation: The "*" character is not supported in the Windows HOSTS file and requires DNS configuration.
Project Environment
List of extensions and modules (space-separated) that form the project environment.

PHP/Nginx/Node.js modules: The environments of these modules are always connected (if set for the domain) and do not need to be specified in this parameter.
Project Launch Command
Defines the command to start the project (e.g., nodemon app.js). Template variables can be used.
Project URL
URL opened when selecting Open project in browser in Open Server Panel. Template variables can be used.

Application: Can be used to set the URL of the CMS administration panel.

Template Variables

Variable Description
{backend_ip} IP address for connecting to the Backend
{backend_port} Port for connecting to the Backend
{base_dir} Root directory of the project (where the .osp directory is located)
{host} Domain name (Punycode is used for internationalized domains)
{host_decoded} Visible domain name (without Punycode)
{host_scheme} Project request scheme ("http" or "https", depends on the SSL parameter in the project settings)
{http_port} Port for project requests via the HTTP protocol
{https_port} Port for project requests via the HTTPS protocol
{nginx_engine} Nginx engine
{node_engine} Node.js engine
{php_engine} PHP engine
{project_dir} Root directory of the project
{public_dir} Public directory of the project
{scheme_port} Port for project requests (":{http_port}" or ":{https_port}", depends on the SSL parameter in the project settings).

If {http_port} or {https_port} has the standard value of 80 or 443, then {scheme_port} will be empty.
{root_dir} Root directory of Open Server Panel (full path)
{root_drive} Drive of the root directory
{root_path} Path to the root directory of Open Server Panel
{terminal_codepage} Console encoding
