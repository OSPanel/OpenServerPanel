Global Module Environment Variables

In this section, you can set global environment variables for modules.

These variables are applied exclusively to the module environment and do not affect system variables or project environments. Template variables can be used in values.

If a variable exists in the system environment but should not be used in the module environment, use the special filter (see Modules→Allowed System Variables) or remove the variable from the environment by setting it to an empty value.

Template Variables

Variable Description
{root_dir} Open Server Panel root directory (full path)
{root_drive} Root directory drive
{root_path} Path to the Open Server Panel root directory
{terminal_codepage} Terminal encoding (see Modules→Terminal Encoding)
{time_zone} Time zone in Etc/GMT format (see Modules→Time Zone)

In addition to template variables, you can use any Windows environment variables, such as: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, etc.
