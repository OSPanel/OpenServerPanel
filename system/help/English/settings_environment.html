Global module environment variables

In this section, you can set global environment variables for modules.

These variables apply only to the module environment and do not affect system variables or project environments.

Template variables are allowed in values.

If a variable is present in the system environment but should not be used in the module environment, use the special filter (see Modules→Allowed system variables) or remove the variable from the environment by assigning it an empty value.

Template variables

Variable Description
{root_dir} Open Server Panel root directory (full path)
{root_drive} Root directory drive
{root_path} Path to the Open Server Panel root directory
{terminal_codepage} Encoding in the terminal (see Modules→Encoding in the terminal)
{time_zone} Time zone in Etc/GMT format (see Modules→Time zone)

In addition to template variables, you can use any Windows environment variables, for example: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, etc.
