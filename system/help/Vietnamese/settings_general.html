Cài đặt chương trình

Khởi động cùng Windows
Bật tự động khởi động Open Server Panel khi hệ điều hành tải.
Độ trễ
Độ trễ khởi chạy chương trình (tính bằng giây, từ 0 đến 60).

Cho phép hoãn việc khởi chạy ứng dụng trong quá trình khởi động cùng Windows để giảm tải tổng thể cho hệ thống. Điều này đặc biệt hữu ích nếu cần đợi các dịch vụ bên thứ ba hoặc giao diện mạng được khởi tạo đầy đủ.
Kiểm tra phiên bản mới
Bật kiểm tra cập nhật Open Server Panel (yêu cầu kết nối Internet).
Bật bộ lập lịch tác vụ
Kích hoạt bộ lập lịch tác vụ tích hợp. Nếu tham số bị tắt, không tác vụ đã lên lịch nào sẽ được thực thi, bất kể trạng thái của chúng.
Sử dụng tệp HOSTS
Bật ghi tên miền vào tệp HOSTS.

Khuyến nghị khi quyền truy cập tệp HOSTS bị hạn chế trong tổ chức:

1. Cấu hình tất cả các module và dự án cần thiết.
2. Liên hệ quản trị viên hệ thống để mở khóa HOSTS và cố định trạng thái của nó.
3. Sau khi quản trị viên cố định các thay đổi, có thể tắt tùy chọn này.

Quan trọng: Đừng tắt tham số này nếu bạn không chắc chắn về hậu quả!
Khởi chạy module với profile dự án
Khởi chạy các module đồng thời kích hoạt profile trùng với tên dự án.

Được sử dụng khi chọn mục menu «Bật module của dự án» để tự động kích hoạt profile có cùng tên với dự án hiện tại, nếu có.
Không tắt module của các dự án ẩn
Không tắt các module của dự án ẩn khi chọn mục menu «Tắt tất cả module». “Ẩn” được hiểu là các dự án được đặt danh mục "hidden".

Theo mặc định, lệnh «Tắt tất cả module» sẽ dừng hoạt động của tất cả các module, bao gồm cả những module được sử dụng bởi các dự án dịch vụ ẩn (ví dụ, PHPMyAdmin). Tùy chọn này cho phép giữ cho các dự án dịch vụ ẩn hoạt động, không tắt các module cần thiết cho chúng, trong khi tất cả các module khác sẽ bị tắt.
Ngôn ngữ giao diện
Ngôn ngữ giao diện người dùng của Open Server Panel.

Nếu tệp bản địa hóa không tồn tại hoặc có lỗi, tiếng Anh sẽ được sử dụng.
Miền API
Miền cục bộ cho API và giao diện web (đang phát triển)

Khuyến nghị: Nếu sử dụng VPN hoặc proxy, hãy thêm miền này vào danh sách ngoại lệ.
Địa chỉ IP API
Địa chỉ IPv4 cho API và giao diện web (đang phát triển).

Khuyến nghị: Nếu sử dụng VPN hoặc proxy, hãy thêm địa chỉ IP này vào danh sách ngoại lệ.
Cổng API
Cổng được sử dụng cho API và giao diện web (đang phát triển). Open Server Panel sẽ không thể khởi chạy nếu cổng được chỉ định đã được ứng dụng khác sử dụng.
Sử dụng Windows Terminal
Bật sử dụng Windows Terminal thay cho giao diện dòng lệnh tiêu chuẩn.

Yêu cầu: Windows Terminal phải được cài đặt trong hệ thống và khai báo trong biến môi trường PATH.

Windows Terminal như cmd.exe: Windows Terminal có thể thay thế cmd.exe và được khai báo trong biến môi trường %COMSPEC% trên các phiên bản Windows mới. Nếu vậy, hãy giữ tùy chọn này bật.

Phiên bản Windows Terminal mới: Nếu Windows Terminal mở cửa sổ mới thay vì tab, hãy cấu hình như sau: Cài đặt→Khởi chạy→Hành vi phiên bản mới→Gắn vào cửa sổ được sử dụng gần nhất.
Tiêu đề ngắn cho dự án
Khi bật tùy chọn này, tiêu đề cửa sổ terminal sẽ chỉ hiển thị tên dự án thay vì mô tả chi tiết môi trường.
Bao gồm môi trường hệ thống vào môi trường dự án
Sử dụng môi trường hệ thống (System) trong terminal ngay cả khi nó không được đặt trong cài đặt dự án. Môi trường hệ thống cho phép sử dụng các chương trình được cài đặt trong hệ thống (ví dụ, git.exe hoặc ssh.exe).

Chỉ tắt tùy chọn này khi xảy ra xung đột với phần mềm hệ thống.
Hỗ trợ ANSI
Bật hỗ trợ mã ANSI để quản lý màu sắc trong terminal.

Chế độ "Tự động" (mặc định):
- Bản vá chỉ áp dụng cho Windows 10 đến phiên bản 1903 bao gồm. Trên các phiên bản Windows mới hơn, hỗ trợ mã ANSI đã được tích hợp sẵn.
- Bản vá không áp dụng cho các terminal hỗ trợ ANSI theo mặc định (ví dụ, Windows Terminal).
Thư mục để tìm dự án
Danh sách các thư mục mà Open Server Panel sẽ tìm dự án. Ngăn cách đường dẫn bằng dấu chấm phẩy (;).

Ngoại lệ: Các thư mục con node_modules và vendor sẽ bị bỏ qua.
Độ sâu
Độ sâu lồng nhau tối đa của thư mục khi tìm dự án.

Tăng giá trị này có thể làm chậm quá trình khởi động Open Server Panel nếu trong các thư mục chỉ định có chứa số lượng lớn thư mục con.
Kích thước tối đa của tệp nhật ký
Kích thước tối đa của tệp nhật ký tính bằng megabyte. Khi vượt quá giá trị chỉ định, tệp log sẽ được tạo lại vào lần khởi động chương trình tiếp theo.

Đặt giá trị 0 để xóa nhật ký mỗi lần khởi động chương trình.

Đặt giá trị 100 MB để tắt hoàn toàn việc xóa nhật ký.
