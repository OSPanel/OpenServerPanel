Cài đặt chương trình

Khởi động cùng Windows
Bật tự động khởi động Open Server Panel khi khởi động hệ điều hành.
Kiểm tra phiên bản mới
Bật kiểm tra cập nhật Open Server Panel (yêu cầu kết nối Internet).
Bật trình lập lịch tác vụ
Kích hoạt trình lập lịch tác vụ tích hợp. Nếu tham số này bị tắt, không có tác vụ theo lịch nào sẽ được thực hiện, bất kể trạng thái của chúng.
Sử dụng tệp HOSTS
Bật ghi tên miền vào tệp HOSTS.

Khuyến nghị khi truy cập tệp HOSTS bị hạn chế trong tổ chức:

1. Cấu hình tất cả các module và dự án cần thiết.
2. Liên hệ với quản trị viên hệ thống để mở khóa HOSTS và cố định trạng thái của nó.
3. Sau khi quản trị viên cố định các thay đổi, bạn có thể tắt tùy chọn này.

Quan trọng: Đừng tắt tham số này nếu bạn không chắc chắn về hậu quả!
Ngôn ngữ giao diện
Ngôn ngữ giao diện người dùng của Open Server Panel.

Nếu tệp bản địa hóa không tồn tại hoặc chứa lỗi, tiếng Anh sẽ được sử dụng.
Tên miền API
Tên miền cục bộ cho API và giao diện web (đang phát triển)

Khuyến nghị: Nếu bạn sử dụng VPN hoặc proxy, hãy thêm tên miền này vào danh sách ngoại lệ.
Địa chỉ IP API
Địa chỉ IPv4 cho API và giao diện web (đang phát triển).

Khuyến nghị: Nếu bạn sử dụng VPN hoặc proxy, hãy thêm địa chỉ IP này vào danh sách ngoại lệ.
Cổng API
Cổng được sử dụng cho API và giao diện web (đang phát triển). Open Server Panel sẽ không khởi động nếu cổng đã được sử dụng.
Sử dụng Windows Terminal
Bật sử dụng Windows Terminal thay vì giao diện dòng lệnh tiêu chuẩn.

Yêu cầu: Windows Terminal phải được cài đặt trong hệ thống và được thêm vào biến môi trường PATH.

Windows Terminal như cmd.exe: Trong phiên bản Windows mới, Windows Terminal có thể thay thế cmd.exe và được đặt trong biến môi trường %COMSPEC%. Nếu vậy, hãy để tùy chọn này được bật.

Phiên bản Windows Terminal mới: Nếu Windows Terminal mở cửa sổ mới thay vì tab, hãy cấu hình nó như sau: Cài đặt→Khởi động→Hành vi phiên bản mới→Gắn kết với cửa sổ được sử dụng gần đây nhất.
Tiêu đề dự án ngắn
Khi kích hoạt tùy chọn này, chỉ tên dự án sẽ được hiển thị trong tiêu đề cửa sổ terminal thay vì mô tả chi tiết.
Sử dụng môi trường hệ thống với môi trường dự án
Sử dụng môi trường hệ thống (System) trong terminal, ngay cả khi nó không được đặt trong cài đặt dự án. Môi trường hệ thống cho phép sử dụng các chương trình được cài đặt trong hệ thống (ví dụ: git.exe hoặc ssh.exe).

Chỉ tắt tùy chọn này khi xảy ra xung đột với phần mềm hệ thống.
Hỗ trợ ANSI
Bật hỗ trợ mã ANSI để điều khiển màu sắc trong terminal.

Chế độ "Tự động" (mặc định):
- Bản sửa lỗi chỉ áp dụng cho Windows 7, 8 và Windows 10 (đến phiên bản 1903). Trong phiên bản Windows mới hơn, hỗ trợ mã ANSI đã được tích hợp sẵn.
- Bản sửa lỗi không áp dụng cho các terminal mặc định hỗ trợ ANSI (ví dụ: Windows Terminal).
Thư mục tìm kiếm dự án
Danh sách thư mục mà Open Server Panel sẽ tìm kiếm dự án. Phân tách các đường dẫn bằng dấu chấm phẩy (;).

Loại trừ: Thư mục con node_modules và vendor bị bỏ qua.
Độ sâu
Độ sâu tối đa của thư mục lồng nhau khi tìm kiếm dự án.

Tăng giá trị này có thể làm chậm quá trình khởi động Open Server Panel nếu trong các thư mục được chỉ định có số lượng lớn thư mục con.
Kích thước tệp nhật ký tối đa
Kích thước tối đa của tệp nhật ký tính bằng megabyte. Khi vượt quá giá trị này, tệp nhật ký sẽ được tạo lại vào lần khởi động tiếp theo của chương trình.

Đặt giá trị 0 để xóa tệp nhật ký mỗi khi khởi động chương trình.

Đặt giá trị 100 MB để tắt hoàn toàn việc xóa tệp nhật ký.
