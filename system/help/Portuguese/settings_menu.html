Configurações do menu

Tema de aparência
Tema de aparência para os ícones do menu.
Tamanho da fonte
Tamanho da fonte do menu em pixels. A opção permite definir o tamanho da fonte do menu independentemente das configurações do sistema.

Defina o controle deslizante para o valor mínimo de 12px para desativar a função de controle do tamanho da fonte (será usado o tamanho do sistema).
Mostrar ícone na área de notificações
Mostrar o ícone do programa na área de notificações do Windows.

Desativação: Desative esta opção se você usar um tipo de inicialização automática que não exija login do usuário do Windows (Agendador de Tarefas do Windows→Iniciar ao carregar o computador).
Mostrar ícones para os itens do menu
Mostrar ícones no menu do programa. Os ícones não são exibidos se a renderização do sistema estiver ativada.
Ativar renderização do sistema
Ative esta opção apenas quando for necessário garantir compatibilidade com programas de acesso à tela (screen readers).

Atenção! Os ícones no menu não são exibidos se a renderização do sistema estiver ativada.
Mostrar separador vertical
Ao ativar esta opção, os ícones no menu do programa serão separados por um separador vertical.
Não agrupar listas de um único item
Não agrupar listas que contenham apenas um item.
