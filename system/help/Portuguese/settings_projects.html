Configurações globais dos projetos

Os parâmetros definidos nesta seção são usados caso outros valores não estejam especificados nas configurações do projeto.

HTTP
Define o módulo do servidor web utilizado para os projetos.
NODE
Indica o engine Node.js para executar aplicações Node.js.

Instalação do Node.js: Pré-instale a versão necessária do Node.js com o comando osp node <latest|lts|номер>.
PHP
Define o módulo PHP utilizado para processar arquivos PHP.
Ativar
Define o estado padrão do projeto (ativado ou desativado).
Codificação do terminal
Codificação do terminal ao trabalhar com o ambiente do projeto.

Valores especiais:
- system: Usa a codificação do sistema.

Importante: Se o valor não for definido, ao formar o ambiente final do projeto a codificação do terminal será definida pelo último ambiente conectado no qual ela estiver definida, por exemplo, o ambiente do módulo PHP.
IP
Define o(s) endereço(s) IP usado(s) por todos os projetos sem configurações individuais.

Limitação: Projetos que usam o mesmo endereço IP devem funcionar na mesma versão do PHP.

Suporte a múltiplos IPs: É possível indicar vários endereços IP separados por espaço, incluindo IPv6. No arquivo HOSTS, os domínios receberão o primeiro IP indicado.

Atribuição automática: Se deixar o campo vazio, o endereço IP será atribuído automaticamente.

Recomendações:
  • O gerenciamento automático de endereços IP é recomendado para a maioria dos usuários.
  • A atribuição manual de IP deve ser usada apenas em requisitos específicos de configuração de rede.
HTTP
Define a porta para conexões HTTP.
HTTPS
Define a porta para conexões HTTPS.
TLS
Ativa ou desativa o suporte a TLS.
Arquivo de certificado
Indica o caminho para o arquivo do certificado TLS. É possível usar variáveis de template.

Caracteres permitidos: A-Za-z0-9-+_.\:

Recomendação: Deixe o campo vazio para geração automática de certificados.
Arquivo de chave
Indica o caminho para o arquivo da chave TLS. É possível usar variáveis de template.

Caracteres permitidos: A-Za-z0-9-+_.\:

Recomendação: Deixe o campo vazio para geração automática da chave.
Endereço IP (backend)
Indica o endereço IP pelo qual é realizada a conexão com a parte servidor (Backend).
Porta (backend)
Define o número da porta para conexão com a parte servidor (Backend).
Ativar (backend)
Permite encaminhar automaticamente todo o tráfego de entrada (HTTP e HTTPS) do projeto para a parte servidor (Backend). Útil para testes ou desenvolvimento quando frontend e backend estão separados.
Diretório do projeto
Indica o diretório raiz do projeto. A navegação para este diretório é realizada pelo comando osp project <DOMAIN> simultaneamente com a ativação do ambiente do projeto. É possível usar variáveis de template.

Caracteres permitidos: A-Za-z0-9-+_.\:
Diretório público
Define o diretório público do projeto. É possível usar variáveis de template.

Caracteres permitidos: A-Za-z0-9-+_.\:
Apelidos
Indica nomes de domínio adicionais (aliases) para o projeto (separados por espaço). É possível usar variáveis de template.

Limitação: O caractere "*" não é suportado no Windows pelo arquivo HOSTS e requer configuração de DNS.
Ambiente do projeto
Lista de add-ons e módulos (separados por espaço) que formam o ambiente do projeto.

HTTP, NODE e PHP: Os ambientes desses engines são sempre conectados (se definidos para o domínio) e não precisam ser indicados neste parâmetro.
Comando de inicialização do projeto
Define o comando para iniciar o projeto (por exemplo, nodemon app.js). É possível usar variáveis de template.
URL do projeto
URL usado ao abrir o projeto em Menu→Projeto→Abrir no navegador, bem como ao abrir aliases de domínio do projeto. É possível usar variáveis de template.

Aplicação: É possível definir a URL do painel administrativo da CMS.

Variáveis de template

Variável Descrição
{backend_ip} Endereço IP de conexão com a parte servidor (Backend)
{backend_port} Porta de conexão com a parte servidor (Backend)
{base_dir} Diretório raiz do projeto (onde está localizado o diretório .osp)
{date_time} Data/hora atual (a variável está disponível apenas para o comando de inicialização do aplicativo do projeto)
{host} Nome do domínio (para domínios internacionalizados é usado Punycode)
{host_decoded} Nome visível do domínio (sem Punycode)
{host_scheme} Esquema da requisição ao projeto ("http" ou "https", depende do parâmetro TLS nas configurações do projeto)
{http_port} Porta da requisição ao projeto via protocolo HTTP
{https_port} Porta da requisição ao projeto via protocolo HTTPS
{http_engine} Engine HTTP
{node_engine} Engine NODE
{php_engine} Engine PHP
{project_root} Diretório raiz do projeto
{web_root} Diretório público do projeto
{scheme_port} Porta da requisição ao projeto (":{http_port}" ou ":{https_port}", depende do parâmetro TLS nas configurações do projeto).

Se {http_port} ou {https_port} tiver o valor padrão 80 ou 443, então {scheme_port} ficará vazio.
{root_dir} Diretório raiz do Open Server Panel (caminho completo)
{root_drive} Unidade do diretório raiz
{root_path} Caminho para o diretório raiz do Open Server Panel
{terminal_codepage} Codificação do console
