Variáveis globais de ambiente dos módulos

Nesta seção é possível definir variáveis globais de ambiente para os módulos.

Essas variáveis atuam apenas no ambiente dos módulos e não afetam as variáveis do sistema ou o ambiente dos projetos.

Nos valores é permitido o uso de variáveis de modelo.

Se uma variável estiver presente no ambiente do sistema, mas não deve ser usada no ambiente dos módulos, utilize o filtro especial (ver Módulos→Variáveis do sistema permitidas) ou remova a variável do ambiente definindo um valor vazio.

Variáveis de modelo

Variável Descrição
{root_dir} Diretório raiz do Open Server Panel (caminho completo)
{root_drive} Unidade do diretório raiz
{root_path} Caminho para o diretório raiz do Open Server Panel
{terminal_codepage} Codificação no terminal (ver Módulos→Codificação no terminal)
{time_zone} Fuso horário no formato Etc/GMT (ver Módulos→Fuso horário)

Além das variáveis de modelo, é possível usar quaisquer variáveis de ambiente do Windows, por exemplo: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% etc.
