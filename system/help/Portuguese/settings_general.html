Configurações do programa

Iniciar junto com o Windows
Ativar a inicialização automática do Open Server Panel ao carregar o sistema operacional.
Atraso
Atraso na inicialização do programa (em segundos, de 0 a 60).

Permite adiar o início do aplicativo durante a inicialização junto com o Windows, para reduzir a carga geral no sistema. Isso é especialmente útil se for necessário aguardar a inicialização completa de serviços de terceiros ou interfaces de rede.
Verificar a disponibilidade de novas versões
Ativar a verificação de atualizações do Open Server Panel (é necessária conexão com a Internet).
Ativar o agendador de tarefas
Ativar o agendador de tarefas embutido. Se o parâmetro estiver desativado, nenhuma tarefa agendada será executada, independentemente do seu status.
Usar o arquivo HOSTS
Ativar a gravação de nomes de domínio no arquivo HOSTS.

Recomendações em caso de acesso limitado ao arquivo HOSTS na organização:

1. Configure todos os módulos e projetos necessários.
2. Entre em contato com o administrador do sistema para desbloquear o HOSTS e fixar seu estado.
3. Após a fixação das alterações pelo administrador, esta opção pode ser desativada.

Importante: Não desative este parâmetro se não tiver certeza das consequências!
Iniciar módulos com o perfil do projeto
Iniciar módulos com a ativação simultânea do perfil que coincide com o nome do projeto.

É usado ao selecionar o item de menu «Ativar módulos do projeto», para ativar automaticamente o perfil com o mesmo nome do projeto atual, se existir.
Não desligar módulos de projetos ocultos
Não desligar os módulos de projetos ocultos ao selecionar o item de menu «Desligar todos os módulos». Por "ocultos" entendem-se os projetos para os quais foi definida a categoria "hidden".

Por padrão, o comando «Desligar todos os módulos» interrompe o funcionamento de absolutamente todos os módulos, incluindo aqueles usados por projetos de serviço ocultos (por exemplo, PHPMyAdmin). Esta opção permite manter a operabilidade dos projetos de serviço ocultos, sem desligar os módulos necessários para eles, enquanto todos os demais módulos serão desligados.
Idioma da interface
Idioma da interface do usuário do Open Server Panel.

Se o arquivo de localização estiver ausente ou contiver erros, o idioma inglês será utilizado.
Domínio da API
Domínio local para a API e interface web (em desenvolvimento)

Recomendação: Se usar VPN ou proxy, adicione este domínio às exceções.
Endereço IP da API
Endereço IPv4 para a API e interface web (em desenvolvimento).

Recomendação: Se usar VPN ou proxy, adicione este endereço IP às exceções.
Porta da API
Porta usada para a API e interface web (em desenvolvimento). O Open Server Panel não poderá iniciar se a porta especificada já estiver sendo usada por outro aplicativo.
Usar o Windows Terminal
Ativar o uso do Windows Terminal em vez da interface de comando padrão.

Requisitos: O Windows Terminal deve estar instalado no sistema e definido na variável de ambiente PATH.

Windows Terminal como cmd.exe: O Windows Terminal pode substituir o cmd.exe e estar definido na variável de ambiente %COMSPEC% nas novas versões do Windows. Se for o caso, deixe esta opção ativada.

Novas instâncias do Windows Terminal: Se o Windows Terminal abrir novas janelas em vez de abas, configure-o assim: Configurações→Inicialização→Comportamento de nova instância→Anexar à última janela usada.
Título curto do projeto
Ao ativar esta opção, o título da janela do terminal exibirá apenas o nome do projeto em vez da descrição detalhada do ambiente.
Incluir o ambiente do sistema no ambiente do projeto
Usar o ambiente do sistema (System) no terminal, mesmo que não esteja definido nas configurações do projeto. O ambiente do sistema permite usar programas instalados no sistema (por exemplo, git.exe ou ssh.exe).

Desative esta opção apenas em caso de conflitos com software do sistema.
Suporte a ANSI
Ativar o suporte a códigos ANSI para controle de cores no terminal.

Modo "Automático" (padrão):
- A correção é aplicada apenas ao Windows 10 até a versão 1903 inclusive. Em versões mais recentes do Windows, o suporte a códigos ANSI já está embutido.
- A correção não é aplicada a terminais que suportam ANSI por padrão (por exemplo, Windows Terminal).
Diretórios para busca de projetos
Lista de diretórios nos quais o Open Server Panel procurará projetos. Separe os caminhos com ponto e vírgula (;).

Exceções: Os subdiretórios node_modules e vendor são ignorados.
Profundidade
Profundidade máxima de aninhamento de diretórios ao buscar projetos.

Aumentar este valor pode desacelerar a inicialização do Open Server Panel, se nos diretórios especificados houver um grande número de subdiretórios.
Tamanho máximo do arquivo de log
Tamanho máximo do arquivo de log em megabytes. Ao exceder o valor especificado, o arquivo de log será recriado na próxima inicialização do programa.

Defina o valor 0 para limpar os logs a cada inicialização do programa.

Defina o valor 100 MB para desativar completamente a limpeza dos logs.
