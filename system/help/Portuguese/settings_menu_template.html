Criar itens de menu personalizados

  1. Adicione uma nova seção com um identificador [ID] exclusivo
  2. Organize as seções na ordem desejada — isso definirá a ordem dos itens no menu
  3. Salve as alterações e reinicie o Open Server Panel para aplicar as alterações

Informações importantes

Ao criar itens de menu personalizados, certifique-se de que os identificadores das seções não se repitam. Isso pode levar a conflitos no funcionamento do menu.

Configurações dos itens de menu

Ordem de classificação: Os itens do menu são classificados na mesma ordem em que as seções correspondentes estão dispostas no template.

caption Título do item de menu. Suporta constantes de idioma no formato {lang_xxx}.

Padrão: não definido
category

Define a localização do item de menu na hierarquia. Suporta um nível de aninhamento (por exemplo, "Meus Favoritos\Trabalho").

Categorias especiais:

  • projects, modules, addons - adiciona o item ao menu de ações correspondente
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - adiciona o item para um elemento específico

Se a categoria não for especificada, o item é criado no menu raiz.

Padrão: não definido
command Comando a ser executado ao ativar o item de menu. Itens sem comando são ignorados.

Padrão: não definido
enabled Ativa/desativa a exibição do item de menu.

Padrão: on | Valores: on, off
hide Controla a visibilidade da janela do aplicativo chamado. Não afeta processos filhos.

Padrão: off | Valores: on, off
hr_after Adiciona um separador horizontal após o item de menu.

Padrão: off | Valores: on, off
hr_before Adiciona um separador horizontal antes do item de menu.

Padrão: off | Valores: on, off
icon Ícone do conjunto Font Awesome Free (Solid/Regular/Brands).

Padrão: não definido
need_alias Exibe o item de menu apenas para um alias de domínio. No template de menu pode haver apenas um item com need_alias=on!
Aplicável para categorias: projects

Padrão: não definido | Valores: on, off
need_category

Restringe a exibição do item de menu a módulos/addons de uma determinada categoria.

Formatos suportados:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Padrão: não definido
need_module_shell Exibe o item de menu dependendo da disponibilidade de shell/cli no módulo pai.
Aplicável para categorias: modules, modules\<имя_модуля>

Padrão: não definido | Valores: on, off
need_state Exibe o item de menu dependendo do estado do módulo pai.
Aplicável para categorias: modules, modules\<имя_модуля>

Padrão: não definido | Valores: on, off
need_start_cmd Exibe o item de menu quando houver um comando de inicialização nas configurações do projeto.
Aplicável para categorias: projects, projects\<имя_домена>

Padrão: não definido | Valores: on, off
need_use_wt Exibe o item de menu dependendo da configuração de uso do Windows Terminal no Open Server Panel.

Padrão: não definido | Valores: on, off
work_directory Diretório de trabalho para execução do comando. Pode ser alterado durante a execução dos comandos.

Padrão: {root_dir}

Variáveis de template

Nos parâmetros "command" e "work_directory" você pode usar as seguintes variáveis de template:

Variáveis gerais

Variável Descrição
{date_time} Data/hora atual (variável disponível apenas para o parâmetro "command")
{root_dir} Diretório raiz do Open Server Panel (caminho completo)
{root_drive} Unidade do diretório raiz
{root_path} Caminho para o diretório raiz do Open Server Panel
{web_panel_url} URL da interface web

Variáveis especiais (apenas para projects e projects\<имя_домена>)

Variável Descrição
{base_dir} Diretório base do projeto
{host} Nome de domínio (Punycode)
{host_decoded} Nome de domínio visível (sem Punycode)
{host_scheme} Esquema de requisição ao projeto ("http" ou "https", depende do parâmetro TLS nas configurações do projeto)
{http_port} Porta de requisição ao projeto via protocolo HTTP
{https_port} Porta de requisição ao projeto via protocolo HTTPS
{menu_caption} Título do item de menu (apenas para a categoria projects com need_alias=ON)
{http_engine} Engine HTTP
{node_engine} Engine Node.js
{php_engine} Engine PHP
{project_root} Diretório raiz do projeto
{base_url} URL do projeto
{web_root} Diretório público do projeto
{scheme_port} Porta de requisição ao projeto (":{http_port}" ou ":{https_port}", depende do parâmetro TLS nas configurações do projeto). Se {http_port} ou {https_port} tiver o valor padrão 80 ou 443, então {scheme_port} ficará vazio.
{app_start_command} Comando de inicialização do aplicativo do projeto (se configurado)
{terminal_codepage} Codificação do console

Variáveis especiais (apenas para addons e addons\<имя_дополнения>)

Variável Descrição
{addon_name} Nome do addon
{terminal_codepage} Codificação do console

Variáveis especiais (apenas para modules e modules\<имя_модуля>)

Variável Descrição
{ip} Endereço IP do módulo
{log_level} Nível de registro de erros
{module_name} Nome do módulo
{port} Porta do módulo
{profile_name} Nome do perfil atual de configurações do módulo
{query_log_level} Nível de registro de consultas
{shell_command} Comando de inicialização da shell/cli do módulo (se configurado)
{terminal_codepage} Codificação do console
{time_zone} Fuso horário

Valores especiais de comandos

Comando Descrição
command_open_logs_viewer Abrir a janela de visualização de logs
command_open_idn_converter Abrir o conversor IDN
command_open_options Abrir a janela de configurações do programa

Além das variáveis de template, você pode usar quaisquer variáveis de ambiente do Windows, por exemplo: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% etc.

Exemplo de uso

[bookmark_1]

caption  = Google
category = Meus Favoritos\Motores de busca
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opções do CMD.EXE

  • /c: Executar o comando e fechar o terminal.
  • /k: Executar o comando e manter o terminal aberto.
