Créer des éléments de menu personnalisés

  1. Ajoutez une nouvelle section avec un identifiant unique [ID]
  2. Disposez les sections dans l’ordre souhaité — cela déterminera l’ordre des éléments dans le menu
  3. Enregistrez les modifications et redémarrez Open Server Panel pour appliquer les changements

Information importante

Lors de la création d’éléments de menu personnalisés, veillez à ce que les identifiants des sections ne se répètent pas. Cela peut entraîner des conflits dans le fonctionnement du menu.

Paramètres des éléments de menu

Ordre de tri : Les éléments de menu sont triés dans le même ordre que les sections correspondantes dans le modèle.

caption Titre de l’élément de menu. Prend en charge les constantes linguistiques au format {lang_xxx}.

Par défaut : non défini
category

Définit l’emplacement de l’élément de menu dans la hiérarchie. Prend en charge un niveau d’imbrication (par exemple, "Mes favoris\Travail").

Catégories spéciales :

  • projects, modules, addons - ajoute un élément au menu d’actions correspondant
  • projects\, modules\, addons\ - ajoute un élément pour un élément spécifique

Si la catégorie n’est pas spécifiée, l’élément est créé dans le menu racine.

Par défaut : non défini
command Commande à exécuter lors de l’activation de l’élément de menu. Les éléments sans commande sont ignorés.

Par défaut : non défini
enabled Active/désactive l’affichage de l’élément de menu.

Par défaut : on | Valeurs : on, off
hide Contrôle la visibilité de la fenêtre de l’application appelée. N’affecte pas les processus enfants.

Par défaut : off | Valeurs : on, off
hr_after Ajoute un séparateur horizontal après l’élément de menu.

Par défaut : off | Valeurs : on, off
hr_before Ajoute un séparateur horizontal avant l’élément de menu.

Par défaut : off | Valeurs : on, off
icon Icône du set Font Awesome Free (Solid/Regular/Brands).

Par défaut : non défini
need_alias Affiche l’élément de menu uniquement pour un alias de domaine. Le modèle de menu ne peut contenir qu’un seul élément avec need_alias=on !
Applicable aux catégories : projects

Par défaut : non défini | Valeurs : on, off
need_category

Limite l’affichage de l’élément de menu aux modules/extensions d’une catégorie spécifique.

Formats pris en charge :

  • modules, addons
  • modules\, addons\
Par défaut : non défini
need_module_shell Affiche l’élément de menu selon la présence d’un shell/cli du module parent.
Applicable aux catégories : modules, modules\

Par défaut : non défini | Valeurs : on, off
need_state Affiche l’élément de menu selon l’état du module parent.
Applicable aux catégories : modules, modules\

Par défaut : non défini | Valeurs : on, off
need_start_cmd Affiche l’élément de menu si une commande de démarrage est définie dans les paramètres du projet.
Applicable aux catégories : projects, projects\

Par défaut : non défini | Valeurs : on, off
need_use_wt Affiche l’élément de menu selon le paramètre d’utilisation de Windows Terminal dans Open Server Panel.

Par défaut : non défini | Valeurs : on, off
work_directory Répertoire de travail pour l’exécution de la commande. Peut changer pendant l’exécution des commandes.

Par défaut : {root_dir}

Variables de modèle

Dans les paramètres "command" et "work_directory", vous pouvez utiliser les variables de modèle suivantes :

Variables générales

Variable Description
{date_time} Date/heure actuelle (variable disponible uniquement pour le paramètre "command")
{root_dir} Répertoire racine de Open Server Panel (chemin complet)
{root_drive} Lecteur du répertoire racine
{root_path} Chemin vers le répertoire racine de Open Server Panel
{web_panel_url} URL de l’interface web

Variables spéciales (uniquement pour projects et projects\<nom_de_domaine>)

Variable Description
{base_dir} Répertoire de base du projet
{host} Nom de domaine (Punycode)
{host_decoded} Nom de domaine visible (sans Punycode)
{host_scheme} Schéma de requête vers le projet ("http" ou "https", dépend du paramètre TLS dans les paramètres du projet)
{http_port} Port de requête vers le projet via le protocole HTTP
{https_port} Port de requête vers le projet via le protocole HTTPS
{menu_caption} Titre de l’élément de menu (uniquement pour la catégorie projects avec need_alias=ON)
{http_engine} Moteur HTTP
{node_engine} Moteur Node.js
{php_engine} Moteur PHP
{project_root} Répertoire racine du projet
{base_url} URL du projet
{web_root} Répertoire public du projet
{scheme_port} Port de requête vers le projet (":{http_port}" ou ":{https_port}", dépend du paramètre TLS dans les paramètres du projet). Si {http_port} ou {https_port} a la valeur standard 80 ou 443, alors {scheme_port} sera vide.
{app_start_command} Commande de démarrage de l’application du projet (si définie)
{terminal_codepage} Encodage de la console

Variables spéciales (uniquement pour addons et addons\<nom_de_l’extension>)

Variable Description
{addon_name} Nom de l’extension
{terminal_codepage} Encodage de la console

Variables spéciales (uniquement pour modules et modules\<nom_du_module>)

Variable Description
{ip} Adresse IP du module
{log_level} Niveau de journalisation des erreurs
{module_name} Nom du module
{port} Port du module
{profile_name} Nom du profil de configuration actuel du module
{query_log_level} Niveau de journalisation des requêtes
{shell_command} Commande de lancement du shell/cli du module (si définie)
{terminal_codepage} Encodage de la console
{time_zone} Fuseau horaire

Valeurs de commande spéciales

Commande Description
command_open_logs_viewer Ouvrir la fenêtre de visualisation des journaux
command_open_idn_converter Ouvrir le convertisseur IDN
command_open_options Ouvrir la fenêtre des paramètres du programme

En plus des variables de modèle, vous pouvez utiliser n’importe quelles variables d’environnement Windows, par exemple : %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, etc.

Exemple d’utilisation

[bookmark_1]

caption  = Google
category = Mes favoris\Systèmes de recherche
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Options de CMD.EXE

  • /c : Exécuter la commande et fermer le terminal.
  • /k : Exécuter la commande et laisser le terminal ouvert.
