Paramètres globaux des modules

Les paramètres définis dans cette section s’appliquent lorsque, dans les réglages d’un module spécifique, l’option correspondante est définie sur auto (par défaut).

Mode silencieux
Désactive les fenêtres contextuelles d’erreurs de Windows Error Reporting et du module lui-même.

Recommandation : Désactivez ce mode uniquement si nécessaire pour diagnostiquer des problèmes de fonctionnement du module.
Ajouter un en-tête au fichier journal
Active l’ajout automatique d’un en-tête dans le fichier journal à chaque démarrage du module. Utile lorsque le nettoyage automatique des logs est désactivé pour séparer les sessions de travail.
Nombre maximal de démarrages infructueux
Détermine combien de démarrages consécutifs infructueux du module sont autorisés avant qu’il ne passe à l’état « Erreur ».
Temps de vérification de la santé du module
Définit la période de test de bon fonctionnement du module après son démarrage réussi.

Début du décompte : À partir du moment du démarrage réussi du module.

Passage à l’état « Erreur » : Si le module se termine de manière anormale durant la période d’essai, il ne sera pas relancé automatiquement et passera à l’état « Erreur ». Cela s’applique également aux cas où le module ne parvient pas à se lancer au niveau du système.

Désactivation de la vérification : La valeur 0 désactive la période d’essai, et le module sera toujours redémarré en cas de défaillance.

Recommandation : N’indiquez pas la valeur 0 ni une période trop courte (moins de 30 secondes), car cela peut entraîner des boucles de redémarrage infinies.
Temps d’attente de l’arrêt du module
Définit la durée maximale pendant laquelle le module est autorisé à terminer son travail.

Arrêt forcé : Si le module ne se termine pas dans le délai indiqué, il sera arrêté de force.

Désactivation de l’attente : La valeur 0 désactive la période d’attente. Le programme attendra la fin du module pendant une durée illimitée.

Avertissement : Forcer l’arrêt du module peut entraîner des dommages aux données, une perte de modifications non enregistrées ou une terminaison incorrecte des processus. Utilisez ce réglage avec prudence.
Taille maximale du fichier journal
Taille maximale du fichier journal en mégaoctets. En cas de dépassement de la valeur indiquée, le fichier log sera recréé au prochain démarrage du module.

Définissez la valeur 0 pour nettoyer les journaux à chaque démarrage du module.

Définissez la valeur 100 Mo pour désactiver complètement le nettoyage des journaux.
Encodage du terminal
Encodage du terminal lors du travail avec l’environnement du module.

Valeurs spéciales :
- system: Utilise l’encodage du système.
Fuseau horaire
Définit le fuseau horaire du module au format Etc/GMT (par exemple, Etc/GMT-3).

Valeurs spéciales :
- system: Utilise le fuseau horaire du système.

Important : Le format Etc/GMT a un décalage inversé par rapport à l’UTC (par exemple, Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Environnements d’extensions utilisés
Définit la liste des extensions (indiquées séparées par des espaces) dont les environnements (le cas échéant) sont joints à l’environnement du module. Les indicateurs d’information dans le terminal n’affichent pas ces environnements supplémentaires.

Avertissement : Utilisez cette option uniquement en comprenant pleinement son objet.
Variables système autorisées
Définit la liste des variables d’environnement Windows (indiquées séparées par des espaces) qui sont transmises à l’environnement du module.

But : Permet d’isoler l’environnement de travail du module d’un logiciel similaire installé sur le système.

Avertissement : Modifier cette liste sans en comprendre pleinement l’impact peut entraîner un fonctionnement instable du module.
