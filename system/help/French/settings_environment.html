Variables d’environnement globales des modules

Dans cette section, vous pouvez définir des variables d’environnement globales pour les modules.

Ces variables ne s’appliquent que dans l’environnement des modules et n’affectent pas les variables système ni l’environnement des projets.

L’utilisation de variables modèles est autorisée dans les valeurs.

Si une variable est présente dans l’environnement système mais ne doit pas être utilisée dans l’environnement des modules, utilisez le filtre spécial (voir Modules→Variables système autorisées) ou supprimez la variable de l’environnement en lui attribuant une valeur vide.

Variables modèles

Variable Description
{root_dir} Répertoire racine de Open Server Panel (chemin complet)
{root_drive} Lecteur du répertoire racine
{root_path} Chemin vers le répertoire racine de Open Server Panel
{terminal_codepage} Encodage dans le terminal (voir Modules→Encodage dans le terminal)
{time_zone} Fuseau horaire au format Etc/GMT (voir Modules→Fuseau horaire)

En plus des variables modèles, vous pouvez utiliser n’importe quelles variables d’environnement Windows, par exemple : %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, etc.
