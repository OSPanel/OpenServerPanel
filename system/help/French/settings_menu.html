Paramètres du menu

Thème d’apparence
Thème d’apparence pour les icônes du menu.
Taille de police
Taille de police du menu en pixels. Cette option permet de définir la taille de police du menu indépendamment des paramètres système.

Réglez le curseur sur la valeur minimale de 12px pour désactiver le contrôle de la taille de police (la taille système sera utilisée).
Afficher l’icône dans la zone de notification
Afficher l’icône du programme dans la zone de notification de Windows.

Désactivation : Désactivez cette option si vous utilisez un type de démarrage automatique ne nécessitant pas la connexion de l’utilisateur Windows (Planificateur de tâches Windows→Démarrage au chargement de l’ordinateur).
Afficher des icônes pour les éléments de menu
Afficher des icônes dans le menu du programme. Les icônes ne s’affichent pas si le rendu système est activé.
Activer le rendu système
Activez cette option uniquement si nécessaire pour assurer la compatibilité avec les logiciels d’accès à l’écran (lecteurs d’écran).

Attention ! Les icônes du menu ne s’affichent pas si le rendu système est activé.
Afficher le séparateur vertical
Lorsque cette option est activée, les icônes du menu du programme seront séparées par un séparateur vertical.
Ne pas regrouper les listes d’un seul élément
Ne pas regrouper les listes ne contenant qu’un seul élément.
Projets : afficher
Afficher le menu de gestion des projets.
Projets : regrouper
Regrouper les projets par zone de domaine dans le menu.
Projets : menu imbriqué
Afficher le menu des projets dans un sous-menu séparé.
Projets : afficher le séparateur
Afficher une ligne de séparation après le menu des projets.
Modules : afficher
Afficher le menu de gestion des modules.
Modules : regrouper
Regrouper les modules dans le menu.
Modules : menu imbriqué
Afficher le menu des modules dans un sous-menu séparé.
Modules : afficher le séparateur
Afficher une ligne de séparation après le menu des modules.
Extensions : afficher
Afficher le menu des extensions.
Extensions : regrouper
Regrouper les extensions dans le menu.
Extensions : menu imbriqué
Afficher le menu des extensions dans un sous-menu séparé.
Extensions : afficher le séparateur
Afficher une ligne de séparation après le menu des extensions.
