Paramètres globaux des projets

Les paramètres définis dans cette section sont utilisés si d’autres valeurs ne sont pas spécifiées dans les paramètres du projet.

HTTP
Détermine le module du serveur web utilisé pour les projets.
NODE
Indique le moteur Node.js pour exécuter les applications Node.js.

Installation de Node.js : Installez au préalable la version requise de Node.js à l’aide de la commande osp node <latest|lts|номер>.
PHP
Détermine le module PHP utilisé pour le traitement des fichiers PHP.
Activer
Détermine l’état par défaut du projet (activé ou désactivé).
Encodage du terminal
Encodage du terminal lors du travail avec l’environnement du projet.

Valeurs spéciales :
- system : L’encodage système est utilisé.

Important : Si la valeur n’est pas définie, lors de la formation de l’environnement final du projet, l’encodage du terminal sera défini par le dernier environnement connecté dans lequel il est spécifié, par exemple l’environnement du module PHP.
IP
Définit la ou les adresses IP utilisées par tous les projets sans paramètres individuels.

Limitation : Les projets utilisant la même adresse IP doivent fonctionner sur une même version de PHP.

Prise en charge de plusieurs IP : Vous pouvez spécifier plusieurs adresses IP séparées par un espace, y compris IPv6. Dans le fichier HOSTS, le premier IP indiqué sera attribué aux domaines.

Attribution automatique : Si vous laissez le champ vide, l’adresse IP sera attribuée automatiquement.

Recommandations :
  • La gestion automatique des adresses IP est recommandée pour la plupart des utilisateurs.
  • La définition manuelle de l’adresse IP ne doit être utilisée que pour des exigences spécifiques de configuration réseau.
HTTP
Détermine le port pour les connexions HTTP.
HTTPS
Détermine le port pour les connexions HTTPS.
TLS
Active ou désactive la prise en charge de TLS.
Fichier de certificat
Indique le chemin vers le fichier de certificat TLS. Vous pouvez utiliser des variables de modèle.

Caractères autorisés : A-Za-z0-9-+_.\:

Recommandation : Laissez le champ vide pour une génération automatique des certificats.
Fichier de clé
Indique le chemin vers le fichier de clé TLS. Vous pouvez utiliser des variables de modèle.

Caractères autorisés : A-Za-z0-9-+_.\:

Recommandation : Laissez le champ vide pour une génération automatique de la clé.
Adresse IP (backend)
Indique l’adresse IP utilisée pour se connecter à la partie serveur (Backend).
Port (backend)
Définit le numéro de port pour la connexion à la partie serveur (Backend).
Activer (backend)
Permet de rediriger automatiquement tout le trafic entrant (HTTP et HTTPS) du projet vers la partie serveur (Backend). Utile pour les tests ou le développement lorsque le frontend et le backend sont séparés.
Répertoire du projet
Indique le répertoire racine du projet. La navigation vers ce répertoire s’effectue avec la commande osp project <DOMAIN> en même temps que l’activation de l’environnement du projet. Vous pouvez utiliser des variables de modèle.

Caractères autorisés : A-Za-z0-9-+_.\:
Répertoire public
Détermine le répertoire public du projet. Vous pouvez utiliser des variables de modèle.

Caractères autorisés : A-Za-z0-9-+_.\:
Alias
Indique des noms de domaine supplémentaires (alias) pour le projet (séparés par un espace). Vous pouvez utiliser des variables de modèle.

Limitation : Le caractère "*" n’est pas pris en charge par le fichier HOSTS sous Windows et nécessite une configuration DNS.
Environnement du projet
Liste des add-ons et modules (séparés par un espace) qui forment l’environnement du projet.

HTTP, NODE et PHP : Les environnements de ces moteurs sont toujours connectés (s’ils sont définis pour le domaine) et ne nécessitent pas d’être indiqués dans ce paramètre.
Commande de démarrage du projet
Détermine la commande pour démarrer le projet (par exemple, nodemon app.js). Vous pouvez utiliser des variables de modèle.
URL du projet
L’URL utilisée lors de l’ouverture du projet Menu→Projet→Ouvrir dans le navigateur, ainsi que lors de l’ouverture des alias de domaine du projet. Vous pouvez utiliser des variables de modèle.

Utilisation : Vous pouvez définir l’URL du panneau d’administration du CMS.

Variables de modèle

Variable Description
{backend_ip} Adresse IP de connexion à la partie serveur (Backend)
{backend_port} Port de connexion à la partie serveur (Backend)
{base_dir} Répertoire racine du projet (où se trouve le répertoire .osp)
{date_time} Date/heure actuelle (variable disponible uniquement pour la commande de lancement de l’application du projet)
{host} Nom de domaine (pour les domaines internationalisés, Punycode est utilisé)
{host_decoded} Nom de domaine visible (sans Punycode)
{host_scheme} Schéma de la requête vers le projet ("http" ou "https", dépend du paramètre TLS dans les paramètres du projet)
{http_port} Port de la requête vers le projet via le protocole HTTP
{https_port} Port de la requête vers le projet via le protocole HTTPS
{http_engine} Moteur HTTP
{node_engine} Moteur NODE
{php_engine} Moteur PHP
{project_root} Répertoire racine du projet
{web_root} Répertoire public du projet
{scheme_port} Port de la requête vers le projet (":{http_port}" ou ":{https_port}", dépend du paramètre TLS dans les paramètres du projet).

Si {http_port} ou {https_port} a la valeur standard 80 ou 443, alors {scheme_port} sera vide.
{root_dir} Répertoire racine d’Open Server Panel (chemin complet)
{root_drive} Lecteur du répertoire racine
{root_path} Chemin vers le répertoire racine d’Open Server Panel
{terminal_codepage} Encodage de la console
