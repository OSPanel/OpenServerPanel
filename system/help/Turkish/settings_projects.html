Projelerin genel ayarları

Bu bölümde belirtilen parametreler, proje ayarlarında başka değerler belirtilmediyse kullanılır.

HTTP
Projeler için kullanılan web sunucusu modülünü belirler.
NODE
Node.js uygulamalarını çalıştırmak için Node.js engine belirtir.

Node.js kurulumu: Gerekli Node.js sürümünü önceden osp node <latest|lts|номер> komutu ile kurun.
PHP
PHP dosyalarını işlemek için kullanılan PHP modülünü belirler.
Etkinleştir
Projenin varsayılan durumunu belirler (açık veya kapalı).
Terminal kodlaması
Proje ortamıyla çalışırken terminalin kodlaması.

Özel değerler:
- system: Sistem kodlaması kullanılır.

Önemli: Değer belirtilmezse, projenin nihai ortamı oluşturulurken terminal kodlaması, örneğin PHP modülü ortamı gibi, kodlamanın belirtildiği en son bağlanan ortam tarafından ayarlanır.
IP
Bireysel ayarları olmayan tüm projeler tarafından kullanılan IP adres(ler)ini belirler.

Sınırlama: Aynı IP adresini kullanan projeler aynı PHP sürümünde çalışmalıdır.

Birden fazla IP desteği: Boşlukla ayrılarak birden fazla IP adresi, IPv6 dahil, belirtilebilir. HOSTS dosyasında alan adlarına ilk belirtilen IP atanır.

Otomatik atama: Alan boş bırakılırsa IP adresi otomatik olarak atanır.

Öneriler:
  • IP adreslerinin otomatik yönetimi çoğu kullanıcı için önerilir.
  • IP adresinin manuel olarak belirlenmesi yalnızca özel ağ yapılandırma gereksinimlerinde kullanılmalıdır.
HTTP
HTTP bağlantıları için portu belirler.
HTTPS
HTTPS bağlantıları için portu belirler.
TLS
TLS desteğini etkinleştirir veya devre dışı bırakır.
Sertifika dosyası
TLS sertifika dosyasının yolunu belirtir. Şablon değişkenleri kullanılabilir.

İzin verilen karakterler: A-Za-z0-9-+_.\:

Öneri: Sertifikaların otomatik oluşturulması için alanı boş bırakın.
Anahtar dosyası
TLS anahtar dosyasının yolunu belirtir. Şablon değişkenleri kullanılabilir.

İzin verilen karakterler: A-Za-z0-9-+_.\:

Öneri: Anahtarın otomatik oluşturulması için alanı boş bırakın.
IP adresi (backend)
Backend'e bağlantı kurmak için kullanılan IP adresini belirtir.
Port (backend)
Backend'e bağlantı için port numarasını belirler.
Etkinleştir (backend)
Projenin tüm gelen trafiğini (HTTP ve HTTPS) otomatik olarak Backend'e yönlendirmenizi sağlar. Frontend ve backend ayrıldığında test veya geliştirme için kullanışlıdır.
Proje dizini
Projenin kök dizinini belirtir. Bu dizine geçiş, proje ortamı etkinleştirilirken eşzamanlı olarak osp project <DOMAIN> komutuyla yapılır. Şablon değişkenleri kullanılabilir.

İzin verilen karakterler: A-Za-z0-9-+_.\:
Genel dizin
Projenin genel dizinini belirler. Şablon değişkenleri kullanılabilir.

İzin verilen karakterler: A-Za-z0-9-+_.\:
Takma adlar
Proje için ek alan adlarını (alias) belirtir (boşlukla ayrılmış). Şablon değişkenleri kullanılabilir.

Sınırlama: "*" karakteri Windows'ta HOSTS dosyası tarafından desteklenmez ve DNS yapılandırması gerektirir.
Proje ortamı
Projenin ortamını oluşturan eklenti ve modüllerin listesi (boşlukla ayrılmış).

HTTP, NODE ve PHP: Bu engine'lerin ortamları her zaman bağlanır (alan adı için belirtilmişse) ve bu parametrede belirtilmesi gerekmez.
Proje başlatma komutu
Projeyi başlatmak için komutu belirler (örneğin, nodemon app.js). Şablon değişkenleri kullanılabilir.
Proje URL'si
Projeyi Menü→Proje→Tarayıcıda aç ile açarken ve ayrıca projenin alan adı takma adlarını (alias) açarken kullanılan URL. Şablon değişkenleri kullanılabilir.

Kullanım: CMS yönetim panelinin URL'si belirtilebilir.

Şablon değişkenleri

Değişken Açıklama
{backend_ip} Backend'e bağlantı için IP adresi
{backend_port} Backend'e bağlantı için port
{base_dir} Projenin kök dizini (.osp dizininin bulunduğu yer)
{date_time} Geçerli tarih/saat (değişken yalnızca projenin uygulama başlatma komutu için kullanılabilir)
{host} Alan adı (uluslararası alan adları için Punycode kullanılır)
{host_decoded} Görünen alan adı (Punycode olmadan)
{host_scheme} Projeye istek şeması ("http" veya "https", proje ayarlarındaki TLS parametresine bağlıdır)
{http_port} Projeye HTTP protokolüyle istek için port
{https_port} Projeye HTTPS protokolüyle istek için port
{http_engine} HTTP engine
{node_engine} NODE engine
{php_engine} PHP engine
{project_root} Projenin kök dizini
{web_root} Projenin genel dizini
{scheme_port} Projeye istek için port (":{http_port}" veya ":{https_port}", proje ayarlarındaki TLS parametresine bağlıdır).

Eğer {http_port} veya {https_port} standart değer olan 80 veya 443 ise, {scheme_port} boş olacaktır.
{root_dir} Open Server Panel'in kök dizini (tam yol)
{root_drive} Kök dizinin sürücüsü
{root_path} Open Server Panel'in kök dizinine giden yol
{terminal_codepage} Konsolun kodlaması
