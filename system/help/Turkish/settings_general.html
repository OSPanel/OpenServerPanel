Program ayarları

Windows ile birlikte başlat
İşletim sistemi yüklenirken Open Server Panel'in otomatik başlatılmasını etkinleştir.
Gecikme
Programın başlatılma gecikmesi (saniye cinsinden, 0 ile 60 arası).

Windows ile birlikte yükleme sırasında uygulamanın başlangıcını ertelemeye olanak tanır ve sistem üzerindeki genel yükü azaltır. Bu, özellikle üçüncü taraf servislerin veya ağ arayüzlerinin tam başlatılmasını beklemek gerektiğinde faydalıdır.
Yeni sürümlerin varlığını kontrol et
Open Server Panel güncellemelerini kontrol etmeyi etkinleştir (İnternet bağlantısı gerekir).
Görev zamanlayıcıyı etkinleştir
Dahili görev zamanlayıcıyı etkinleştir. Parametre devre dışı bırakılırsa, durumlarından bağımsız olarak hiçbir zamanlanmış görev yürütülmez.
HOSTS dosyasını kullan
Alan adlarını HOSTS dosyasına yazmayı etkinleştir.

Kuruluşta HOSTS dosyasına erişim kısıtlıyken öneriler:

1. Gerekli tüm modülleri ve projeleri yapılandırın.
2. HOSTS'u kilitlerinin kaldırılması ve durumunun sabitlenmesi için sistem yöneticisine başvurun.
3. Yönetici değişiklikleri sabitledikten sonra bu seçeneği devre dışı bırakabilirsiniz.

Önemli: Sonuçlarından emin değilseniz bu parametreyi devre dışı bırakmayın!
Modülleri proje profili ile başlat
Modülleri, proje adıyla aynı ada sahip profilin eşzamanlı etkinleştirilmesiyle başlat.

Menüden “Proje modüllerini etkinleştir” seçildiğinde, mevcut projeyle aynı ada sahip bir profil varsa otomatik olarak etkinleştirmek için kullanılır.
Gizli projelerin modüllerini kapatma
Menüde “Tüm modülleri kapat” seçildiğinde gizli projelerin modüllerini kapatma. "Gizli" ile "hidden" kategorisi atanan projeler kastedilmektedir.

Varsayılan olarak “Tüm modülleri kapat” komutu, gizli yardımcı projeler (örneğin, PHPMyAdmin) tarafından kullanılanlar da dahil olmak üzere tüm modüllerin çalışmasını durdurur. Bu seçenek, gerekli modülleri kapatmadan gizli yardımcı projelerin çalışabilirliğini korumanıza olanak tanır; bu sırada diğer tüm modüller kapatılır.
Arayüz dili
Open Server Panel kullanıcı arayüzünün dili.

Yerelleştirme dosyası yoksa veya hatalar içeriyorsa İngilizce dil kullanılacaktır.
API alan adı
API ve web arayüzü için yerel alan adı (geliştirme aşamasında)

Öneri: VPN veya proxy kullanılıyorsa, bu alan adını istisnalara ekleyin.
API IP adresi
API ve web arayüzü için IPv4 adresi (geliştirme aşamasında).

Öneri: VPN veya proxy kullanılıyorsa, bu IP adresini istisnalara ekleyin.
API portu
API ve web arayüzü için kullanılan port (geliştirme aşamasında). Belirtilen port başka bir uygulama tarafından zaten kullanılıyorsa Open Server Panel başlatılamaz.
Windows Terminal kullan
Standart komut arayüzü yerine Windows Terminal kullanımını etkinleştir.

Gereksinimler: Windows Terminal sistemde kurulu olmalı ve PATH ortam değişkenine eklenmiş olmalıdır.

cmd.exe olarak Windows Terminal: Windows Terminal, kendisi cmd.exe'nin yerini alabilir ve Windows'un yeni sürümlerinde %COMSPEC% ortam değişkenine yazılabilir. Durum böyleyse, bu seçeneği açık bırakın.

Windows Terminal'in yeni örnekleri: Windows Terminal sekmeler yerine yeni pencereler açıyorsa şu şekilde yapılandırın: Ayarlar→Başlatma→Yeni örnek davranışı→Son kullanılan pencereye ekle.
Kısa proje başlığı
Bu seçenek etkinleştirildiğinde, terminal penceresinin başlığında ortamın ayrıntılı açıklaması yerine yalnızca projenin adı görüntülenecektir.
Sistem ortamını proje ortamına dahil et
Proje ayarlarında belirtilmemiş olsa bile terminalde sistem (System) ortamını kullan. Sistem ortamı, sistemde yüklü programların (örneğin, git.exe veya ssh.exe) kullanılmasını sağlar.

Bu seçeneği yalnızca sistem yazılımlarıyla çakışmalar oluştuğunda devre dışı bırakın.
ANSI desteği
Terminalde renkleri yönetmek için ANSI kod desteğini etkinleştir.

"Otomatik" modu (varsayılan):
- Düzeltme yalnızca Windows 10 sürüm 1903 dahil olmak üzere bu sürüme kadar uygulanır. Daha yeni Windows sürümlerinde ANSI kod desteği zaten yerleşiktir.
- Düzeltme, varsayılan olarak ANSI destekleyen terminaller için uygulanmaz (örneğin, Windows Terminal).
Projeleri aramak için dizinler
Open Server Panel'in projeleri arayacağı dizinlerin listesi. Yolları noktalı virgül (;) ile ayırın.

İstisnalar: node_modules ve vendor alt dizinleri yok sayılır.
Derinlik
Projeleri ararken dizinlerin maksimum iç içe olma derinliği.

Bu değerin artırılması, belirtilen dizinlerde çok sayıda alt dizin bulunuyorsa Open Server Panel'in başlatılmasını yavaşlatabilir.
Maksimum günlük dosyası boyutu
Günlük dosyasının megabayt cinsinden maksimum boyutu. Belirtilen değer aşıldığında, günlük dosyası programın bir sonraki başlatılışında yeniden oluşturulacaktır.

Program her başlatıldığında günlükleri temizlemek için değeri 0 olarak ayarlayın.

Günlük temizlemeyi tamamen devre dışı bırakmak için değeri 100 MB olarak ayarlayın.
