Menü ayarları

Görünüm teması
Menü simgeleri için görünüm teması.
Yazı tipi boyutu
Piksel cinsinden menü yazı tipi boyutu. Seçenek, menü yazı tipi boyutunu sistem ayarlarından bağımsız olarak belirlemenize olanak tanır.

Yazı tipi boyutu kontrolü özelliğini devre dışı bırakmak için kaydırıcıyı minimum 12px değerine ayarlayın (sistem boyutu kullanılacaktır).
Bildirim alanında simgeyi göster
Program simgesini Windows bildirim alanında göster.

Devre dışı bırakma: Bu seçeneği, Windows kullanıcı oturumu gerektirmeyen bir otomatik başlatma türü kullanıyorsanız devre dışı bırakın (Windows Görev Zamanlayıcı→Bilgisayar açılışında başlat).
Menü öğeleri için simgeleri göster
Program menüsünde simgeleri göster. Sistem çizimi etkinse simgeler görüntülenmez.
Sistem çizimini etkinleştir
Bu seçeneği yalnızca ekran erişim programlarıyla (ekran okuyucularla) uyumluluğu sağlamak gerektiğinde etkinleştirin.

Dikkat! Sistem çizimi etkinse menüde simgeler görüntülenmez.
Dikey ayırıcıyı göster
Bu seçenek etkinleştirildiğinde program menüsündeki simgeler dikey bir ayırıcıyla ayrılacaktır.
Tek öğeden oluşan listeleri gruplandırma
Yalnızca bir öğe içeren listeleri gruplandırma.
Projeler: göster
Proje yönetimi menüsünü göster.
Projeler: gruplandır
Projeleri menüde alan adına göre grupla.
Projeler: iç içe menü
Projeler menüsünü ayrı bir alt menüde göster.
Projeler: ayırıcıyı göster
Projeler menüsünden sonra ayırma çizgisini göster.

Modüller: ayırıcıyı göster
Modüller menüsünden sonra ayırma çizgisini göster.
