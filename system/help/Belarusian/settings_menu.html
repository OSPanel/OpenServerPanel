Налады меню

Тэма афармлення
Тэма афармлення для іконак меню.
Памер шрыфту
Памер шрыфту меню ў пікселях. Опцыя дазваляе задаць памер шрыфту меню незалежна ад сістэмных наладаў.

Усталюйце паўзунок у мінімальнае значэнне 12px для адключэння функцыі кантролю памеру шрыфту (будзе выкарыстаны сістэмны памер).
Паказваць значок у вобласці апавяшчэнняў
Паказваць значок праграмы ў вобласці апавяшчэнняў Windows.

Адключэнне: Адключыце гэтую опцыю, калі вы запускаеце Open Server Panel у асяроддзі Windows Server Core або выкарыстоўваеце тып аўтазапуску, які не патрабуе ўваходу карыстальніка Windows (Планіроўшчык заданняў Windows→Запуск пры загрузцы кампутара).
Паказваць значкі для пунктаў меню
Паказваць значкі ў меню праграмы. Значкі не адлюстроўваюцца калі ўключана сістэмнае адмаляванне.
Уключыць сістэмнае адмаляванне
Уключайце дадзеную опцыю толькі пры неабходнасці забеспячэння сумяшчальнасці з праграмамі экраннага доступу (скрын-рыдарамі).
Паказваць вертыкальны падзяляльнік
Пры ўключэнні дадзенай опцыі іконкі ў меню праграмы будуць аддзелены вертыкальным падзяляльнікам.
Не групаваць спісы з аднаго элемента
Не групаваць спісы, якія змяшчаюць толькі адзін элемент.
Дадаткі: паказваць
Паказваць меню дадаткаў.
Дадаткі: групаваць
Групаваць дадаткі ў меню.
Дадаткі: укладзенае меню
Паказваць меню дадаткаў у асобным падменю.
Дадаткі: паказваць падзяляльнік
Паказваць падзяляльную лінію пасля меню дадаткаў.
Модулі: паказваць
Паказваць меню кіравання модулямі.
Модулі: групаваць
Групаваць модулі ў меню.
Модулі: укладзенае меню
Паказваць меню модуляў у асобным падменю.
Модулі: паказваць падзяляльнік
Паказваць падзяляльную лінію пасля меню модуляў.
Праекты: паказваць
Паказваць меню кіравання праектамі.
Праекты: групаваць
Групаваць праекты па даменнай зоне ў меню.
Праекты: укладзенае меню
Паказваць меню праектаў у асобным падменю.
Праекты: паказваць падзяляльнік
Паказваць падзяляльную лінію пасля меню праектаў.
