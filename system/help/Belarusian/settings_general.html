Налады праграмы

Запускаць разам з Windows
Уключыць аўтазапуск Open Server Panel пры загрузцы аперацыйнай сістэмы.
Затрымка
Затрымка запуску праграмы (у секундах, ад 0 да 60).

Дазваляе адкласці старт праграмы, каб паменшыць нагрузку на сістэму пры запуску. Гэта асабліва карысна, калі трэба дачакацца поўнай ініцыялізацыі старонніх сэрвісаў ці сеткавых інтэрфейсаў.
Правяраць наяўнасць новых версій
Уключыць праверку абнаўленняў Open Server Panel (патрабуецца падключэнне да Інтэрнэту).
Уключыць планавальнік заданняў
Актываваць убудаваны планавальнік заданняў. Калі параметр адключаны, ніякія запланаваныя заданні не будуць выконвацца, незалежна ад іх статусу.
Выкарыстоўваць файл HOSTS
Уключыць запіс дамэнных імёнаў у файл HOSTS.

Рэкамендацыі пры абмежаваным доступе да файла HOSTS у арганізацыі:

1. Наладзьце ўсе неабходныя модулі і праекты.
2. Звярніцеся да сістэмнага адміністратара для разблакіроўкі HOSTS і фіксацыі яго стану.
3. Пасля фіксацыі зменаў адміністратарам можна адключыць гэтую опцыю.

Важна: Не адключайце гэты параметр, калі не ўпэўнены ў наступствах!
Запускаць модулі з профілем праекта
Запускаць модулі з адначасовай актывацыяй профілю, які супадае з імем праекта.

Выкарыстоўваецца пры выбары пункта меню "Уключыць модулі праекта", каб аўтаматычна актываваць профіль з тым жа імем, што і ў бягучага праекта, калі такі існуе.
Мова інтэрфейсу
Мова карыстальніцкага інтэрфейсу Open Server Panel.

Калі файл лакалізацыі адсутнічае або ўтрымлівае памылкі, будзе выкарыстоўвацца англійская мова.
Дамэн API
Лакальны дамэн для API і вэб-інтэрфейсу (у распрацоўцы)

Рэкамендацыя: Калі выкарыстоўваецца VPN або проксі, дадайце гэты дамэн у выключэнні.
IP-адрас API
IPv4-адрас для API і вэб-інтэрфейсу (у распрацоўцы).

Рэкамендацыя: Калі выкарыстоўваецца VPN або проксі, дадайце гэты IP-адрас у выключэнні.
Порт API
Порт, які выкарыстоўваецца для API і вэб-інтэрфейсу (у распрацоўцы). Open Server Panel не зможа запусціцца, калі ўказаны порт ужо выкарыстоўваецца іншай праграмай.
Выкарыстоўваць Windows Terminal
Уключыць выкарыстанне Windows Terminal замест стандартнага каманднага інтэрфейсу.

Патрабаванні: Windows Terminal павінен быць усталяваны ў сістэме і прапісаны ў пераменнай асяроддзя PATH.

Windows Terminal як cmd.exe: Windows Terminal можа замяняць сабой cmd.exe і быць прапісаным у пераменнай асяроддзя %COMSPEC% у новых версіях Windows. Калі гэта так, пакіньце гэтую опцыю ўключанай.

Новыя экзэмпляры Windows Terminal: Калі Windows Terminal адкрывае новыя вокны замест укладак, наладзьце яго так: Параметры→Запуск→Паводзіны новага экзэмпляра→Далучаць да апошняга выкарыстанага акна.
Кароткі загаловак праекта
Пры актывацыі гэтай опцыі ў загалоўку акна тэрмінала будзе адлюстроўвацца толькі імя праекта замест падрабязнага апісання.
Уключаць сістэмнае асяроддзе ў акружэнне праекта
Выкарыстоўваць асяроддзе сістэмы (System) у тэрмінале, нават калі яно не зададзена ў наладах праекта. Сістэмнае асяроддзе дазваляе выкарыстоўваць праграмы, усталяваныя ў сістэме (напрыклад, git.exe або ssh.exe).

Адключайце гэтую опцыю толькі пры ўзнікненні канфліктаў з сістэмным ПЗ.
Падтрымка ANSI
Уключыць падтрымку ANSI-кодаў для кіравання колерамі ў тэрмінале.

Рэжым "Аўтаматычна" (па змаўчанні):
- Выпраўленне прымяняецца толькі да Windows 7, 8 і Windows 10 (да версіі 1903 уключна). У больш новых версіях Windows падтрымка ANSI-кодаў ужо ўбудавана.
- Выпраўленне не прымяняецца для тэрміналаў, якія падтрымліваюць ANSI па змаўчанні (напрыклад, Windows Terminal).
Каталогі для пошуку праектаў
Спіс дырэкторый, у якіх Open Server Panel будзе шукаць праекты. Раздзяляйце шляхі кропкай з коскай (;).

Выключэнні: Падкаталогі node_modules і vendor ігнаруюцца.
Глыбіня
Максімальная глыбіня ўкладанасці каталогаў пры пошуку праектаў.

Павелічэнне гэтага значэння можа запаволіць запуск Open Server Panel, калі ва ўказаных каталогах утрымліваецца вялікая колькасць падкаталогаў.
Максімальны памер файла журнала
Максімальны памер файла журнала ў мегабайтах. Пры перавышэнні паказанага значэння лог-файл будзе перастворанны пры наступным запуску праграмы.

Усталюйце значэнне 0, каб ачышчаць лог-файлы пры кожным запуску праграмы.

Усталюйце значэнне 100 МБ, каб цалкам адключыць ачыстку лог-файлаў.
