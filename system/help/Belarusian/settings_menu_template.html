Стварэнне ўласных пунктаў меню

  1. Дадайце новую секцыю з унікальным ідэнтыфікатарам [ID]
  2. Размясціце секцыі ў патрэбным парадку — гэта вызначыць парадак пунктаў у меню
  3. Захавайце змены і перазапусціце Open Server Panel для прымянення змен

Важная інфармацыя

Пры стварэнні ўласных пунктаў меню сачыце за тым, каб ідэнтыфікатары секцый не паўтараліся. Гэта можа прывесці да канфліктаў у працы меню.

Налады пунктаў меню

Парадак сартавання: Пункты меню сартыруюцца ў тым жа парадку, у якім размешчаны адпаведныя секцыі ў шаблоне.

caption Загаловак пункта меню. Падтрымлівае моўныя канстанты ў фармаце {lang_xxx}.

Па змоўчанні: не зададзена
category

Вызначае размяшчэнне пункта меню ў іерархіі. Падтрымлівае адзін узровень укладання (напрыклад, "Мае Закладкі\Праца").

Спецыяльныя катэгорыі:

  • projects, modules, addons - дадае пункт у адпаведнае меню дзеянняў
  • projects\<імя_дамена>, modules\<імя_модуля>, addons\<імя_дапаўнення> - дадае пункт для канкрэтнага элемента

Калі катэгорыя не ўказана, пункт ствараецца ў каранёвым меню.

Па змоўчанні: не зададзена
command Каманда для выканання пры актывацыі пункта меню. Пункты без каманды ігнаруюцца.

Па змоўчанні: не зададзена
enabled Уключае/адключае адлюстраванне пункта меню.

Па змоўчанні: on | Значэнні: on, off
hide Кіруе бачнасцю акна выкліканай праграмы. Не ўплывае на доччыны працэсы.

Па змоўчанні: off | Значэнні: on, off
hr_after Дадае гарызантальны падзельнік пасля пункта меню.

Па змоўчанні: off | Значэнні: on, off
hr_before Дадае гарызантальны падзельнік перад пунктам меню.

Па змоўчанні: off | Значэнні: on, off
icon Іконка з набору Font Awesome Free (Solid/Regular/Brands).

Па змоўчанні: не зададзена
need_alias Адлюстроўвае пункт меню толькі для даменнага псеўданіма. У шаблоне меню можа быць толькі адзін пункт з need_alias=on!
Прымянімa для катэгорый: projects

Па змоўчанні: не зададзена | Значэнні: on, off
need_category

Абмяжоўвае адлюстраванне пункта меню модулямі/дапаўненнямі пэўнай катэгорыі.

Падтрымліваемыя фарматы:

  • modules, addons
  • modules\<імя_модуля>, addons\<імя_дапаўнення>
Па змоўчанні: не зададзена
need_module_shell Адлюстроўвае пункт меню ў залежнасці ад наяўнасці shell/cli у бацькоўскага модуля.
Прымянімa для катэгорый: modules, modules\<імя_модуля>

Па змоўчанні: не зададзена | Значэнні: on, off
need_state Адлюстроўвае пункт меню ў залежнасці ад стану бацькоўскага модуля.
Прымянімa для катэгорый: modules, modules\<імя_модуля>

Па змоўчанні: не зададзена | Значэнні: on, off
need_start_cmd Адлюстроўвае пункт меню пры наяўнасці каманды запуску ў наладах праекта.
Прымянімa для катэгорый: projects, projects\<імя_дамена>

Па змоўчанні: не зададзена | Значэнні: on, off
need_use_wt Адлюстроўвае пункт меню ў залежнасці ад налады выкарыстання Windows Terminal у Open Server Panel.

Па змоўчанні: не зададзена | Значэнні: on, off
work_directory Працоўная дырэкторыя для выканання каманды. Можа змяняцца падчас выканання каманд.

Па змоўчанні: {root_dir}

Шаблонныя зменныя

У параметрах "command" і "work_directory" можна выкарыстоўваць наступныя шаблонныя зменныя:

Агульныя зменныя

Зменная Апісанне
{date_time} Бягучая дата/час (зменная даступна толькі для параметра "command")
{root_dir} Каранёвы каталог Open Server Panel (поўны шлях)
{root_drive} Диск каранёвага каталога
{root_path} Шлях да каранёвага каталога Open Server Panel
{web_panel_url} URL-адрас вэб-інтэрфейсу

Асаблівыя зменныя (толькі для projects і projects\<імя_дамена>)

Зменная Апісанне
{base_dir} Базавы каталог праекта
{host} Імя дамена (Punycode)
{host_decoded} Бачнае імя дамена (без Punycode)
{host_scheme} Схема запыту да праекта ("http" або "https", залежыць ад параметра TLS у наладах праекта)
{http_port} Порт запыту да праекта па пратаколе HTTP
{https_port} Порт запыту да праекта па пратаколе HTTPS
{menu_caption} Загаловак пункта меню (толькі для катэгорыі projects з need_alias=ON)
{http_engine} Рухавік HTTP
{node_engine} Рухавік Node.js
{php_engine} Рухавік PHP
{project_root} Каранёвы каталог праекта
{base_url} URL праекта
{web_root} Публічны каталог праекта
{scheme_port} Порт запыту да праекта (":{http_port}" або ":{https_port}", залежыць ад параметра TLS у наладах праекта). Калі {http_port} або {https_port} мае стандартнае значэнне 80 або 443, то {scheme_port} будзе пустым.
{app_start_command} Каманда запуску прыкладання праекта (калі настроена)
{terminal_codepage} Кадаванне кансолі

Асаблівыя зменныя (толькі для addons і addons\<імя_дапаўнення>)

Зменная Апісанне
{addon_name} Імя дапаўнення
{terminal_codepage} Кадаванне кансолі

Асаблівыя зменныя (толькі для modules і modules\<імя_модуля>)

Зменная Апісанне
{ip} IP-адрас модуля
{log_level} Узровень журналявання памылак
{module_name} Імя модуля
{port} Порт модуля
{profile_name} Імя бягучага профілю наладаў модуля
{query_log_level} Узровень журналявання запытаў
{shell_command} Каманда запуску shell/cli абалонкі модуля (калі настроена)
{terminal_codepage} Кадаванне кансолі
{time_zone} Часавы пояс

Асаблівыя значэнні каманд

Каманда Апісанне
command_open_logs_viewer Адкрыць акно прагляду журналаў
command_open_idn_converter Адкрыць IDN-канвертар
command_open_options Адкрыць акно наладаў праграмы

Акрамя шаблонных зменных, можна выкарыстоўваць любыя зменныя асяроддзя Windows, напрыклад: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% і г.д.

Прыклад выкарыстання

[bookmark_1]

caption  = Google
category = Мае Закладкі\Пошукавыя сістэмы
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Опцыі CMD.EXE

  • /c: Выканаць каманду і закрыць тэрмінал.
  • /k: Выканаць каманду і пакінуць тэрмінал адкрытым.
