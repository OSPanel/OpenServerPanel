Стварэнне ўласных пунктаў меню

  1. Дадайце новую секцыю з унікальным ідэнтыфікатарам [ID]
  2. Размясціце секцыі ў жаданым парадку — гэта вызначыць парадак пунктаў у меню
  3. Захавайце змены і перазапусціце Open Server Panel для прымянення змен

Важная інфармацыя

Пры стварэнні ўласных пунктаў меню сачыце за тым, каб ідэнтыфікатары секцый не паўтараліся. Гэта можа прывесці да канфліктаў у працы меню.

Налады пунктаў меню

Парадак сартавання: Пункты меню сартуюцца ў тым жа парадку, у якім размешчаны адпаведныя секцыі ў шаблоне.

caption Загаловак пункта меню. Падтрымлівае моўныя канстанты ў фармаце {lang_xxx}.

Па змаўчанні: не зададзена
category

Вызначае размяшчэнне пункта меню ў іерархіі. Падтрымлівае адзін узровень укладанасці (напрыклад, "Мае Закладкі\Праца").

Спецыяльныя катэгорыі:

  • projects, modules, addons - дадае пункт у адпаведнае меню дзеянняў
  • projects\<імя_дамена>, modules\<імя_модуля>, addons\<імя_дадатку> - дадае пункт для канкрэтнага элемента

Калі катэгорыя не ўказана, пункт ствараецца ў каранёвым меню.

Па змаўчанні: не зададзена
command Каманда для выканання пры актывацыі пункта меню. Пункты без каманды ігнаруюцца.

Па змаўчанні: не зададзена
enabled Уключае/адключае адлюстраванне пункта меню.

Па змаўчанні: on | Значэнні: on, off
hide Кіруе бачнасцю акна выклікаемага дадатку. Не ўплывае на даччыныя працэсы.

Па змаўчанні: off | Значэнні: on, off
hr_after Дадае гарызантальны падзяляльнік пасля пункта меню.

Па змаўчанні: off | Значэнні: on, off
hr_before Дадае гарызантальны падзяляльнік перад пунктам меню.

Па змаўчанні: off | Значэнні: on, off
icon Іконка з набору Font Awesome Free (Solid/Regular/Brands).

Па змаўчанні: не зададзена
need_alias Адлюстроўвае пункт меню толькі для дамэннага псеўданіма. У шаблоне меню можа быць толькі адзін пункт з need_alias=on!
Ужывальна для катэгорый: projects

Па змаўчанні: не зададзена | Значэнні: on, off
need_category

Абмяжоўвае адлюстраванне пункта меню модулямі/дадаткамі пэўнай катэгорыі.

Падтрымліваемыя фарматы:

  • modules, addons
  • modules\<імя_модуля>, addons\<імя_дадатку>
Па змаўчанні: не зададзена
need_module_shell Адлюстроўвае пункт меню ў залежнасці ад наяўнасці shell/cli у бацькоўскага модуля.
Ужываецца для катэгорый: modules, modules\<імя_модуля>

Па змаўчанні: не зададзена | Значэнні: on, off
need_state Адлюстроўвае пункт меню ў залежнасці ад стану бацькоўскага модуля.
Ужываецца для катэгорый: modules, modules\<імя_модуля>

Па змаўчанні: не зададзена | Значэнні: on, off
need_start_cmd Адлюстроўвае пункт меню пры наяўнасці каманды запуску ў наладах праекта.
Ужываецца для катэгорый: projects, projects\<імя_дамена>

Па змаўчанні: не зададзена | Значэнні: on, off
need_use_wt Адлюстроўвае пункт меню ў залежнасці ад налады выкарыстання Windows Terminal у Open Server Panel.

Па змаўчанні: не зададзена | Значэнні: on, off
work_directory Працоўная дырэкторыя для выканання каманды. Можа змяняцца падчас выканання каманд.

Па змаўчанні: {root_dir}

Шаблонныя зменныя

У параметрах "command" і "work_directory" можна выкарыстоўваць наступныя шаблонныя зменныя:

Агульныя зменныя

Зменная Апісанне
{root_dir} Каранёвы каталог Open Server Panel (поўны шлях)
{root_drive} Дыск каранёвага каталога
{root_path} Шлях да каранёвага каталога Open Server Panel
{web_panel_url} URL-адрас вэб-інтэрфейса

Асаблівыя зменныя (толькі для projects і projects\<імя_дамена>)

Зменная Апісанне
{base_dir} Базавы каталог праекта
{host} Імя дамена (Punycode)
{host_decoded} Бачнае імя дамена (без Punycode)
{host_scheme} Схема запыту да праекта ("http" ці "https", залежыць ад параметра SSL у наладах праекта)
{menu_caption} Загаловак пункта меню (толькі для катэгорыі projects з need_alias=ON)
{nginx_engine} Рухавік Nginx
{node_engine} Рухавік Node.js
{php_engine} Рухавік PHP
{project_dir} Каранёвы каталог праекта
{project_url} URL праекта
{public_dir} Публічны каталог праекта
{start_command} Каманда запуску праекта (калі наладжана)
{terminal_codepage} Кадыроўка кансолі

Асаблівыя зменныя (толькі для addons і addons\<імя_дадатку>)

Зменная Апісанне
{addon_name} Імя дадатку
{terminal_codepage} Кадыроўка кансолі

Асаблівыя зменныя (толькі для modules і modules\<імя_модуля>)

Зменная Апісанне
{ip} IP-адрас модуля
{log_level} Узровень журналявання памылак
{module_name} Імя модуля
{port} Порт модуля
{profile_name} Імя бягучага профілю наладаў модуля
{query_log_level} Узровень журналявання запытаў
{shell_command} Каманда запуску shell/cli абалонкі модуля (калі наладжана)
{terminal_codepage} Кадыроўка кансолі
{time_zone} Часавы пояс

Асаблівыя значэнні каманд

Каманда Апісанне
command_open_logs_viewer Адкрыць акно прагляду журналаў
command_open_idn_converter Адкрыць IDN-канвертар
command_open_options Адкрыць акно наладаў праграмы

Акрамя шаблонных зменных, можна выкарыстоўваць любыя зменныя асяроддзя Windows, напрыклад: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH% і г.д.

Прыклады выкарыстання

[21]

caption  = Адкрыць у PhpStorm
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = Мае Закладкі\Пошукавыя сістэмы
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Опцыі `cmd.exe`

  • /c: Выканаць каманду і закрыць тэрмінал.
  • /k: Выканаць каманду і пакінуць тэрмінал адкрытым.
