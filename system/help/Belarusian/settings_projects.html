Глабальныя налады праектаў

Параметры, зададзеныя ў гэтым раздзеле, выкарыстоўваюцца ў выпадку, калі ў наладах праекта не ўказаныя іншыя значэнні.

HTTP
Вызначае выкарыстоўваны модуль вэб-сервера для праектаў.
NODE
Паказвае рухавік Node.js для запуску Node.js-прыкладанняў.

Усталяванне Node.js: Папярэдне ўсталюйце патрэбную версію Node.js з дапамогай каманды osp node <latest|lts|номер>.
PHP
Вызначае выкарыстоўваны модуль PHP для апрацоўкі PHP-файлаў.
Уключыць
Вызначае стан праекта па змаўчанні (уключаны або выключаны).
Кадыроўка тэрмінала
Кадыроўка тэрмінала пры працы з асяроддзем праекта.

Спецыяльныя значэнні:
- system: Выкарыстоўваецца сістэмная кадыроўка.

Важна: Калі значэнне не зададзена, пры фарміраванні выніковага асяроддзя праекта кадыроўка тэрмінала будзе ўсталявана апошнім падключаным асяроддзем, у якім яна зададзена, напрыклад, асяроддзем модуля PHP.
IP
Задае IP-адрас(ы), які выкарыстоўваецца ўсімі праектамі без індывідуальных налад.

Абмежаванне: Праекты, што выкарыстоўваюць адзін і той жа IP-адрас, павінны працаваць на адной версіі PHP.

Падтрымка некалькіх IP: Можна ўказаць некалькі IP-адрасоў праз прабел, уключаючы IPv6. У файле HOSTS даменам будзе прызначаны першы ўказаны IP.

Аўтаматычнае прызначэнне: Калі пакінуць поле пустым, IP-адрас будзе прызначацца аўтаматычна.

Рэкамендацыі:
  • Аўтаматычнае кіраванне IP-адрасамі рэкамендуецца большасці карыстальнікаў.
  • Ручное задання IP-адраса варта выкарыстоўваць толькі пры спецыфічных патрабаваннях сеткавай канфігурацыі.
HTTP
Вызначае порт для злучэнняў па HTTP.
HTTPS
Вызначае порт для злучэнняў па HTTPS.
TLS
Уключае або выключае падтрымку TLS.
Файл сертыфіката
Паказвае шлях да файла TLS-сертыфіката. Можна выкарыстоўваць шаблонныя зменныя.

Дапушчальныя сімвалы: A-Za-z0-9-+_.\:

Рэкамендацыя: Пакіньце поле пустым для аўтаматычнай генерацыі сертыфікатаў.
Файл ключа
Паказвае шлях да файла TLS-ключа. Можна выкарыстоўваць шаблонныя зменныя.

Дапушчальныя сімвалы: A-Za-z0-9-+_.\:

Рэкамендацыя: Пакіньце поле пустым для аўтаматычнай генерацыі ключа.
IP-адрас (backend)
Паказвае IP-адрас, па якім ажыццяўляецца падключэнне да сервернай часткі (Backend).
Порт (backend)
Вызначае нумар порта для падключэння да сервернай часткі (Backend).
Уключыць (backend)
Дазваляе аўтаматычна накіроўваць увесь уваходны трафік (HTTP і HTTPS) праекта на серверную частку (Backend). Карысна для тэставання або распрацоўкі, калі фронтенд і бэкенд падзелены.
Каталог праекта
Паказвае каранёвы каталог праекта. Пераход у гэты каталог ажыццяўляецца па камандзе osp project <DOMAIN> адначасова з актывацыяй асяроддзя праекта. Можна выкарыстоўваць шаблонныя зменныя.

Дазволеныя сімвалы: A-Za-z0-9-+_.\:
Публічны каталог
Вызначае публічны каталог праекта. Можна выкарыстоўваць шаблонныя зменныя.

Дазволеныя сімвалы: A-Za-z0-9-+_.\:
Псеўданімы
Паказвае дадатковыя даменныя імёны (аліасы) для праекта (праз прабел). Можна выкарыстоўваць шаблонныя зменныя.

Абмежаванне: Сімвал "*" не падтрымліваецца ў Windows файлам HOSTS і патрабуе наладкі DNS.
Асяроддзе праекта
Пералік дапаўненняў і модуляў (праз прабел), што фарміруюць асяроддзе праекта.

HTTP, NODE і PHP: Асяроддзі гэтых рухавікоў падключаюцца заўсёды (калі зададзены для дамена) і не патрабуюць указання ў гэтым параметры.
Каманда запуску праекта
Вызначае каманду для запуску праекта (напрыклад, nodemon app.js). Можна выкарыстоўваць шаблонныя зменныя.
URL праекта
URL, які выкарыстоўваецца пры адкрыцці праекта Меню→Праект→Адкрыць у браўзеры, а таксама пры адкрыцці даменных псеўданімаў праекта (аліасаў). Можна выкарыстоўваць шаблонныя зменныя.

Выкарыстанне: Можна задаць URL панэлі адміністравання CMS.

Шаблонныя зменныя

Зменная Апісанне
{backend_ip} IP-адрас падключэння да сервернай часткі (Backend)
{backend_port} Порт падключэння да сервернай часткі (Backend)
{base_dir} Каранёвы каталог праекта (дзе знаходзіцца каталог .osp)
{date_time} Бягучая дата/час (зменная даступная толькі для каманды запуску прыкладання праекта)
{host} Імя дамена (для інтэрнацыяналізаваных даменаў выкарыстоўваецца Punycode)
{host_decoded} Бачнае імя дамена (без Punycode)
{host_scheme} Схема запыту да праекта ("http" або "https", залежыць ад параметра TLS у наладах праекта)
{http_port} Порт запыту да праекта па пратаколе HTTP
{https_port} Порт запыту да праекта па пратаколе HTTPS
{http_engine} Рухавік HTTP
{node_engine} Рухавік NODE
{php_engine} Рухавік PHP
{project_root} Каранёвы каталог праекта
{web_root} Публічны каталог праекта
{scheme_port} Порт запыту да праекта (":{http_port}" або ":{https_port}", залежыць ад параметра TLS у наладах праекта).

Калі {http_port} або {https_port} мае стандартнае значэнне 80 або 443, то {scheme_port} будзе пустым.
{root_dir} Каранёвы каталог Open Server Panel (поўны шлях)
{root_drive} Дыск каранёвага каталога
{root_path} Шлях да каранёвага каталога Open Server Panel
{terminal_codepage} Кадыроўка кансолі
