Глабальныя налады праектаў

Параметры, зададзеныя ў дадзеным раздзеле, выкарыстоўваюцца ў выпадку, калі ў наладах праекта не ўказаны іншыя значэнні.

Уключыць
Вызначае стан праекта па змаўчанні (уключаны ці выключаны).
Кадыроўка тэрмінала
Кадыроўка тэрмінала пры працы з асяроддзем праекта.

Спецыяльныя значэнні:
- system: Выкарыстоўваецца сістэмная кадыроўка.
- (пустое значэнне): Кадыроўка тэрмінала застаецца нязменнай.

Важна: Калі значэнне не зададзена, пры фарміраванні канчатковага асяроддзя праекта кадыроўка тэрмінала будзе ўстаноўлена апошнім падлучаным асяроддзем, у якім яна зададзена, напрыклад, асяроддзем модуля PHP.
Nginx
Вызначае выкарыстоўваемую версію вэб-сервера Nginx для праектаў.
Node
Указвае рухавік Node.js для запуску Node.js-дадаткаў.

Усталёўка Node.js: Папярэдне ўсталюйце патрэбную версію Node.js з дапамогай дадатку NVM.
PHP
Вызначае выкарыстоўваемы рухавік PHP для апрацоўкі PHP-файлаў.

Важна: Модулі PHP без прэфікса FCGI з'яўляюцца інтэграванымі модулямі Apache+PHP.
IP
Задае IP-адрас(ы), выкарыстоўваемы ўсімі праектамі без індывідуальных наладаў.

Абмежаванне: Праекты, якія выкарыстоўваюць адзін і той жа IP-адрас, павінны працаваць на адной версіі PHP.

Падтрымка некалькіх IP: Можна ўказаць некалькі IP-адрасоў праз прагал, уключаючы IPv6. У файле HOSTS даменам будзе прызначаны першы ўказаны IP.

Аўтаматычнае прызначэнне: Калі пакінуць поле пустым, IP-адрас будзе прызначацца аўтаматычна.

Рэкамендацыі:
  • Аўтаматычнае кіраванне IP-адрасамі рэкамендуецца большасці карыстальнікаў.
  • Ручное заданне IP-адраса варта выкарыстоўваць толькі пры спецыфічных патрабаваннях сеткавай канфігурацыі.
HTTP
Вызначае порт для злучэнняў па HTTP.
HTTPS
Вызначае порт для злучэнняў па HTTPS.
SSL
Уключае або адключае падтрымку SSL для праектаў без індывідуальных наладаў.
Файл сертыфіката
Указвае шлях да файла SSL-сертыфіката. Можна выкарыстоўваць шаблонныя зменныя.

Дапушчальныя сімвалы: A-Za-z0-9-+_.\:

Рэкамендацыя: Пакіньце поле пустым для аўтаматычнай генерацыі сертыфікатаў.
Файл ключа
Указвае шлях да файла SSL-ключа. Можна выкарыстоўваць шаблонныя зменныя.

Дапушчальныя сімвалы: A-Za-z0-9-+_.\:

Рэкамендацыя: Пакіньце поле пустым для аўтаматычнай генерацыі ключа.
Каталог праекта
Указвае каранёвы каталог праекта. Пераход у гэты каталог ажыццяўляецца па камандзе osp project <DOMAIN> адначасова з актывацыяй асяроддзя праекта. Можна выкарыстоўваць шаблонныя зменныя.

Дазволеныя сімвалы: A-Za-z0-9-+_.\:
Публічны каталог
Вызначае публічны каталог праекта. Можна выкарыстоўваць шаблонныя зменныя.

Дазволеныя сімвалы: A-Za-z0-9-+_.\:
Псеўданімы
Указвае дадатковыя даменныя імёны (аліасы) для праекта (праз прагал). Можна выкарыстоўваць шаблонныя зменныя.

Паддамены: Калі псеўданім не змяшчае кропку, ён разглядаецца як паддамен (напрыклад, "www" -> "www.test.local").

Абмежаванне: Сімвал "*" не падтрымліваецца ў Windows файлам HOSTS і патрабуе наладкі DNS.
Асяроддзе праекта
Пералік дадаткаў і модуляў (праз прагал), якія фарміруюць асяроддзе праекта.

Модулі PHP/Nginx/Node.js: Асяроддзі гэтых модуляў падключаюцца заўсёды (калі зададзены для дамена) і не патрабуюць указання ў гэтым параметры.
Каманда запуску праекта
Вызначае каманду для запуску праекта (напрыклад, nodemon app.js). Можна выкарыстоўваць шаблонныя зменныя.
URL праекта
URL, які адкрываецца пры выбары Адкрыць праект у браўзеры ў Open Server Panel. Можна выкарыстоўваць шаблонныя зменныя.

Прымяненне: Можна задаць URL панэлі адміністравання CMS.

Шаблонныя зменныя

Зменная Апісанне
{base_dir} Каранёвы каталог праекта (дзе знаходзіцца каталог .osp)
{host} Імя дамена (для інтэрнацыяналізаваных даменаў выкарыстоўваецца Punycode)
{host_decoded} Бачнае імя дамена (без Punycode)
{root_dir} Каранёвы каталог Open Server Panel (поўны шлях)
{root_drive} Дыск каранёвага каталога
{root_path} Шлях да каранёвага каталога Open Server Panel
