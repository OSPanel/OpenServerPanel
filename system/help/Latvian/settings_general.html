Programmas iestatījumi

Palaist kopā ar Windows
Ieslēgt Open Server Panel autorunināšanu operētājsistēmas ielādes laikā.
Aizture
Programmas palaišanas aizture (sekundēs, no 0 līdz 60).

Ļauj atlikt lietotnes startu ielādes laikā kopā ar Windows, lai samazinātu kopējo sistēmas noslodzi. Tas ir īpaši noderīgi, ja nepieciešams sagaidīt pilnīgu trešo pušu servisu vai tīkla interfeisu inicializāciju.
Pārbaudīt jaunu versiju esamību
Ieslēgt Open Server Panel atjauninājumu pārbaudi (nepieciešams interneta savienojums).
Ieslēgt uzdevumu plānotāju
Aktivizēt iebūvēto uzdevumu plānotāju. Ja parametrs ir izslēgts, nekādi ieplānotie uzdevumi netiks izpildīti neatkarīgi no to statusa.
Izmantot HOSTS failu
Ieslēgt domēna vārdu ierakstīšanu HOSTS failā.

Ieteikumi situācijās ar ierobežotu piekļuvi HOSTS failam organizācijā:

1. Nokonfigurējiet visus nepieciešamos moduļus un projektus.
2. Vērsieties pie sistēmas administratora, lai atbloķētu HOSTS un fiksētu tā stāvokli.
3. Pēc administratora veiktās fiksācijas šo opciju var izslēgt.

Svarīgi: Neizslēdziet šo parametru, ja neesat pārliecināti par sekām!
Palaist moduļus ar projekta profilu
Palaist moduļus, vienlaicīgi aktivizējot profilu, kas sakrīt ar projekta nosaukumu.

Tiek izmantots, izvēloties izvēlnes punktu «Ieslēgt projekta moduļus», lai automātiski aktivizētu profilu ar tādu pašu nosaukumu kā aktuālajam projektam, ja tāds pastāv.
Neizslēgt slēpto projektu moduļus
Neizslēgt slēpto projektu moduļus, izvēloties izvēlnes punktu «Izslēgt visus moduļus». Ar "slēptiem" tiek saprasti tie projekti, kuriem norādīta kategorija "hidden".

Pēc noklusējuma komanda «Izslēgt visus moduļus» aptur pilnīgi visu moduļu darbību, tostarp tos, kurus izmanto slēptie dienestu projekti (piemēram, PHPMyAdmin). Šī opcija ļauj saglabāt slēpto dienestu projektu darbspēju, neizslēdzot tiem nepieciešamos moduļus, kamēr visi pārējie moduļi tiks izslēgti.
Saskarnes valoda
Open Server Panel lietotāja saskarnes valoda.

Ja lokalizācijas fails nav pieejams vai satur kļūdas, tiks izmantota angļu valoda.
API domēns
Lokālais domēns API un tīmekļa saskarnei (izstrādē)

Ieteikums: Ja tiek izmantots VPN vai starpniekserveris, pievienojiet šo domēnu izņēmumiem.
API IP adrese
IPv4 adrese API un tīmekļa saskarnei (izstrādē).

Ieteikums: Ja tiek izmantots VPN vai starpniekserveris, pievienojiet šo IP adresi izņēmumiem.
API ports
Ports, ko izmanto API un tīmekļa saskarnei (izstrādē). Open Server Panel nevarēs palaisties, ja norādīto portu jau izmanto cita lietotne.
Izmantot Windows Terminal
Ieslēgt Windows Terminal izmantošanu standarta komandrindas interfeisa vietā.

Prasības: Windows Terminal jābūt instalētam sistēmā un norādītam vides mainīgajā PATH.

Windows Terminal kā cmd.exe: Windows Terminal var aizstāt cmd.exe un būt norādīts vides mainīgajā %COMSPEC% jaunākajās Windows versijās. Ja tā ir, atstājiet šo opciju ieslēgtu.

Jauni Windows Terminal eksemplāri: Ja Windows Terminal atver jaunus logus tā vietā, lai atvērtu cilnes, konfigurējiet to: Iestatījumi→Palaišana→Jauna eksemplāra uzvedība→Pievienot pēdējam izmantotajam logam.
Īss projekta virsraksts
Aktivizējot šo opciju, termināla loga virsrakstā tiks rādīts tikai projekta nosaukums, nevis detalizēts vides apraksts.
Iekļaut sistēmas vidi projekta vidē
Izmantot sistēmas (System) vidi terminālī, pat ja tā nav norādīta projekta iestatījumos. Sistēmas vide ļauj izmantot sistēmā instalētās programmas (piemēram, git.exe vai ssh.exe).

Izslēdziet šo opciju tikai tad, ja rodas konflikti ar sistēmas programmatūru.
ANSI atbalsts
Ieslēgt ANSI kodu atbalstu krāsu pārvaldībai terminālī.

Režīms "Automātiski" (pēc noklusējuma):
- Labojums tiek piemērots tikai Windows 10 līdz versijai 1903 ieskaitot. Jaunākās Windows versijās ANSI kodu atbalsts jau ir iebūvēts.
- Labojums netiek piemērots termināļiem, kas pēc noklusējuma atbalsta ANSI (piemēram, Windows Terminal).
Katalogi projektu meklēšanai
Katalogu saraksts, kuros Open Server Panel meklēs projektus. Ceļus atdaliet ar semikolu (;).

Izņēmumi: Apakškatalogi node_modules un vendor tiek ignorēti.
Dziļums
Maksimālais katalogu ligzdotības dziļums, meklējot projektus.

Šīs vērtības palielināšana var palēnināt Open Server Panel palaišanu, ja norādītajos katalogos ir liels skaits apakškatalogu.
Maksimālais žurnāla faila izmērs
Maksimālais žurnāla faila izmērs megabaitos. Pārsniedzot norādīto vērtību, žurnāla fails tiks pārizveidots nākamajā programmas palaišanas reizē.

Iestatiet vērtību 0, lai dzēstu žurnālus katrā programmas palaišanas reizē.

Iestatiet vērtību 100 MB, lai pilnībā atspējotu žurnālu tīrīšanu.
