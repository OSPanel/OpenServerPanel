Globālie projektu iestatījumi

Parametri, kas norādīti šajā sadaļā, tiek izmantoti gadījumā, ja projekta iestatījumos nav norādītas citas vērtības.

HTTP
Nosaka tīmekļa servera moduli, ko izmanto projektiem.
NODE
Norāda Node.js dzinēju Node.js lietotņu palaišanai.

Node.js instalēšana: Iepriekš instalējiet vajadzīgo Node.js versiju ar komandu osp node <latest|lts|номер>.
PHP
Nosaka PHP moduli, kas tiek izmantots PHP failu apstrādei.
Ieslēgt
Nosaka projekta stāvokli pēc noklusējuma (ieslēgts vai izslēgts).
Termināļa kodējums
Termināļa kodējums, strādājot ar projekta vidi.

Īpašas vērtības:
- system: Tiek izmantots sistēmas kodējums.

Svarīgi: Ja vērtība nav norādīta, veidojot projekta galīgo vidi, termināļa kodējumu iestatīs pēdējā pieslēgtā vide, kurā tas ir norādīts, piemēram, PHP moduļa vide.
IP
Nosaka IP adresi(es), ko izmanto visi projekti bez individuāliem iestatījumiem.

Ierobežojums: Projekti, kas izmanto vienu un to pašu IP adresi, ir jādarbojas ar vienu un to pašu PHP versiju.

Vairāku IP atbalsts: Var norādīt vairākas IP adreses, atdalot ar atstarpi, ieskaitot IPv6. Failā HOSTS domēniem tiks piešķirts pirmais norādītais IP.

Automātiska piešķiršana: Ja lauku atstājat tukšu, IP adrese tiks piešķirta automātiski.

Ieteikumi:
  • Automātiska IP adrešu pārvaldība ir ieteicama vairumam lietotāju.
  • Manuālu IP adreses norādīšanu izmantojiet tikai specifiskās tīkla konfigurācijas prasībās.
HTTP
Nosaka portu savienojumiem, izmantojot HTTP.
HTTPS
Nosaka portu savienojumiem, izmantojot HTTPS.
TLS
Ieslēdz vai izslēdz TLS atbalstu.
Sertifikāta fails
Norāda ceļu uz TLS sertifikāta failu. Var izmantot veidnes mainīgos.

Atļautie simboli: A-Za-z0-9-+_.\:

Ieteikums: Atstājiet lauku tukšu, lai sertifikāti tiktu ģenerēti automātiski.
Atslēgas fails
Norāda ceļu uz TLS atslēgas failu. Var izmantot veidnes mainīgos.

Atļautie simboli: A-Za-z0-9-+_.\:

Ieteikums: Atstājiet lauku tukšu, lai atslēga tiktu ģenerēta automātiski.
IP adrese (backend)
Norāda IP adresi, pa kuru tiek veikts pieslēgums servera daļai (Backend).
Ports (backend)
Nosaka porta numuru pieslēgumam servera daļai (Backend).
Ieslēgt (backend)
Ļauj automātiski novirzīt visu ienākošo projekta trafiku (HTTP un HTTPS) uz servera daļu (Backend). Noder testišanai vai izstrādei, kad frontend un backend ir atdalīti.
Projekta katalogs
Norāda projekta saknes katalogu. Pāreja uz šo katalogu tiek veikta ar komandu osp project <DOMAIN> vienlaikus ar projekta vides aktivizāciju. Var izmantot veidnes mainīgos.

Atļautie simboli: A-Za-z0-9-+_.\:
Publiskais katalogs
Nosaka projekta publisko katalogu. Var izmantot veidnes mainīgos.

Atļautie simboli: A-Za-z0-9-+_.\:
Pseidonīmi
Norāda papildu domēna vārdus (aliasus) projektam (caur atstarpi). Var izmantot veidnes mainīgos.

Ierobežojums: Simbolu "*" Windows HOSTS fails neatbalsta, un tas prasa DNS konfigurāciju.
Projekta vide
Papildinājumu un moduļu saraksts (caur atstarpi), kas veido projekta vidi.

HTTP, NODE un PHP: Šo dzinēju vides tiek pieslēgtas vienmēr (ja tās ir norādītas domēnam) un tām nav nepieciešams norādījums šajā parametrā.
Projekta palaišanas komanda
Nosaka komandu projekta palaišanai (piemēram, nodemon app.js). Var izmantot veidnes mainīgos.
Projekta URL
URL, ko izmanto, atverot projektu Izvēlne→Projekts→Atvērt pārlūkā, kā arī atverot projekta domēna pseidonīmus (aliasus). Var izmantot veidnes mainīgos.

Pielietojums: Var norādīt CMS administrēšanas paneļa URL.

Veidnes mainīgie

Mainīgais Apraksts
{backend_ip} IP adrese pieslēgumam servera daļai (Backend)
{backend_port} Ports pieslēgumam servera daļai (Backend)
{base_dir} Projekta saknes katalogs (kur atrodas katalogs .osp)
{date_time} Pašreizējais datums/laiks (mainīgais pieejams tikai projekta lietotnes palaišanas komandai)
{host} Domēna nosaukums (internacionalizētiem domēniem tiek izmantots Punycode)
{host_decoded} Redzamais domēna nosaukums (bez Punycode)
{host_scheme} Pieprasījuma shēma projektam ("http" vai "https", atkarīgs no TLS parametra projekta iestatījumos)
{http_port} Projekta pieprasījuma ports caur HTTP protokolu
{https_port} Projekta pieprasījuma ports caur HTTPS protokolu
{http_engine} HTTP dzinējs
{node_engine} NODE dzinējs
{php_engine} PHP dzinējs
{project_root} Projekta saknes katalogs
{web_root} Projekta publiskais katalogs
{scheme_port} Projekta pieprasījuma ports (":{http_port}" vai ":{https_port}", atkarīgs no TLS parametra projekta iestatījumos).

Ja {http_port} vai {https_port} ir standarta vērtība 80 vai 443, tad {scheme_port} būs tukšs.
{root_dir} Open Server Panel saknes katalogs (pilns ceļš)
{root_drive} Saknes kataloga disks
{root_path} Ceļš uz Open Server Panel saknes katalogu
{terminal_codepage} Konsoles kodējums
