Savējo izvēlnes vienumu izveide

  1. Pievienojiet jaunu sadaļu ar unikālu identifikatoru [ID]
  2. Novietojiet sadaļas vēlamajā secībā — tas noteiks vienumu kārtību izvēlnē
  3. Saglabājiet izmaiņas un pārstartējiet Open Server Panel, lai piemērotu izmaiņas

Svarīga informācija

Veidojot savus izvēlnes vienumus, pārliecinieties, ka sadaļu identifikatori neatkārtojas. Tas var izraisīt konfliktus izvēlnes darbībā.

Izvēlnes vienumu iestatījumi

Kārtošanas secība: Izvēlnes vienumi tiek kārtoti tajā pašā secībā, kādā atbilstošās sadaļas ir izvietotas šablonā.

caption Izvēlnes vienuma virsraksts. Atbalsta valodu konstantes formātā {lang_xxx}.

Pēc noklusējuma: nav norādīts
category

Nosaka izvēlnes vienuma novietojumu hierarhijā. Atbalsta vienu ligzdotības līmeni (piemēram, "Manas grāmatzīmes\Darbs").

Speciālās kategorijas:

  • projects, modules, addons - pievieno vienumu atbilstošajai darbību izvēlnei
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - pievieno vienumu konkrētam elementam

Ja kategorija nav norādīta, vienums tiek izveidots saknes izvēlnē.

Pēc noklusējuma: nav norādīts
command Komanda, kas tiek izpildīta, aktivizējot izvēlnes vienumu. Vienumi bez komandas tiek ignorēti.

Pēc noklusējuma: nav norādīts
enabled Ieslēdz/izslēdz izvēlnes vienuma rādīšanu.

Pēc noklusējuma: on | Vērtības: on, off
hide Kontrolē izsauktās lietotnes loga redzamību. Neietekmē bērnprocesus.

Pēc noklusējuma: off | Vērtības: on, off
hr_after Pievieno horizontālu atdalītāju pēc izvēlnes vienuma.

Pēc noklusējuma: off | Vērtības: on, off
hr_before Pievieno horizontālu atdalītāju pirms izvēlnes vienuma.

Pēc noklusējuma: off | Vērtības: on, off
icon Ikona no Font Awesome Free (Solid/Regular/Brands) kopas.

Pēc noklusējuma: nav norādīts
need_alias Rāda izvēlnes vienumu tikai domēna aliasam. Izvēlnes šablonā var būt tikai viens vienums ar need_alias=on!
Piemērojams kategorijām: projects

Pēc noklusējuma: nav norādīts | Vērtības: on, off
need_category

Ierobežo izvēlnes vienuma rādīšanu noteiktas kategorijas moduļiem/papildinājumiem.

Atbalstītie formāti:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Pēc noklusējuma: nav norādīts
need_module_shell Rāda izvēlnes vienumu atkarībā no vecākmodeļa shell/cli esamības.
Piemērojams kategorijām: modules, modules\<имя_модуля>

Pēc noklusējuma: nav norādīts | Vērtības: on, off
need_state Rāda izvēlnes vienumu atkarībā no vecākmodeļa stāvokļa.
Piemērojams kategorijām: modules, modules\<имя_модуля>

Pēc noklusējuma: nav norādīts | Vērtības: on, off
need_start_cmd Rāda izvēlnes vienumu, ja projekta iestatījumos ir norādīta palaišanas komanda.
Piemērojams kategorijām: projects, projects\<имя_домена>

Pēc noklusējuma: nav norādīts | Vērtības: on, off
need_use_wt Rāda izvēlnes vienumu atkarībā no Windows Terminal izmantošanas iestatījuma Open Server Panel vidē.

Pēc noklusējuma: nav norādīts | Vērtības: on, off
work_directory Darba direktorija komandas izpildei. Var mainīties komandu izpildes laikā.

Pēc noklusējuma: {root_dir}

Šablona mainīgie

Parametros "command" un "work_directory" var izmantot šādus šablona mainīgos:

Kopīgie mainīgie

Mainīgais Apraksts
{date_time} Pašreizējais datums/laiks (mainīgais pieejams tikai parametram "command")
{root_dir} Open Server Panel saknes katalogs (pilns ceļš)
{root_drive} Saknes kataloga disks
{root_path} Ceļš uz Open Server Panel saknes katalogu
{web_panel_url} Tīmekļa interfeisa URL adrese

Īpašie mainīgie (tikai projects un projects\<имя_домена>)

Mainīgais Apraksts
{base_dir} Projekta bāzes katalogs
{host} Domēna nosaukums (Punycode)
{host_decoded} Redzamais domēna nosaukums (bez Punycode)
{host_scheme} Pieprasījuma shēma projektam ("http" vai "https", atkarīgs no TLS parametra projekta iestatījumos)
{http_port} HTTP pieprasījuma ports projektam
{https_port} HTTPS pieprasījuma ports projektam
{menu_caption} Izvēlnes vienuma virsraksts (tikai projekta kategorijai ar need_alias=ON)
{http_engine} HTTP dzinējs
{node_engine} Node.js dzinējs
{php_engine} PHP dzinējs
{project_root} Projekta saknes katalogs
{base_url} Projekta URL
{web_root} Projekta publiskais katalogs
{scheme_port} Pieprasījuma ports projektam (":{http_port}" vai ":{https_port}", atkarīgs no TLS parametra projekta iestatījumos). Ja {http_port} vai {https_port} ir standarta vērtība 80 vai 443, tad {scheme_port} būs tukšs.
{app_start_command} Projekta lietotnes palaišanas komanda (ja iestatīta)
{terminal_codepage} Konsoles kodējums

Īpašie mainīgie (tikai addons un addons\<имя_дополнения>)

Mainīgais Apraksts
{addon_name} Papildinājuma nosaukums
{terminal_codepage} Konsoles kodējums

Īpašie mainīgie (tikai modules un modules\<имя_модуля>)

Mainīgais Apraksts
{ip} Moduļa IP adrese
{log_level} Kļūdu žurnalēšanas līmenis
{module_name} Moduļa nosaukums
{port} Moduļa ports
{profile_name} Moduļa pašreizējā profila nosaukums
{query_log_level} Pieprasījumu žurnalēšanas līmenis
{shell_command} Moduļa shell/cli čaulas palaišanas komanda (ja iestatīta)
{terminal_codepage} Konsoles kodējums
{time_zone} Laika josla

Īpašas komandu vērtības

Komanda Apraksts
command_open_logs_viewer Atvērt žurnālu skatītāju
command_open_idn_converter Atvērt IDN pārveidotāju
command_open_options Atvērt programmas iestatījumu logu

Bez šablona mainīgajiem var izmantot jebkurus Windows vides mainīgos, piemēram: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% u.c.

Lietošanas piemērs

caption  = Google

command  = cmd.exe /c "start "" "https://google.com""

icon     = bookmark

CMD.EXE opcijas

  • /c: Izpildīt komandu un aizvērt termināli.
  • /k: Izpildīt komandu un atstāt termināli atvērtu.
