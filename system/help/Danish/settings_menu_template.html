Oprettelse af egne menupunkter

  1. Tilføj en ny sektion med en unik identifikator [ID]
  2. Arranger sektionerne i den ønskede rækkefølge — dette bestemmer rækkefølgen af punkter i menuen
  3. Gem ændringerne og genstart Open Server Panel for at anvende ændringerne

Vigtig information

Når du opretter egne menupunkter, skal du sikre, at sektionernes identifikatorer ikke gentages. Dette kan føre til konflikter i menuens funktion.

Indstillinger for menupunkter

Sorteringsrækkefølge: Menupunkter sorteres i samme rækkefølge som de tilsvarende sektioner er placeret i skabelonen.

caption Menupunktets titel. Understøtter sprogkonstanter i formatet {lang_xxx}.

Som standard: ikke angivet
category

Bestemmer menupunktets placering i hierarkiet. Understøtter ét niveau af indlejring (f.eks. "Mine Bogmærker\Arbejde").

Særlige kategorier:

  • projects, modules, addons - tilføjer punktet til den tilsvarende handlingsmenu
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - tilføjer punktet for et specifikt element

Hvis kategorien ikke er angivet, oprettes punktet i rodmenuen.

Som standard: ikke angivet
command Kommandoen, der skal udføres, når menupunktet aktiveres. Punkter uden kommando ignoreres.

Som standard: ikke angivet
enabled Slår visning af menupunktet til/fra.

Som standard: on | Værdier: on, off
hide Styrer synligheden af det kaldte programs vindue. Påvirker ikke underprocesser.

Som standard: off | Værdier: on, off
hr_after Tilføjer en horisontal separator efter menupunktet.

Som standard: off | Værdier: on, off
hr_before Tilføjer en horisontal separator før menupunktet.

Som standard: off | Værdier: on, off
icon Ikon fra sættet Font Awesome Free (Solid/Regular/Brands).

Som standard: ikke angivet
need_alias Viser menupunktet kun for et domænealias. Der kan kun være ét punkt med need_alias=on i menuskabelonen!
Anvendelig for kategorier: projects

Som standard: ikke angivet | Værdier: on, off
need_category

Begrænser visningen af menupunktet til modules/addons af en bestemt kategori.

Understøttede formater:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Som standard: ikke angivet
need_module_shell Viser menupunktet afhængigt af om det overordnede modul har shell/cli.
Anvendelig for kategorier: modules, modules\<имя_модуля>

Som standard: ikke angivet | Værdier: on, off
need_state Viser menupunktet afhængigt af det overordnede moduls tilstand.
Anvendelig for kategorier: modules, modules\<имя_модуля>

Som standard: ikke angivet | Værdier: on, off
need_start_cmd Viser menupunktet, hvis der er en startkommando i projektindstillingerne.
Anvendelig for kategorier: projects, projects\<имя_домена>

Som standard: ikke angivet | Værdier: on, off
need_use_wt Viser menupunktet afhængigt af indstillingen for brug af Windows Terminal i Open Server Panel.

Som standard: ikke angivet | Værdier: on, off
work_directory Arbejdsmappe til at udføre kommandoen. Kan ændres under udførelsen af kommandoer.

Som standard: {root_dir}

Skabelonvariabler

I parametrene "command" og "work_directory" kan du bruge følgende skabelonvariabler:

Generelle variabler

Variabel Beskrivelse
{date_time} Nuværende dato/tid (variablen er kun tilgængelig for parameteren "command")
{root_dir} Rodmappen for Open Server Panel (fuld sti)
{root_drive} Drevet for rodmappen
{root_path} Sti til rodmappen for Open Server Panel
{web_panel_url} URL-adressen til webgrænsefladen

Særlige variabler (kun for projects og projects\<имя_домена>)

Variabel Beskrivelse
{base_dir} Projektets basismappe
{host} Domænenavn (Punycode)
{host_decoded} Synligt domænenavn (uden Punycode)
{host_scheme} Forespørgslens skema til projektet ("http" eller "https", afhænger af TLS-parameteren i projektindstillingerne)
{http_port} Forespørgselsport til projektet via HTTP
{https_port} Forespørgselsport til projektet via HTTPS
{menu_caption} Menupunktets titel (kun for kategorien projects med need_alias=ON)
{http_engine} HTTP-motor
{node_engine} Node.js-motor
{php_engine} PHP-motor
{project_root} Projektets rodmappe
{base_url} Projektets URL
{web_root} Projektets offentlige mappe
{scheme_port} Forespørgselsport til projektet (":{http_port}" eller ":{https_port}", afhænger af TLS-parameteren i projektindstillingerne). Hvis {http_port} eller {https_port} har standardværdien 80 eller 443, vil {scheme_port} være tom.
{app_start_command} Projektets app-startkommando (hvis konfigureret)
{terminal_codepage} Konsolkodning

Særlige variabler (kun for addons og addons\<имя_дополнения>)

Variabel Beskrivelse
{addon_name} Navnet på tilføjelsen
{terminal_codepage} Konsolkodning

Særlige variabler (kun for modules og modules\<имя_модуля>)

Variabel Beskrivelse
{ip} Modulets IP-adresse
{log_level} Fejllogningsniveau
{module_name} Modulets navn
{port} Modulets port
{profile_name} Navnet på modulets aktuelle profil
{query_log_level} Forespørgselslogningsniveau
{shell_command} Kommando til at starte modulets shell/cli (hvis konfigureret)
{terminal_codepage} Konsolkodning
{time_zone} Tidszone

Særlige kommando-værdier

Kommando Beskrivelse
command_open_logs_viewer Åbn logvisningsvinduet
command_open_idn_converter Åbn IDN-konverteren
command_open_options Åbn programmets indstillingsvindue

Ud over skabelonvariabler kan du bruge enhver Windows-miljøvariabel, for eksempel: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% osv.

Eksempel på brug

[bookmark_1]

caption  = Google
category = Mine Bogmærker\Søgemaskiner
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE-indstillinger

  • /c: Udfør kommandoen og luk terminalen.
  • /k: Udfør kommandoen og lad terminalen forblive åben.
