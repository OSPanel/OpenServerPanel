Globale projektindstillinger

De parametre, der er angivet i dette afsnit, bruges, hvis der ikke er angivet andre værdier i projektindstillingerne.

HTTP
Bestemmer den webservermodul, der bruges til projekter.
NODE
Angiver Node.js-motoren til at køre Node.js-applikationer.

Installation af Node.js: Installer på forhånd den ønskede version af Node.js med kommandoen osp node <latest|lts|номер>.
PHP
Bestemmer det anvendte PHP-modul til behandling af PHP-filer.
Aktivér
Bestemmer projektets standardtilstand (aktiveret eller deaktiveret).
Terminalkodning
Terminalens kodning ved arbejde med projektmiljøet.

Specielle værdier:
- system: Systemkodning bruges.

Vigtigt: Hvis værdien ikke er angivet, vil terminalkodningen ved dannelsen af projektets endelige miljø blive sat af det sidst tilkoblede miljø, hvor den er angivet, for eksempel PHP-modulets miljø.
IP
Angiver den IP-adresse(r), der bruges af alle projekter uden individuelle indstillinger.

Begrænsning: Projekter, der bruger den samme IP-adresse, skal køre på den samme version af PHP.

Understøttelse af flere IP'er: Du kan angive flere IP-adresser adskilt af mellemrum, inklusive IPv6. I HOSTS-filen vil domæner få tildelt den første angivne IP.

Automatisk tildeling: Hvis feltet efterlades tomt, tildeles IP-adressen automatisk.

Anbefalinger:
  • Automatisk håndtering af IP-adresser anbefales for de fleste brugere.
  • Manuel angivelse af IP-adresse bør kun bruges ved specifikke krav til netværkskonfiguration.
HTTP
Bestemmer porten til forbindelser via HTTP.
HTTPS
Bestemmer porten til forbindelser via HTTPS.
TLS
Aktiverer eller deaktiverer understøttelse af TLS.
Certifikatfil
Angiver stien til TLS-certifikatfilen. Der kan bruges skabelonvariabler.

Tilladte tegn: A-Za-z0-9-+_.\:

Anbefaling: Lad feltet være tomt for automatisk generering af certifikater.
Nøglefil
Angiver stien til TLS-nøglefilen. Der kan bruges skabelonvariabler.

Tilladte tegn: A-Za-z0-9-+_.\:

Anbefaling: Lad feltet være tomt for automatisk generering af nøglen.
IP-adresse (backend)
Angiver IP-adressen, som forbindelsen til serverdelen (Backend) oprettes over.
Port (backend)
Bestemmer portnummeret til forbindelse til serverdelen (Backend).
Aktivér (backend)
Gør det muligt automatisk at omdirigere al indgående trafik (HTTP og HTTPS) for projektet til serverdelen (Backend). Nyttigt til test eller udvikling, når frontend og backend er adskilt.
Projektdirectory
Angiver projektets rodmappe. Skift til denne mappe udføres med kommandoen osp project <DOMAIN> samtidig med aktivering af projektmiljøet. Der kan bruges skabelonvariabler.

Tilladte tegn: A-Za-z0-9-+_.\:
Offentlig mappe
Bestemmer projektets offentlige mappe. Der kan bruges skabelonvariabler.

Tilladte tegn: A-Za-z0-9-+_.\:
Aliasser
Angiver yderligere domænenavne (aliasser) for projektet (adskilt af mellemrum). Der kan bruges skabelonvariabler.

Begrænsning: Tegnet "*" understøttes ikke i Windows-filen HOSTS og kræver DNS-konfiguration.
Projektmiljø
Liste over tilføjelser og moduler (adskilt af mellemrum), der danner projektets miljø.

HTTP, NODE og PHP: Miljøerne for disse motorer tilsluttes altid (hvis angivet for domænet) og kræver ikke angivelse i denne parameter.
Projektets startkommando
Bestemmer kommandoen til at starte projektet (for eksempel nodemon app.js). Der kan bruges skabelonvariabler.
Projektets URL
URL, der bruges ved åbning af projektet via Menu→Projekt→Åbn i browser, samt ved åbning af projektets domænealiasser. Der kan bruges skabelonvariabler.

Anvendelse: Du kan angive URL'en til CMS'ets administrationspanel.

Skabelonvariabler

Variabel Beskrivelse
{backend_ip} IP-adresse til forbindelse til serverdelen (Backend)
{backend_port} Port til forbindelse til serverdelen (Backend)
{base_dir} Projektets rodmappe (hvor mappen .osp befinder sig)
{date_time} Nuværende dato/tid (variablen er kun tilgængelig for kommandoen til at starte projektets applikation)
{host} Domænenavn (for internationaliserede domæner bruges Punycode)
{host_decoded} Synligt domænenavn (uden Punycode)
{host_scheme} Forespørgslens skema til projektet ("http" eller "https", afhænger af TLS-parameteren i projektindstillingerne)
{http_port} Forespørgselsport til projektet via HTTP-protokollen
{https_port} Forespørgselsport til projektet via HTTPS-protokollen
{http_engine} HTTP-motor
{node_engine} NODE-motor
{php_engine} PHP-motor
{project_root} Projektets rodmappe
{web_root} Projektets offentlige mappe
{scheme_port} Forespørgselsport til projektet (":{http_port}" eller ":{https_port}", afhænger af TLS-parameteren i projektindstillingerne).

Hvis {http_port} eller {https_port} har standardværdien 80 eller 443, vil {scheme_port} være tom.
{root_dir} Open Server Panels rodmappe (fuld sti)
{root_drive} Drevet for rodmappen
{root_path} Stien til Open Server Panels rodmappe
{terminal_codepage} Konsolkodning
