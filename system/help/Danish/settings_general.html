Programindstillinger

Start sammen med Windows
Aktivér automatisk start af Open Server Panel ved opstart af operativsystemet.
Forsinkelse
Forsinkelse af programstart (i sekunder, fra 0 til 60).

Giver mulighed for at udsætte start af applikationen under opstart sammen med Windows for at reducere den samlede systembelastning. Dette er især nyttigt, hvis man skal vente på fuld initialisering af tredjepartstjenester eller netværksgrænseflader.
Kontrollér for nye versioner
Aktivér kontrol for opdateringer af Open Server Panel (kræver internetforbindelse).
Aktivér jobplanlægger
Aktivér den indbyggede jobplanlægger. Hvis parameteren er deaktiveret, vil ingen planlagte jobs blive udført, uanset deres status.
Brug HOSTS-filen
Aktivér skrivning af domænenavne til HOSTS-filen.

Anbefalinger ved begrænset adgang til HOSTS-filen i en organisation:

1. Konfigurer alle nødvendige moduler og projekter.
2. Kontakt systemadministratoren for at låse HOSTS op og fastlåse dens tilstand.
3. Efter at administratoren har fastlåst ændringerne, kan denne indstilling deaktiveres.

Vigtigt: Deaktiver ikke denne parameter, medmindre du er sikker på konsekvenserne!
Start moduler med projektprofil
Start moduler med samtidig aktivering af profilen, der matcher projektnavnet.

Bruges, når menupunktet «Aktivér projektmoduler» vælges, for automatisk at aktivere en profil med samme navn som det aktuelle projekt, hvis en sådan findes.
Sluk ikke moduler for skjulte projekter
Sluk ikke moduler for skjulte projekter, når menupunktet «Sluk alle moduler» vælges. Med "skjulte" menes de projekter, for hvilke kategorien "hidden" er angivet.

Som standard stopper kommandoen «Sluk alle moduler» driften af absolut alle moduler, inklusive dem, der bruges af skjulte serviceprojekter (f.eks. PHPMyAdmin). Denne indstilling gør det muligt at bevare funktionaliteten af skjulte serviceprojekter uden at deaktivere de moduler, de kræver, mens alle andre moduler slukkes.
Grænsefladesprog
Sprog for brugergrænsefladen i Open Server Panel.

Hvis lokaliseringsfilen mangler eller indeholder fejl, bruges engelsk.
API-domæne
Lokalt domæne til API og webgrænseflade (under udvikling)

Anbefaling: Hvis der bruges VPN eller proxy, skal du tilføje dette domæne til undtagelser.
API IP-adresse
IPv4-adresse til API og webgrænseflade (under udvikling).

Anbefaling: Hvis der bruges VPN eller proxy, skal du tilføje denne IP-adresse til undtagelser.
API-port
Port, der bruges til API og webgrænseflade (under udvikling). Open Server Panel kan ikke starte, hvis den angivne port allerede bruges af en anden applikation.
Brug Windows Terminal
Aktivér brug af Windows Terminal i stedet for standard kommandogrænsefladen.

Krav: Windows Terminal skal være installeret i systemet og angivet i miljøvariablen PATH.

Windows Terminal som cmd.exe: Windows Terminal kan erstatte cmd.exe og være angivet i miljøvariablen %COMSPEC% i nyere versioner af Windows. Hvis det er tilfældet, lad denne indstilling være aktiveret.

Nye instanser af Windows Terminal: Hvis Windows Terminal åbner nye vinduer i stedet for faner, konfigurer den således: Indstillinger→Start→Adfærd for ny instans→Sammenføj til sidst anvendte vindue.
Kort projekttitel
Når denne indstilling er aktiveret, vises kun projektnavnet i terminalvinduets titel i stedet for en detaljeret beskrivelse af miljøet.
Medtag systemmiljø i projektets miljø
Brug systemets miljø (System) i terminalen, selv hvis det ikke er angivet i projektindstillingerne. Systemmiljøet gør det muligt at bruge programmer, der er installeret i systemet (for eksempel git.exe eller ssh.exe).

Deaktiver kun denne indstilling, hvis der opstår konflikter med systemsoftware.
ANSI-understøttelse
Aktivér understøttelse af ANSI-koder til styring af farver i terminalen.

Tilstand "Automatisk" (standard):
- Rettelsen anvendes kun på Windows 10 op til og med version 1903. I nyere versioner af Windows er understøttelse af ANSI-koder allerede indbygget.
- Rettelsen anvendes ikke for terminaler, der understøtter ANSI som standard (for eksempel Windows Terminal).
Kataloger til søgning efter projekter
Liste over kataloger, hvor Open Server Panel vil søge efter projekter. Adskil stier med semikolon (;).

Undtagelser: Underkatalogerne node_modules og vendor ignoreres.
Dybde
Maksimal mappeindlejringsdybde ved søgning efter projekter.

En forøgelse af denne værdi kan gøre opstart af Open Server Panel langsommere, hvis de angivne kataloger indeholder et stort antal underkataloger.
Maksimal logfilstørrelse
Maksimal størrelse på logfilen i megabyte. Når den angivne værdi overskrides, vil logfilen blive genskabt ved næste programstart.

Angiv værdien 0 for at rydde loggene ved hver programstart.

Angiv værdien 100 MB for helt at deaktivere rydning af logge.
