모듈 환경의 전역 변수

이 섹션에서는 모듈을 위한 전역 환경 변수를 설정할 수 있습니다.

이 변수들은 모듈 환경에서만 적용되며 시스템 변수나 프로젝트 환경에는 영향을 주지 않습니다.

값에는 템플릿 변수를 사용할 수 있습니다.

변수가 시스템 환경에 존재하지만 모듈 환경에서는 사용되면 안 되는 경우, 전용 필터를 사용하세요(참조: 모듈→허용된 시스템 변수) 또는 값을 비워 환경에서 변수를 제거하세요.

템플릿 변수

변수 설명
{root_dir} Open Server Panel의 루트 디렉터리(전체 경로)
{root_drive} 루트 디렉터리가 위치한 드라이브
{root_path} Open Server Panel의 루트 디렉터리 경로
{terminal_codepage} 터미널 인코딩(참조: 모듈→터미널 인코딩)
{time_zone} Etc/GMT 형식의 시간대(참조: 모듈→시간대)

템플릿 변수 외에도 Windows의 임의의 환경 변수를 사용할 수 있습니다. 예: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% 등.
