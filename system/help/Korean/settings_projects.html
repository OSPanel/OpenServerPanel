프로젝트 전역 설정

이 섹션에서 지정한 매개변수는 프로젝트 설정에 다른 값이 지정되지 않은 경우에 사용됩니다.

HTTP
프로젝트에 사용되는 웹 서버 모듈을 결정합니다.
NODE
Node.js 애플리케이션 실행에 사용할 Node.js 엔진을 지정합니다.

Node.js 설치: 필요한 버전의 Node.js를 사전에 osp node <latest|lts|номер> 명령으로 설치하세요.
PHP
PHP 파일 처리를 위해 사용되는 PHP 모듈을 결정합니다.
활성화
프로젝트의 기본 상태(활성 또는 비활성)를 결정합니다.
터미널 인코딩
프로젝트 환경에서 작업할 때의 터미널 인코딩입니다.

특수 값:
- system: 시스템 인코딩을 사용합니다.

중요: 값이 지정되지 않은 경우, 최종 프로젝트 환경을 구성할 때 터미널 인코딩은 마지막으로 연결된 환경(예: PHP 모듈 환경)에서 지정된 값으로 설정됩니다.
IP
개별 설정이 없는 모든 프로젝트에서 사용되는 IP 주소(들)를 지정합니다.

제한: 동일한 IP 주소를 사용하는 프로젝트는 동일한 PHP 버전에서 작동해야 합니다.

다중 IP 지원: 공백으로 구분하여 여러 IP 주소를 지정할 수 있으며, IPv6도 포함됩니다. HOSTS 파일에서는 도메인에 첫 번째로 지정된 IP가 할당됩니다.

자동 할당: 필드를 비워두면 IP 주소가 자동으로 할당됩니다.

권장 사항:
  • 대부분의 사용자에게는 IP 주소 자동 관리가 권장됩니다.
  • 수동 IP 지정은 특수한 네트워크 구성 요구 사항이 있을 때만 사용하세요.
HTTP
HTTP 연결을 위한 포트를 결정합니다.
HTTPS
HTTPS 연결을 위한 포트를 결정합니다.
TLS
TLS 지원을 활성화하거나 비활성화합니다.
인증서 파일
TLS 인증서 파일의 경로를 지정합니다. 템플릿 변수를 사용할 수 있습니다.

허용 문자: A-Za-z0-9-+_.\:

권장: 자동으로 인증서를 생성하려면 필드를 비워두세요.
키 파일
TLS 키 파일의 경로를 지정합니다. 템플릿 변수를 사용할 수 있습니다.

허용 문자: A-Za-z0-9-+_.\:

권장: 키를 자동 생성하려면 필드를 비워두세요.
IP 주소 (backend)
서버 측(Backend)에 연결할 IP 주소를 지정합니다.
포트 (backend)
서버 측(Backend)에 연결할 포트 번호를 결정합니다.
활성화 (backend)
프로젝트의 모든 수신 트래픽(HTTP 및 HTTPS)을 자동으로 서버 측(Backend)으로 라우팅할 수 있습니다. 프론트엔드와 백엔드가 분리된 테스트 또는 개발에 유용합니다.
프로젝트 디렉터리
프로젝트의 루트 디렉터리를 지정합니다. 이 디렉터리로의 이동은 프로젝트 환경 활성화와 동시에 osp project <DOMAIN> 명령으로 수행됩니다. 템플릿 변수를 사용할 수 있습니다.

허용 문자: A-Za-z0-9-+_.\:
공개 디렉터리
프로젝트의 공개 디렉터리를 지정합니다. 템플릿 변수를 사용할 수 있습니다.

허용 문자: A-Za-z0-9-+_.\:
별칭
프로젝트의 추가 도메인 이름(별칭)을 공백으로 구분하여 지정합니다. 템플릿 변수를 사용할 수 있습니다.

제한: 문자 "*"는 Windows의 HOSTS 파일에서 지원되지 않으며 DNS 설정이 필요합니다.
프로젝트 환경
프로젝트 환경을 구성하는 추가 기능 및 모듈의 목록(공백으로 구분)입니다.

HTTP, NODE 및 PHP: 이 엔진들의 환경은 항상 연결되며(도메인에 대해 지정된 경우) 이 매개변수에 명시할 필요가 없습니다.
프로젝트 시작 명령
프로젝트를 시작하기 위한 명령을 지정합니다(예: nodemon app.js). 템플릿 변수를 사용할 수 있습니다.
프로젝트 URL
메뉴→프로젝트→브라우저에서 열기에서 프로젝트를 열 때 사용되는 URL이며, 프로젝트의 도메인 별칭을 열 때도 사용됩니다. 템플릿 변수를 사용할 수 있습니다.

사용 예: CMS 관리 패널의 URL을 지정할 수 있습니다.

템플릿 변수

변수 설명
{backend_ip} 서버 측(Backend) 연결 IP 주소
{backend_port} 서버 측(Backend) 연결 포트
{base_dir} 프로젝트 루트 디렉터리(.osp 디렉터리가 위치한 곳)
{date_time} 현재 날짜/시간(변수는 프로젝트 애플리케이션 시작 명령에서만 사용 가능)
{host} 도메인 이름(국제화 도메인의 경우 Punycode 사용)
{host_decoded} 가시적 도메인 이름(Punycode 없음)
{host_scheme} 프로젝트 요청 스킴("http" 또는 "https", 프로젝트 설정의 TLS 매개변수에 따라 결정)
{http_port} HTTP 프로토콜로 프로젝트에 요청하는 포트
{https_port} HTTPS 프로토콜로 프로젝트에 요청하는 포트
{http_engine} HTTP 엔진
{node_engine} NODE 엔진
{php_engine} PHP 엔진
{project_root} 프로젝트 루트 디렉터리
{web_root} 프로젝트 공개 디렉터리
{scheme_port} 프로젝트 요청 포트(":{http_port}" 또는 ":{https_port}", 프로젝트 설정의 TLS 매개변수에 따라 결정).

{http_port} 또는 {https_port}가 기본값 80 또는 443인 경우 {scheme_port}는 비어 있습니다.
{root_dir} Open Server Panel 루트 디렉터리(전체 경로)
{root_drive} 루트 디렉터리 드라이브
{root_path} Open Server Panel 루트 디렉터리 경로
{terminal_codepage} 콘솔 인코딩
