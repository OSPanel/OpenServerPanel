메뉴 설정

테마
메뉴 아이콘에 대한 테마입니다.
글꼴 크기
메뉴의 글꼴 크기(픽셀). 이 옵션은 시스템 설정과 무관하게 메뉴의 글꼴 크기를 지정할 수 있습니다.

글꼴 크기 제어 기능을 끄려면 슬라이더를 최소값 12px로 설정하세요(시스템 크기가 사용됩니다).
알림 영역에 아이콘 표시
Windows 알림 영역에 프로그램 아이콘을 표시합니다.

비활성화: Windows 사용자 로그온이 필요하지 않은 자동 시작 유형을 사용하는 경우 이 옵션을 비활성화하세요(Windows 작업 스케줄러→컴퓨터 부팅 시 시작).
메뉴 항목에 아이콘 표시
프로그램 메뉴에 아이콘을 표시합니다. 시스템 렌더링이 켜져 있으면 아이콘이 표시되지 않습니다.
시스템 렌더링 사용
화면 접근 프로그램(스크린 리더)과의 호환이 필요한 경우에만 이 옵션을 사용하세요.

주의! 시스템 렌더링이 켜져 있으면 메뉴에 아이콘이 표시되지 않습니다.
세로 구분자 표시
이 옵션을 켜면 프로그램 메뉴의 아이콘이 세로 구분자로 분리됩니다.
단일 항목 목록 묶지 않기
