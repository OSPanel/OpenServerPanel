사용자 지정 메뉴 항목 만들기

  1. 고유 식별자 [ID]를 가진 새 섹션을 추가하세요
  2. 원하는 순서로 섹션을 배치하세요 — 이것이 메뉴 항목의 순서를 결정합니다
  3. 변경 사항을 저장하고 변경 사항을 적용하려면 Open Server Panel을 다시 시작하세요

중요한 정보

사용자 지정 메뉴 항목을 만들 때 섹션 식별자가 중복되지 않도록 하세요. 이는 메뉴 동작에 충돌을 일으킬 수 있습니다.

메뉴 항목 설정

정렬 순서: 메뉴 항목은 템플릿에서 해당 섹션이 배치된 순서와 동일하게 정렬됩니다.

caption 메뉴 항목의 제목. {lang_xxx} 형식의 언어 상수를 지원합니다.

기본값: 설정되지 않음
category

메뉴 항목의 계층 구조 내 위치를 결정합니다. 한 단계의 중첩만 지원합니다(예: "나의 북마크\업무").

특수 카테고리:

  • projects, modules, addons - 해당 작업 메뉴에 항목을 추가합니다
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - 특정 항목에 대해 항목을 추가합니다

카테고리가 지정되지 않으면 항목은 루트 메뉴에 생성됩니다.

기본값: 설정되지 않음
command 메뉴 항목이 활성화될 때 실행할 명령. 명령이 없는 항목은 무시됩니다.

기본값: 설정되지 않음
enabled 메뉴 항목 표시를 켜거나 끕니다.

기본값: on | 값: on, off
hide 호출된 애플리케이션 창의 가시성을 제어합니다. 하위 프로세스에는 영향을 주지 않습니다.

기본값: off | 값: on, off
hr_after 메뉴 항목 뒤에 가로 구분선을 추가합니다.

기본값: off | 값: on, off
hr_before 메뉴 항목 앞에 가로 구분선을 추가합니다.

기본값: off | 값: on, off
icon Font Awesome Free (Solid/Regular/Brands) 아이콘입니다.

기본값: 설정되지 않음
need_alias 도메인 별칭에 대해서만 메뉴 항목을 표시합니다. 템플릿 메뉴에는 need_alias=on인 항목이 하나만 있어야 합니다!
적용 범주: projects

기본값: 설정되지 않음 | 값: on, off
need_category

특정 카테고리의 모듈/애드온에 대해 메뉴 항목 표시를 제한합니다.

지원 형식:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
기본값: 설정되지 않음
need_module_shell 상위 모듈에 shell/cli가 있는지 여부에 따라 메뉴 항목을 표시합니다.
적용 범주: modules, modules\<имя_модуля>

기본값: 설정되지 않음 | 값: on, off
need_state 상위 모듈의 상태에 따라 메뉴 항목을 표시합니다.
적용 범주: modules, modules\<имя_модуля>

기본값: 설정되지 않음 | 값: on, off
need_start_cmd 프로젝트 설정에 시작 명령이 있는 경우에 메뉴 항목을 표시합니다.
적용 범주: projects, projects\<имя_домена>

기본값: 설정되지 않음 | 값: on, off
need_use_wt Open Server Panel에서 Windows Terminal 사용 설정 여부에 따라 메뉴 항목을 표시합니다.

기본값: 설정되지 않음 | 값: on, off
work_directory 명령 실행을 위한 작업 디렉터리. 명령 실행 중에 변경될 수 있습니다.

기본값: {root_dir}

템플릿 변수

"command" 및 "work_directory" 매개변수에서 다음 템플릿 변수를 사용할 수 있습니다:

일반 변수

변수 설명
{date_time} 현재 날짜/시간(변수는 "command" 매개변수에만 사용 가능)
{root_dir} Open Server Panel의 루트 디렉터리(전체 경로)
{root_drive} 루트 디렉터리의 드라이브
{root_path} Open Server Panel의 루트 디렉터리 경로
{web_panel_url} 웹 인터페이스의 URL 주소

특수 변수 (projects 및 projects\<имя_домена> 전용)

변수 설명
{base_dir} 프로젝트의 기준 디렉터리
{host} 도메인 이름(Punycode)
{host_decoded} 보이는 도메인 이름(Punycode 제외)
{host_scheme} 프로젝트 요청 스킴("http" 또는 "https", 프로젝트 설정의 TLS 매개변수에 따라 다름)
{http_port} HTTP 프로토콜로 프로젝트에 요청하는 포트
{https_port} HTTPS 프로토콜로 프로젝트에 요청하는 포트
{menu_caption} 메뉴 항목 제목(projects 카테고리에서 need_alias=ON인 경우에만)
{http_engine} HTTP 엔진
{node_engine} Node.js 엔진
{php_engine} PHP 엔진
{project_root} 프로젝트의 루트 디렉터리
{base_url} 프로젝트 URL
{web_root} 프로젝트의 공개 디렉터리
{scheme_port} 프로젝트 요청 포트(":{http_port}" 또는 ":{https_port}", 프로젝트 설정의 TLS 매개변수에 따라 다름). {http_port} 또는 {https_port}가 표준 값 80 또는 443인 경우 {scheme_port}는 비어 있습니다.
{app_start_command} 프로젝트 애플리케이션의 시작 명령(설정된 경우)
{terminal_codepage} 콘솔 인코딩

특수 변수 (addons 및 addons\<имя_дополнения> 전용)

변수 설명
{addon_name} 애드온 이름
{terminal_codepage} 콘솔 인코딩

특수 변수 (modules 및 modules\<имя_модуля> 전용)

변수 설명
{ip} 모듈의 IP 주소
{log_level} 오류 로깅 수준
{module_name} 모듈 이름
{port} 모듈 포트
{profile_name} 모듈의 현재 설정 프로필 이름
{query_log_level} 요청 로깅 수준
{shell_command} 모듈의 shell/cli 셸 시작 명령(설정된 경우)
{terminal_codepage} 콘솔 인코딩
{time_zone} 시간대

특수 명령 값

명령 설명
command_open_logs_viewer 로그 뷰어 창 열기
command_open_idn_converter IDN 변환기 열기
command_open_options 프로그램 설정 창 열기

템플릿 변수 외에도 %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% 등과 같은 모든 Windows 환경 변수를 사용할 수 있습니다.

사용 예시

[bookmark_1]

caption  = Google
category = 나의 북마크\검색 엔진
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE 옵션

  • /c: 명령을 실행하고 터미널을 닫습니다.
  • /k: 명령을 실행하고 터미널을 열린 상태로 둡니다.
