Globale Umgebungsvariablen der Module

In diesem Abschnitt können globale Umgebungsvariablen für die Module festgelegt werden.

Diese Variablen gelten nur in der Modulumgebung und beeinflussen weder die Systemvariablen noch die Projektumgebung.

In den Werten ist die Verwendung von Vorlagenvariablen zulässig.

Wenn eine Variable in der Systemumgebung vorhanden ist, aber nicht in der Modulumgebung verwendet werden soll, verwenden Sie den speziellen Filter (siehe Module→Zulässige Systemvariablen) oder entfernen Sie die Variable aus der Umgebung, indem Sie ihr einen leeren Wert zuweisen.

Vorlagenvariablen

Variable Beschreibung
{root_dir} Stammverzeichnis von Open Server Panel (vollständiger Pfad)
{root_drive} Laufwerk des Stammverzeichnisses
{root_path} Pfad zum Stammverzeichnis von Open Server Panel
{terminal_codepage} Zeichencodierung im Terminal (siehe Module→Zeichencodierung im Terminal)
{time_zone} Zeitzone im Format Etc/GMT (siehe Module→Zeitzone)

Neben den Vorlagenvariablen können beliebige Windows-Umgebungsvariablen verwendet werden, z. B.: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% usw.
