Globale Modulumgebungsvariablen

In diesem Abschnitt können Sie globale Umgebungsvariablen für Module festlegen.

Diese Variablen werden ausschließlich in der Modulumgebung angewendet und haben keinen Einfluss auf Systemvariablen oder die Projektumgebung. In den Werten können Vorlagenvariablen verwendet werden.

Wenn eine Variable in der Systemumgebung vorhanden ist, aber in der Modulumgebung nicht verwendet werden soll, verwenden Sie den speziellen Filter (siehe Module→Erlaubte Systemvariablen) oder entfernen Sie die Variable aus der Umgebung, indem Sie ihr einen leeren Wert zuweisen.

Vorlagenvariablen

Variable Beschreibung
{root_dir} Stammverzeichnis des Open Server Panels (vollständiger Pfad)
{root_drive} Laufwerk des Stammverzeichnisses
{root_path} Pfad zum Stammverzeichnis des Open Server Panels
{terminal_codepage} Codierung im Terminal (siehe Module→Terminal-Codierung)
{time_zone} Zeitzone im Format Etc/GMT (siehe Module→Zeitzone)

Neben Vorlagenvariablen können Sie auch beliebige Windows-Umgebungsvariablen verwenden, wie z.B.: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH% usw.
