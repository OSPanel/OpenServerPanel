Erstellen eigener Menüpunkte

  1. Fügen Sie einen neuen Abschnitt mit einer eindeutigen Kennung [ID] hinzu
  2. Ordnen Sie die Abschnitte in der gewünschten Reihenfolge an – dies bestimmt die Reihenfolge der Punkte im Menü
  3. Speichern Sie die Änderungen und starten Sie das Open Server Panel neu, um die Änderungen zu übernehmen

Wichtige Information

Achten Sie bei der Erstellung eigener Menüpunkte darauf, dass sich die Abschnittskennungen nicht wiederholen. Dies kann zu Konflikten in der Menüfunktion führen.

Menüpunkt-Einstellungen

Sortierreihenfolge: Die Menüpunkte werden in der gleichen Reihenfolge sortiert, in der die entsprechenden Abschnitte in der Vorlage angeordnet sind.

caption Überschrift des Menüpunkts. Unterstützt Sprachkonstanten im Format {lang_xxx}.

Standard: nicht definiert
category

Bestimmt die Position des Menüpunkts in der Hierarchie. Unterstützt eine Verschachtelungsebene (z.B. "Meine Lesezeichen\Arbeit").

Spezielle Kategorien:

  • projects, modules, addons - fügt den Punkt zum entsprechenden Aktionsmenü hinzu
  • projects\, modules\, addons\ - fügt den Punkt für ein bestimmtes Element hinzu

Wenn keine Kategorie angegeben ist, wird der Punkt im Hauptmenü erstellt.

Standard: nicht definiert
command Befehl, der bei Aktivierung des Menüpunkts ausgeführt wird. Punkte ohne Befehl werden ignoriert.

Standard: nicht definiert
enabled Aktiviert/deaktiviert die Anzeige des Menüpunkts.

Standard: on | Werte: on, off
hide Steuert die Sichtbarkeit des Fensters der aufgerufenen Anwendung. Hat keinen Einfluss auf untergeordnete Prozesse.

Standard: off | Werte: on, off
hr_after Fügt nach dem Menüpunkt einen horizontalen Trennstrich hinzu.

Standard: off | Werte: on, off
hr_before Fügt vor dem Menüpunkt einen horizontalen Trennstrich hinzu.

Standard: off | Werte: on, off
icon Symbol aus dem Font Awesome Free Set (Solid/Regular/Brands).

Standard: nicht definiert
need_alias Zeigt den Menüpunkt nur für einen Domain-Alias an. In der Menüvorlage kann es nur einen Punkt mit need_alias=on geben!
Anwendbar für Kategorien: projects

Standard: nicht definiert | Werte: on, off
need_category

Beschränkt die Anzeige des Menüpunkts auf Module/Add-ons einer bestimmten Kategorie.

Unterstützte Formate:

  • modules, addons
  • modules\, addons\
Standard: nicht definiert
need_module_shell Zeigt den Menüpunkt abhängig vom Vorhandensein einer Shell/CLI beim übergeordneten Modul an.
Anwendbar für Kategorien: modules, modules\

Standard: nicht definiert | Werte: on, off
need_state Zeigt den Menüpunkt abhängig vom Status des übergeordneten Moduls an.
Anwendbar für Kategorien: modules, modules\

Standard: nicht definiert | Werte: on, off
need_start_cmd Zeigt den Menüpunkt an, wenn in den Projekteinstellungen ein Startbefehl vorhanden ist.
Anwendbar für Kategorien: projects, projects\

Standard: nicht definiert | Werte: on, off
need_use_wt Zeigt den Menüpunkt abhängig von der Einstellung zur Verwendung des Windows Terminals im Open Server Panel an.

Standard: nicht definiert | Werte: on, off
work_directory Arbeitsverzeichnis für die Ausführung des Befehls. Kann während der Befehlsausführung geändert werden.

Standard: {root_dir}

Vorlagenvariablen

In den Parametern "command" und "work_directory" können die folgenden Vorlagenvariablen verwendet werden:

Allgemeine Variablen

Variable Beschreibung
{root_dir} Stammverzeichnis des Open Server Panels (vollständiger Pfad)
{root_drive} Laufwerk des Stammverzeichnisses
{root_path} Pfad zum Stammverzeichnis des Open Server Panels
{web_panel_url} URL-Adresse der Weboberfläche

Spezielle Variablen (nur für projects und projects\<Domainname>)

Variable Beschreibung
{base_dir} Basisverzeichnis des Projekts
{host} Domainname (Punycode)
{host_decoded} Sichtbarer Domainname (ohne Punycode)
{host_scheme} Anfrageschema für das Projekt ("http" oder "https", abhängig vom SSL-Parameter in den Projekteinstellungen)
{menu_caption} Überschrift des Menüpunkts (nur für die Kategorie projects mit need_alias=ON)
{nginx_engine} Nginx-Engine
{node_engine} Node.js-Engine
{php_engine} PHP-Engine
{project_dir} Stammverzeichnis des Projekts
{project_url} Projekt-URL
{public_dir} Öffentliches Verzeichnis des Projekts
{start_command} Projektstart-Befehl (falls konfiguriert)
{terminal_codepage} Konsolencodierung

Spezielle Variablen (nur für addons und addons\<Add-on-Name>)

Variable Beschreibung
{addon_name} Name des Add-ons
{terminal_codepage} Konsolencodierung

Spezielle Variablen (nur für modules und modules\<Modulname>)

Variable Beschreibung
{ip} IP-Adresse des Moduls
{log_level} Fehlerprotokollierungsebene
{module_name} Name des Moduls
{port} Port des Moduls
{profile_name} Name des aktuellen Moduleinstellungsprofils
{query_log_level} Abfrageprotokollierungsebene
{shell_command} Startbefehl für die Shell/CLI des Moduls (falls konfiguriert)
{terminal_codepage} Konsolencodierung
{time_zone} Zeitzone

Spezielle Befehlswerte

Befehl Beschreibung
command_open_logs_viewer Öffnet das Protokollansichtsfenster
command_open_idn_converter Öffnet den IDN-Konverter
command_open_options Öffnet das Programmeinstellungsfenster

Neben Vorlagenvariablen können Sie auch beliebige Windows-Umgebungsvariablen verwenden, wie z.B.: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH% usw.

Verwendungsbeispiele

[21]

caption  = In PhpStorm öffnen
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = Meine Lesezeichen\Suchmaschinen
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Optionen für `cmd.exe`

  • /c: Befehl ausführen und Terminal schließen.
  • /k: Befehl ausführen und Terminal geöffnet lassen.
