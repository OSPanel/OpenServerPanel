Benutzerdefinierte Menüelemente erstellen

  1. Fügen Sie einen neuen Abschnitt mit einer eindeutigen Kennung [ID] hinzu
  2. Ordnen Sie die Abschnitte in der gewünschten Reihenfolge an — dies bestimmt die Reihenfolge der Elemente im Menü
  3. Speichern Sie die Änderungen und starten Sie Open Server Panel neu, um die Änderungen anzuwenden

Wichtige Information

Achten Sie bei der Erstellung benutzerdefinierter Menüelemente darauf, dass sich die Abschnittkennungen nicht wiederholen. Dies kann zu Konflikten in der Menüfunktionalität führen.

Menüelement-Einstellungen

Sortierreihenfolge: Menüelemente werden in derselben Reihenfolge sortiert wie die entsprechenden Abschnitte in der Vorlage.

caption Titel des Menüelements. Unterstützt Sprachkonstanten im Format {lang_xxx}.

Standard: nicht festgelegt
category

Bestimmt die Position des Elements in der Menühierarchie. Unterstützt eine Verschachtelungsebene (zum Beispiel "Meine Lesezeichen\Arbeit").

Spezielle Kategorien:

  • projects, modules, addons - fügt das Element zum entsprechenden Aktionsmenü hinzu
  • projects\, modules\, addons\ - fügt ein Element für ein bestimmtes Element hinzu

Wenn die Kategorie nicht angegeben ist, wird das Element im Stammmenü erstellt.

Standard: nicht festgelegt
command Befehl, der bei Aktivierung des Menüelements ausgeführt wird. Elemente ohne Befehl werden ignoriert.

Standard: nicht festgelegt
enabled Aktiviert/deaktiviert die Anzeige des Menüelements.

Standard: on | Werte: on, off
hide Steuert die Sichtbarkeit des aufgerufenen Anwendungsfensters. Hat keinen Einfluss auf untergeordnete Prozesse.

Standard: off | Werte: on, off
hr_after Fügt nach dem Menüelement einen horizontalen Trennbalken hinzu.

Standard: off | Werte: on, off
hr_before Fügt vor dem Menüelement einen horizontalen Trennbalken hinzu.

Standard: off | Werte: on, off
icon Symbol aus dem Font Awesome Free Set (Solid/Regular/Brands).

Standard: nicht festgelegt
need_alias Zeigt das Menüelement nur für einen Domain-Alias an. Die Menüvorlage kann nur ein Element mit need_alias=on haben!
Anwendbar für Kategorien: projects

Standard: nicht festgelegt | Werte: on, off
need_category

Beschränkt die Anzeige des Menüelements auf Module/Add-Ons einer bestimmten Kategorie.

Unterstützte Formate:

  • modules, addons
  • modules\, addons\
Standard: nicht festgelegt
need_module_shell Zeigt das Menüelement abhängig vom Vorhandensein von Shell/CLI im übergeordneten Modul an.
Anwendbar für Kategorien: modules, modules\

Standard: nicht festgelegt | Werte: on, off
need_state Zeigt das Menüelement abhängig vom Zustand des übergeordneten Moduls an.
Anwendbar für Kategorien: modules, modules\

Standard: nicht festgelegt | Werte: on, off
need_start_cmd Zeigt das Menüelement an, wenn in den Projekteinstellungen ein Startbefehl vorhanden ist.
Anwendbar für Kategorien: projects, projects\

Standard: nicht festgelegt | Werte: on, off
need_use_wt Zeigt das Menüelement abhängig von der Windows Terminal-Verwendungseinstellung in Open Server Panel an.

Standard: nicht festgelegt | Werte: on, off
work_directory Arbeitsverzeichnis für die Befehlsausführung. Kann während der Befehlsausführung geändert werden.

Standard: {root_dir}

Vorlagenvariablen

Die folgenden Vorlagenvariablen können in den Parametern "command" und "work_directory" verwendet werden:

Allgemeine Variablen

Variable Beschreibung
{root_dir} Open Server Panel Stammverzeichnis (vollständiger Pfad)
{root_drive} Laufwerk des Stammverzeichnisses
{root_path} Pfad zum Open Server Panel Stammverzeichnis
{web_panel_url} Web-Interface-URL

Spezielle Variablen (nur für projects und projects\<domain_name>)

Variable Beschreibung
{base_dir} Projekt-Basisverzeichnis
{host} Domainname (Punycode)
{host_decoded} Sichtbarer Domainname (ohne Punycode)
{host_scheme} Projekt-Anfrageschema ("http" oder "https", abhängig vom SSL-Parameter in den Projekteinstellungen)
{http_port} HTTP-Protokoll-Anfrageport für das Projekt
{https_port} HTTPS-Protokoll-Anfrageport für das Projekt
{menu_caption} Menüelement-Titel (nur für die Kategorie projects mit need_alias=ON)
{nginx_engine} Nginx-Engine
{node_engine} Node.js-Engine
{php_engine} PHP-Engine
{project_dir} Projekt-Stammverzeichnis
{project_url} Projekt-URL
{public_dir} Öffentliches Projektverzeichnis
{scheme_port} Projekt-Anfrageport (":{http_port}" oder ":{https_port}", abhängig vom SSL-Parameter in den Projekteinstellungen). Wenn {http_port} oder {https_port} einen Standardwert von 80 oder 443 hat, dann ist {scheme_port} leer.
{start_command} Projekt-Startbefehl (falls konfiguriert)
{terminal_codepage} Konsolencodierung

Spezielle Befehlswerte

Zusätzlich zu Vorlagenvariablen können Sie auch Windows-Umgebungsvariablen verwenden, wie z.B.: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH% usw.

Anwendungsbeispiele

[21]

caption  = In PhpStorm öffnen
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = Meine Lesezeichen\Suchmaschinen
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

`cmd.exe` Optionen

  • /c: Befehl ausführen und Terminal schließen.
  • /k: Befehl ausführen und Terminal geöffnet lassen.
