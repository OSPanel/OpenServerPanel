Eigene Menüpunkte erstellen

  1. Fügen Sie einen neuen Abschnitt mit einer eindeutigen Kennung [ID] hinzu
  2. Ordnen Sie die Abschnitte in der gewünschten Reihenfolge an – dies bestimmt die Reihenfolge der Punkte im Menü
  3. Speichern Sie die Änderungen und starten Sie Open Server Panel neu, um die Änderungen anzuwenden

Wichtige Information

Achten Sie beim Erstellen eigener Menüpunkte darauf, dass sich die Abschnittskennungen nicht wiederholen. Dies kann zu Konflikten in der Menüfunktion führen.

Menüpunkt-Einstellungen

Sortierreihenfolge: Die Menüpunkte werden in derselben Reihenfolge sortiert, in der die entsprechenden Abschnitte in der Vorlage angeordnet sind.

caption Titel des Menüpunktes. Unterstützt Sprachkonstanten im Format {lang_xxx}.

Standard: nicht festgelegt
category

Bestimmt die Position des Menüpunktes in der Hierarchie. Unterstützt eine Ebene der Verschachtelung (z. B. "Meine Lesezeichen\Arbeit").

Spezielle Kategorien:

  • projects, modules, addons - fügt den Punkt zum entsprechenden Aktionsmenü hinzu
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - fügt einen Punkt für ein konkretes Element hinzu

Wenn keine Kategorie angegeben ist, wird der Punkt im Hauptmenü erstellt.

Standard: nicht festgelegt
command Befehl, der bei Aktivierung des Menüpunktes ausgeführt wird. Punkte ohne Befehl werden ignoriert.

Standard: nicht festgelegt
enabled Aktiviert/deaktiviert die Anzeige des Menüpunktes.

Standard: on | Werte: on, off
hide Steuert die Sichtbarkeit des Fensters der aufgerufenen Anwendung. Beeinflusst keine untergeordneten Prozesse.

Standard: off | Werte: on, off
hr_after Fügt nach dem Menüpunkt einen horizontalen Trenner hinzu.

Standard: off | Werte: on, off
hr_before Fügt vor dem Menüpunkt einen horizontalen Trenner hinzu.

Standard: off | Werte: on, off
icon Icon aus dem Font Awesome Free (Solid/Regular/Brands) Set.

Standard: nicht festgelegt
need_alias Zeigt den Menüpunkt nur für einen Domain-Alias an. In der Menüvorlage darf es nur einen Punkt mit need_alias=on geben!
Anwendbar für Kategorien: projects

Standard: nicht festgelegt | Werte: on, off
need_category

Begrenzt die Anzeige des Menüpunktes auf Module/Addons einer bestimmten Kategorie.

Unterstützte Formate:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Standard: nicht festgelegt
need_module_shell Zeigt den Menüpunkt abhängig von der Verfügbarkeit einer shell/cli des übergeordneten Moduls an.
Anwendbar für Kategorien: modules, modules\<имя_модуля>

Standard: nicht festgelegt | Werte: on, off
need_state Zeigt den Menüpunkt abhängig vom Zustand des übergeordneten Moduls an.
Anwendbar für Kategorien: modules, modules\<имя_модуля>

Standard: nicht festgelegt | Werte: on, off
need_start_cmd Zeigt den Menüpunkt an, wenn in den Projekteinstellungen ein Startbefehl vorhanden ist.
Anwendbar für Kategorien: projects, projects\<имя_домена>

Standard: nicht festgelegt | Werte: on, off
need_use_wt Zeigt den Menüpunkt abhängig von der Einstellung zur Verwendung von Windows Terminal in Open Server Panel an.

Standard: nicht festgelegt | Werte: on, off
work_directory Arbeitsverzeichnis für die Befehlsausführung. Kann während der Befehlsausführung geändert werden.

Standard: {root_dir}

Template-Variablen

In den Parametern "command" und "work_directory" können die folgenden Template-Variablen verwendet werden:

Allgemeine Variablen

Variable Beschreibung
{date_time} Aktuelles Datum/Uhrzeit (Variable ist nur für den Parameter "command" verfügbar)
{root_dir} Stammverzeichnis von Open Server Panel (vollständiger Pfad)
{root_drive} Laufwerk des Stammverzeichnisses
{root_path} Pfad zum Stammverzeichnis von Open Server Panel
{web_panel_url} URL-Adresse der Weboberfläche

Spezielle Variablen (nur für projects und projects\<имя_домена>)

Variable Beschreibung
{base_dir} Basisverzeichnis des Projekts
{host} Domainname (Punycode)
{host_decoded} Sichtbarer Domainname (ohne Punycode)
{host_scheme} Abfrageschema zum Projekt ("http" oder "https", abhängig vom TLS-Parameter in den Projekteinstellungen)
{http_port} Abfrageport zum Projekt über HTTP
{https_port} Abfrageport zum Projekt über HTTPS
{menu_caption} Menüpunkt-Titel (nur für die Kategorie projects mit need_alias=ON)
{http_engine} HTTP-Engine
{node_engine} Node.js-Engine
{php_engine} PHP-Engine
{project_root} Projektstammverzeichnis
{base_url} Projekt-URL
{web_root} Öffentliches Verzeichnis des Projekts
{scheme_port} Abfrageport zum Projekt (":{http_port}" oder ":{https_port}", abhängig vom TLS-Parameter in den Projekteinstellungen). Wenn {http_port} oder {https_port} den Standardwert 80 bzw. 443 hat, ist {scheme_port} leer.
{app_start_command} Startbefehl der Projektanwendung (falls konfiguriert)
{terminal_codepage} Konsolencodierung

Variable Beschreibung

Spezielle Befehlswerte

Befehl Beschreibung
command_open_logs_viewer Protokollanzeige öffnen
command_open_idn_converter IDN-Konverter öffnen
command_open_options Einstellungsfenster des Programms öffnen

Neben den Template-Variablen können beliebige Windows-Umgebungsvariablen verwendet werden, z. B.: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% usw.

Beispiel

[bookmark_1]

caption  = Google
category = Meine Lesezeichen\Suchmaschinen
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE-Optionen

  • /c: Befehl ausführen und Terminal schließen.
  • /k: Befehl ausführen und Terminal geöffnet lassen.
