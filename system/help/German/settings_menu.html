Designthema
Designthema für Menüsymbole.
Schriftgröße
Schriftgröße des Menüs in Pixeln. Mit dieser Option können Sie die Schriftgröße des Menüs unabhängig von den Systemeinstellungen festlegen.

Stellen Sie den Schieberegler auf den Minimalwert 12px, um die Schriftgrößenkontrollfunktion zu deaktivieren (es wird die Systemgröße verwendet).
Symbol im Benachrichtigungsbereich anzeigen
Programmsymbol im Windows-Benachrichtigungsbereich anzeigen.

Deaktivierung: Deaktivieren Sie diese Option, wenn Sie Open Server Panel in einer Windows Server Core-Umgebung ausführen oder einen Autostart-Typ verwenden, der keine Windows-Benutzeranmeldung erfordert (Windows-Aufgabenplanung→Beim Computerstart ausführen).
Symbole für Menüpunkte anzeigen
Symbole im Programmmenü anzeigen. Symbole werden nicht angezeigt, wenn die Systemdarstellung aktiviert ist.
Systemdarstellung aktivieren
Aktivieren Sie diese Option nur, wenn es für die Kompatibilität mit Bildschirmleseprogrammen (Screen-Readern) erforderlich ist.
Vertikalen Trennstrich anzeigen
Wenn diese Option aktiviert ist, werden Symbole im Programmmenü durch einen vertikalen Trennstrich getrennt.
