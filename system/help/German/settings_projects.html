Globale Projekteinstellungen

Die in diesem Abschnitt festgelegten Parameter werden verwendet, wenn in den Projekteinstellungen keine anderen Werte angegeben sind.

Nginx
Bestimmt die verwendete Version des Nginx-Webservers für Projekte.
Node
Gibt die Node.js-Engine zum Ausführen von Node.js-Anwendungen an.

Node.js-Installation: Installieren Sie vorher die gewünschte Node.js-Version mit dem NVM-Add-on.
PHP
Bestimmt die PHP-Engine, die zur Verarbeitung von PHP-Dateien verwendet wird.

Wichtig: PHP-Module ohne FCGI-Präfix sind integrierte Apache+PHP-Module.
Aktivieren
Bestimmt den Standardzustand des Projekts (aktiviert oder deaktiviert).
Terminal-Codierung
Die Zeichencodierung des Terminals bei der Arbeit mit der Projektumgebung.

Spezielle Werte:
- system: Die Systemcodierung wird verwendet.

Wichtig: Wenn kein Wert angegeben ist, wird bei der Erstellung der endgültigen Projektumgebung die Terminal-Codierung durch die zuletzt verbundene Umgebung festgelegt, in der sie definiert ist, z.B. durch die PHP-Modulumgebung.
IP
Legt die IP-Adresse(n) fest, die von allen Projekten ohne individuelle Einstellungen verwendet werden.

Einschränkung: Projekte, die dieselbe IP-Adresse verwenden, müssen mit derselben PHP-Version arbeiten.

Unterstützung mehrerer IPs: Sie können mehrere IP-Adressen durch Leerzeichen getrennt angeben, einschließlich IPv6. In der HOSTS-Datei wird den Domains die erste angegebene IP zugewiesen.

Automatische Zuweisung: Wenn Sie das Feld leer lassen, wird die IP-Adresse automatisch zugewiesen.

Empfehlungen:
  • Die automatische IP-Adressverwaltung wird für die meisten Benutzer empfohlen.
  • Eine manuelle IP-Adresszuweisung sollte nur bei spezifischen Netzwerkkonfigurationsanforderungen verwendet werden.
HTTP
Definiert den Port für HTTP-Verbindungen.
HTTPS
Definiert den Port für HTTPS-Verbindungen.
SSL
Aktiviert oder deaktiviert die SSL-Unterstützung für Projekte ohne individuelle Einstellungen.
Zertifikatsdatei
Gibt den Pfad zur SSL-Zertifikatsdatei an. Vorlagenvariablen können verwendet werden.

Zulässige Zeichen: A-Za-z0-9-+_.\:

Empfehlung: Lassen Sie das Feld leer, um Zertifikate automatisch zu generieren.
Schlüsseldatei
Gibt den Pfad zur SSL-Schlüsseldatei an. Vorlagenvariablen können verwendet werden.

Zulässige Zeichen: A-Za-z0-9-+_.\:

Empfehlung: Lassen Sie das Feld leer, um den Schlüssel automatisch zu generieren.
Projektverzeichnis
Gibt das Stammverzeichnis des Projekts an. Der Wechsel in dieses Verzeichnis erfolgt mit dem Befehl osp project <DOMAIN> gleichzeitig mit der Aktivierung der Projektumgebung. Vorlagenvariablen können verwendet werden.

Erlaubte Zeichen: A-Za-z0-9-+_.\:
Öffentliches Verzeichnis
Definiert das öffentliche Verzeichnis des Projekts. Vorlagenvariablen können verwendet werden.

Erlaubte Zeichen: A-Za-z0-9-+_.\:
Aliase
Gibt zusätzliche Domainnamen (Aliase) für das Projekt an (durch Leerzeichen getrennt). Vorlagenvariablen können verwendet werden.

Subdomains: Wenn ein Alias keinen Punkt enthält, wird er als Subdomain betrachtet (z.B. "www" -> "www.test.local").

Einschränkung: Das Zeichen "*" wird unter Windows in der HOSTS-Datei nicht unterstützt und erfordert eine DNS-Konfiguration.
Projektumgebung
Liste der Add-ons und Module (durch Leerzeichen getrennt), die die Projektumgebung bilden.

PHP/Nginx/Node.js-Module: Die Umgebungen dieser Module werden immer verbunden (wenn sie für die Domain festgelegt sind) und müssen in diesem Parameter nicht angegeben werden.
Projektstart-Befehl
Definiert den Befehl zum Starten des Projekts (z.B. nodemon app.js). Vorlagenvariablen können verwendet werden.
Projekt-URL
URL, die geöffnet wird, wenn Projekt im Browser öffnen im Open Server Panel ausgewählt wird. Vorlagenvariablen können verwendet werden.

Anwendung: Sie können eine URL für das CMS-Administrationsbereich festlegen.

Vorlagenvariablen

Variable Beschreibung
{base_dir} Stammverzeichnis des Projekts (wo sich das .osp-Verzeichnis befindet)
{host} Domainname (für internationalisierte Domains wird Punycode verwendet)
{host_decoded} Sichtbarer Domainname (ohne Punycode)
{host_scheme} Anfrageschema des Projekts ("http" oder "https", abhängig vom SSL-Parameter in den Projekteinstellungen)
{http_port} Anfrageport des Projekts über das HTTP-Protokoll
{https_port} Anfrageport des Projekts über das HTTPS-Protokoll
{nginx_engine} Nginx-Engine
{node_engine} Node.js-Engine
{php_engine} PHP-Engine
{project_dir} Stammverzeichnis des Projekts
{public_dir} Öffentliches Verzeichnis des Projekts
{scheme_port} Anfrageport des Projekts (":{http_port}" oder ":{https_port}", abhängig vom SSL-Parameter in den Projekteinstellungen).

Wenn {http_port} oder {https_port} den Standardwert 80 oder 443 hat, dann wird {scheme_port} leer sein.
{root_dir} Stammverzeichnis von Open Server Panel (vollständiger Pfad)
{root_drive} Laufwerk des Stammverzeichnisses
{root_path} Pfad zum Stammverzeichnis von Open Server Panel
{terminal_codepage} Konsolencodierung
