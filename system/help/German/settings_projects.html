Globale Projekteinstellungen

Die in diesem Abschnitt festgelegten Parameter werden verwendet, wenn in den Projekteinstellungen keine anderen Werte angegeben sind.

HTTP
Legt das verwendete Webserver-Modul für Projekte fest.
NODE
Gibt die Node.js-Engine zum Starten von Node.js-Anwendungen an.

Installation von Node.js: Installieren Sie zuvor die gewünschte Node.js-Version mit dem Befehl osp node <latest|lts|номер>.
PHP
Legt das verwendete PHP-Modul zur Verarbeitung von PHP-Dateien fest.
Aktivieren
Legt den Standardzustand des Projekts fest (ein- oder ausgeschaltet).
Terminal-Codierung
Codierung des Terminals bei der Arbeit mit der Projektumgebung.

Spezielle Werte:
- system: Es wird die Systemcodierung verwendet.

Wichtig: Wenn kein Wert angegeben ist, wird die Terminal-Codierung bei der Bildung der endgültigen Projektumgebung von der zuletzt eingebundenen Umgebung übernommen, in der sie festgelegt ist, z. B. von der Umgebung des PHP-Moduls.
IP
Legt die IP-Adresse(n) fest, die von allen Projekten ohne individuelle Einstellungen verwendet werden.

Einschränkung: Projekte, die dieselbe IP-Adresse verwenden, müssen auf derselben PHP-Version laufen.

Unterstützung mehrerer IPs: Es können mehrere IP-Adressen durch Leerzeichen angegeben werden, einschließlich IPv6. In der HOSTS-Datei wird den Domains die zuerst angegebene IP zugewiesen.

Automatische Zuweisung: Wenn das Feld leer bleibt, wird die IP-Adresse automatisch zugewiesen.

Empfehlungen:
  • Die automatische Verwaltung der IP-Adressen wird den meisten Nutzern empfohlen.
  • Die manuelle Festlegung der IP-Adresse sollte nur bei spezifischen Anforderungen der Netzwerkkonfiguration verwendet werden.
HTTP
Legt den Port für HTTP-Verbindungen fest.
HTTPS
Legt den Port für HTTPS-Verbindungen fest.
TLS
Aktiviert oder deaktiviert die Unterstützung von TLS.
Zertifikat-Datei
Gibt den Pfad zur TLS-Zertifikatdatei an. Platzhaltervariablen können verwendet werden.

Zulässige Zeichen: A-Za-z0-9-+_.\:

Empfehlung: Lassen Sie das Feld leer für die automatische Generierung von Zertifikaten.
Schlüssel-Datei
Gibt den Pfad zur TLS-Schlüsseldatei an. Platzhaltervariablen können verwendet werden.

Zulässige Zeichen: A-Za-z0-9-+_.\:

Empfehlung: Lassen Sie das Feld leer für die automatische Generierung des Schlüssels.
IP-Adresse (Backend)
Gibt die IP-Adresse an, über die die Verbindung zum Backend hergestellt wird.
Port (Backend)
Legt die Portnummer für die Verbindung zum Backend fest.
Aktivieren (Backend)
Ermöglicht das automatische Weiterleiten des gesamten eingehenden Projektverkehrs (HTTP und HTTPS) an das Backend. Nützlich für Tests oder Entwicklung, wenn Frontend und Backend getrennt sind.
Projektverzeichnis
Gibt das Projektstammverzeichnis an. Der Wechsel in dieses Verzeichnis erfolgt mit dem Befehl osp project <DOMAIN> gleichzeitig mit der Aktivierung der Projektumgebung. Platzhaltervariablen können verwendet werden.

Zulässige Zeichen: A-Za-z0-9-+_.\:
Öffentliches Verzeichnis
Legt das öffentliche Verzeichnis des Projekts fest. Platzhaltervariablen können verwendet werden.

Zulässige Zeichen: A-Za-z0-9-+_.\:
Aliasse
Gibt zusätzliche Domainnamen (Aliasse) für das Projekt an (durch Leerzeichen getrennt). Platzhaltervariablen können verwendet werden.

Einschränkung: Das Zeichen "*" wird unter Windows von der HOSTS-Datei nicht unterstützt und erfordert eine DNS-Konfiguration.
Projektumgebung
Liste der Add-ons und Module (durch Leerzeichen), die die Projektumgebung bilden.

HTTP, NODE und PHP: Die Umgebungen dieser Engines werden immer eingebunden (sofern für die Domain festgelegt) und müssen in diesem Parameter nicht angegeben werden.
Projekt-Startbefehl
Legt den Befehl zum Starten des Projekts fest (z. B. nodemon app.js). Platzhaltervariablen können verwendet werden.
Projekt-URL
Die URL, die beim Öffnen des Projekts über Menü→Projekt→Im Browser öffnen sowie beim Öffnen von Domainaliasen des Projekts verwendet wird. Platzhaltervariablen können verwendet werden.

Verwendung: Es kann die URL des Admin-Panels einer CMS angegeben werden.

Platzhaltervariablen

Variable Beschreibung
{backend_ip} IP-Adresse der Verbindung zum Backend
{backend_port} Port der Verbindung zum Backend
{base_dir} Stammverzeichnis des Projekts (wo sich das Verzeichnis .osp befindet)
{date_time} Aktuelles Datum/Uhrzeit (Variable ist nur für den Startbefehl der Projektanwendung verfügbar)
{host} Domainname (für internationalisierte Domains wird Punycode verwendet)
{host_decoded} Sichtbarer Domainname (ohne Punycode)
{host_scheme} Anfrageschema zum Projekt ("http" oder "https", abhängig vom TLS-Parameter in den Projekteinstellungen)
{http_port} Port der Anfrage zum Projekt über das HTTP-Protokoll
{https_port} Port der Anfrage zum Projekt über das HTTPS-Protokoll
{http_engine} HTTP-Engine
{node_engine} NODE-Engine
{php_engine} PHP-Engine
{project_root} Stammverzeichnis des Projekts
{web_root} Öffentliches Verzeichnis des Projekts
{scheme_port} Anfrageport zum Projekt (":{http_port}" oder ":{https_port}", abhängig vom TLS-Parameter in den Projekteinstellungen).

Wenn {http_port} oder {https_port} den Standardwert 80 bzw. 443 hat, ist {scheme_port} leer.
{root_dir} Stammverzeichnis von Open Server Panel (vollständiger Pfad)
{root_drive} Laufwerk des Stammverzeichnisses
{root_path} Pfad zum Stammverzeichnis von Open Server Panel
{terminal_codepage} Konsolencodierung
