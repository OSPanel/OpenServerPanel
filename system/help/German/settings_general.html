Programmeinstellungen

Mit Windows starten
Autostart von Open Server Panel beim Hochfahren des Betriebssystems aktivieren.
Verzögerung
Verzögerung des Programmstarts (in Sekunden, von 0 bis 60).

Ermöglicht es, den Start der Anwendung zu verzögern, um die Systemlast beim Hochfahren zu verringern. Dies ist besonders nützlich, wenn auf die vollständige Initialisierung von Drittanbieterdiensten oder Netzwerkschnittstellen gewartet werden muss.
Nach neuen Versionen suchen
Aktivieren der Aktualisierungsprüfung für Open Server Panel (Internetverbindung erforderlich).
Aufgabenplaner aktivieren
Den integrierten Aufgabenplaner aktivieren. Wenn dieser Parameter deaktiviert ist, werden keine geplanten Aufgaben ausgeführt, unabhängig von ihrem Status.
HOSTS-Datei verwenden
Aktivieren des Schreibens von Domainnamen in die HOSTS-Datei.

Empfehlungen bei eingeschränktem Zugriff auf die HOSTS-Datei in Organisationen:

1. Konfigurieren Sie alle erforderlichen Module und Projekte.
2. Wenden Sie sich an Ihren Systemadministrator, um die HOSTS-Datei zu entsperren und ihren Zustand zu fixieren.
3. Nachdem der Administrator die Änderungen festgelegt hat, können Sie diese Option deaktivieren.

Wichtig: Deaktivieren Sie diesen Parameter nicht, wenn Sie sich über die Folgen nicht im Klaren sind!
Module mit Projektprofil starten
Module mit gleichzeitiger Aktivierung eines Profils starten, das dem Projektnamen entspricht.

Wird verwendet, wenn der Menüpunkt "Projektmodule aktivieren" ausgewählt wird, um automatisch ein Profil mit demselben Namen wie das aktuelle Projekt zu aktivieren, sofern ein solches existiert.
Module ausgeblendeter Projekte nicht deaktivieren
Die Module ausgeblendeter Projekte werden beim Auswählen der Menüoption "Alle Module deaktivieren" nicht deaktiviert. Standardmäßig stoppt der Befehl "Alle Module deaktivieren" die Arbeit aller Module, einschließlich derjenigen, die von Hilfsprojekten verwendet werden (z.B. PHPMyAdmin). Diese Option ermöglicht es, die Funktionalität ausgeblendeter Hilfsprojekte zu erhalten, indem die dafür erforderlichen Module nicht deaktiviert werden, während alle anderen Module deaktiviert werden.
Oberflächensprache
Benutzeroberflächen-Sprache für Open Server Panel.

Wenn die Lokalisierungsdatei fehlt oder Fehler enthält, wird Englisch verwendet.
API-Domain
Lokale Domain für API und Weboberfläche (in Entwicklung)

Empfehlung: Bei Verwendung von VPN oder Proxy fügen Sie diese Domain zu den Ausnahmen hinzu.
API-IP-Adresse
IPv4-Adresse für API und Weboberfläche (in Entwicklung).

Empfehlung: Bei Verwendung von VPN oder Proxy fügen Sie diese IP-Adresse zu den Ausnahmen hinzu.
API-Port
Port für API und Weboberfläche (in Entwicklung). Open Server Panel kann nicht gestartet werden, wenn der angegebene Port bereits von einer anderen Anwendung verwendet wird.
Windows Terminal verwenden
Aktivieren der Verwendung von Windows Terminal anstelle der Standardbefehlsschnittstelle.

Anforderungen: Windows Terminal muss im System installiert und in der PATH-Umgebungsvariable definiert sein.

Windows Terminal als cmd.exe: Windows Terminal kann in neueren Windows-Versionen cmd.exe ersetzen und in der Umgebungsvariable %COMSPEC% definiert sein. Ist dies der Fall, lassen Sie diese Option aktiviert.

Neue Windows Terminal-Instanzen: Wenn Windows Terminal neue Fenster statt Tabs öffnet, konfigurieren Sie es wie folgt: Einstellungen→Start→Verhalten der neuen Instanz→Am zuletzt verwendeten Fenster anhängen.
Kurzer Projekttitel
Wenn diese Option aktiviert ist, wird nur der Projektname im Fenstertitel des Terminals angezeigt, anstatt einer detaillierten Beschreibung.
Systemumgebung in Projektumgebung einbeziehen
Die Systemumgebung (System) im Terminal verwenden, auch wenn sie nicht in den Projekteinstellungen angegeben ist. Die Systemumgebung ermöglicht die Verwendung von im System installierten Programmen (wie git.exe oder ssh.exe).

Deaktivieren Sie diese Option nur, wenn Konflikte mit Systemsoftware auftreten.
ANSI-Unterstützung
Unterstützung für ANSI-Codes zur Steuerung von Farben im Terminal aktivieren.

"Automatischer" Modus (Standard):
- Die Korrektur wird nur auf Windows 7, 8 und Windows 10 (bis einschließlich Version 1903) angewendet. In neueren Windows-Versionen ist die ANSI-Code-Unterstützung bereits integriert.
- Die Korrektur wird nicht auf Terminals angewendet, die ANSI standardmäßig unterstützen (z.B. Windows Terminal).
Projektsuche-Verzeichnisse
Liste der Verzeichnisse, in denen Open Server Panel nach Projekten sucht. Trennen Sie Pfade durch Semikolons (;).

Ausschlüsse: Unterverzeichnisse node_modules und vendor werden ignoriert.
Tiefe
Maximale Verzeichnisschachtelungstiefe bei der Suche nach Projekten.

Eine Erhöhung dieses Wertes kann den Start von Open Server Panel verlangsamen, wenn die angegebenen Verzeichnisse eine große Anzahl von Unterverzeichnissen enthalten.
Maximale Protokolldateigröße
Maximale Größe der Protokolldatei in Megabyte. Wenn der angegebene Wert überschritten wird, wird die Protokolldatei beim nächsten Programmstart neu erstellt.

Setzen Sie den Wert auf 0, um Protokolldateien bei jedem Programmstart zu löschen.

Setzen Sie den Wert auf 100 MB, um die Bereinigung von Protokolldateien vollständig zu deaktivieren.
