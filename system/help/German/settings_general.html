Programmeinstellungen

Beim Start von Windows ausführen
Automatischen Start von Open Server Panel beim Laden des Betriebssystems aktivieren.
Verzögerung
Startverzögerung des Programms (in Sekunden, von 0 bis 60).

Ermöglicht es, den Start der Anwendung während des Systemstarts zusammen mit Windows zu verzögern, um die Gesamtbelastung des Systems zu verringern. Dies ist besonders nützlich, wenn auf die vollständige Initialisierung externer Dienste oder Netzwerkschnittstellen gewartet werden muss.
Auf neue Versionen prüfen
Prüfung auf Updates von Open Server Panel aktivieren (Internetverbindung erforderlich).
Aufgabenplaner aktivieren
Den integrierten Aufgabenplaner aktivieren. Wenn der Parameter deaktiviert ist, werden keine geplanten Aufgaben ausgeführt, unabhängig von ihrem Status.
HOSTS-Datei verwenden
Eintragen von Domainnamen in die HOSTS-Datei aktivieren.

Empfehlungen bei eingeschränktem Zugriff auf die HOSTS-Datei in der Organisation:

1. Richten Sie alle erforderlichen Module und Projekte ein.
2. Wenden Sie sich an den Systemadministrator, um die HOSTS-Datei zu entsperren und ihren Zustand zu fixieren.
3. Nach der Fixierung der Änderungen durch den Administrator kann diese Option deaktiviert werden.

Wichtig: Deaktivieren Sie diesen Parameter nicht, wenn Sie sich nicht über die Folgen im Klaren sind!
Module mit dem Projektprofil starten
Module mit gleichzeitiger Aktivierung eines Profils starten, das mit dem Projektnamen übereinstimmt.

Wird verwendet, wenn der Menüpunkt „Projektmodule einschalten“ ausgewählt wird, um das Profil mit demselben Namen wie das aktuelle Projekt automatisch zu aktivieren, falls ein solches existiert.
Module versteckter Projekte nicht ausschalten
Module versteckter Projekte nicht ausschalten, wenn der Menüpunkt „Alle Module ausschalten“ gewählt wird. Unter „versteckt“ sind Projekte zu verstehen, für die die Kategorie „hidden“ festgelegt ist.

Standardmäßig stoppt der Befehl „Alle Module ausschalten“ die Arbeit absolut aller Module, einschließlich derjenigen, die von versteckten Systemprojekten verwendet werden (zum Beispiel PHPMyAdmin). Diese Option ermöglicht es, die Funktionsfähigkeit versteckter Systemprojekte zu erhalten, ohne die dafür benötigten Module zu deaktivieren, während alle anderen Module ausgeschaltet werden.
Sprache der Benutzeroberfläche
Sprache der Benutzeroberfläche von Open Server Panel.

Wenn die Lokalisierungsdatei fehlt oder Fehler enthält, wird Englisch verwendet.
API-Domain
Lokale Domain für API und Weboberfläche (in Entwicklung)

Empfehlung: Wenn VPN oder Proxy verwendet wird, fügen Sie diese Domain zu den Ausnahmen hinzu.
API-IP-Adresse
IPv4-Adresse für API und Weboberfläche (in Entwicklung).

Empfehlung: Wenn VPN oder Proxy verwendet wird, fügen Sie diese IP-Adresse zu den Ausnahmen hinzu.
API-Port
Port, der für API und Weboberfläche verwendet wird (in Entwicklung). Open Server Panel kann nicht gestartet werden, wenn der angegebene Port bereits von einer anderen Anwendung verwendet wird.
Windows Terminal verwenden
Verwendung von Windows Terminal anstelle der standardmäßigen Befehlsoberfläche aktivieren.

Anforderungen: Windows Terminal muss im System installiert und in der Umgebungsvariable PATH eingetragen sein.

Windows Terminal als cmd.exe: Windows Terminal kann cmd.exe ersetzen und in der Umgebungsvariable %COMSPEC% in neuen Windows-Versionen eingetragen sein. Wenn dies der Fall ist, lassen Sie diese Option aktiviert.

Neue Instanzen von Windows Terminal: Wenn Windows Terminal neue Fenster statt Tabs öffnet, konfigurieren Sie es wie folgt: Einstellungen→Start→Verhalten neuer Instanzen→An letztes verwendetes Fenster anheften.
Kurzer Projekttitel
Wenn diese Option aktiviert ist, wird im Fenstertitel des Terminals nur der Projektname anstelle einer detaillierten Beschreibung der Umgebung angezeigt.
Systemumgebung in die Projektumgebung einbeziehen
Systemumgebung (System) im Terminal verwenden, auch wenn sie in den Projekteinstellungen nicht festgelegt ist. Die Systemumgebung ermöglicht die Nutzung von im System installierten Programmen (z. B. git.exe oder ssh.exe).

Deaktivieren Sie diese Option nur bei Konflikten mit Systemsoftware.
ANSI-Unterstützung
Unterstützung von ANSI-Codes zur Farbsteuerung im Terminal aktivieren.

Modus „Automatisch“ (Standard):
- Der Fix wird nur auf Windows 10 bis einschließlich Version 1903 angewendet. In neueren Windows-Versionen ist die Unterstützung von ANSI-Codes bereits integriert.
- Der Fix wird nicht auf Terminals angewendet, die ANSI standardmäßig unterstützen (z. B. Windows Terminal).
Verzeichnisse zur Projektsuche
Liste der Verzeichnisse, in denen Open Server Panel nach Projekten sucht. Trennen Sie Pfade mit einem Semikolon (;).

Ausnahmen: Unterverzeichnisse node_modules und vendor werden ignoriert.
Tiefe
Maximale Verzeichnistiefe bei der Projektsuche.

Die Erhöhung dieses Wertes kann den Start von Open Server Panel verlangsamen, wenn die angegebenen Verzeichnisse eine große Anzahl von Unterverzeichnissen enthalten.
Maximale Protokolldateigröße
Maximale Größe der Protokolldatei in Megabytes. Bei Überschreitung des angegebenen Wertes wird die Logdatei beim nächsten Programmstart neu erstellt.

Setzen Sie den Wert auf 0, um die Protokolle bei jedem Programmstart zu löschen.

Setzen Sie den Wert auf 100 MB, um die Protokollbereinigung vollständig zu deaktivieren.
