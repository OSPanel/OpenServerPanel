Tworzenie własnych pozycji menu

  1. Dodaj nową sekcję z unikalnym identyfikatorem [ID]
  2. Ułóż sekcje w żądanej kolejności — to określi kolejność pozycji w menu
  3. Zapisz zmiany i uruchom ponownie Open Server Panel, aby zastosować zmiany

Ważne informacje

Podczas tworzenia własnych pozycji menu upewnij się, że identyfikatory sekcji się nie powtarzają. Może to prowadzić do konfliktów w działaniu menu.

Ustawienia pozycji menu

Kolejność sortowania: Pozycje menu są sortowane w takiej samej kolejności, w jakiej rozmieszczone są odpowiednie sekcje w szablonie.

caption Tytuł pozycji menu. Wspiera stałe językowe w formacie {lang_xxx}.

Domyślnie: nie ustawiono
category

Określa położenie pozycji menu w hierarchii. Obsługuje jeden poziom zagnieżdżenia (np. "Moje Zakładki\Praca").

Specjalne kategorie:

  • projects, modules, addons - dodaje pozycję do odpowiedniego menu działań
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - dodaje pozycję dla konkretnego elementu

Jeśli kategoria nie jest podana, pozycja tworzona jest w menu głównym.

Domyślnie: nie ustawiono
command Komenda do wykonania po aktywacji pozycji menu. Pozycje bez komendy są ignorowane.

Domyślnie: nie ustawiono
enabled Włącza/wyłącza wyświetlanie pozycji menu.

Domyślnie: on | Wartości: on, off
hide Kontroluje widoczność okna wywoływanej aplikacji. Nie wpływa na procesy potomne.

Domyślnie: off | Wartości: on, off
hr_after Dodaje poziomy separator po pozycji menu.

Domyślnie: off | Wartości: on, off
hr_before Dodaje poziomy separator przed pozycją menu.

Domyślnie: off | Wartości: on, off
icon Ikona z zestawu Font Awesome Free (Solid/Regular/Brands).

Domyślnie: nie ustawiono
need_alias Wyświetla pozycję menu tylko dla aliasu domenowego. W szablonie menu może być tylko jedna pozycja z need_alias=on!
Dotyczy kategorii: projects

Domyślnie: nie ustawiono | Wartości: on, off
need_category

Ogranicza wyświetlanie pozycji menu do modułów/dodatków określonej kategorii.

Obsługiwane formaty:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Domyślnie: nie ustawiono
need_module_shell Wyświetla pozycję menu w zależności od dostępności shell/cli u nadrzędnego modułu.
Dotyczy kategorii: modules, modules\<имя_модуля>

Domyślnie: nie ustawiono | Wartości: on, off
need_state Wyświetla pozycję menu w zależności od stanu nadrzędnego modułu.
Dotyczy kategorii: modules, modules\<имя_модуля>

Domyślnie: nie ustawiono | Wartości: on, off
need_start_cmd Wyświetla pozycję menu, gdy w ustawieniach projektu dostępna jest komenda uruchomienia.
Dotyczy kategorii: projects, projects\<имя_домена>

Domyślnie: nie ustawiono | Wartości: on, off
need_use_wt Wyświetla pozycję menu w zależności od ustawienia użycia Windows Terminal w Open Server Panel.

Domyślnie: nie ustawiono | Wartości: on, off
work_directory Katalog roboczy do wykonania komendy. Może zmieniać się w trakcie wykonywania komend.

Domyślnie: {root_dir}

Zmienne szablonowe

W parametrach "command" i "work_directory" można używać następujących zmiennych szablonowych:

Zmienne ogólne

Zmienna Opis
{date_time} Aktualna data/godzina (zmienna dostępna tylko dla parametru "command")
{root_dir} Katalog główny Open Server Panel (pełna ścieżka)
{root_drive} Dysk katalogu głównego
{root_path} Ścieżka do katalogu głównego Open Server Panel
{web_panel_url} Adres URL interfejsu web

Zmienne specjalne (tylko dla projects i projects\<имя_домена>)

Zmienna Opis
{base_dir} Katalog bazowy projektu
{host} Nazwa domeny (Punycode)
{host_decoded} Widoczna nazwa domeny (bez Punycode)
{host_scheme} Schemat żądania do projektu ("http" lub "https", zależy od parametru TLS w ustawieniach projektu)
{http_port} Port żądania do projektu przez protokół HTTP
{https_port} Port żądania do projektu przez protokół HTTPS
{menu_caption} Tytuł pozycji menu (tylko dla kategorii projects z need_alias=ON)
{http_engine} Silnik HTTP
{node_engine} Silnik Node.js
{php_engine} Silnik PHP
{project_root} Katalog główny projektu
{base_url} URL projektu
{web_root} Katalog publiczny projektu
{scheme_port} Port żądania do projektu (":{http_port}" lub ":{https_port}", zależy od parametru TLS w ustawieniach projektu). Jeśli {http_port} lub {https_port} ma standardową wartość 80 lub 443, to {scheme_port} będzie pusty.
{app_start_command} Komenda uruchomienia aplikacji projektu (jeśli skonfigurowana)
{terminal_codepage} Kodowanie konsoli

Zmienne specjalne (tylko dla addons i addons\<имя_дополнения>)

Zmienna Opis
{addon_name} Nazwa dodatku
{terminal_codepage} Kodowanie konsoli

Zmienne specjalne (tylko dla modules i modules\<имя_модуля>)

Zmienna Opis
{ip} Adres IP modułu
{log_level} Poziom logowania błędów
{module_name} Nazwa modułu
{port} Port modułu
{profile_name} Nazwa bieżącego profilu ustawień modułu
{query_log_level} Poziom logowania zapytań
{shell_command} Komenda uruchomienia powłoki shell/cli modułu (jeśli skonfigurowana)
{terminal_codepage} Kodowanie konsoli
{time_zone} Strefa czasowa

Specjalne wartości komend

Komenda Opis
command_open_logs_viewer Otwórz okno podglądu logów
command_open_idn_converter Otwórz konwerter IDN
command_open_options Otwórz okno ustawień programu

Oprócz zmiennych szablonowych można używać dowolnych zmiennych środowiskowych Windows, na przykład: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% itd.

Przykład użycia

[bookmark_1]

caption  = Google
category = Moje Zakładki\Wyszukiwarki
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opcje CMD.EXE

  • /c: Wykonaj komendę i zamknij terminal.
  • /k: Wykonaj komendę i pozostaw terminal otwarty.
