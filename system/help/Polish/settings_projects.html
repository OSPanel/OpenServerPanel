Globalne ustawienia projektów

Parametry określone w tej sekcji są używane, jeśli w ustawieniach projektu nie podano innych wartości.

HTTP
Określa używany moduł serwera WWW dla projektów.
NODE
Wskazuje silnik Node.js do uruchamiania aplikacji Node.js.

Instalacja Node.js: Wcześniej zainstaluj wymaganą wersję Node.js za pomocą polecenia osp node <latest|lts|номер>.
PHP
Określa używany moduł PHP do obsługi plików PHP.
Włącz
Określa domyślny stan projektu (włączony lub wyłączony).
Kodowanie terminala
Kodowanie terminala podczas pracy ze środowiskiem projektu.

Wartości specjalne:
- system: Używane jest kodowanie systemowe.

Ważne: Jeśli wartość nie jest ustawiona, przy tworzeniu końcowego środowiska projektu kodowanie terminala zostanie ustawione przez ostatnio dołączone środowisko, w którym jest ono określone, na przykład środowisko modułu PHP.
IP
Ustawia adres(y) IP używany przez wszystkie projekty bez indywidualnych ustawień.

Ograniczenie: Projekty używające tego samego adresu IP muszą działać na jednej wersji PHP.

Obsługa wielu IP: Można podać kilka adresów IP oddzielonych spacją, w tym IPv6. W pliku HOSTS domenom zostanie przypisany pierwszy podany IP.

Automatyczne przypisanie: Jeśli pole pozostanie puste, adres IP będzie przypisywany automatycznie.

Rekomendacje:
  • Automatyczne zarządzanie adresami IP jest zalecane dla większości użytkowników.
  • Ręczne ustawienie adresu IP należy stosować tylko przy specyficznych wymaganiach konfiguracji sieci.
HTTP
Określa port dla połączeń HTTP.
HTTPS
Określa port dla połączeń HTTPS.
TLS
Włącza lub wyłącza obsługę TLS.
Plik certyfikatu
Określa ścieżkę do pliku certyfikatu TLS. Można używać zmiennych szablonowych.

Dozwolone znaki: A-Za-z0-9-+_.\:

Rekomendacja: Pozostaw pole puste, aby generować certyfikaty automatycznie.
Plik klucza
Określa ścieżkę do pliku klucza TLS. Można używać zmiennych szablonowych.

Dozwolone znaki: A-Za-z0-9-+_.\:

Rekomendacja: Pozostaw pole puste, aby generować klucz automatycznie.
Adres IP (backend)
Wskazuje adres IP, pod którym realizowane jest połączenie z częścią serwerową (Backend).
Port (backend)
Określa numer portu do połączenia z częścią serwerową (Backend).
Włącz (backend)
Umożliwia automatyczne kierowanie całego przychodzącego ruchu (HTTP i HTTPS) projektu do części serwerowej (Backend). Przydatne do testów lub rozwoju, gdy frontend i backend są rozdzielone.
Katalog projektu
Określa katalog główny projektu. Przejście do tego katalogu odbywa się poleceniem osp project <DOMAIN> jednocześnie z aktywacją środowiska projektu. Można używać zmiennych szablonowych.

Dozwolone znaki: A-Za-z0-9-+_.\:
Katalog publiczny
Określa publiczny katalog projektu. Można używać zmiennych szablonowych.

Dozwolone znaki: A-Za-z0-9-+_.\:
Pseudonimy
Określa dodatkowe nazwy domen (aliasy) dla projektu (oddzielone spacją). Można używać zmiennych szablonowych.

Ograniczenie: Symbol "*" nie jest obsługiwany w Windows przez plik HOSTS i wymaga konfiguracji DNS.
Środowisko projektu
Wykaz dodatków i modułów (oddzielonych spacją), które tworzą środowisko projektu.

HTTP, NODE i PHP: Środowiska tych silników są dołączane zawsze (jeśli są ustawione dla domeny) i nie wymagają wskazania w tym parametrze.
Polecenie uruchomienia projektu
Określa polecenie do uruchomienia projektu (na przykład nodemon app.js). Można używać zmiennych szablonowych.
URL projektu
URL używany przy otwieraniu projektu przez Menu→Projekt→Otwórz w przeglądarce, a także przy otwieraniu aliasów domenowych projektu. Można używać zmiennych szablonowych.

Zastosowanie: Można podać URL panelu administracyjnego CMS.

Zmienne szablonowe

Zmienna Opis
{backend_ip} Adres IP połączenia z częścią serwerową (Backend)
{backend_port} Port połączenia z częścią serwerową (Backend)
{base_dir} Katalog główny projektu (gdzie znajduje się katalog .osp)
{date_time} Bieżąca data/czas (zmienna dostępna tylko dla polecenia uruchomienia aplikacji projektu)
{host} Nazwa domeny (dla zinternacjonalizowanych domen używany jest Punycode)
{host_decoded} Widoczna nazwa domeny (bez Punycode)
{host_scheme} Schemat żądania do projektu ("http" lub "https", zależy od parametru TLS w ustawieniach projektu)
{http_port} Port żądania do projektu przez protokół HTTP
{https_port} Port żądania do projektu przez protokół HTTPS
{http_engine} Silnik HTTP
{node_engine} Silnik NODE
{php_engine} Silnik PHP
{project_root} Katalog główny projektu
{web_root} Katalog publiczny projektu
{scheme_port} Port żądania do projektu (":{http_port}" lub ":{https_port}", zależy od parametru TLS w ustawieniach projektu).

Jeśli {http_port} lub {https_port} ma standardową wartość 80 lub 443, to {scheme_port} będzie puste.
{root_dir} Katalog główny Open Server Panel (pełna ścieżka)
{root_drive} Dysk katalogu głównego
{root_path} Ścieżka do katalogu głównego Open Server Panel
{terminal_codepage} Kodowanie konsoli
