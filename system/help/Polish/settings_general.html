Ustawienia programu

Uruchamiaj razem z Windows
Włącz autostart Open Server Panel podczas ładowania systemu operacyjnego.
Opóźnienie
Opóźnienie uruchomienia programu (w sekundach, od 0 do 60).

Pozwala odłożyć start aplikacji podczas ładowania razem z Windows, aby zmniejszyć ogólne obciążenie systemu. Jest to szczególnie przydatne, jeśli trzeba poczekać na pełną inicjalizację zewnętrznych usług lub interfejsów sieciowych.
Sprawdzaj dostępność nowych wersji
Włącz sprawdzanie aktualizacji Open Server Panel (wymagane połączenie z Internetem).
Włącz harmonogram zadań
Aktywuj wbudowany harmonogram zadań. Jeśli parametr jest wyłączony, żadne zaplanowane zadania nie będą wykonywane, niezależnie od ich statusu.
Używaj pliku HOSTS
Włącz zapisywanie nazw domen do pliku HOSTS.

Zalecenia przy ograniczonym dostępie do pliku HOSTS w organizacji:

1. Skonfiguruj wszystkie niezbędne moduły i projekty.
2. Skontaktuj się z administratorem systemu w celu odblokowania HOSTS i utrwalenia jego stanu.
3. Po utrwaleniu zmian przez administratora można wyłączyć tę opcję.

Ważne: Nie wyłączaj tego parametru, jeśli nie jesteś pewien konsekwencji!
Uruchamiaj moduły z profilem projektu
Uruchamiaj moduły z jednoczesną aktywacją profilu odpowiadającego nazwie projektu.

Używane przy wyborze pozycji menu «Włącz moduły projektu», aby automatycznie aktywować profil o tej samej nazwie co bieżący projekt, jeśli taki istnieje.
Nie wyłączaj modułów ukrytych projektów
Nie wyłączaj modułów ukrytych projektów przy wyborze pozycji menu «Wyłącz wszystkie moduły». Pod "ukrytymi" rozumiane są te projekty, dla których ustawiono kategorię "hidden".

Domyślnie polecenie «Wyłącz wszystkie moduły» zatrzymuje działanie absolutnie wszystkich modułów, w tym tych używanych przez ukryte projekty systemowe (na przykład PHPMyAdmin). Ta opcja pozwala zachować działanie ukrytych projektów systemowych, nie wyłączając niezbędnych dla nich modułów, podczas gdy wszystkie pozostałe moduły zostaną wyłączone.
Język interfejsu
Język interfejsu użytkownika Open Server Panel.

Jeśli plik lokalizacji jest nieobecny lub zawiera błędy, użyty zostanie język angielski.
Domena API
Lokalna domena dla API i interfejsu webowego (w trakcie opracowania)

Zalecenie: Jeśli używany jest VPN lub proxy, dodaj tę domenę do wyjątków.
Adres IP API
Adres IPv4 dla API i interfejsu webowego (w trakcie opracowania).

Zalecenie: Jeśli używany jest VPN lub proxy, dodaj ten adres IP do wyjątków.
Port API
Port używany dla API i interfejsu webowego (w trakcie opracowania). Open Server Panel nie będzie mógł się uruchomić, jeśli wskazany port jest już używany przez inny program.
Używaj Windows Terminal
Włącz użycie Windows Terminal zamiast standardowego interfejsu wiersza poleceń.

Wymagania: Windows Terminal musi być zainstalowany w systemie i wpisany w zmiennej środowiskowej PATH.

Windows Terminal jako cmd.exe: Windows Terminal może zastępować cmd.exe i być wpisany w zmiennej środowiskowej %COMSPEC% w nowych wersjach Windows. Jeśli tak jest, pozostaw tę opcję włączoną.

Nowe instancje Windows Terminal: Jeśli Windows Terminal otwiera nowe okna zamiast kart, skonfiguruj go tak: Ustawienia→Uruchamianie→Zachowanie nowej instancji→Dołącz do ostatnio używanego okna.
Krótki tytuł projektu
Po aktywowaniu tej opcji w tytule okna terminala będzie wyświetlana tylko nazwa projektu zamiast szczegółowego opisu środowiska.
Dołącz systemowe środowisko do środowiska projektu
Używaj środowiska systemu (System) w terminalu, nawet jeśli nie jest ono zadane w ustawieniach projektu. Systemowe środowisko pozwala używać programów zainstalowanych w systemie (na przykład git.exe lub ssh.exe).

Wyłączaj tę opcję tylko w przypadku konfliktów z oprogramowaniem systemowym.
Obsługa ANSI
Włącz obsługę kodów ANSI do zarządzania kolorami w terminalu.

Tryb "Automatycznie" (domyślnie):
- Poprawka stosowana jest tylko do Windows 10 do wersji 1903 włącznie. W nowszych wersjach Windows obsługa kodów ANSI jest już wbudowana.
- Poprawka nie jest stosowana dla terminali domyślnie wspierających ANSI (na przykład Windows Terminal).
Katalogi do wyszukiwania projektów
Lista katalogów, w których Open Server Panel będzie wyszukiwać projekty. Ścieżki oddzielaj średnikiem (;).

Wyjątki: Podkatalogi node_modules i vendor są ignorowane.
Głębokość
Maksymalna głębokość zagnieżdżenia katalogów podczas wyszukiwania projektów.

Zwiększenie tej wartości może spowolnić uruchamianie Open Server Panel, jeśli w podanych katalogach znajduje się duża liczba podkatalogów.
Maksymalny rozmiar pliku dziennika
Maksymalny rozmiar pliku dziennika w megabajtach. Po przekroczeniu wskazanej wartości plik logu zostanie utworzony ponownie przy następnym uruchomieniu programu.

Ustaw wartość 0, aby czyścić dzienniki przy każdym uruchomieniu programu.

Ustaw wartość 100 MB, aby całkowicie wyłączyć czyszczenie dzienników.
