Pengaturan global modul

Parameter yang ditentukan di bagian ini diterapkan ketika di pengaturan modul tertentu untuk opsi terkait ditetapkan nilai auto (default).

Mode kerja senyap
Menonaktifkan pesan pop-up kesalahan dari Windows Error Reporting dan dari modul itu sendiri.

Rekomendasi: Nonaktifkan mode ini hanya bila diperlukan untuk mendiagnosis masalah dalam operasi modul.
Tambahkan header ke file log
Mengaktifkan penambahan otomatis header ke file log setiap kali modul dijalankan. Berguna saat pembersihan log otomatis dinonaktifkan untuk memisahkan sesi kerja.
Jumlah maksimum peluncuran yang gagal
Menentukan berapa banyak peluncuran modul berturut-turut yang gagal diperbolehkan sebelum modul berpindah ke status “Kesalahan”.
Waktu pemeriksaan kesehatan modul
Menentukan periode pengujian kesehatan modul setelah peluncuran yang berhasil.

Mulai penghitungan: Sejak momen peluncuran modul yang berhasil.

Peralihan ke status “Kesalahan”: Jika modul berhenti secara tiba-tiba selama masa uji, modul tidak akan dimulai ulang secara otomatis dan akan berpindah ke status “Kesalahan”. Ini juga berlaku ketika modul gagal diluncurkan pada tingkat sistem.

Menonaktifkan pemeriksaan: Nilai 0 menonaktifkan masa uji, dan modul selalu akan dimulai ulang saat terjadi kegagalan.

Rekomendasi: Jangan menetapkan nilai 0 atau periode yang terlalu pendek (kurang dari 30 detik), karena ini dapat menyebabkan loop restart tanpa akhir.
Waktu tunggu penghentian modul
Menentukan waktu maksimum di mana modul diizinkan untuk mengakhiri pekerjaannya.

Penghentian paksa: Jika modul tidak berhenti dalam waktu yang ditentukan, modul akan dihentikan secara paksa.

Menonaktifkan waktu tunggu: Nilai 0 menonaktifkan periode menunggu. Program akan menunggu modul berhenti tanpa batas waktu.

Peringatan: Penghentian paksa modul dapat menyebabkan kerusakan data, kehilangan perubahan yang belum disimpan, atau penghentian proses yang tidak benar. Gunakan pengaturan ini dengan hati-hati.
Ukuran maksimum file log
Ukuran maksimum file log dalam megabyte. Saat nilai yang ditentukan terlampaui, file log akan dibuat ulang pada peluncuran modul berikutnya.

Tetapkan nilai 0 untuk membersihkan log pada setiap peluncuran modul.

Tetapkan nilai 100 MB untuk sepenuhnya menonaktifkan pembersihan log.
Encoding terminal
Encoding terminal saat bekerja dengan lingkungan modul.

Nilai khusus:
- system: Menggunakan encoding sistem.
Zona waktu
Menentukan zona waktu modul dalam format Etc/GMT (misalnya, Etc/GMT-3).

Nilai khusus:
- system: Menggunakan zona waktu sistem.

Penting: Format Etc/GMT memiliki offset terbalik relatif terhadap UTC (misalnya, Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Lingkungan add-on yang digunakan
Menentukan daftar add-on (ditentukan dipisahkan spasi) yang lingkungannya (jika ada) dilampirkan ke lingkungan modul. Indikator informasi di terminal tidak menampilkan lingkungan tambahan ini.

Peringatan: Gunakan opsi ini hanya jika Anda sepenuhnya memahami tujuannya.
Variabel sistem yang diizinkan
Menentukan daftar variabel lingkungan Windows (ditentukan dipisahkan spasi) yang diteruskan ke lingkungan modul.

Tujuan: Memungkinkan untuk mengisolasi lingkungan kerja modul dari perangkat lunak serupa yang terpasang di sistem.

Peringatan: Mengubah daftar ini tanpa pemahaman penuh terhadap dampaknya dapat menyebabkan operasi modul yang tidak stabil.
