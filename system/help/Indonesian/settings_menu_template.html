Membuat item menu kustom

  1. Tambahkan bagian baru dengan pengenal unik [ID]
  2. Atur bagian-bagian dalam urutan yang diinginkan — ini akan menentukan urutan item di menu
  3. Simpan perubahan dan mulai ulang Open Server Panel untuk menerapkan perubahan

Informasi penting

Saat membuat item menu kustom, pastikan pengenal bagian tidak duplikat. Ini dapat menyebabkan konflik dalam operasi menu.

Pengaturan item menu

Urutan pengurutan: Item menu diurutkan dalam urutan yang sama dengan posisi bagian terkait dalam template.

caption Judul item menu. Mendukung konstanta bahasa dalam format {lang_xxx}.

Default: tidak ditentukan
category

Menentukan lokasi item menu dalam hierarki. Mendukung satu tingkat kedalaman (misalnya, "Bookmark Saya\Pekerjaan").

Kategori khusus:

  • projects, modules, addons - menambahkan item ke menu tindakan yang sesuai
  • projects\, modules\, addons\ - menambahkan item untuk elemen tertentu

Jika kategori tidak ditentukan, item dibuat di menu root.

Default: tidak ditentukan
command Perintah yang dijalankan saat item menu diaktifkan. Item tanpa perintah akan diabaikan.

Default: tidak ditentukan
enabled Mengaktifkan/menonaktifkan tampilan item menu.

Default: on | Nilai: on, off
hide Mengatur visibilitas jendela aplikasi yang dipanggil. Tidak memengaruhi proses turunan.

Default: off | Nilai: on, off
hr_after Menambahkan pemisah horizontal setelah item menu.

Default: off | Nilai: on, off
hr_before Menambahkan pemisah horizontal sebelum item menu.

Default: off | Nilai: on, off
icon Ikon dari set Font Awesome Free (Solid/Regular/Brands).

Default: tidak ditentukan
need_alias Menampilkan item menu hanya untuk alias domain. Dalam template menu hanya boleh ada satu item dengan need_alias=on!
Berlaku untuk kategori: projects

Default: tidak ditentukan | Nilai: on, off
need_category

Membatasi tampilan item menu untuk modules/addons dari kategori tertentu.

Format yang didukung:

  • modules, addons
  • modules\, addons\
Default: tidak ditentukan
need_module_shell Menampilkan item menu tergantung pada ketersediaan shell/cli pada modul induk.
Berlaku untuk kategori: modules, modules\

Default: tidak ditentukan | Nilai: on, off
need_state Menampilkan item menu tergantung pada status modul induk.
Berlaku untuk kategori: modules, modules\

Default: tidak ditentukan | Nilai: on, off
need_start_cmd Menampilkan item menu jika ada perintah start di pengaturan proyek.
Berlaku untuk kategori: projects, projects\

Default: tidak ditentukan | Nilai: on, off
need_use_wt Menampilkan item menu tergantung pada pengaturan penggunaan Windows Terminal di Open Server Panel.

Default: tidak ditentukan | Nilai: on, off
work_directory Direktori kerja untuk menjalankan perintah. Dapat berubah selama eksekusi perintah.

Default: {root_dir}

Variabel template

Dalam parameter "command" dan "work_directory" Anda dapat menggunakan variabel template berikut:

Variabel umum

Variabel Deskripsi
{date_time} Tanggal/waktu saat ini (variabel hanya tersedia untuk parameter "command")
{root_dir} Direktori root Open Server Panel (path lengkap)
{root_drive} Drive dari direktori root
{root_path} Path ke direktori root Open Server Panel
{web_panel_url} URL antarmuka web

Variabel khusus (hanya untuk projects dan projects\<nama_domain>)

Variabel Deskripsi
{base_dir} Direktori dasar proyek
{host} Nama domain (Punycode)
{host_decoded} Nama domain yang terlihat (tanpa Punycode)
{host_scheme} Skema permintaan ke proyek ("http" atau "https", tergantung pada parameter TLS di pengaturan proyek)
{http_port} Port permintaan ke proyek melalui protokol HTTP
{https_port} Port permintaan ke proyek melalui protokol HTTPS
{menu_caption} Judul item menu (hanya untuk kategori projects dengan need_alias=ON)
{http_engine} Engine HTTP
{node_engine} Engine Node.js
{php_engine} Engine PHP
{project_root} Direktori root proyek
{base_url} URL proyek
{web_root} Direktori publik proyek
{scheme_port} Port permintaan ke proyek (":{http_port}" atau ":{https_port}", tergantung pada parameter TLS di pengaturan proyek). Jika {http_port} atau {https_port} memiliki nilai standar 80 atau 443, maka {scheme_port} akan kosong.
{app_start_command} Perintah untuk memulai aplikasi proyek (jika dikonfigurasi)
{terminal_codepage} Encoding konsol

Variabel Deskripsi

Nilai perintah khusus

Perintah Deskripsi
command_open_logs_viewer Buka jendela penampil log
command_open_idn_converter Buka IDN-converter
command_open_options Buka jendela pengaturan program

Selain variabel template, Anda dapat menggunakan variabel lingkungan Windows apa pun, misalnya: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, dll.

Contoh penggunaan

[bookmark_1]

caption  = Google
category = Bookmark Saya\Sistem pencarian
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opsi CMD.EXE

  • /c: Jalankan perintah dan tutup terminal.
  • /k: Jalankan perintah dan biarkan terminal tetap terbuka.
