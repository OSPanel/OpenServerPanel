Variabel lingkungan global modul

Di bagian ini Anda dapat menetapkan variabel lingkungan global untuk modul.

Variabel ini hanya berlaku di lingkungan modul dan tidak memengaruhi variabel sistem atau lingkungan proyek.

Dalam nilai diperbolehkan penggunaan variabel templat.

Jika variabel ada di lingkungan sistem tetapi tidak boleh digunakan di lingkungan modul, gunakan filter khusus (lihat Modul→Variabel sistem yang diizinkan) atau hapus variabel dari lingkungan dengan memberinya nilai kosong.

Variabel templat

Variabel Deskripsi
{root_dir} Direktori root Open Server Panel (jalur lengkap)
{root_drive} Drive direktori root
{root_path} Jalur ke direktori root Open Server Panel
{terminal_codepage} Pengodean di terminal (lihat Modul→Pengodean di terminal)
{time_zone} Zona waktu dalam format Etc/GMT (lihat Modul→Zona waktu)

Selain variabel templat, Anda dapat menggunakan variabel lingkungan Windows apa pun, misalnya: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% dan lain-lain.
