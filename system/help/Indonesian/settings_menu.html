Pengaturan menu

Tema tampilan
Tema tampilan untuk ikon menu.
Ukuran font
Ukuran font menu dalam piksel. Opsi ini memungkinkan Anda mengatur ukuran font menu secara terpisah dari pengaturan sistem.

Atur penggeser ke nilai minimum 12px untuk menonaktifkan fungsi kontrol ukuran font (ukuran sistem akan digunakan).
Tampilkan ikon di area notifikasi
Tampilkan ikon program di area notifikasi Windows.

Menonaktifkan: Nonaktifkan opsi ini jika Anda menggunakan tipe mulai otomatis yang tidak memerlukan login pengguna Windows (Windows Task Scheduler→Mulai saat komputer boot).
Tampilkan ikon untuk item menu
Tampilkan ikon di menu program. Ikon tidak ditampilkan jika rendering sistem diaktifkan.
Aktifkan rendering sistem
Aktifkan opsi ini hanya bila perlu untuk memastikan kompatibilitas dengan program akses layar (screen reader).

Perhatian! Ikon di menu tidak ditampilkan jika rendering sistem diaktifkan.
Tampilkan pemisah vertikal
Saat opsi ini diaktifkan, ikon di menu program akan dipisahkan oleh pemisah vertikal.
Jangan mengelompokkan daftar dari satu elemen
Jangan mengelompokkan daftar yang hanya berisi satu elemen.
