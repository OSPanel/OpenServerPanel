Pengaturan program

Jalankan bersama Windows
Aktifkan mulai otomatis Open Server Panel saat sistem operasi boot.
Penundaan
Penundaan peluncuran program (dalam detik, dari 0 hingga 60).

Memungkinkan menunda mulai aplikasi saat boot bersama Windows untuk mengurangi beban keseluruhan pada sistem. Ini sangat berguna jika perlu menunggu inisialisasi penuh layanan pihak ketiga atau antarmuka jaringan.
Periksa pembaruan
Aktifkan pemeriksaan pembaruan Open Server Panel (membutuhkan koneksi Internet).
Aktifkan penjadwal tugas
Aktifkan penjadwal tugas bawaan. Jika parameter dinonaktifkan, tidak ada tugas terjadwal yang akan dijalankan, terlepas dari statusnya.
Gunakan file HOSTS
Aktifkan pencatatan nama domain ke file HOSTS.

Rekomendasi saat akses ke file HOSTS dibatasi di organisasi:

1. Konfigurasikan semua modul dan proyek yang diperlukan.
2. Hubungi administrator sistem untuk membuka blokir HOSTS dan mengunci statusnya.
3. Setelah perubahan dikunci oleh administrator, opsi ini dapat dinonaktifkan.

Penting: Jangan menonaktifkan parameter ini jika Anda tidak yakin dengan konsekuensinya!
Jalankan modul dengan profil proyek
Jalankan modul dengan aktivasi simultan profil yang namanya sama dengan nama proyek.

Digunakan saat memilih menu «Aktifkan modul proyek», untuk secara otomatis mengaktifkan profil dengan nama yang sama dengan proyek saat ini, jika ada.
Jangan matikan modul proyek tersembunyi
Jangan matikan modul proyek tersembunyi saat memilih menu «Matikan semua modul». Yang dimaksud dengan "tersembunyi" adalah proyek yang dikategorikan sebagai "hidden".

Secara default, perintah «Matikan semua modul» menghentikan semua modul, termasuk modul yang digunakan oleh proyek layanan tersembunyi (misalnya, PHPMyAdmin). Opsi ini memungkinkan menjaga kelayakan proyek layanan tersembunyi tanpa menonaktifkan modul yang diperlukan untuknya, sementara semua modul lainnya akan dimatikan.
Bahasa antarmuka
Bahasa antarmuka pengguna Open Server Panel.

Jika file lokalisasi tidak ada atau berisi kesalahan, bahasa Inggris akan digunakan.
Domain API
Domain lokal untuk API dan antarmuka web (dalam pengembangan)

Rekomendasi: Jika menggunakan VPN atau proxy, tambahkan domain ini ke pengecualian.
Alamat IP API
Alamat IPv4 untuk API dan antarmuka web (dalam pengembangan).

Rekomendasi: Jika menggunakan VPN atau proxy, tambahkan alamat IP ini ke pengecualian.
Port API
Port yang digunakan untuk API dan antarmuka web (dalam pengembangan). Open Server Panel tidak akan dapat berjalan jika port yang ditentukan sudah digunakan oleh aplikasi lain.
Gunakan Windows Terminal
Aktifkan penggunaan Windows Terminal alih-alih antarmuka perintah standar.

Persyaratan: Windows Terminal harus terpasang di sistem dan terdaftar di variabel lingkungan PATH.

Windows Terminal sebagai cmd.exe: Windows Terminal dapat menggantikan cmd.exe dan terdaftar di variabel lingkungan %COMSPEC% pada versi Windows terbaru. Jika demikian, biarkan opsi ini tetap diaktifkan.

Instans Windows Terminal baru: Jika Windows Terminal membuka jendela baru alih-alih tab, atur seperti ini: Settings→Startup→New instance behavior→Attach to most recently used window.
Judul proyek singkat
Saat opsi ini diaktifkan, judul jendela terminal hanya akan menampilkan nama proyek alih-alih deskripsi rinci lingkungan.
Sertakan lingkungan sistem dalam lingkungan proyek
Gunakan lingkungan sistem (System) di terminal, bahkan jika tidak ditentukan di pengaturan proyek. Lingkungan sistem memungkinkan penggunaan program yang terpasang di sistem (misalnya, git.exe atau ssh.exe).

Nonaktifkan opsi ini hanya jika terjadi konflik dengan perangkat lunak sistem.
Dukungan ANSI
Aktifkan dukungan kode ANSI untuk mengelola warna di terminal.

Mode "Otomatis" (default):
- Perbaikan diterapkan hanya untuk Windows 10 hingga versi 1903 inklusif. Pada versi Windows yang lebih baru, dukungan kode ANSI sudah bawaan.
- Perbaikan tidak diterapkan untuk terminal yang mendukung ANSI secara default (misalnya, Windows Terminal).
Direktori untuk mencari proyek
Daftar direktori tempat Open Server Panel akan mencari proyek. Pisahkan path dengan titik koma (;).

Pengecualian: Subdirektori node_modules dan vendor diabaikan.
Kedalaman
Kedalaman maksimum hierarki direktori saat mencari proyek.

Meningkatkan nilai ini dapat memperlambat peluncuran Open Server Panel jika direktori yang ditentukan berisi banyak subdirektori.
Ukuran maksimum file log
Ukuran maksimum file log dalam megabita. Saat melebihi nilai yang ditentukan, file log akan dibuat ulang pada peluncuran program berikutnya.

Atur nilai 0 untuk membersihkan log pada setiap peluncuran program.

Atur nilai 100 MB untuk sepenuhnya menonaktifkan pembersihan log.
