Pengaturan global proyek

Parameter yang ditentukan di bagian ini digunakan jika tidak ada nilai lain yang ditentukan dalam pengaturan proyek.

HTTP
Menentukan modul web server yang digunakan untuk proyek.
NODE
Menentukan engine Node.js untuk menjalankan aplikasi Node.js.

Instalasi Node.js: Instal terlebih dahulu versi Node.js yang diperlukan menggunakan perintah osp node <latest|lts|номер>.
PHP
Menentukan modul PHP yang digunakan untuk memproses file PHP.
Aktifkan
Menentukan status default proyek (diaktifkan atau dinonaktifkan).
Enkoding terminal
Enkoding terminal saat bekerja dengan lingkungan proyek.

Nilai khusus:
- system: Menggunakan enkoding sistem.

Penting: Jika nilai tidak ditentukan, saat membentuk lingkungan akhir proyek, enkoding terminal akan ditetapkan oleh lingkungan terakhir yang dihubungkan, di mana enkoding ditentukan, misalnya oleh lingkungan modul PHP.
IP
Menetapkan alamat IP yang digunakan oleh semua proyek tanpa pengaturan individual.

Pembatasan: Proyek yang menggunakan alamat IP yang sama harus berjalan pada satu versi PHP.

Dukungan multi-IP: Anda dapat menentukan beberapa alamat IP dipisahkan spasi, termasuk IPv6. Di file HOSTS, domain akan ditetapkan ke IP pertama yang ditentukan.

Penetapan otomatis: Jika kolom dibiarkan kosong, alamat IP akan ditetapkan secara otomatis.

Rekomendasi:
  • Pengelolaan alamat IP otomatis direkomendasikan untuk sebagian besar pengguna.
  • Penetapan IP secara manual hanya digunakan untuk kebutuhan konfigurasi jaringan yang spesifik.
HTTP
Menentukan port untuk koneksi HTTP.
HTTPS
Menentukan port untuk koneksi HTTPS.
TLS
Mengaktifkan atau menonaktifkan dukungan TLS.
File sertifikat
Menentukan path ke file sertifikat TLS. Anda dapat menggunakan variabel template.

Karakter yang diizinkan: A-Za-z0-9-+_.\:

Rekomendasi: Biarkan kolom kosong untuk pembuatan sertifikat otomatis.
File kunci
Menentukan path ke file kunci TLS. Anda dapat menggunakan variabel template.

Karakter yang diizinkan: A-Za-z0-9-+_.\:

Rekomendasi: Biarkan kolom kosong untuk pembuatan kunci otomatis.
Alamat IP (backend)
Menentukan alamat IP yang digunakan untuk terhubung ke sisi server (Backend).
Port (backend)
Menentukan nomor port untuk terhubung ke sisi server (Backend).
Aktifkan (backend)
Memungkinkan untuk secara otomatis mengarahkan seluruh trafik masuk (HTTP dan HTTPS) proyek ke sisi server (Backend). Berguna untuk pengujian atau pengembangan ketika frontend dan backend dipisahkan.
Direktori proyek
Menentukan direktori root proyek. Berpindah ke direktori ini dilakukan dengan perintah osp project <DOMAIN> bersamaan dengan aktivasi lingkungan proyek. Anda dapat menggunakan variabel template.

Karakter yang diperbolehkan: A-Za-z0-9-+_.\:
Direktori publik
Menentukan direktori publik proyek. Anda dapat menggunakan variabel template.

Karakter yang diperbolehkan: A-Za-z0-9-+_.\:
Alias
Menentukan nama domain tambahan (alias) untuk proyek (dipisahkan spasi). Anda dapat menggunakan variabel template.

Pembatasan: Simbol "*" tidak didukung oleh file HOSTS di Windows dan memerlukan pengaturan DNS.
Lingkungan proyek
Daftar add-on dan modul (dipisahkan spasi) yang membentuk lingkungan proyek.

HTTP, NODE dan PHP: Lingkungan engine ini selalu dihubungkan (jika ditentukan untuk domain) dan tidak perlu dicantumkan di parameter ini.
Perintah menjalankan proyek
Menentukan perintah untuk menjalankan proyek (misalnya, nodemon app.js). Anda dapat menggunakan variabel template.
URL proyek
URL yang digunakan saat membuka proyek melalui Menu→Proyek→Buka di browser, serta saat membuka alias domain proyek. Anda dapat menggunakan variabel template.

Penerapan: Anda dapat menentukan URL panel administrasi CMS.

Variabel template

Variabel Deskripsi
{backend_ip} Alamat IP untuk koneksi ke sisi server (Backend)
{backend_port} Port untuk koneksi ke sisi server (Backend)
{base_dir} Direktori root proyek (tempat direktori .osp berada)
{date_time} Tanggal/waktu saat ini (variabel hanya tersedia untuk perintah menjalankan aplikasi proyek)
{host} Nama domain (untuk domain internasional digunakan Punycode)
{host_decoded} Nama domain yang terlihat (tanpa Punycode)
{host_scheme} Skema permintaan ke proyek ("http" atau "https", tergantung parameter TLS di pengaturan proyek)
{http_port} Port permintaan ke proyek melalui protokol HTTP
{https_port} Port permintaan ke proyek melalui protokol HTTPS
{http_engine} Engine HTTP
{node_engine} Engine NODE
{php_engine} Engine PHP
{project_root} Direktori root proyek
{web_root} Direktori publik proyek
{scheme_port} Port permintaan ke proyek (":{http_port}" atau ":{https_port}", bergantung pada parameter TLS di pengaturan proyek).

Jika {http_port} atau {https_port} memiliki nilai standar 80 atau 443, maka {scheme_port} akan kosong.
{root_dir} Direktori root Open Server Panel (path penuh)
{root_drive} Drive direktori root
{root_path} Path ke direktori root Open Server Panel
{terminal_codepage} Enkoding konsol
