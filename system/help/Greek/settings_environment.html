Καθολικές μεταβλητές περιβάλλοντος των modules

Σε αυτήν την ενότητα μπορείτε να ορίσετε καθολικές μεταβλητές περιβάλλοντος για τα modules.

Αυτές οι μεταβλητές ισχύουν μόνο στο περιβάλλον των modules και δεν επηρεάζουν τις συστημικές μεταβλητές ή το περιβάλλον των έργων.

Στις τιμές επιτρέπεται η χρήση προτυποποιημένων μεταβλητών.

Εάν μια μεταβλητή υπάρχει στο συστημικό περιβάλλον αλλά δεν πρέπει να χρησιμοποιείται στο περιβάλλον των modules, χρησιμοποιήστε το ειδικό φίλτρο (βλ. Modules→Επιτρεπόμενες συστημικές μεταβλητές) ή αφαιρέστε τη μεταβλητή από το περιβάλλον, ορίζοντάς την σε κενή τιμή.

Προτυποποιημένες μεταβλητές

Μεταβλητή Περιγραφή
{root_dir} Ριζικός κατάλογος του Open Server Panel (πλήρης διαδρομή)
{root_drive} Δίσκος του ριζικού καταλόγου
{root_path} Διαδρομή προς τον ριζικό κατάλογο του Open Server Panel
{terminal_codepage} Κωδικοποίηση στο τερματικό (βλ. Modules→Κωδικοποίηση στο τερματικό)
{time_zone} Ζώνη ώρας σε μορφή Etc/GMT (βλ. Modules→Ζώνη ώρας)

Εκτός από τις προτυποποιημένες μεταβλητές, μπορείτε να χρησιμοποιείτε οποιεσδήποτε μεταβλητές περιβάλλοντος των Windows, για παράδειγμα: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% κ.λπ.
