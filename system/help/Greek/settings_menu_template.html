Δημιουργία προσαρμοσμένων στοιχείων μενού

  1. Προσθέστε μια νέα ενότητα με μοναδικό αναγνωριστικό [ID]
  2. Τοποθετήστε τις ενότητες με την επιθυμητή σειρά — αυτό θα καθορίσει τη σειρά των στοιχείων στο μενού
  3. Αποθηκεύστε τις αλλαγές και επανεκκινήστε το Open Server Panel για να εφαρμοστούν οι αλλαγές

Σημαντικές πληροφορίες

Κατά τη δημιουργία προσαρμοσμένων στοιχείων μενού, βεβαιωθείτε ότι τα αναγνωριστικά των ενοτήτων δεν επαναλαμβάνονται. Αυτό μπορεί να οδηγήσει σε συγκρούσεις στη λειτουργία του μενού.

Ρυθμίσεις στοιχείων μενού

Σειρά ταξινόμησης: Τα στοιχεία μενού ταξινομούνται με την ίδια σειρά με την οποία είναι τοποθετημένες οι αντίστοιχες ενότητες στο πρότυπο.

caption Τίτλος στοιχείου μενού. Υποστηρίζει γλωσσικές σταθερές στη μορφή {lang_xxx}.

Προεπιλογή: δεν έχει οριστεί
category

Καθορίζει τη θέση του στοιχείου μενού στην ιεραρχία. Υποστηρίζει ένα επίπεδο φωλιάσματος (π.χ. "Οι Σελιδοδείκτες μου\Εργασία").

Ειδικές κατηγορίες:

  • projects, modules, addons - προσθέτει το στοιχείο στο αντίστοιχο μενού ενεργειών
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - προσθέτει το στοιχείο για συγκεκριμένο αντικείμενο

Αν δεν έχει καθοριστεί κατηγορία, το στοιχείο δημιουργείται στο ριζικό μενού.

Προεπιλογή: δεν έχει οριστεί
command Εντολή για εκτέλεση κατά την ενεργοποίηση του στοιχείου μενού. Τα στοιχεία χωρίς εντολή παρακάμπτονται.

Προεπιλογή: δεν έχει οριστεί
enabled Ενεργοποιεί/απενεργοποιεί την εμφάνιση του στοιχείου μενού.

Προεπιλογή: on | Τιμές: on, off
hide Ελέγχει την ορατότητα του παραθύρου της καλούμενης εφαρμογής. Δεν επηρεάζει τις θυγατρικές διεργασίες.

Προεπιλογή: off | Τιμές: on, off
hr_after Προσθέτει οριζόντιο διαχωριστικό μετά το στοιχείο μενού.

Προεπιλογή: off | Τιμές: on, off
hr_before Προσθέτει οριζόντιο διαχωριστικό πριν από το στοιχείο μενού.

Προεπιλογή: off | Τιμές: on, off
icon Εικονίδιο από το σετ Font Awesome Free (Solid/Regular/Brands).

Προεπιλογή: δεν έχει οριστεί
need_alias Εμφανίζει το στοιχείο μενού μόνο για domain alias. Στο πρότυπο μενού μπορεί να υπάρχει μόνο ένα στοιχείο με need_alias=on!
Ισχύει για κατηγορίες: projects

Προεπιλογή: δεν έχει οριστεί | Τιμές: on, off
need_category

Περιορίζει την εμφάνιση του στοιχείου μενού σε modules/addons συγκεκριμένης κατηγορίας.

Υποστηριζόμενες μορφές:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Προεπιλογή: δεν έχει οριστεί
need_module_shell Εμφανίζει το στοιχείο μενού ανάλογα με τη διαθεσιμότητα shell/cli στο γονικό module.
Ισχύει για κατηγορίες: modules, modules\<имя_модуля>

Προεπιλογή: δεν έχει οριστεί | Τιμές: on, off
need_state Εμφανίζει το στοιχείο μενού ανάλογα με την κατάσταση του γονικού module.
Ισχύει για κατηγορίες: modules, modules\<имя_модуля>

Προεπιλογή: δεν έχει οριστεί | Τιμές: on, off
need_start_cmd Εμφανίζει το στοιχείο μενού όταν υπάρχει εντολή εκκίνησης στις ρυθμίσεις του project.
Ισχύει για κατηγορίες: projects, projects\<имя_домена>

Προεπιλογή: δεν έχει οριστεί | Τιμές: on, off
need_use_wt Εμφανίζει το στοιχείο μενού ανάλογα με τη ρύθμιση χρήσης του Windows Terminal στο Open Server Panel.

Προεπιλογή: δεν έχει οριστεί | Τιμές: on, off
work_directory Κατάλογος εργασίας για την εκτέλεση της εντολής. Μπορεί να αλλάζει κατά την εκτέλεση εντολών.

Προεπιλογή: {root_dir}

Μεταβλητές προτύπου

Στις παραμέτρους "command" και "work_directory" μπορείτε να χρησιμοποιήσετε τις ακόλουθες μεταβλητές προτύπου:

Γενικές μεταβλητές

Μεταβλητή Περιγραφή
{date_time} Τρέχουσα ημερομηνία/ώρα (η μεταβλητή είναι διαθέσιμη μόνο για την παράμετρο "command")
{root_dir} Ριζικός κατάλογος του Open Server Panel (πλήρης διαδρομή)
{root_drive} Δίσκος του ριζικού καταλόγου
{root_path} Διαδρομή προς τον ριζικό κατάλογο του Open Server Panel
{web_panel_url} URL διεύθυνση του web-διεπαφής

Ειδικές μεταβλητές (μόνο για projects και projects\<имя_домена>)

Μεταβλητή Περιγραφή
{base_dir} Βασικός κατάλογος του project
{host} Όνομα domain (Punycode)
{host_decoded} Ορατό όνομα domain (χωρίς Punycode)
{host_scheme} Σχήμα αιτήματος προς το project ("http" ή "https", εξαρτάται από την παράμετρο TLS στις ρυθμίσεις του project)
{http_port} Θύρα αιτήματος προς το project μέσω πρωτοκόλλου HTTP
{https_port} Θύρα αιτήματος προς το project μέσω πρωτοκόλλου HTTPS
{menu_caption} Τίτλος στοιχείου μενού (μόνο για την κατηγορία projects με need_alias=ON)
{http_engine} Μηχανή HTTP
{node_engine} Μηχανή Node.js
{php_engine} Μηχανή PHP
{project_root} Ριζικός κατάλογος του project
{base_url} URL του project
{web_root} Δημόσιος κατάλογος του project
{scheme_port} Θύρα αιτήματος προς το project (":{http_port}" ή ":{https_port}", εξαρτάται από την παράμετρο TLS στις ρυθμίσεις του project). Αν το {http_port} ή το {https_port} έχει την τυπική τιμή 80 ή 443, τότε το {scheme_port} θα είναι κενό.
{app_start_command} Εντολή εκκίνησης της εφαρμογής του project (αν έχει ρυθμιστεί)
{terminal_codepage} Κωδικοσελίδα κονσόλας

Ειδικές μεταβλητές (μόνο για addons και addons\<имя_дополнения>)

Μεταβλητή Περιγραφή
{addon_name} Όνομα του addon
{terminal_codepage} Κωδικοσελίδα κονσόλας

Ειδικές μεταβλητές (μόνο για modules και modules\<имя_модуля>)

Μεταβλητή Περιγραφή
{ip} IP-διεύθυνση του module
{log_level} Επίπεδο καταγραφής σφαλμάτων
{module_name} Όνομα του module
{port} Θύρα του module
{profile_name} Όνομα του τρέχοντος προφίλ ρυθμίσεων του module
{query_log_level} Επίπεδο καταγραφής αιτημάτων
{shell_command} Εντολή εκκίνησης shell/cli του module (αν έχει ρυθμιστεί)
{terminal_codepage} Κωδικοσελίδα κονσόλας
{time_zone} Ζώνη ώρας

Ειδικές τιμές εντολών

Εντολή Περιγραφή
command_open_logs_viewer Άνοιγμα παραθύρου προβολής logs
command_open_idn_converter Άνοιγμα IDN-μετατροπέα
command_open_options Άνοιγμα παραθύρου ρυθμίσεων προγράμματος

Εκτός από τις μεταβλητές προτύπου, μπορείτε να χρησιμοποιήσετε οποιεσδήποτε μεταβλητές περιβάλλοντος των Windows, για παράδειγμα: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% κ.λπ.

Παράδειγμα χρήσης

[bookmark_1]

caption  = Google
category = Οι Σελιδοδείκτες μου\Μηχανές αναζήτησης
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Επιλογές CMD.EXE

  • /c: Εκτέλεση της εντολής και κλείσιμο του τερματικού.
  • /k: Εκτέλεση της εντολής και διατήρηση του τερματικού ανοιχτού.
