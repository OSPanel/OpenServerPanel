Καθολικές ρυθμίσεις έργων

Οι παράμετροι που ορίζονται σε αυτήν την ενότητα χρησιμοποιούνται εάν στις ρυθμίσεις του έργου δεν έχουν καθοριστεί άλλες τιμές.

HTTP
Καθορίζει τη χρησιμοποιούμενη μονάδα του web server για τα έργα.
NODE
Υποδεικνύει τη μηχανή Node.js για την εκτέλεση εφαρμογών Node.js.

Εγκατάσταση Node.js: Προεγκαταστήστε την απαιτούμενη έκδοση του Node.js με την εντολή osp node <latest|lts|номер>.
PHP
Καθορίζει τη χρησιμοποιούμενη μονάδα PHP για την επεξεργασία αρχείων PHP.
Ενεργοποίηση
Καθορίζει την προεπιλεγμένη κατάσταση του έργου (ενεργό ή ανενεργό).
Κωδικοσελίδα τερματικού
Η κωδικοποίηση του τερματικού κατά την εργασία με το περιβάλλον του έργου.

Ειδικές τιμές:
- system: Χρησιμοποιείται η συστημική κωδικοποίηση.

Σημαντικό: Εάν η τιμή δεν έχει οριστεί, κατά το σχηματισμό του τελικού περιβάλλοντος του έργου η κωδικοποίηση του τερματικού θα οριστεί από το τελευταίο συνδεδεμένο περιβάλλον στο οποίο έχει καθοριστεί, για παράδειγμα από το περιβάλλον της μονάδας PHP.
IP
Ορίζει τη διεύθυνση(εις) IP που χρησιμοποιείται από όλα τα έργα χωρίς ατομικές ρυθμίσεις.

Περιορισμός: Έργα που χρησιμοποιούν την ίδια διεύθυνση IP πρέπει να λειτουργούν στην ίδια έκδοση PHP.

Υποστήριξη πολλαπλών IP: Μπορείτε να καθορίσετε πολλές διευθύνσεις IP με κενό, συμπεριλαμβανομένου του IPv6. Στο αρχείο HOSTS τα domains θα αντιστοιχιστούν στην πρώτη καθορισμένη IP.

Αυτόματη ανάθεση: Εάν αφήσετε το πεδίο κενό, η διεύθυνση IP θα αποδίδεται αυτόματα.

Συστάσεις:
  • Η αυτόματη διαχείριση διευθύνσεων IP συνιστάται για τους περισσότερους χρήστες.
  • Η χειροκίνητη ορισμός διεύθυνσης IP πρέπει να χρησιμοποιείται μόνο σε ειδικές απαιτήσεις δικτυακής διαμόρφωσης.
HTTP
Καθορίζει τη θύρα για συνδέσεις μέσω HTTP.
HTTPS
Καθορίζει τη θύρα για συνδέσεις μέσω HTTPS.
TLS
Ενεργοποιεί ή απενεργοποιεί την υποστήριξη TLS.
Αρχείο πιστοποιητικού
Υποδεικνύει τη διαδρομή προς το αρχείο πιστοποιητικού TLS. Μπορείτε να χρησιμοποιήσετε μεταβλητές προτύπου.

Επιτρεπόμενοι χαρακτήρες: A-Za-z0-9-+_.\:

Σύσταση: Αφήστε το πεδίο κενό για αυτόματη δημιουργία πιστοποιητικών.
Αρχείο κλειδιού
Υποδεικνύει τη διαδρομή προς το αρχείο κλειδιού TLS. Μπορείτε να χρησιμοποιήσετε μεταβλητές προτύπου.

Επιτρεπόμενοι χαρακτήρες: A-Za-z0-9-+_.\:

Σύσταση: Αφήστε το πεδίο κενό για αυτόματη δημιουργία κλειδιού.
Διεύθυνση IP (backend)
Υποδεικνύει τη διεύθυνση IP μέσω της οποίας πραγματοποιείται η σύνδεση στο backend.
Θύρα (backend)
Καθορίζει τον αριθμό θύρας για σύνδεση στο backend.
Ενεργοποίηση (backend)
Επιτρέπει την αυτόματη προώθηση όλης της εισερχόμενης κίνησης (HTTP και HTTPS) του έργου στο backend. Χρήσιμο για δοκιμές ή ανάπτυξη όταν το frontend και το backend είναι διαχωρισμένα.
Κατάλογος έργου
Υποδεικνύει τον ριζικό κατάλογο του έργου. Η μετάβαση σε αυτόν τον κατάλογο πραγματοποιείται με την εντολή osp project <DOMAIN> ταυτόχρονα με την ενεργοποίηση του περιβάλλοντος του έργου. Μπορείτε να χρησιμοποιήσετε μεταβλητές προτύπου.

Επιτρεπόμενοι χαρακτήρες: A-Za-z0-9-+_.\:
Δημόσιος κατάλογος
Καθορίζει τον δημόσιο κατάλογο του έργου. Μπορείτε να χρησιμοποιήσετε μεταβλητές προτύπου.

Επιτρεπόμενοι χαρακτήρες: A-Za-z0-9-+_.\:
Ψευδώνυμα
Υποδεικνύει πρόσθετα ονόματα domain (aliases) για το έργο (με κενό). Μπορείτε να χρησιμοποιήσετε μεταβλητές προτύπου.

Περιορισμός: Ο χαρακτήρας "*" δεν υποστηρίζεται στα Windows από το αρχείο HOSTS και απαιτεί ρύθμιση DNS.
Περιβάλλον έργου
Κατάλογος πρόσθετων και μονάδων (με κενό) που διαμορφώνουν το περιβάλλον του έργου.

HTTP, NODE και PHP: Τα περιβάλλοντα αυτών των μηχανών συνδέονται πάντα (εάν έχουν καθοριστεί για το domain) και δεν απαιτούν αναφορά σε αυτήν την παράμετρο.
Εντολή εκκίνησης έργου
Καθορίζει την εντολή για την εκκίνηση του έργου (π.χ. nodemon app.js). Μπορείτε να χρησιμοποιήσετε μεταβλητές προτύπου.
URL έργου
Το URL που χρησιμοποιείται κατά το άνοιγμα του έργου από το Μενού→Έργο→Άνοιγμα σε πρόγραμμα περιήγησης, καθώς και κατά το άνοιγμα των ψευδωνύμων domain του έργου (aliases). Μπορείτε να χρησιμοποιήσετε μεταβλητές προτύπου.

Χρήση: Μπορείτε να ορίσετε το URL του πίνακα διαχείρισης μιας CMS.

Μεταβλητές προτύπου

Μεταβλητή Περιγραφή
{backend_ip} Διεύθυνση IP σύνδεσης στο backend
{backend_port} Θύρα σύνδεσης στο backend
{base_dir} Ριζικός κατάλογος έργου (όπου βρίσκεται ο κατάλογος .osp)
{date_time} Τρέχουσα ημερομηνία/ώρα (η μεταβλητή είναι διαθέσιμη μόνο για την εντολή εκκίνησης της εφαρμογής του έργου)
{host} Όνομα domain (για διεθνοποιημένα domains χρησιμοποιείται Punycode)
{host_decoded} Ορατό όνομα domain (χωρίς Punycode)
{host_scheme} Σχήμα αιτήματος προς το έργο ("http" ή "https", εξαρτάται από την παράμετρο TLS στις ρυθμίσεις του έργου)
{http_port} Θύρα αιτήματος προς το έργο μέσω πρωτοκόλλου HTTP
{https_port} Θύρα αιτήματος προς το έργο μέσω πρωτοκόλλου HTTPS
{http_engine} Μηχανή HTTP
{node_engine} Μηχανή NODE
{php_engine} Μηχανή PHP
{project_root} Ριζικός κατάλογος έργου
{web_root} Δημόσιος κατάλογος έργου
{scheme_port} Θύρα αιτήματος προς το έργο (":{http_port}" ή ":{https_port}", εξαρτάται από την παράμετρο TLS στις ρυθμίσεις του έργου).

Εάν το {http_port} ή το {https_port} έχει την προεπιλεγμένη τιμή 80 ή 443, τότε το {scheme_port} θα είναι κενό.
{root_dir} Ριζικός κατάλογος του Open Server Panel (πλήρης διαδρομή)
{root_drive} Ο δίσκος του ριζικού καταλόγου
{root_path} Διαδρομή προς τον ριζικό κατάλογο του Open Server Panel
{terminal_codepage} Κωδικοσελίδα κονσόλας
