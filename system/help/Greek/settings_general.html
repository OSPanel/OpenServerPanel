Ρυθμίσεις προγράμματος

Εκκίνηση μαζί με τα Windows
Ενεργοποίηση αυτόματης εκκίνησης του Open Server Panel κατά τη φόρτωση του λειτουργικού συστήματος.
Καθυστέρηση
Καθυστέρηση εκκίνησης του προγράμματος (σε δευτερόλεπτα, από 0 έως 60).

Επιτρέπει την αναβολή της εκκίνησης της εφαρμογής κατά τη φόρτωση μαζί με τα Windows, ώστε να μειωθεί το συνολικό φορτίο στο σύστημα. Είναι ιδιαίτερα χρήσιμο αν χρειάζεται να περιμένετε την πλήρη αρχικοποίηση εξωτερικών υπηρεσιών ή δικτυακών διεπαφών.
Έλεγχος για νέες εκδόσεις
Ενεργοποίηση ελέγχου ενημερώσεων του Open Server Panel (απαιτείται σύνδεση στο Internet).
Ενεργοποίηση προγραμματιστή εργασιών
Ενεργοποίηση του ενσωματωμένου προγραμματιστή εργασιών. Αν η παράμετρος είναι απενεργοποιημένη, κανένα προγραμματισμένο task δεν θα εκτελείται, ανεξάρτητα από την κατάστασή του.
Χρήση του αρχείου HOSTS
Ενεργοποίηση καταγραφής ονομάτων domain στο αρχείο HOSTS.

Συστάσεις σε περιβάλλον με περιορισμένη πρόσβαση στο αρχείο HOSTS στον οργανισμό:

1. Ρυθμίστε όλα τα απαραίτητα modules και έργα.
2. Επικοινωνήστε με τον διαχειριστή συστήματος για ξεκλείδωμα του HOSTS και «πάγωμα» της κατάστασής του.
3. Μετά τη σταθεροποίηση των αλλαγών από τον διαχειριστή μπορείτε να απενεργοποιήσετε αυτήν την επιλογή.

Σημαντικό: Μην απενεργοποιείτε αυτήν την παράμετρο αν δεν είστε βέβαιοι για τις συνέπειες!
Εκκίνηση modules με το προφίλ του έργου
Εκκίνηση modules με ταυτόχρονη ενεργοποίηση του προφίλ που συμπίπτει με το όνομα του έργου.

Χρησιμοποιείται όταν επιλέγεται το στοιχείο μενού «Ενεργοποίηση modules έργου», ώστε να ενεργοποιείται αυτόματα το προφίλ με το ίδιο όνομα όπως του τρέχοντος έργου, εφόσον υπάρχει.
Να μην απενεργοποιούνται τα modules κρυφών έργων
Να μην απενεργοποιούνται τα modules κρυφών έργων κατά την επιλογή του στοιχείου μενού «Απενεργοποίηση όλων των modules». Ως "κρυφά" νοούνται τα έργα για τα οποία έχει οριστεί η κατηγορία "hidden".

Από προεπιλογή, η εντολή «Απενεργοποίηση όλων των modules» σταματά τη λειτουργία απολύτως όλων των modules, συμπεριλαμβανομένων αυτών που χρησιμοποιούνται από κρυφά υπηρεσιακά έργα (π.χ. PHPMyAdmin). Η παρούσα επιλογή επιτρέπει τη διατήρηση της λειτουργικότητας των κρυφών υπηρεσιακών έργων, χωρίς απενεργοποίηση των αναγκαίων για αυτά modules, ενώ όλα τα υπόλοιπα modules θα απενεργοποιούνται.
Γλώσσα διεπαφής
Η γλώσσα του περιβάλλοντος χρήστη του Open Server Panel.

Αν λείπει το αρχείο τοπικοποίησης ή περιέχει σφάλματα, θα χρησιμοποιηθεί η αγγλική γλώσσα.
Domain API
Τοπικό domain για το API και το web interface (υπό ανάπτυξη)

Σύσταση: Αν χρησιμοποιείται VPN ή proxy, προσθέστε αυτό το domain στις εξαιρέσεις.
IP-διεύθυνση API
IPv4 διεύθυνση για το API και το web interface (υπό ανάπτυξη).

Σύσταση: Αν χρησιμοποιείται VPN ή proxy, προσθέστε αυτήν την IP-διεύθυνση στις εξαιρέσεις.
Θύρα API
Η θύρα που χρησιμοποιείται για το API και το web interface (υπό ανάπτυξη). Το Open Server Panel δεν θα μπορέσει να εκκινηθεί αν η καθορισμένη θύρα χρησιμοποιείται ήδη από άλλη εφαρμογή.
Χρήση Windows Terminal
Ενεργοποίηση χρήσης του Windows Terminal αντί της προεπιλεγμένης γραμμής εντολών.

Απαιτήσεις: Το Windows Terminal πρέπει να είναι εγκατεστημένο στο σύστημα και δηλωμένο στη μεταβλητή περιβάλλοντος PATH.

Windows Terminal ως cmd.exe: Το Windows Terminal μπορεί να αντικαθιστά το cmd.exe και να είναι δηλωμένο στη μεταβλητή περιβάλλοντος %COMSPEC% στις νέες εκδόσεις των Windows. Αν ισχύει αυτό, αφήστε αυτήν την επιλογή ενεργοποιημένη.

Νέα instances του Windows Terminal: Αν το Windows Terminal ανοίγει νέα παράθυρα αντί για καρτέλες, ρυθμίστε το ως εξής: Ρυθμίσεις→Εκκίνηση→Συμπεριφορά νέου instance→Προσάρτηση στο τελευταίο χρησιμοποιημένο παράθυρο.
Σύντομος τίτλος έργου
Με την ενεργοποίηση αυτής της επιλογής, στον τίτλο του παραθύρου του τερματικού θα εμφανίζεται μόνο το όνομα του έργου αντί για την αναλυτική περιγραφή του περιβάλλοντος.
Συμπερίληψη συστημικού περιβάλλοντος στο περιβάλλον έργου
Χρήση του περιβάλλοντος του συστήματος (System) στο τερματικό, ακόμη και αν δεν έχει οριστεί στις ρυθμίσεις του έργου. Το συστημικό περιβάλλον επιτρέπει τη χρήση προγραμμάτων εγκατεστημένων στο σύστημα (π.χ. git.exe ή ssh.exe).

Απενεργοποιήστε αυτήν την επιλογή μόνο αν προκύπτουν συγκρούσεις με λογισμικό του συστήματος.
Υποστήριξη ANSI
Ενεργοποίηση υποστήριξης ANSI codes για διαχείριση χρωμάτων στο τερματικό.

Λειτουργία "Αυτόματα" (προεπιλογή):
- Η διόρθωση εφαρμόζεται μόνο στα Windows 10 έως και την έκδοση 1903. Στις νεότερες εκδόσεις των Windows η υποστήριξη ANSI codes είναι ήδη ενσωματωμένη.
- Η διόρθωση δεν εφαρμόζεται σε τερματικά που υποστηρίζουν από προεπιλογή ANSI (π.χ. Windows Terminal).
Κατάλογοι για αναζήτηση έργων
Λίστα καταλόγων στους οποίους το Open Server Panel θα αναζητά έργα. Διαχωρίστε τις διαδρομές με ελληνικό ερωτηματικό (;).

Εξαιρέσεις: Οι υποκατάλογοι node_modules και vendor αγνοούνται.
Βάθος
Μέγιστο βάθος εμφωλευμένων καταλόγων κατά την αναζήτηση έργων.

Η αύξηση αυτής της τιμής μπορεί να επιβραδύνει την εκκίνηση του Open Server Panel, αν στους καθορισμένους καταλόγους υπάρχουν μεγάλοι αριθμοί υποκαταλόγων.
Μέγιστο μέγεθος αρχείου καταγραφής
Μέγιστο μέγεθος αρχείου καταγραφής σε megabytes. Όταν ξεπεραστεί η καθορισμένη τιμή, το log file θα αναδημιουργηθεί στην επόμενη εκκίνηση του προγράμματος.

Ορίστε τιμή 0 για να καθαρίζονται τα logs σε κάθε εκκίνηση του προγράμματος.

Ορίστε τιμή 100 MB για να απενεργοποιήσετε πλήρως τον καθαρισμό των logs.
