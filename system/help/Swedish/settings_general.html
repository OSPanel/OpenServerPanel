Programinställningar

Starta tillsammans med Windows
Aktivera autostart av Open Server Panel vid operativsystemets uppstart.
Fördröjning
Fördröjning av programstart (i sekunder, från 0 till 60).

Möjliggör att skjuta upp applikationens start under uppstarten tillsammans med Windows för att minska den totala systembelastningen. Detta är särskilt användbart om du behöver invänta fullständig initialisering av tredjepartstjänster eller nätverksgränssnitt.
Sök efter nya versioner
Aktivera kontroll av uppdateringar för Open Server Panel (Internetanslutning krävs).
Aktivera schemaläggare
Aktivera den inbyggda schemaläggaren. Om parametern är avstängd kommer inga schemalagda jobb att köras, oavsett deras status.
Använd filen HOSTS
Aktivera skrivning av domännamn till filen HOSTS.

Rekommendationer vid begränsad åtkomst till filen HOSTS i organisationen:

1. Konfigurera alla nödvändiga moduler och projekt.
2. Kontakta systemadministratören för att låsa upp HOSTS och låsa dess tillstånd.
3. Efter att administratören har fastställt ändringarna kan du inaktivera detta alternativ.

Viktigt: Inaktivera inte den här parametern om du inte är säker på konsekvenserna!
Starta moduler med projektprofil
Starta moduler med samtidig aktivering av en profil som matchar projektets namn.

Används när menyalternativet «Aktivera projektmoduler» väljs för att automatiskt aktivera profilen med samma namn som det aktuella projektet, om en sådan finns.
Stäng inte av moduler för dolda projekt
Stäng inte av moduler för dolda projekt när menyalternativet «Stäng av alla moduler» väljs. Med "dolda" avses de projekt för vilka kategorin "hidden" har angetts.

Som standard stoppar kommandot «Stäng av alla moduler» alla moduler, inklusive de som används av dolda systemprojekt (till exempel PHPMyAdmin). Detta alternativ gör det möjligt att behålla funktionaliteten i dolda systemprojekt utan att stänga av de moduler som krävs för dem, medan alla andra moduler stängs av.
Gränssnittsspråk
Användargränssnittets språk i Open Server Panel.

Om lokaliseringsfilen saknas eller innehåller fel kommer engelska att användas.
API-domän
Lokal domän för API och webbgränssnitt (under utveckling)

Rekommendation: Om VPN eller proxy används, lägg till denna domän i undantag.
API-IP-adress
IPv4-adress för API och webbgränssnitt (under utveckling).

Rekommendation: Om VPN eller proxy används, lägg till denna IP-adress i undantag.
API-port
Port som används för API och webbgränssnitt (under utveckling). Open Server Panel kan inte starta om den angivna porten redan används av en annan applikation.
Använd Windows Terminal
Aktivera användning av Windows Terminal istället för standardkommandogränssnittet.

Krav: Windows Terminal måste vara installerad i systemet och angiven i miljövariabeln PATH.

Windows Terminal som cmd.exe: Windows Terminal kan ersätta cmd.exe och anges i miljövariabeln %COMSPEC% i nyare versioner av Windows. Om så är fallet, lämna detta alternativ aktiverat.

Nya instanser av Windows Terminal: Om Windows Terminal öppnar nya fönster istället för flikar, konfigurera den så här: Inställningar→Start→Beteende för ny instans→Fäst till senast använda fönster.
Kort projekttitel
När detta alternativ är aktiverat kommer endast projektets namn att visas i terminalfönstrets titel istället för en detaljerad miljöbeskrivning.
Inkludera systemmiljö i projektets miljö
Använd systemets miljö (System) i terminalen även om den inte är angiven i projektinställningarna. Systemmiljön gör det möjligt att använda program som är installerade i systemet (t.ex. git.exe eller ssh.exe).

Inaktivera detta alternativ endast om konflikter uppstår med systemprogramvara.
ANSI-stöd
Aktivera stöd för ANSI-koder för färgstyrning i terminalen.

Läge "Automatiskt" (standard):
- Korrigeringen tillämpas endast på Windows 10 upp till version 1903 inklusive. I nyare versioner av Windows är stöd för ANSI-koder redan inbyggt.
- Korrigeringen tillämpas inte för terminaler som stöder ANSI som standard (till exempel Windows Terminal).
Kataloger för projektsökning
Lista över kataloger där Open Server Panel kommer att söka efter projekt. Separera sökvägar med semikolon (;).

Undantag: Underkatalogerna node_modules och vendor ignoreras.
Djup
Maximal katalogdjupnivå vid sökning efter projekt.

Att öka detta värde kan sakta ner starten av Open Server Panel om de angivna katalogerna innehåller ett stort antal underkataloger.
Maximal loggfilstorlek
Maximal storlek på loggfilen i megabyte. När det angivna värdet överskrids kommer loggfilen att återskapas vid nästa programstart.

Ange värdet 0 för att rensa loggar vid varje programstart.

Ange värdet 100 MB för att helt inaktivera rensning av loggar.
