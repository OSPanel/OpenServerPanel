Globala miljövariabler för moduler

I det här avsnittet kan du ange globala miljövariabler för moduler.

Dessa variabler gäller endast i modulernas miljö och påverkar inte systemvariabler eller projektmiljöer.

Mallvariabler kan användas i värden.

Om en variabel finns i systemmiljön men inte ska användas i modulernas miljö, använd ett särskilt filter (se Moduler→Tillåtna systemvariabler) eller ta bort variabeln från miljön genom att ange ett tomt värde.

Mallvariabler

Variabel Beskrivning
{root_dir} Rotkatalogen för Open Server Panel (fullständig sökväg)
{root_drive} Enheten för rotkatalogen
{root_path} Sökväg till rotkatalogen för Open Server Panel
{terminal_codepage} Kodning i terminalen (se Moduler→Kodning i terminalen)
{time_zone} Tidszon i formatet Etc/GMT (se Moduler→Tidszon)

Förutom mallvariabler kan du använda valfria Windows-miljövariabler, till exempel: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% osv.
