Skapa egna menyalternativ

  1. Lägg till en ny sektion med ett unikt identifierare [ID]
  2. Ordna sektionerna i önskad ordning — detta bestämmer ordningen på menyalternativen
  3. Spara ändringarna och starta om Open Server Panel för att tillämpa ändringarna

Viktig information

När du skapar egna menyalternativ, se till att sektionsidentifierare inte upprepas. Detta kan leda till konflikter i menyfunktionen.

Inställningar för menyalternativ

Sorteringsordning: Menyalternativ sorteras i samma ordning som motsvarande sektioner i mallen.

caption Menyalternativets rubrik. Stöder språkkonstanter i formatet {lang_xxx}.

Standard: inte angivet
category

Anger menyalternativets placering i hierarkin. Stöder en nivå av underkategorier (t.ex. "Mina bokmärken\Arbete").

Särskilda kategorier:

  • projects, modules, addons - lägger till ett alternativ i motsvarande åtgärdsmeny
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - lägger till ett alternativ för ett specifikt objekt

Om kategorin inte anges skapas alternativet i rotmenyn.

Standard: inte angivet
command Kommando som ska köras när menyalternativet aktiveras. Alternativ utan kommando ignoreras.

Standard: inte angivet
enabled Aktiverar/inaktiverar visningen av menyalternativet.

Standard: on | Värden: on, off
hide Styr synligheten för fönstret för det startade programmet. Påverkar inte underprocesser.

Standard: off | Värden: on, off
hr_after Lägger till en horisontell avskiljare efter menyalternativet.

Standard: off | Värden: on, off
hr_before Lägger till en horisontell avskiljare före menyalternativet.

Standard: off | Värden: on, off
icon Ikon från Font Awesome Free (Solid/Regular/Brands).

Standard: inte angivet
need_alias Visar menyalternativet endast för ett domänalias. Det kan finnas endast ett alternativ med need_alias=on i menymallen!
Gäller för kategorier: projects

Standard: inte angivet | Värden: on, off
need_category

Begränsar visningen av menyalternativ till modules/addons i en viss kategori.

Stödda format:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Standard: inte angivet
need_module_shell Visar menyalternativet beroende på om shell/cli finns i den överordnade modulen.
Gäller för kategorier: modules, modules\<имя_модуля>

Standard: inte angivet | Värden: on, off
need_state Visar menyalternativet beroende på den överordnade modulens tillstånd.
Gäller för kategorier: modules, modules\<имя_модуля>

Standard: inte angivet | Värden: on, off
need_start_cmd Visar menyalternativet om det finns ett startkommando i projektinställningarna.
Gäller för kategorier: projects, projects\<имя_домена>

Standard: inte angivet | Värden: on, off
need_use_wt Visar menyalternativet beroende på inställningen för användning av Windows Terminal i Open Server Panel.

Standard: inte angivet | Värden: on, off
work_directory Arbetskatalog för att köra kommandot. Kan ändras under kommandokörning.

Standard: {root_dir}

Mallvariabler

I parametrarna "command" och "work_directory" kan följande mallvariabler användas:

{root_dir} Open Server Panels rotkatalog (fullständig sökväg)
{root_drive} Enheten för rotkatalogen
{root_path} Sökväg till Open Server Panels rotkatalog
{web_panel_url} Webbgränssnittets URL-adress

Variabel Beskrivning
{base_dir} Projektets baskatalog
{host} Domännamn (Punycode)
{host_decoded} Synligt domännamn (utan Punycode)
{host_scheme} Förfrågans schema till projektet ("http" eller "https", beror på TLS-parametern i projektinställningarna)
{http_port} Projektets förfrågningsport via HTTP
{https_port} Projektets förfrågningsport via HTTPS
{menu_caption} Menyalternativets rubrik (endast för kategorin projects med need_alias=ON)
{http_engine} HTTP-motor
{node_engine} Node.js-motor
{php_engine} PHP-motor
{project_root} Projektets rotkatalog

{app_start_command} Projektets applikationsstartkommando (om det är konfigurerat)

Särskilda kommandovärden

Kommando Beskrivning

Förutom mallvariabler kan du använda valfria Windows-miljövariabler, till exempel: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% osv.

Exempel på användning

[bookmark_1]

caption  = Google
category = Mina bokmärken\Sökmotorer
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE-alternativ

  • /c: Kör kommandot och stäng terminalen.
  • /k: Kör kommandot och lämna terminalen öppen.
