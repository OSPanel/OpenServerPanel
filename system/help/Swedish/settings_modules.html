Globala modulinställningar

Parametrarna som anges i detta avsnitt tillämpas i de fall då värdet auto (standard) är inställt för motsvarande alternativ i en specifik moduls inställningar.

Tyst läge
Inaktiverar popup-felmeddelanden från Windows Error Reporting och själva modulen.

Rekommendation: Inaktivera detta läge endast när det behövs för felsökning av modulens drift.
Lägg till rubrik i loggfilen
Aktiverar automatisk tilläggning av en rubrik i loggfilen vid varje modulstart. Användbart när automatisk loggrensning är avstängd för att separera arbetssessioner.
Maximalt antal misslyckade starter
Anger hur många på varandra följande misslyckade modulstarter som tillåts innan den går över till tillståndet ”Fel”.
Tid för kontroll av modulens funktion
Anger testperioden för modulens funktion efter en lyckad start.

Startpunkt: Från och med den lyckade modulstarten.

Övergång till tillståndet ”Fel”: Om modulen kraschar under prövotiden kommer den inte att startas om automatiskt och går över till tillståndet ”Fel”. Detta gäller även i fall då modulen inte kan startas på systemnivå.

Inaktivera kontrollen: Värdet 0 inaktiverar prövotiden och modulen kommer alltid att startas om vid fel.

Rekommendation: Sätt inte värdet 0 eller en alltför kort period (mindre än 30 sekunder), eftersom detta kan leda till oändliga omstartsloopar.
Tidsgräns för modulens avstängning
Anger maximal tid som modulen tillåts för att avsluta sitt arbete.

Tvingad avstängning: Om modulen inte avslutar inom angiven tid kommer den att stoppas med tvång.

Inaktivera väntan: Värdet 0 inaktiverar väntetiden. Programmet kommer att vänta på att modulen avslutar på obestämd tid.

Varning: Tvingad stopp av modulen kan leda till dataskador, förlust av osparade ändringar eller felaktigt avslut av processer. Använd denna inställning med försiktighet.
Maximal storlek på loggfil
Maximal storlek på loggfilen i megabyte. När det angivna värdet överskrids kommer loggfilen återskapas vid nästa modulstart.

Ställ in värdet 0 för att rensa loggar vid varje modulstart.

Ställ in värdet 100 MB för att helt inaktivera loggrensning.
Terminalkodning
Terminalens kodning vid arbete med modulens miljö.

Specialvärden:
- system: Systemets kodning används.
Tidszon
Anger modulens tidszon i formatet Etc/GMT (t.ex. Etc/GMT-3).

Specialvärden:
- system: Systemets tidszon används.

Viktigt: Formatet Etc/GMT har omvänt offset i förhållande till UTC (t.ex. Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Använda tilläggsmiljöer
Anger en lista över tillägg (anges separerade med mellanslag) vars miljöer (om sådana finns) kopplas till modulens miljö. Informationsindikatorer i terminalen visar inte dessa extra miljöer.

Varning: Använd detta alternativ endast om du fullt ut förstår dess syfte.
Tillåtna systemvariabler
Anger en lista över Windows-miljövariabler (anges separerade med mellanslag) som överförs till modulens miljö.

Syfte: Gör det möjligt att isolera modulens arbetsmiljö från motsvarande programvara installerad i systemet.

Varning: Att ändra denna lista utan full förståelse för dess påverkan kan leda till instabil moduldrift.
