Globala projektinställningar

Parametrarna i detta avsnitt används om inga andra värden anges i projektets inställningar.

HTTP
Anger den webbservermodul som används för projekten.
NODE
Anger Node.js-motorn för att köra Node.js-applikationer.

Installation av Node.js: Installera i förväg önskad version av Node.js med kommandot osp node <latest|lts|номер>.
PHP
Anger den PHP-modul som används för att bearbeta PHP-filer.
Aktivera
Anger projektets standardläge (på eller av).
Terminalkodning
Terminalens kodning vid arbete med projektets miljö.

Specialvärden:
- system: Systemets kodning används.

Viktigt: Om värdet inte är angivet kommer terminalens kodning i den slutliga projektmiljön att sättas av den senast anslutna miljön där den är angiven, till exempel PHP-modulens miljö.
IP
Anger IP-adress(er) som används av alla projekt utan individuella inställningar.

Begränsning: Projekt som använder samma IP-adress måste köras på samma PHP-version.

Stöd för flera IP: Du kan ange flera IP-adresser separerade med mellanslag, inklusive IPv6. I HOSTS-filen tilldelas domäner den första angivna IP:n.

Automatisk tilldelning: Om fältet lämnas tomt tilldelas IP-adress automatiskt.

Rekommendationer:
  • Automatisk hantering av IP-adresser rekommenderas för de flesta användare.
  • Manuell angivelse av IP-adress bör användas endast vid specifika nätverkskrav.
HTTP
Anger porten för HTTP-anslutningar.
HTTPS
Anger porten för HTTPS-anslutningar.
TLS
Aktiverar eller inaktiverar stöd för TLS.
Certifikatfil
Anger sökvägen till TLS-certifikatfilen. Mallvariabler kan användas.

Tillåtna tecken: A-Za-z0-9-+_.\:

Rekommendation: Lämna fältet tomt för automatisk generering av certifikat.
Nyckelfil
Anger sökvägen till TLS-nyckelfilen. Mallvariabler kan användas.

Tillåtna tecken: A-Za-z0-9-+_.\:

Rekommendation: Lämna fältet tomt för automatisk generering av nyckel.
IP-adress (backend)
Anger IP-adressen som används för anslutning till serverdelen (Backend).
Port (backend)
Anger portnumret för anslutning till serverdelen (Backend).
Aktivera (backend)
Möjliggör automatisk vidarebefordran av all inkommande trafik (HTTP och HTTPS) för projektet till serverdelen (Backend). Användbart för testning eller utveckling när frontend och backend är separerade.
Projektkatalog
Anger projektets rotkatalog. Växling till denna katalog sker med kommandot osp project <DOMAIN> samtidigt som projektmiljön aktiveras. Mallvariabler kan användas.

Tillåtna tecken: A-Za-z0-9-+_.\:
Publik katalog
Anger projektets publika katalog. Mallvariabler kan användas.

Tillåtna tecken: A-Za-z0-9-+_.\:
Alias
Anger ytterligare domännamn (alias) för projektet (separeras med mellanslag). Mallvariabler kan användas.

Begränsning: Tecknet "*" stöds inte av HOSTS-filen i Windows och kräver DNS-konfiguration.
Projektmiljö
Lista över tillägg och moduler (separeras med mellanslag) som formar projektets miljö.

HTTP, NODE och PHP: Miljöerna för dessa motorer ansluts alltid (om de är angivna för domänen) och behöver inte anges i denna parameter.
Projektets startkommando
Anger kommandot för att starta projektet (t.ex. nodemon app.js). Mallvariabler kan användas.
Projektets URL
URL som används när projektet öppnas via Meny→Projekt→Öppna i webbläsare, samt när projektets domänalias öppnas. Mallvariabler kan användas.

Användning: Du kan ange URL till CMS administrationspanel.

Mallvariabler

Variabel Beskrivning
{backend_ip} IP-adress för anslutning till serverdelen (Backend)
{backend_port} Port för anslutning till serverdelen (Backend)
{base_dir} Projektets rotkatalog (där katalogen .osp finns)
{date_time} Aktuellt datum/tid (variabeln är endast tillgänglig för projektets applikationsstartkommando)
{host} Domännamn (för internationaliserade domäner används Punycode)
{host_decoded} Synligt domännamn (utan Punycode)
{host_scheme} Förfrågans schema till projektet ("http" eller "https", beror på parametern TLS i projektinställningarna)
{http_port} Port för förfrågan till projektet via HTTP
{https_port} Port för förfrågan till projektet via HTTPS
{http_engine} HTTP-motor
{node_engine} NODE-motor
{php_engine} PHP-motor
{project_root} Projektets rotkatalog
{web_root} Projektets publika katalog
{scheme_port} Port för förfrågan till projektet (":{http_port}" eller ":{https_port}", beror på parametern TLS i projektinställningarna).

Om {http_port} eller {https_port} har standardvärdet 80 eller 443 kommer {scheme_port} att vara tom.
{root_dir} Open Server Panels rotkatalog (fullständig sökväg)
{root_drive} Enheten för rotkatalogen
{root_path} Sökväg till Open Server Panels rotkatalog
{terminal_codepage} Konsolens kodning
