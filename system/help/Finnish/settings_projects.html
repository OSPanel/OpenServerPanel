Projektien globaalit asetukset

Tässä osiossa määritettyjä parametreja käytetään, jos projektin asetuksissa ei ole määritetty muita arvoja.

HTTP
Määrittää projekteissa käytettävän web-palvelinmoduulin.
NODE
Määrittää Node.js-moottorin Node.js-sovellusten suorittamiseen.

Node.js:n asennus: Asenna tarvittava Node.js-versio etukäteen komennolla osp node <latest|lts|numero>.
PHP
Määrittää käytettävän PHP-moduulin PHP-tiedostojen käsittelyyn.
Ota käyttöön
Määrittää projektin oletustilan (päälle tai pois päältä).
Päätteen merkistökoodaus
Päätteen merkistökoodaus projektin ympäristössä työskenneltäessä.

Erityisarvot:
- system: Käytetään järjestelmän merkistökoodausta.

Tärkeää: Jos arvoa ei ole asetettu, projektin lopullista ympäristöä muodostettaessa päätteen merkistökoodaus asetetaan viimeisimmän liitetyn ympäristön mukaisesti, jossa se on määritetty, esimerkiksi PHP-moduulin ympäristön mukaisesti.
IP
Asettaa IP-osoitteen/-osoitteet, joita käyttävät kaikki projektit ilman yksilöllisiä asetuksia.

Rajoitus: Sama IP-osoitetta käyttävien projektien on toimittava samalla PHP-versiolla.

Useiden IP:iden tuki: Voit määrittää useita IP-osoitteita välilyönnillä erotettuina, mukaan lukien IPv6. HOSTS-tiedostossa domaineille osoitetaan ensimmäinen määritetty IP.

Automaattinen määrittäminen: Jos kenttä jätetään tyhjäksi, IP-osoite määritetään automaattisesti.

Suositukset:
  • Automaattista IP-osoitteiden hallintaa suositellaan useimmille käyttäjille.
  • Manuaalista IP-osoitteen asettamista tulisi käyttää vain erityisten verkkokonfiguraatiovaatimusten yhteydessä.
HTTP
Määrittää HTTP-yhteyksien portin.
HTTPS
Määrittää HTTPS-yhteyksien portin.
TLS
Ottaa käyttöön tai poistaa käytöstä TLS-tuen.
Sertifikaattitiedosto
Määrittää polun TLS-sertifikaattitiedostoon. Voit käyttää mallimuuttujia.

Sallitut merkit: A-Za-z0-9-+_.\:

Suositus: Jätä kenttä tyhjäksi sertifikaattien automaattista luontia varten.
Avaintiedosto
Määrittää polun TLS-avaintiedostoon. Voit käyttää mallimuuttujia.

Sallitut merkit: A-Za-z0-9-+_.\:

Suositus: Jätä kenttä tyhjäksi avaimen automaattista luontia varten.
IP-osoite (backend)
Määrittää IP-osoitteen, jota pitkin muodostetaan yhteys palvelinpuoleen (Backend).
Portti (backend)
Määrittää porttinumeron yhteydelle palvelinpuoleen (Backend).
Ota käyttöön (backend)
Mahdollistaa kaiken projektin tulevan liikenteen (HTTP ja HTTPS) automaattisen ohjaamisen palvelinpuolelle (Backend). Hyödyllinen testauksessa tai kehityksessä, kun frontend ja backend ovat erillään.
Projektihakemisto
Määrittää projektin juurihakemiston. Siirtyminen tähän hakemistoon tapahtuu komennolla osp project <DOMAIN> samanaikaisesti projektin ympäristön aktivoinnin kanssa. Voit käyttää mallimuuttujia.

Sallitut merkit: A-Za-z0-9-+_.\:
Julkinen hakemisto
Määrittää projektin julkisen hakemiston. Voit käyttää mallimuuttujia.

Sallitut merkit: A-Za-z0-9-+_.\:
Aliakset
Määrittää projektin lisäverkkotunnukset (aliakset) välilyönnillä erotettuina. Voit käyttää mallimuuttujia.

Rajoitus: Merkkiä "*" ei tueta Windowsin HOSTS-tiedostossa ja se edellyttää DNS-määritystä.
Projektin ympäristö
Luettelo lisäosista ja moduuleista (välilyönnillä erotettuina), jotka muodostavat projektin ympäristön.

HTTP, NODE ja PHP: Näiden moottorien ympäristöt liitetään aina (jos ne on määritetty domainille) eikä niitä tarvitse ilmoittaa tässä parametrissa.
Projektin käynnityskomento
Määrittää komennon projektin käynnistämiseen (esimerkiksi nodemon app.js). Voit käyttää mallimuuttujia.
Projektin URL
URL, jota käytetään, kun projekti avataan Valikko→Projekti→Avaa selaimessa, sekä avattaessa projektin domain-aliasia. Voit käyttää mallimuuttujia.

Käyttö: Voit määrittää CMS:n hallintapaneelin URL-osoitteen.

Mallimuuttujat

Muuttuja Kuvaus
{backend_ip} Yhteyden IP-osoite palvelinpuolelle (Backend)
{backend_port} Yhteyden portti palvelinpuolelle (Backend)
{base_dir} Projektin juurihakemisto (missä .osp-hakemisto sijaitsee)
{date_time} Nykyinen päivämäärä/aika (muuttuja on käytettävissä vain projektisovelluksen käynnityskomennossa)
{host} Verkkotunnuksen nimi (kansainvälisten domainien osalta käytetään Punycodea)
{host_decoded} Näkyvä verkkotunnuksen nimi (ilman Punycodea)
{host_scheme} Projektin pyyntöjen skeema ("http" tai "https", riippuu projektin asetusten TLS-parametrista)
{http_port} Projektin pyyntöportti HTTP-protokollalla
{https_port} Projektin pyyntöportti HTTPS-protokollalla
{http_engine} HTTP-moottori
{node_engine} NODE-moottori
{php_engine} PHP-moottori
{project_root} Projektin juurihakemisto
{web_root} Projektin julkinen hakemisto
{scheme_port} Projektin pyyntöportti (":{http_port}" tai ":{https_port}", riippuu projektin asetusten TLS-parametrista).

Jos {http_port} tai {https_port} on oletusarvo 80 tai 443, {scheme_port} on tyhjä.
{root_dir} Open Server Panelin juurihakemisto (koko polku)
{root_drive} Juurihakemiston asema
{root_path} Polku Open Server Panelin juurihakemistoon
{terminal_codepage} Konsolin merkistökoodaus
