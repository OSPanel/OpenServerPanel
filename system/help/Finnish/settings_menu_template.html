Omien valikkokohtien luominen

  1. Lisää uusi osio, jolla on yksilöllinen tunniste [ID]
  2. Sijoita osiot haluttuun järjestykseen — tämä määrittää valikkokohtien järjestyksen
  3. Tallenna muutokset ja käynnistä Open Server Panel uudelleen, jotta muutokset tulevat voimaan

Tärkeää tietoa

Kun luot omia valikkokohtia, varmista, että osioiden tunnisteet eivät toistu. Tämä voi johtaa ristiriitoihin valikon toiminnassa.

Valikkokohtien asetukset

Lajittelujärjestys: Valikkokohdat lajitellaan samassa järjestyksessä kuin vastaavat osiot on sijoitettu mallissa.

caption Valikkokohdan otsikko. Tukee kielivakioita muodossa {lang_xxx}.

Oletus: ei asetettu
category

Määrittää valikkokohdan sijainnin hierarkiassa. Tukee yhtä sisennystasoa (esimerkiksi "Omat kirjanmerkit\Työ").

Erikoiskategoriat:

  • projects, modules, addons - lisää kohdan vastaavaan toimenpidevalikkoon
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - lisää kohdan tietylle elementille

Jos kategoriaa ei ole määritetty, kohta luodaan juurivalikkoon.

Oletus: ei asetettu
command Komento, joka suoritetaan valikkokohdan aktivoinnissa. Kohdat ilman komentoa ohitetaan.

Oletus: ei asetettu
enabled Ottaa käyttöön/pois käytöstä valikkokohdan näyttämisen.

Oletus: on | Arvot: on, off
hide Hallitsee kutsutun sovellusikkunan näkyvyyttä. Ei vaikuta lapsiprosesseihin.

Oletus: off | Arvot: on, off
hr_after Lisää vaakasuoran erotinviivan valikkokohdan jälkeen.

Oletus: off | Arvot: on, off
hr_before Lisää vaakasuoran erotinviivan ennen valikkokohtaa.

Oletus: off | Arvot: on, off
icon Ikoni Font Awesome Free -kokoelmasta (Solid/Regular/Brands).

Oletus: ei asetettu
need_alias Näyttää valikkokohdan vain domain-aliasille. Valikkomallissa voi olla vain yksi kohta, jossa need_alias=on!
Soveltuu kategorioille: projects

Oletus: ei asetettu | Arvot: on, off
need_category

Rajoittaa valikkokohdan näyttämisen tietyn kategorian moduleille/addoneille.

Tuetut muodot:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Oletus: ei asetettu
need_module_shell Näyttää valikkokohdan sen mukaan, onko ylätason modulilla shell/cli käytettävissä.
Soveltuu kategorioille: modules, modules\<имя_модуля>

Oletus: ei asetettu | Arvot: on, off
need_state Näyttää valikkokohdan ylätason modulin tilan perusteella.
Soveltuu kategorioille: modules, modules\<имя_модуля>

Oletus: ei asetettu | Arvot: on, off
need_start_cmd Näyttää valikkokohdan, jos projektin asetuksissa on käynnistyskomento.
Soveltuu kategorioille: projects, projects\<имя_домена>

Oletus: ei asetettu | Arvot: on, off
need_use_wt Näyttää valikkokohdan Open Server Panelin Windows Terminal -käyttöasetuksen mukaan.

Oletus: ei asetettu | Arvot: on, off
work_directory Työhakemisto komennon suorittamista varten. Voi muuttua komentojen suorituksen aikana.

Oletus: {root_dir}

Mallimuuttujat

Parametreissa "command" ja "work_directory" voidaan käyttää seuraavia mallimuuttujia:

Yleiset muuttujat

Muuttuja Kuvaus
{date_time} Nykyinen päiväys/aika (muuttuja on käytettävissä vain parametrille "command")
{root_dir} Open Server Panelin juurihakemisto (täysi polku)
{root_drive} Juurihakemiston asema
{root_path} Polku Open Server Panelin juurihakemistoon
{web_panel_url} Web-käyttöliittymän URL-osoite

Erityismuuttujat (vain projects ja projects\<имя_домена>)

Muuttuja Kuvaus
{base_dir} Projektin perushakemisto
{host} Verkkotunnuksen nimi (Punycode)
{host_decoded} Näkyvä verkkotunnuksen nimi (ilman Punycodea)
{host_scheme} Projektin pyyntöjärjestelmä ("http" tai "https", riippuu TLS-asetuksesta projektissa)
{http_port} Projektin HTTP-pyynnön portti
{https_port} Projektin HTTPS-pyynnön portti
{menu_caption} Valikkokohdan otsikko (vain kategoriassa projects, kun need_alias=ON)
{http_engine} HTTP-moottori
{node_engine} Node.js -moottori
{php_engine} PHP-moottori
{project_root} Projektin juurihakemisto
{base_url} Projektin URL
{web_root} Projektin julkinen hakemisto
{scheme_port} Projektin pyynnön portti (":{http_port}" tai ":{https_port}", riippuu TLS-asetuksesta projektissa). Jos {http_port} tai {https_port} on vakioarvo 80 tai 443, {scheme_port} on tyhjä.
{app_start_command} Projektin sovelluksen käynnityskomento (jos määritetty)
{terminal_codepage} Konsolin merkistökoodaus

Erityismuuttujat (vain addons ja addons\<имя_дополнения>)

Muuttuja Kuvaus
{addon_name} Lisäosan nimi
{terminal_codepage} Konsolin merkistökoodaus

Erityismuuttujat (vain modules ja modules\<имя_модуля>)

Muuttuja Kuvaus
{ip} Modulin IP-osoite
{log_level} Virhelokituksen taso
{module_name} Modulin nimi
{port} Modulin portti
{profile_name} Modulin nykyisen asetusprofiilin nimi
{query_log_level} Pyyntölokituksen taso
{shell_command} Modulin shell/cli -kuoren käynnityskomento (jos määritetty)
{terminal_codepage} Konsolin merkistökoodaus
{time_zone} Aikavyöhyke

Erityiset komentojen arvot

Komento Kuvaus
command_open_logs_viewer Avaa lokien katseluikkunan
command_open_idn_converter Avaa IDN-muuntimen
command_open_options Avaa ohjelman asetusikkunan

Mallimuuttujien lisäksi voidaan käyttää mitä tahansa Windowsin ympäristömuuttujia, esimerkiksi: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% jne.

Käyttöesimerkki

[bookmark_1]

caption  = Google
category = Omat kirjanmerkit\Hakukoneet
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE -asetukset

  • /c: Suorita komento ja sulje terminaali.
  • /k: Suorita komento ja jätä terminaali auki.
