Ohjelman asetukset

Käynnistä yhdessä Windowsin kanssa
Ota käyttöön Open Server Panelin automaattinen käynnistys käyttöjärjestelmän latautuessa.
Viive
Ohjelman käynnistysviive (sekunteina, 0–60).

Mahdollistaa sovelluksen käynnistyksen lykkäämisen Windowsin käynnistyksen yhteydessä, jotta järjestelmän kokonaiskuormitus vähenee. Tämä on erityisen hyödyllistä, jos on odotettava ulkoisten palveluiden tai verkkoliitäntöjen täydellistä alustusta.
Tarkista uusien versioiden saatavuus
Ota käyttöön Open Server Panelin päivitysten tarkistus (Internet-yhteys vaaditaan).
Ota käyttöön Tehtäväajastin
Aktivoi sisäänrakennettu tehtäväajastin. Jos asetus on pois päältä, yhtään ajastettua tehtävää ei suoriteta niiden tilasta riippumatta.
Käytä HOSTS-tiedostoa
Ota käyttöön verkkotunnusten kirjoitus HOSTS-tiedostoon.

Suositukset, kun organisaatiossa on rajoitettu pääsy HOSTS-tiedostoon:

1. Määritä kaikki tarvittavat moduulit ja projektit.
2. Ota yhteyttä järjestelmänvalvojaan, jotta HOSTS avataan ja sen tila lukitaan.
3. Muutosten lukituksen jälkeen voit poistaa tämän valinnan käytöstä.

Tärkeää: Älä poista tätä asetusta käytöstä, ellet ole varma seurauksista!
Käynnistä moduulit projektin profiililla
Käynnistä moduulit samanaikaisesti aktivoiden profiilin, joka vastaa projektin nimeä.

Käytetään valittaessa valikosta ”Ota projektin moduulit käyttöön”, jotta profiili, jonka nimi on sama kuin nykyisen projektin, aktivoidaan automaattisesti, jos sellainen on olemassa.
Älä sammuta piilotettujen projektien moduuleja
Älä sammuta piilotettujen projektien moduuleja, kun valitaan valikosta ”Sammuta kaikki moduulit”. ”Piilotetuilla” tarkoitetaan projekteja, joille on asetettu kategoria ”hidden”.

Oletuksena komento ”Sammuta kaikki moduulit” pysäyttää kaikkien moduulien toiminnan, mukaan lukien niiden, joita käyttävät piilotetut ylläpitoprojektit (esim. PHPMyAdmin). Tämä valinta antaa säilyttää piilotettujen ylläpitoprojektien toimivuuden sammuttamatta niille tarvittavia moduuleja, samalla kun kaikki muut moduulit sammutetaan.
Käyttöliittymän kieli
Open Server Panelin käyttöliittymän kieli.

Jos lokalisointitiedosto puuttuu tai sisältää virheitä, käytetään englannin kieltä.
API-domain
Paikallinen domain API:lle ja web-käyttöliittymälle (kehitteillä)

Suositus: Jos käytössä on VPN tai välityspalvelin, lisää tämä domain poikkeuksiin.
API:n IP-osoite
IPv4-osoite API:lle ja web-käyttöliittymälle (kehitteillä).

Suositus: Jos käytössä on VPN tai välityspalvelin, lisää tämä IP-osoite poikkeuksiin.
API-portti
Portti, jota käytetään API:lle ja web-käyttöliittymälle (kehitteillä). Open Server Panel ei käynnisty, jos määritettyä porttia käyttää jo toinen sovellus.
Käytä Windows Terminalia
Ota käyttöön Windows Terminalin käyttö oletuskomentorajapinnan sijasta.

Vaatimukset: Windows Terminal on oltava asennettuna järjestelmään ja määritettynä PATH-ympäristömuuttujaan.

Windows Terminal cmd.exe:nä: Windows Terminal voi korvata cmd.exe:n ja olla määritettynä %COMSPEC%-ympäristömuuttujaan Windowsin uudemmissa versioissa. Jos näin on, jätä tämä asetus päälle.

Windows Terminalin uudet instanssit: Jos Windows Terminal avaa uusia ikkunoita välilehtien sijaan, säädä se näin: Asetukset→Käynnistys→Uuden instanssin toiminta→Liitä viimeksi käytettyyn ikkunaan.
Lyhyt projektin otsikko
Kun tämä valinta on käytössä, terminaali-ikkunan otsikossa näytetään vain projektin nimi ympäristön yksityiskohtaisen kuvauksen sijaan.
Sisällytä järjestelmäympäristö projektin ympäristöön
Käytä järjestelmän (System) ympäristöä terminaalissa, vaikka sitä ei olisi määritetty projektin asetuksissa. Järjestelmäympäristö mahdollistaa järjestelmään asennettujen ohjelmien käytön (esim. git.exe tai ssh.exe).

Poista tämä valinta käytöstä vain, jos järjestelmäohjelmiston kanssa ilmenee ristiriitoja.
ANSI-tuki
Ota käyttöön ANSI-koodien tuki värien hallintaan terminaalissa.

Tila ”Automaattinen” (oletus):
- Korjaus sovelletaan vain Windows 10:een versioon 1903 asti (mukaan lukien). Uudemmissa Windows-versioissa ANSI-tuki on jo sisäänrakennettu.
- Korjausta ei sovelleta terminaaleihin, jotka tukevat ANSIa oletuksena (esim. Windows Terminal).
Projektien hakemistot
Luettelo hakemistoista, joista Open Server Panel etsii projekteja. Erota polut puolipisteellä (;).

Poikkeukset: Alikansiot node_modules ja vendor ohitetaan.
Syvyys
Suurin hakemistojen sisäkkäisyyden syvyys projekteja etsittäessä.

Tämän arvon kasvattaminen voi hidastaa Open Server Panelin käynnistystä, jos määritetyissä hakemistoissa on suuri määrä alihakemistoja.
Lokin maksimikoko
Lokitiedoston enimmäiskoko megatavuina. Jos määritetty arvo ylittyy, lokitiedosto luodaan uudelleen seuraavan ohjelman käynnistyksen yhteydessä.

Aseta arvoksi 0, jotta lokit tyhjennetään jokaisella ohjelman käynnistyksellä.

Aseta arvoksi 100 Mt, jotta lokien tyhjennys poistetaan kokonaan käytöstä.
