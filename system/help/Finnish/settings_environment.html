Moduulien globaalit ympäristömuuttujat

Tässä osiossa voit määrittää moduuleille globaalit ympäristömuuttujat.

Nämä muuttujat ovat voimassa vain moduulien ympäristössä eivätkä vaikuta järjestelmän muuttujiiin tai projektien ympäristöön.

Arvoissa voidaan käyttää mallimuuttujia.

Jos muuttuja on läsnä järjestelmän ympäristössä, mutta sitä ei tule käyttää moduulien ympäristössä, käytä erityistä suodatinta (ks. Moduulit→Sallitut järjestelmämuuttujat) tai poista muuttuja ympäristöstä antamalla sille tyhjä arvo.

Mallimuuttujat

Muuttuja Kuvaus
{root_dir} Open Server Panelin juurihakemisto (koko polku)
{root_drive} Juurihakemiston asema
{root_path} Polku Open Server Panelin juurihakemistoon
{terminal_codepage} Koodaus terminaalissa (ks. Moduulit→Koodaus terminaalissa)
{time_zone} Aikavyöhyke muodossa Etc/GMT (ks. Moduulit→Aikavyöhyke)

Mallimuuttujien lisäksi voidaan käyttää mitä tahansa Windowsin ympäristömuuttujia, esimerkiksi: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% jne.
