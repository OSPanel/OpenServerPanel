專案全域設定

在此區段中指定的參數，將在專案設定未提供其他值時使用。

HTTP
定義專案所使用的 Web 伺服器模組。
NODE
指定用於執行 Node.js 應用的 Node.js 引擎。

安裝 Node.js： 請先使用指令 osp node <latest|lts|номер> 安裝所需版本的 Node.js。
PHP
定義用於處理 PHP 檔案的 PHP 模組。
啟用
定義專案的預設狀態（啟用或停用）。
終端機編碼
專案環境工作的終端機編碼。

特殊值：
- system: 使用系統編碼。

重要： 若未設定此值，在組成最終的專案環境時，終端機編碼將採用最後被載入且有設定此值的環境，例如 PHP 模組的環境。
IP
設定提供給所有未做個別設定之專案使用的 IP 位址。

限制： 使用相同 IP 位址的專案必須在同一版本的 PHP 上運行。

多 IP 支援： 可透過空白分隔指定多個 IP 位址，包含 IPv6。在 HOSTS 檔案中，網域將指派為第一個所填的 IP。

自動指派： 若留白，IP 位址將自動指派。

建議：
  • 大多數使用者建議使用自動管理 IP 位址。
  • 僅在具特定網路配置需求時才使用手動指定 IP 位址。
HTTP
定義 HTTP 連線的連接埠。
HTTPS
定義 HTTPS 連線的連接埠。
TLS
啟用或停用 TLS 支援。
憑證檔案
指定 TLS 憑證檔案路徑。可使用樣板變數。

可用字元： A-Za-z0-9-+_.\:

建議： 留白以自動產生憑證。
金鑰檔案
指定 TLS 金鑰檔案路徑。可使用樣板變數。

可用字元： A-Za-z0-9-+_.\:

建議： 留白以自動產生金鑰。
IP 位址（backend）
指定連線到後端（Backend）的 IP 位址。
連接埠（backend）
定義連線到後端（Backend）的連接埠號碼。
啟用（backend）
允許自動將專案的所有入站流量（HTTP 與 HTTPS）導向到後端（Backend）。對於前後端分離的測試或開發情境很有用。
專案目錄
指定專案的根目錄。執行 osp project <DOMAIN> 指令並同時啟用專案環境時，會切換至此目錄。可使用樣板變數。

允許字元： A-Za-z0-9-+_.\:
公開目錄
定義專案的公開目錄。可使用樣板變數。

允許字元： A-Za-z0-9-+_.\:
別名
指定專案的額外網域名稱（別名，以空白分隔）。可使用樣板變數。

限制： 符號「*」在 Windows 的 HOSTS 檔案中不受支援，需透過 DNS 設定。
專案環境
構成專案環境的附加元件與模組清單（以空白分隔）。

HTTP、NODE 與 PHP： 這些引擎的環境會在為網域設定時自動載入，無需在此參數中指定。
專案啟動指令
定義啟動專案的指令（例如，nodemon app.js）。可使用樣板變數。
專案 URL
開啟專案時使用的 URL（選單→專案→在瀏覽器中開啟），以及開啟專案網域別名時使用的 URL。可使用樣板變數。

應用： 可以指定 CMS 後台管理面板的 URL。

樣板變數

變數 說明
{backend_ip} 連線到後端（Backend）的 IP 位址
{backend_port} 連線到後端（Backend）的連接埠
{base_dir} 專案根目錄（.osp 目錄所在位置）
{date_time} 目前日期/時間（僅在專案應用啟動指令中可用的變數）
{host} 網域名稱（針對國際化網域使用 Punycode）
{host_decoded} 可見的網域名稱（不含 Punycode）
{host_scheme} 對專案的請求方案（"http" 或 "https"，取決於專案設定中的 TLS 參數）
{http_port} 以 HTTP 協定對專案發出請求的連接埠
{https_port} 以 HTTPS 協定對專案發出請求的連接埠
{http_engine} HTTP 引擎
{node_engine} NODE 引擎
{php_engine} PHP 引擎
{project_root} 專案根目錄
{web_root} 專案公開目錄
{scheme_port} 對專案請求所用的連接埠（":{http_port}" 或 ":{https_port}"，取決於專案設定中的 TLS 參數）。

若 {http_port} 或 {https_port} 為標準值 80 或 443，則 {scheme_port} 為空。
{root_dir} Open Server Panel 根目錄（完整路徑）
{root_drive} 根目錄所在磁碟
{root_path} Open Server Panel 的根目錄路徑
{terminal_codepage} 主控台編碼
