模組環境的全域變數

在本節中可以為模組設定全域環境變數。

這些變數僅在模組環境中生效，不會影響系統變數或專案環境。

在值中允許使用樣板變數。

如果變數存在於系統環境中，但不應在模組環境中使用，請使用專用的篩選器（見 模組→允許的系統變數）或將其值設為空以從環境中移除該變數。

樣板變數

變數 說明
{root_dir} Open Server Panel 的根目錄（完整路徑）
{root_drive} 根目錄所在的磁碟
{root_path} Open Server Panel 的根目錄路徑
{terminal_codepage} 終端的編碼（見 模組→終端的編碼）
{time_zone} Etc/GMT 格式的時區（見 模組→時區）

除了樣板變數之外，還可以使用任何 Windows 環境變數，例如：%SYSTEMROOT%、%SYSTEMDRIVE%、%USERNAME%、%PATH% 等。
