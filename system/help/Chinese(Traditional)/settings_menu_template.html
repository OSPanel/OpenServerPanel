建立自訂功能表項目

  1. 新增具有唯一識別碼 [ID] 的新區段
  2. 按所需順序排列各區段——這將決定功能表項目的順序
  3. 儲存變更並重新啟動 Open Server Panel 以套用變更

重要資訊

建立自訂功能表項目時，請確保區段識別碼不重複。否則可能導致功能表運作衝突。

功能表項目設定

排序順序： 功能表項目依照樣板中相應區段的排列順序進行排序。

caption 功能表項目的標題。支援格式為 {lang_xxx} 的語言常數。

預設：未設定
category

定義功能表項目在階層中的位置。支援一級巢狀（例如，「我的書籤\工作」）。

特殊類別：

  • projects, modules, addons - 將項目加入相應的動作功能表
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - 為特定元素新增項目

若未指定類別，項目將建立於根功能表。

預設：未設定
command 啟用功能表項目時要執行的指令。沒有指令的項目會被忽略。

預設：未設定
enabled 啟用/停用功能表項目的顯示。

預設：on | 值：on, off
hide 控制所呼叫應用程式視窗的可見性。不影響子進程。

預設：off | 值：on, off
hr_after 在功能表項目之後新增水平分隔線。

預設：off | 值：on, off
hr_before 在功能表項目之前新增水平分隔線。

預設：off | 值：on, off
icon 來自 Font Awesome Free (Solid/Regular/Brands) 的圖示。

預設：未設定
need_alias 僅在網域別名下顯示功能表項目。樣板功能表中只能有一個 need_alias=on 的項目！
適用類別：projects

預設：未設定 | 值：on, off
need_category

限制僅對特定類別的模組/外掛顯示功能表項目。

支援格式：

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
預設：未設定
need_module_shell 依據父模組是否具有 shell/cli 顯示功能表項目。
適用類別：modules, modules\<имя_модуля>

預設：未設定 | 值：on, off
need_state 依據父模組的狀態顯示功能表項目。
適用類別：modules, modules\<имя_модуля>

預設：未設定 | 值：on, off
need_start_cmd 當專案設定中存在啟動指令時顯示功能表項目。
適用類別：projects, projects\<имя_домена>

預設：未設定 | 值：on, off
need_use_wt 依據 Open Server Panel 中使用 Windows Terminal 的設定顯示功能表項目。

預設：未設定 | 值：on, off
work_directory 執行指令的工作目錄。在執行過程中可能變更。

預設：{root_dir}

樣板變數

在參數「command」與「work_directory」中可使用以下樣板變數：

通用變數

變數 說明
{date_time} 目前日期/時間（僅適用於參數「command」）
{root_dir} Open Server Panel 的根目錄（完整路徑）
{root_drive} 根目錄所在的磁碟機
{root_path} Open Server Panel 的根目錄路徑
{web_panel_url} Web 介面 URL 位址

特殊變數（僅適用於 projects 與 projects\<имя_домена>）

變數 說明
{base_dir} 專案的基本目錄
{host} 網域名稱（Punycode）
{host_decoded} 可見的網域名稱（非 Punycode）
{host_scheme} 對專案的請求方案（"http" 或 "https"，取決於專案設定中的 TLS 參數）
{http_port} 透過 HTTP 協定對專案的請求埠
{https_port} 透過 HTTPS 協定對專案的請求埠
{menu_caption} 功能表項目的標題（僅適用於類別 projects 且 need_alias=ON）
{http_engine} HTTP 引擎
{node_engine} Node.js 引擎
{php_engine} PHP 引擎
{project_root} 專案根目錄
{base_url} 專案 URL
{web_root} 專案公開目錄
{scheme_port} 對專案的請求埠（":{http_port}" 或 ":{https_port}"，取決於專案設定中的 TLS 參數）。如果 {http_port} 或 {https_port} 為標準值 80 或 443，則 {scheme_port} 為空。
{app_start_command} 專案應用程式的啟動指令（若已設定）
{terminal_codepage} 主控台編碼

特殊變數（僅適用於 addons 與 addons\<имя_дополнения>）

變數 說明
{addon_name} 外掛名稱
{terminal_codepage} 主控台編碼

特殊變數（僅適用於 modules 與 modules\<имя_модуля>）

變數 說明
{ip} 模組的 IP 位址
{log_level} 錯誤日誌等級
{module_name} 模組名稱
{port} 模組埠
{profile_name} 模組目前設定設定檔名稱
{query_log_level} 查詢日誌等級
{shell_command} 模組的 shell/cli 啟動指令（若已設定）
{terminal_codepage} 主控台編碼
{time_zone} 時區

特殊指令值

指令 說明
command_open_logs_viewer 開啟日誌檢視視窗
command_open_idn_converter 開啟 IDN 轉換器
command_open_options 開啟程式設定視窗

除了樣板變數之外，亦可使用任何 Windows 環境變數，例如：%SYSTEMROOT%、%SYSTEMDRIVE%、%USERNAME%、%PATH% 等。

使用範例

[bookmark_1]

caption  = Google
category = 我的書籤\搜尋引擎
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE 選項

  • /c：執行指令後關閉終端機。
  • /k：執行指令後保留終端機開啟。
