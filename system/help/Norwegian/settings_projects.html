Globale prosjektinnstillinger

Parametrene angitt i denne seksjonen brukes hvis andre verdier ikke er spesifisert i prosjektinnstillingene.

HTTP
Angir hvilken webservermodul som brukes for prosjekter.
NODE
Angir Node.js-motoren for å kjøre Node.js-applikasjoner.

Installering av Node.js: Installer ønsket versjon av Node.js på forhånd med kommandoen osp node <latest|lts|номер>.
PHP
Angir hvilken PHP-modul som brukes for å behandle PHP-filer.
Aktiver
Angir standardtilstanden for prosjektet (aktivert eller deaktivert).
Terminalkoding
Terminalens tegnkoding ved arbeid med prosjektmiljøet.

Spesielle verdier:
- system: Systemets koding brukes.

Viktig: Hvis verdien ikke er satt, vil terminalkoding ved opprettelse av prosjektets endelige miljø settes av det sist tilkoblede miljøet der den er angitt, for eksempel PHP-modulens miljø.
IP
Angir IP-adresse(r) som brukes av alle prosjekter uten individuelle innstillinger.

Begrensning: Prosjekter som bruker samme IP-adresse må kjøre på samme PHP-versjon.

Støtte for flere IP-er: Du kan angi flere IP-adresser separert med mellomrom, inkludert IPv6. I HOSTS-filen vil domener få tildelt den første angitte IP-en.

Automatisk tildeling: Hvis feltet er tomt, tildeles IP-adressen automatisk.

Anbefalinger:
  • Automatisk håndtering av IP-adresser anbefales for de fleste brukere.
  • Manuell angivelse av IP-adresse bør kun brukes ved spesifikke krav i nettverkskonfigurasjonen.
HTTP
Angir porten for forbindelser over HTTP.
HTTPS
Angir porten for forbindelser over HTTPS.
TLS
Aktiverer eller deaktiverer støtte for TLS.
Sertifikatfil
Angir stien til TLS-sertifikatfilen. Malvariabler kan brukes.

Tillatte tegn: A-Za-z0-9-+_.\:

Anbefaling: La feltet stå tomt for automatisk generering av sertifikater.
Nøkkelfil
Angir stien til TLS-nøkkelfilen. Malvariabler kan brukes.

Tillatte tegn: A-Za-z0-9-+_.\:

Anbefaling: La feltet stå tomt for automatisk generering av nøkkel.
IP-adresse (backend)
Angir IP-adressen som brukes for tilkobling til serverdelen (Backend).
Port (backend)
Angir portnummeret for tilkobling til serverdelen (Backend).
Aktiver (backend)
Lar deg automatisk videresende all innkommende trafikk (HTTP og HTTPS) for prosjektet til serverdelen (Backend). Nyttig for testing eller utvikling når frontend og backend er separert.
Prosjektkatalog
Angir prosjektets rotkatalog. Navigasjon til denne katalogen utføres med kommandoen osp project <DOMAIN> samtidig med aktivering av prosjektmiljøet. Malvariabler kan brukes.

Tillatte tegn: A-Za-z0-9-+_.\:
Offentlig katalog
Angir prosjektets offentlige katalog. Malvariabler kan brukes.

Tillatte tegn: A-Za-z0-9-+_.\:
Alias
Angir ekstra domenenavn (alias) for prosjektet (separert med mellomrom). Malvariabler kan brukes.

Begrensning: Tegnet "*" støttes ikke av Windows HOSTS-filen og krever DNS-konfigurasjon.
Prosjektmiljø
Liste over tillegg og moduler (separert med mellomrom) som danner prosjektets miljø.

HTTP, NODE og PHP: Miljøene til disse motorene kobles alltid til (hvis angitt for domenet) og trenger ikke spesifiseres i denne parameteren.
Kommando for å starte prosjektet
Angir kommandoen for å starte prosjektet (for eksempel nodemon app.js). Malvariabler kan brukes.
Prosjekt-URL
URL-en som brukes når prosjektet åpnes via Meny→Prosjekt→Åpne i nettleser, samt når prosjektets domenealias åpnes. Malvariabler kan brukes.

Bruk: Du kan angi URL-en til CMS-administrasjonspanelet.

Malvariabler

Variabel Beskrivelse
{backend_ip} IP-adresse for tilkobling til serverdelen (Backend)
{backend_port} Port for tilkobling til serverdelen (Backend)
{base_dir} Prosjektets rotkatalog (der .osp-katalogen finnes)
{date_time} Nåværende dato/tid (variabelen er kun tilgjengelig for kommandoen for å starte prosjektets applikasjon)
{host} Domenenavn (for internasjonaliserte domener brukes Punycode)
{host_decoded} Synlig domenenavn (uten Punycode)
{host_scheme} Forespørselsskjema til prosjektet ("http" eller "https", avhenger av TLS-parameteren i prosjektinnstillingene)
{http_port} Port for forespørsel til prosjektet via HTTP-protokollen
{https_port} Port for forespørsel til prosjektet via HTTPS-protokollen
{http_engine} HTTP-motor
{node_engine} NODE-motor
{php_engine} PHP-motor
{project_root} Prosjektets rotkatalog
{web_root} Prosjektets offentlige katalog
{scheme_port} Port for forespørsel til prosjektet (":{http_port}" eller ":{https_port}", avhenger av TLS-parameteren i prosjektinnstillingene).

Hvis {http_port} eller {https_port} har standardverdien 80 eller 443, vil {scheme_port} være tom.
{root_dir} Rotkatalogen til Open Server Panel (full sti)
{root_drive} Disken til rotkatalogen
{root_path} Sti til rotkatalogen til Open Server Panel
{terminal_codepage} Konsollkoding
