Opprette egne menyelementer

  1. Legg til en ny seksjon med en unik identifikator [ID]
  2. Plasser seksjonene i ønsket rekkefølge — dette bestemmer rekkefølgen på elementene i menyen
  3. Lagre endringene og start Open Server Panel på nytt for å anvende endringene

Viktig informasjon

Når du oppretter egne menyelementer, sørg for at seksjonsidentifikatorene er unike. Duplisering kan føre til konflikter i menyfunksjonen.

Innstillinger for menyelementer

Sorteringsrekkefølge: Menyelementer sorteres i samme rekkefølge som de tilsvarende seksjonene i malen.

caption Tittel på menyelementet. Støtter språkkonstanter i formatet {lang_xxx}.

Som standard: ikke angitt
category

Bestemmer plasseringen av menyelementet i hierarkiet. Støtter ett nivå med nestinger (for eksempel "Mine bokmerker\Arbeid").

Spesielle kategorier:

  • projects, modules, addons - legger til elementet i den tilsvarende handlingsmenyen
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - legger til element for et spesifikt objekt

Hvis kategori ikke er angitt, opprettes elementet i rotmenyen.

Som standard: ikke angitt
command Kommandoen som kjøres når menyelementet aktiveres. Elementer uten kommando ignoreres.

Som standard: ikke angitt
enabled Aktiverer/deaktiverer visning av menyelementet.

Som standard: on | Verdier: on, off
hide Styrer synligheten til vinduet for det startede programmet. Påvirker ikke underprosesser.

Som standard: off | Verdier: on, off
hr_after Legger til en horisontal skillelinje etter menyelementet.

Som standard: off | Verdier: on, off
hr_before Legger til en horisontal skillelinje før menyelementet.

Som standard: off | Verdier: on, off
icon Ikon fra Font Awesome Free (Solid/Regular/Brands).

Som standard: ikke angitt
need_alias Viser menyelementet kun for et domenealias. Det kan bare være ett element med need_alias=on i meny-malen!
Gjelder for kategorier: projects

Som standard: ikke angitt | Verdier: on, off
need_category

Begrenser visning av menyelementet til modules/addons i en bestemt kategori.

Støttede formater:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
Som standard: ikke angitt
need_module_shell Viser menyelementet avhengig av om overordnet modul har shell/cli.
Gjelder for kategorier: modules, modules\<имя_модуля>

Som standard: ikke angitt | Verdier: on, off
need_state Viser menyelementet avhengig av tilstanden til overordnet modul.
Gjelder for kategorier: modules, modules\<имя_модуля>

Som standard: ikke angitt | Verdier: on, off
need_start_cmd Viser menyelementet hvis det finnes en startkommando i prosjektinnstillingene.
Gjelder for kategorier: projects, projects\<имя_домена>

Som standard: ikke angitt | Verdier: on, off
need_use_wt Viser menyelementet avhengig av innstillingen for bruk av Windows Terminal i Open Server Panel.

Som standard: ikke angitt | Verdier: on, off
work_directory Arbeidskatalog for å kjøre kommandoen. Kan endres under kommandokjøring.

Som standard: {root_dir}

Maler-variabler

I parameterne "command" og "work_directory" kan du bruke følgende malvariabler:

Generelle variabler

Variabel Beskrivelse
{date_time} Nåværende dato/tid (variabelen er kun tilgjengelig for parameteren "command")
{root_dir} Rotkatalogen til Open Server Panel (full sti)
{root_drive} Stasjonen for rotkatalogen
{root_path} Sti til rotkatalogen til Open Server Panel
{web_panel_url} URL-adresse til webgrensesnittet

Spesielle variabler (kun for projects og projects\<имя_домена>)

Variabel Beskrivelse
{base_dir} Prosjektets basiskatalog
{host} Domenenavn (Punycode)
{host_decoded} Synlig domenenavn (uten Punycode)
{host_scheme} Forespørselsskjema til prosjektet ("http" eller "https", avhenger av TLS-parameteren i prosjektinnstillingene)
{http_port} Port for forespørsel til prosjektet via HTTP
{https_port} Port for forespørsel til prosjektet via HTTPS
{menu_caption} Tittel på menyelementet (kun for kategorien projects med need_alias=ON)
{http_engine} HTTP-motor
{node_engine} Node.js-motor
{php_engine} PHP-motor
{project_root} Prosjektets rotkatalog
{base_url} Prosjektets URL
{web_root} Prosjektets offentlige katalog
{scheme_port} Port for forespørsel til prosjektet (":{http_port}" eller ":{https_port}", avhenger av TLS-parameteren i prosjektinnstillingene). Hvis {http_port} eller {https_port} har standardverdien 80 eller 443, vil {scheme_port} være tom.
{app_start_command} Startkommando for prosjektets applikasjon (hvis konfigurert)
{terminal_codepage} Konsollens tegnsett

Spesielle variabler (kun for addons og addons\<имя_дополнения>)

Variabel Beskrivelse
{addon_name} Navn på tillegg
{terminal_codepage} Konsollens tegnsett

Spesielle variabler (kun for modules og modules\<имя_модуля>)

Variabel Beskrivelse
{ip} Modulens IP-adresse
{log_level} Nivå for feillogging
{module_name} Modulnavn
{port} Modulens port
{profile_name} Navn på gjeldende modulprofil
{query_log_level} Nivå for forespørselslogging
{shell_command} Kommando for å starte modulens shell/cli (hvis konfigurert)
{terminal_codepage} Konsollens tegnsett
{time_zone} Tidssone

Spesielle kommandoverdier

Kommando Beskrivelse
command_open_logs_viewer Åpne loggvisningsvinduet
command_open_idn_converter Åpne IDN-konverter
command_open_options Åpne programinnstillinger

I tillegg til malvariabler kan du bruke alle Windows-miljøvariabler, for eksempel: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% osv.

Eksempel på bruk

[bookmark_1]

caption  = Google
category = Mine bokmerker\Søkemotorer
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Alternativer for CMD.EXE

  • /c: Kjør kommandoen og lukk terminalen.
  • /k: Kjør kommandoen og la terminalen stå åpen.
