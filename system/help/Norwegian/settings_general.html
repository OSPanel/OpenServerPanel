Programinnstillinger

Start sammen med Windows
Aktiver autostart av Open Server Panel ved oppstart av operativsystemet.
Forsinkelse
Forsinkelse for oppstart av programmet (i sekunder, fra 0 til 60).

Lar deg utsette oppstart av applikasjonen under innlasting sammen med Windows for å redusere den totale belastningen på systemet. Dette er spesielt nyttig hvis du må vente på full initialisering av tredjepartstjenester eller nettverksgrensesnitt.
Sjekk for nye versjoner
Aktiver søk etter oppdateringer for Open Server Panel (krever internettilkobling).
Aktiver oppgaveplanlegger
Aktiver den innebygde oppgaveplanleggeren. Hvis parameteren er deaktivert, vil ingen planlagte oppgaver kjøres, uavhengig av status.
Bruk HOSTS-filen
Aktiver skriving av domenenavn til HOSTS-filen.

Anbefalinger ved begrenset tilgang til HOSTS-filen i en organisasjon:

1. Konfigurer alle nødvendige moduler og prosjekter.
2. Kontakt systemadministratoren for å låse opp HOSTS og låse dens tilstand.
3. Etter at endringene er låst av administratoren, kan dette alternativet deaktiveres.

Viktig: Ikke deaktiver denne parameteren hvis du ikke er sikker på konsekvensene!
Start moduler med prosjektprofil
Start moduler med samtidig aktivering av en profil som samsvarer med prosjektnavnet.

Brukes når du velger menyen «Aktiver prosjektmoduler» for automatisk å aktivere profilen med samme navn som det gjeldende prosjektet, hvis en slik finnes.
Ikke slå av moduler til skjulte prosjekter
Ikke slå av moduler til skjulte prosjekter når du velger menyen «Slå av alle moduler». Med "skjulte" menes de prosjektene som har kategorien "hidden".

Som standard stopper kommandoen «Slå av alle moduler» absolutt alle moduler, inkludert de som brukes av skjulte tjenesteprosjekter (for eksempel PHPMyAdmin). Dette alternativet lar deg opprettholde funksjonaliteten til skjulte tjenesteprosjekter uten å slå av nødvendige moduler for dem, mens alle andre moduler blir slått av.
Grensesnittspråk
Språk for brukergrensesnittet i Open Server Panel.

Hvis lokaliseringsfilen mangler eller inneholder feil, vil engelsk bli brukt.
API-domene
Lokalt domene for API og webgrensesnitt (under utvikling)

Anbefaling: Hvis VPN eller proxy brukes, legg til dette domenet i unntakene.
API IP-adresse
IPv4-adresse for API og webgrensesnitt (under utvikling).

Anbefaling: Hvis VPN eller proxy brukes, legg til denne IP-adressen i unntakene.
API-port
Porten som brukes for API og webgrensesnitt (under utvikling). Open Server Panel vil ikke kunne starte hvis den angitte porten allerede brukes av et annet program.
Bruk Windows Terminal
Aktiver bruk av Windows Terminal i stedet for standard kommandogrensesnitt.

Krav: Windows Terminal må være installert i systemet og oppført i miljøvariabelen PATH.

Windows Terminal som cmd.exe: Windows Terminal kan erstatte cmd.exe og være oppført i miljøvariabelen %COMSPEC% i nyere versjoner av Windows. Hvis dette er tilfelle, la dette alternativet være aktivert.

Nye instanser av Windows Terminal: Hvis Windows Terminal åpner nye vinduer i stedet for faner, konfigurer det slik: Innstillinger→Oppstart→Oppførsel for ny instans→Fest til sist brukte vindu.
Kort prosjekttittel
Når dette alternativet er aktivert, vil bare prosjektnavnet vises i tittellinjen til terminalvinduet i stedet for en detaljert beskrivelse av miljøet.
Inkluder systemmiljø i prosjektets miljø
Bruk systemets miljø (System) i terminalen, selv om det ikke er angitt i prosjektinnstillingene. Systemmiljøet lar deg bruke programmer installert i systemet (for eksempel git.exe eller ssh.exe).

Deaktiver dette alternativet bare hvis det oppstår konflikter med systemprogramvare.
ANSI-støtte
Aktiver støtte for ANSI-koder for fargestyring i terminalen.

Modus "Automatisk" (standard):
- Fiksen brukes kun på Windows 10 opp til og med versjon 1903. I nyere versjoner av Windows er støtte for ANSI-koder allerede innebygget.
- Fiksen brukes ikke for terminaler som støtter ANSI som standard (for eksempel Windows Terminal).
Kataloger for å søke etter prosjekter
Liste over kataloger der Open Server Panel vil søke etter prosjekter. Skill stier med semikolon (;).

Unntak: Undermappene node_modules og vendor ignoreres.
Dybde
Maksimal mappenestingsdybde ved søk etter prosjekter.

Å øke denne verdien kan gjøre oppstart av Open Server Panel tregere hvis de angitte katalogene inneholder et stort antall undermapper.
Maksimal loggfilstørrelse
Maksimal størrelse på loggfilen i megabyte. Når den angitte verdien overskrides, vil loggfilen bli gjenopprettet ved neste oppstart av programmet.

Sett verdien til 0 for å tømme logger ved hver programstart.

Sett verdien til 100 MB for å deaktivere loggtømming helt.
