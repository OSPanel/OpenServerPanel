プロジェクトのグローバル設定

このセクションで指定したパラメータは、プロジェクト設定で別の値が指定されていない場合に使用されます。

HTTP
プロジェクトで使用する Web サーバーモジュールを指定します。
NODE
Node.js アプリケーションを起動するための Node.js エンジンを指定します.

Node.js のインストール: 事前にコマンド osp node <latest|lts|номер> を使用して必要なバージョンの Node.js をインストールしてください。
PHP
PHP ファイルを処理するために使用する PHP モジュールを指定します。
有効化
プロジェクトのデフォルト状態（有効または無効）を指定します。
ターミナルのエンコーディング
プロジェクト環境で作業する際のターミナルのエンコーディング。

特別な値:
- system: システムのエンコーディングを使用します。

重要: 値が指定されていない場合、最終的なプロジェクト環境の作成時に、ターミナルのエンコーディングは最後に接続された環境（例: PHP モジュールの環境）の設定に従って決定されます。
IP
個別設定のないすべてのプロジェクトで使用される IP アドレスを指定します。

制限: 同じ IP アドレスを使用するプロジェクトは、同じバージョンの PHP 上で動作する必要があります。

複数 IP のサポート: IPv6 を含め、スペース区切りで複数の IP アドレスを指定できます。HOSTS ファイルでは、ドメインに最初に指定された IP が割り当てられます。

自動割り当て: フィールドを空のままにすると、IP アドレスは自動的に割り当てられます。

推奨事項:
  • ほとんどのユーザーには IP アドレスの自動管理を推奨します。
  • IP アドレスの手動指定は、特定のネットワーク構成要件がある場合にのみ使用してください。
HTTP
HTTP 接続用のポートを指定します。
HTTPS
HTTPS 接続用のポートを指定します。
TLS
TLS のサポートを有効または無効にします。
証明書ファイル
TLS 証明書ファイルへのパスを指定します。テンプレート変数を使用できます。

使用可能な文字: A-Za-z0-9-+_.\:

推奨: 自動的に証明書を生成する場合は、フィールドを空のままにしてください。
鍵ファイル
TLS キーファイルへのパスを指定します。テンプレート変数を使用できます。

使用可能な文字: A-Za-z0-9-+_.\:

推奨: 自動的に鍵を生成する場合は、フィールドを空のままにしてください。
IP アドレス（backend）
サーバーサイド（Backend）への接続に使用する IP アドレスを指定します。
ポート（backend）
サーバーサイド（Backend）への接続に使用するポート番号を指定します。
有効化（backend）
プロジェクトへのすべての受信トラフィック（HTTP および HTTPS）を自動的にサーバーサイド（Backend）へ転送します。フロントエンドとバックエンドが分離されているテストや開発に有用です。
プロジェクトディレクトリ
プロジェクトのルートディレクトリを指定します。コマンド osp project <DOMAIN> で、このディレクトリへ移動しつつプロジェクト環境をアクティブ化します。テンプレート変数を使用できます。

許可される文字: A-Za-z0-9-+_.\:
公開ディレクトリ
プロジェクトの公開ディレクトリを指定します。テンプレート変数を使用できます。

許可される文字: A-Za-z0-9-+_.\:
エイリアス
プロジェクトの追加ドメイン名（エイリアス）をスペース区切りで指定します。テンプレート変数を使用できます。

制限: "*" は Windows の HOSTS ファイルでサポートされず、DNS 設定が必要です。
プロジェクト環境
プロジェクトの環境を構成するアドオンとモジュールをスペース区切りで列挙します。

HTTP, NODE, PHP: これらのエンジンの環境は常に（ドメインに対して設定されている場合）接続され、このパラメータに指定する必要はありません。
プロジェクト起動コマンド
プロジェクトを起動するコマンド（例: nodemon app.js）を指定します。テンプレート変数を使用できます。
プロジェクト URL
メニュー→プロジェクト→ブラウザーで開く でプロジェクトを開く際、およびプロジェクトのドメインエイリアスを開く際に使用される URL です。テンプレート変数を使用できます。

用途: CMS の管理パネルの URL を指定できます。

テンプレート変数

変数 説明
{backend_ip} サーバーサイド（Backend）への接続 IP アドレス
{backend_port} サーバーサイド（Backend）への接続ポート
{base_dir} プロジェクトのルートディレクトリ（.osp ディレクトリの所在）
{date_time} 現在の日時（プロジェクトアプリの起動コマンドでのみ利用可能）
{host} ドメイン名（国際化ドメインは Punycode を使用）
{host_decoded} 可視のドメイン名（Punycode なし）
{host_scheme} プロジェクトへのリクエストスキーム（"http" または "https"。プロジェクト設定の TLS に依存）
{http_port} HTTP プロトコルでのプロジェクトへのリクエストポート
{https_port} HTTPS プロトコルでのプロジェクトへのリクエストポート
{http_engine} HTTP エンジン
{node_engine} NODE エンジン
{php_engine} PHP エンジン
{project_root} プロジェクトのルートディレクトリ
{web_root} プロジェクトの公開ディレクトリ
{scheme_port} プロジェクトへのリクエストポート（":{http_port}" または ":{https_port}"。プロジェクト設定の TLS に依存）。

{http_port} または {https_port} が標準値の 80 または 443 の場合、{scheme_port} は空になります。
{root_dir} Open Server Panel のルートディレクトリ（フルパス）
{root_drive} ルートディレクトリのドライブ
{root_path} Open Server Panel のルートディレクトリへのパス
{terminal_codepage} コンソールのエンコーディング
