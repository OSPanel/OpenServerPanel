独自のメニュー項目の作成

  1. 一意の識別子 [ID] を持つ新しいセクションを追加します
  2. セクションを希望の順序に配置します — これがメニュー内の項目の順序を決定します
  3. 変更を保存し、Open Server Panel を再起動して変更を適用します

重要な情報

独自のメニュー項目を作成する際は、セクションの識別子が重複しないように注意してください。重複するとメニューの動作に競合が発生する可能性があります。

メニュー項目の設定

並び替え順序: メニュー項目は、テンプレート内で対応するセクションが配置されているのと同じ順序で並び替えられます。

caption メニュー項目のタイトル。{lang_xxx} 形式の言語定数をサポートします。

既定値: 未設定
category

階層内でのメニュー項目の位置を定義します。1 階層のネストのみをサポートします（例: "マイブックマーク\仕事"）。

特別なカテゴリー:

  • projects, modules, addons - 対応するアクションメニューに項目を追加
  • projects\<имя_домена>, modules\<имя_модуля>, addons\<имя_дополнения> - 特定の要素に対する項目を追加

カテゴリーが指定されていない場合、項目はルートメニューに作成されます。

既定値: 未設定
command メニュー項目のアクティブ化時に実行するコマンド。コマンドのない項目は無視されます。

既定値: 未設定
enabled メニュー項目の表示を有効/無効にします。

既定値: on | 値: on, off
hide 起動されるアプリケーションのウィンドウの可視性を制御します。子プロセスには影響しません。

既定値: off | 値: on, off
hr_after メニュー項目の後に水平区切り線を追加します。

既定値: off | 値: on, off
hr_before メニュー項目の前に水平区切り線を追加します。

既定値: off | 値: on, off
icon Font Awesome Free (Solid/Regular/Brands) のアイコン。

既定値: 未設定
need_alias ドメインエイリアスに対してのみメニュー項目を表示します。メニューテンプレートには need_alias=on の項目は 1 つのみ設定可能です。
適用対象カテゴリー: projects

既定値: 未設定 | 値: on, off
need_category

特定のカテゴリーのモジュール/アドオンに対してメニュー項目の表示を制限します。

サポートされる形式:

  • modules, addons
  • modules\<имя_модуля>, addons\<имя_дополнения>
既定値: 未設定
need_module_shell 親モジュールに shell/cli があるかどうかに応じてメニュー項目を表示します。
適用対象カテゴリー: modules, modules\<имя_модуля>

既定値: 未設定 | 値: on, off
need_state 親モジュールの状態に応じてメニュー項目を表示します。
適用対象カテゴリー: modules, modules\<имя_модуля>

既定値: 未設定 | 値: on, off
need_start_cmd プロジェクトの設定に起動コマンドがある場合にメニュー項目を表示します。
適用対象カテゴリー: projects, projects\<имя_домена>

既定値: 未設定 | 値: on, off
need_use_wt Open Server Panel で Windows Terminal を使用する設定に応じてメニュー項目を表示します。

既定値: 未設定 | 値: on, off
work_directory コマンドを実行する作業ディレクトリ。コマンドの実行中に変更される場合があります。

既定値: {root_dir}

テンプレート変数

パラメーター "command" および "work_directory" では、以下のテンプレート変数を使用できます:

共通変数

変数 説明
{date_time} 現在の日時（変数はパラメーター "command" のみで使用可能）
{root_dir} Open Server Panel のルートディレクトリ（フルパス）
{root_drive} ルートディレクトリのドライブ
{root_path} Open Server Panel のルートディレクトリへのパス
{web_panel_url} Web インターフェイスの URL アドレス

特別な変数（projects および projects\<имя_домена> のみ）

変数 説明
{base_dir} プロジェクトのベースディレクトリ
{host} ドメイン名（Punycode）
{host_decoded} 表示用のドメイン名（Punycode なし）
{host_scheme} プロジェクトへのリクエストスキーム（"http" または "https"。プロジェクト設定の TLS パラメーターに依存）
{http_port} HTTP プロトコルでのプロジェクトへのリクエストポート
{https_port} HTTPS プロトコルでのプロジェクトへのリクエストポート
{menu_caption} メニュー項目のタイトル（カテゴリー projects かつ need_alias=ON の場合のみ）
{http_engine} HTTP エンジン
{node_engine} Node.js エンジン
{php_engine} PHP エンジン
{project_root} プロジェクトのルートディレクトリ
{base_url} プロジェクトの URL
{web_root} プロジェクトの公開ディレクトリ
{scheme_port} プロジェクトへのリクエストポート（":{http_port}" または ":{https_port}"。プロジェクト設定の TLS パラメーターに依存）。{http_port} または {https_port} が標準値 80 または 443 の場合、{scheme_port} は空になります。
{app_start_command} プロジェクトアプリケーションの起動コマンド（設定されている場合）
{terminal_codepage} コンソールの文字コード

特別な変数（addons および addons\<имя_дополнения> のみ）

変数 説明
{addon_name} アドオン名
{terminal_codepage} コンソールの文字コード

特別な変数（modules および modules\<имя_модуля> のみ）

変数 説明
{ip} モジュールの IP アドレス
{log_level} エラーログのレベル
{module_name} モジュール名
{port} モジュールのポート
{profile_name} モジュールの現在の設定プロファイル名
{query_log_level} クエリログのレベル
{shell_command} モジュールの shell/cli シェル起動コマンド（設定されている場合）
{terminal_codepage} コンソールの文字コード
{time_zone} タイムゾーン

特別なコマンド値

コマンド 説明
command_open_logs_viewer ログビューアを開く
command_open_idn_converter IDN コンバーターを開く
command_open_options プログラム設定ウィンドウを開く

テンプレート変数に加えて、%SYSTEMROOT%、%SYSTEMDRIVE%、%USERNAME%、%PATH% など、任意の Windows 環境変数を使用できます。

使用例

[bookmark_1]

caption  = Google
category = マイブックマーク\検索エンジン
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

CMD.EXE のオプション

  • /c: コマンドを実行してターミナルを閉じます。
  • /k: コマンドを実行してターミナルを開いたままにします。
