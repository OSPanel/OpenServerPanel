モジュール環境のグローバル変数

このセクションでは、モジュール用のグローバル環境変数を設定できます。

これらの変数はモジュール環境内でのみ有効で、システム変数やプロジェクトの環境には影響しません。

値にはテンプレート変数を使用できます。

変数がシステム環境に存在するが、モジュール環境では使用したくない場合は、専用のフィルター（参照: モジュール→許可されたシステム変数）を使用するか、値を空に設定して環境から変数を削除してください。

テンプレート変数

変数 説明
{root_dir} Open Server Panel のルートディレクトリ（フルパス）
{root_drive} ルートディレクトリのドライブ
{root_path} Open Server Panel のルートディレクトリへのパス
{terminal_codepage} ターミナルのエンコーディング（参照: モジュール→ターミナルのエンコーディング）
{time_zone} Etc/GMT 形式のタイムゾーン（参照: モジュール→タイムゾーン）

テンプレート変数に加えて、%SYSTEMROOT%、%SYSTEMDRIVE%、%USERNAME%、%PATH% など、任意の Windows 環境変数を使用できます。
