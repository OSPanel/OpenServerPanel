メニュー設定

テーマ
メニューアイコンのテーマ。
フォントサイズ
メニューのフォントサイズ（px）。このオプションにより、システム設定とは独立してメニューのフォントサイズを指定できます。

フォントサイズ制御を無効にするには、スライダーを最小値の 12px に設定してください（システムのサイズが使用されます）。
通知領域にアイコンを表示
Windows の通知領域にプログラムのアイコンを表示します。

無効化: Windows ユーザーのログオンを必要としない自動起動方式を使用している場合（Windows タスク スケジューラ→コンピューター起動時に実行）、このオプションを無効にしてください。
メニュー項目にアイコンを表示
プログラムのメニューにアイコンを表示します。システム描画が有効な場合、アイコンは表示されません。
システム描画を有効にする
スクリーンリーダーなどのスクリーンアクセスプログラムとの互換性が必要な場合にのみ、このオプションを有効にしてください。

注意! システム描画が有効な場合、メニューのアイコンは表示されません。
縦のセパレーターを表示
このオプションを有効にすると、プログラムのメニュー内のアイコンが縦のセパレーターで区切られます。
1 要素のみのリストをグループ化しない
要素が 1 つだけのリストはグループ化しない。
プロジェクト: 表示
プロジェクト管理メニューを表示します。
プロジェクト: グループ化
メニュー内でプロジェクトをドメインゾーンごとにグループ化します。
プロジェクト: 入れ子メニュー
プロジェクトメニューを別のサブメニューで表示します。
プロジェクト: セパレーターを表示
プロジェクトメニューの後に区切り線を表示します。
モジュール: 表示
モジュール管理メニューを表示します。
モジュール: グループ化
メニュー内でモジュールをグループ化します。
モジュール: 入れ子メニュー
モジュールメニューを別のサブメニューで表示します。
モジュール: セパレーターを表示
モジュールメニューの後に区切り線を表示します。
アドオン: 表示
アドオンメニューを表示します。
アドオン: グループ化
メニュー内でアドオンをグループ化します。
アドオン: 入れ子メニュー
アドオンメニューを別のサブメニューで表示します。
アドオン: セパレーターを表示
アドオンメニューの後に区切り線を表示します。
