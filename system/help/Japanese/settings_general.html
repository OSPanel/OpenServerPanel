プログラム設定

Windows と同時に起動
オペレーティングシステムの起動時に Open Server Panel の自動起動を有効にします。
遅延
プログラム起動の遅延（秒、0 〜 60）。

Windows と同時起動時にアプリの開始を遅らせ、システム全体の負荷を軽減します。外部サービスやネットワークインターフェースの完全な初期化を待つ必要がある場合に特に有用です。
新しいバージョンの有無を確認
Open Server Panel の更新チェックを有効にします（インターネット接続が必要）。
タスクスケジューラを有効にする
内蔵タスクスケジューラを有効化します。この設定が無効な場合、ステータスに関わらず一切のスケジュール済みタスクは実行されません。
HOSTS ファイルを使用する
ドメイン名を HOSTS ファイルに書き込みます。

組織内で HOSTS ファイルへのアクセスが制限されている場合の推奨事項:

1. 必要なモジュールとプロジェクトをすべて設定します。
2. システム管理者に連絡し、HOSTS のブロック解除と状態の固定を依頼します。
3. 管理者による変更の固定後は、このオプションを無効にできます。

重要: 結果に確信がない場合は、この設定を無効にしないでください！
プロジェクトのプロファイルでモジュールを起動
プロジェクト名と一致するプロファイルを同時に有効化してモジュールを起動します。

メニュー項目「プロジェクトのモジュールを有効にする」を選択した際、現在のプロジェクトと同名のプロファイルが存在する場合、自動的にそのプロファイルを有効化するために使用します。
非表示プロジェクトのモジュールを停止しない
メニュー項目「すべてのモジュールを無効にする」を選択しても、非表示プロジェクトのモジュールを停止しません。ここでの「非表示」とは、カテゴリに「hidden」が設定されたプロジェクトを指します。

デフォルトでは「すべてのモジュールを無効にする」コマンドは、非表示のシステムプロジェクト（例: PHPMyAdmin）で使用されているものも含め、すべてのモジュールを停止します。このオプションにより、必要なモジュールを無効にせずに非表示のシステムプロジェクトの動作を維持しつつ、その他すべてのモジュールを停止できます。
インターフェイスの言語
Open Server Panel のユーザーインターフェイス言語。

ローカライズファイルが存在しない、またはエラーを含む場合は、英語が使用されます。
API ドメイン
API および Web インターフェイス用のローカルドメイン（開発中）

推奨: VPN やプロキシを使用している場合、このドメインを除外設定に追加してください。
API の IP アドレス
API および Web インターフェイス用の IPv4 アドレス（開発中）。

推奨: VPN やプロキシを使用している場合、この IP アドレスを除外設定に追加してください。
API ポート
API および Web インターフェイスで使用されるポート（開発中）。指定したポートが他のアプリケーションで使用中の場合、Open Server Panel は起動できません。
Windows Terminal を使用
標準のコマンドインターフェイスの代わりに Windows Terminal の使用を有効にします。

要件: Windows Terminal がシステムにインストールされ、環境変数 PATH に設定されている必要があります。

cmd.exe としての Windows Terminal: Windows Terminal は cmd.exe を置き換え、新しい Windows バージョンでは環境変数 %COMSPEC% に設定されている場合があります。その場合は、このオプションを有効のままにしてください。

Windows Terminal の新しいインスタンス: Windows Terminal がタブではなく新しいウィンドウを開く場合は、次のように設定してください: 設定→起動→新しいインスタンスの動作→最後に使用したウィンドウに結合。
短いプロジェクトタイトル
このオプションを有効にすると、ターミナルウィンドウのタイトルに詳細な環境説明ではなく、プロジェクト名のみが表示されます。
システム環境をプロジェクト環境に含める
プロジェクト設定で指定されていない場合でも、ターミナルでシステム（System）環境を使用します。システム環境により、システムにインストールされたプログラム（例: git.exe や ssh.exe）を使用できます。

システムのソフトウェアと競合が発生した場合にのみ、このオプションを無効にしてください。
ANSI サポート
ターミナルの色制御用 ANSI コードのサポートを有効にします。

「自動」（デフォルト）モード:
- 修正は Windows 10 バージョン 1903 までにのみ適用されます。より新しい Windows では ANSI コードのサポートが既に組み込まれています。
- デフォルトで ANSI をサポートするターミナル（例: Windows Terminal）には修正は適用されません。
プロジェクト検索用ディレクトリ
Open Server Panel がプロジェクトを検索するディレクトリの一覧。パスはセミコロン（;）で区切ってください。

除外: サブディレクトリ node_modules および vendor は無視されます。
深さ
プロジェクト検索時のディレクトリの最大ネスト深度。

指定値を増やすと、指定ディレクトリ内に多数のサブディレクトリがある場合、Open Server Panel の起動が遅くなる可能性があります。
ログファイルの最大サイズ
ログファイルの最大サイズ（MB）。指定値を超えた場合、次回のプログラム起動時にログファイルは再作成されます。

値を 0 に設定すると、プログラム起動のたびにログを消去します。

値を 100 MB に設定すると、ログの消去を完全に無効にします。
