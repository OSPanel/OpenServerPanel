モジュールのグローバル設定

このセクションで指定したパラメータは、個別モジュールの設定で該当オプションが auto（デフォルト）に設定されている場合に適用されます。

サイレントモード
Windows Error Reporting およびモジュール自身のエラーポップアップを無効にします。

推奨: モジュールの問題を診断する必要がある場合にのみ、このモードを無効にしてください。
ログファイルにヘッダーを追加
モジュールの起動ごとにログファイルへヘッダーを自動追加します。自動ログクリアを無効にしている場合のセッション区切りに有用です。
最大連続失敗起動回数
モジュールが「エラー」状態へ移行する前に許容される連続失敗起動回数を定義します。
モジュール健全性チェック時間
モジュールの正常起動後に行う健全性テストの期間を定義します。

カウント開始: モジュールの正常起動時点から。

「エラー」状態への移行: 試験期間中にモジュールが異常終了した場合、自動再起動は行われず「エラー」状態に移行します。これは、モジュールがシステムレベルで起動できない場合にも該当します。

チェックの無効化: 値 0 は試験期間を無効にし、障害発生時に常に再起動します。

推奨: 値を 0 や短すぎる期間（30 秒未満）に設定しないでください。無限再起動ループの原因となる可能性があります。
モジュール終了待機時間
モジュールに終了が許可される上限時間を定義します。

強制終了: 指定時間内に終了しない場合、強制的に停止されます。

待機の無効化: 値 0 は待機期間を無効にします。プログラムはモジュールの終了を無制限に待機します。

警告: モジュールの強制停止は、データ破損、未保存変更の喪失、プロセスの不正終了を引き起こす可能性があります。この設定は慎重に使用してください。
ログファイルの最大サイズ
ログファイルの最大サイズ（MB）。指定値を超えると、次回モジュール起動時にログファイルは再作成されます。

値を 0 に設定すると、モジュール起動のたびにログをクリアします。

値を 100 MB に設定すると、ログクリアを完全に無効にします。
ターミナルのエンコーディング
モジュール環境で使用するターミナルのエンコーディング。

特別な値:
- system: システムのエンコーディングを使用します。
タイムゾーン
Etc/GMT 形式（例: Etc/GMT-3）でモジュールのタイムゾーンを定義します。

特別な値:
- system: システムのタイムゾーンを使用します。

重要: Etc/GMT 形式は UTC に対して反転したオフセットを持ちます（例: Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow）。
使用するアドオン環境
環境を持つアドオンのリスト（スペース区切り）を定義し、それら（存在する場合）をモジュール環境に結合します。ターミナルの情報インジケーターには、これらの追加環境は表示されません。

警告: このオプションは、その目的を完全に理解している場合のみ使用してください。
許可するシステム環境変数
モジュール環境へ引き渡す Windows の環境変数の一覧（スペース区切り）を定義します。

目的: システムにインストールされた同種のソフトウェアからモジュールの作業環境を分離できます。

警告: 影響を十分に理解せずにこの一覧を変更すると、モジュールの不安定な動作につながる可能性があります。
