Configuración global de módulos

Los parámetros especificados en esta sección se aplican cuando en la configuración de un módulo específico la opción correspondiente está establecida como auto (por defecto).

Modo silencioso
Desactiva los mensajes emergentes de error de Windows Error Reporting y del propio módulo.

Recomendación: Desactive este modo solo cuando sea necesario diagnosticar problemas en el funcionamiento del módulo.
Añadir encabezado al archivo de registro
Activa la adición automática de un encabezado al archivo de registro cada vez que se inicia el módulo. Útil cuando la limpieza automática de registros está desactivada para separar sesiones de trabajo.
Número máximo de inicios fallidos
Determina cuántos inicios fallidos consecutivos del módulo se permiten antes de que pase al estado "Error".
Tiempo de verificación de funcionamiento del módulo
Determina el período de prueba de funcionamiento del módulo después de su inicio exitoso.

Inicio del conteo: Desde el momento del inicio exitoso del módulo.

Transición al estado "Error": Si el módulo termina abruptamente durante el período de prueba, no se reiniciará automáticamente y pasará al estado "Error". Esto también aplica a casos donde el módulo no puede iniciarse a nivel del sistema.

Desactivación de la verificación: El valor 0 desactiva el período de prueba, y el módulo siempre se reiniciará en caso de fallo.

Recomendación: No establezca el valor 0 o un período demasiado corto (menos de 30 segundos), ya que esto puede provocar ciclos infinitos de reinicio.
Tiempo de espera para finalización del módulo
Determina el tiempo límite durante el cual se permite al módulo finalizar su trabajo.

Finalización forzada: Si el módulo no finaliza su trabajo en el tiempo especificado, será detenido forzosamente.

Desactivación de la espera: El valor 0 desactiva el período de espera. El programa esperará indefinidamente la finalización del trabajo del módulo.

Advertencia: La detención forzada del módulo puede provocar daños en los datos, pérdida de cambios no guardados o finalización incorrecta de procesos. Use esta configuración con precaución.
Tamaño máximo del archivo de registro
Tamaño máximo del archivo de registro en megabytes. Si se excede el valor especificado, el archivo de registro se recreará en el próximo inicio del módulo.

Establezca el valor 0 para limpiar los archivos de registro en cada inicio del módulo.

Establezca el valor 100 MB para desactivar completamente la limpieza de archivos de registro.
Codificación de terminal
Codificación de la terminal al trabajar con el entorno del módulo.

Valores especiales:
- system: Se utiliza la codificación del sistema.
- (valor vacío): La codificación de la terminal permanece sin cambios.
Zona horaria
Define la zona horaria del módulo en formato Etc/GMT (por ejemplo, Etc/GMT-3).

Valores especiales:
- system: Se utiliza la zona horaria del sistema.

Importante: El formato Etc/GMT tiene un desplazamiento inverso respecto a UTC (por ejemplo, Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Entornos de complementos utilizados
Define la lista de complementos (separados por espacios) cuyos entornos (si existen) se adjuntan al entorno del módulo. Los indicadores informativos en la terminal no muestran estos entornos adicionales.

Advertencia: Utilice esta opción solo cuando comprenda completamente su propósito.
Variables del sistema permitidas
Define la lista de variables de entorno de Windows (separadas por espacios) que se transmiten al entorno del módulo.

Propósito: Permite aislar el entorno de trabajo del módulo de software similar instalado en el sistema.

Advertencia: La modificación de esta lista sin comprender completamente su impacto puede provocar un funcionamiento inestable del módulo.
