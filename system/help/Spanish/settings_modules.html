Configuración global de los módulos

Los parámetros establecidos en esta sección se aplican cuando en la configuración de un módulo específico para la opción correspondiente se establece el valor auto (por defecto).

Modo silencioso de funcionamiento
Desactiva los mensajes emergentes de error de Windows Error Reporting y del propio módulo.

Recomendación: Desactive este modo solo cuando sea necesario diagnosticar problemas en el funcionamiento del módulo.
Agregar encabezado al archivo de registro
Activa la adición automática de un encabezado al archivo de registro en cada inicio del módulo. Es útil cuando la limpieza automática de logs está desactivada para separar las sesiones de trabajo.
Cantidad máxima de inicios fallidos
Determina cuántos inicios fallidos consecutivos del módulo se permiten antes de que pase al estado «Error».
Tiempo de verificación de operatividad del módulo
Determina el período de prueba de operatividad del módulo después de su inicio exitoso.

Inicio del conteo: Desde el momento del inicio exitoso del módulo.

Transición al estado «Error»: Si el módulo finaliza de forma inesperada durante el periodo de prueba, no se reiniciará automáticamente y pasará al estado «Error». Esto también se aplica a los casos en que el módulo no se puede iniciar a nivel del sistema.

Desactivación de la verificación: El valor 0 desactiva el período de prueba, y el módulo siempre se reiniciará en caso de fallo.

Recomendación: No establezca el valor 0 ni un período demasiado corto (menos de 30 segundos), ya que puede provocar ciclos de reinicio infinitos.
Tiempo de espera para la finalización del módulo
Determina el tiempo límite durante el cual se permite al módulo finalizar su trabajo.

Finalización forzada: Si el módulo no finaliza en el plazo indicado, se detendrá de forma forzada.

Desactivación de la espera: El valor 0 desactiva el período de espera. El programa esperará la finalización del módulo por tiempo ilimitado.

Advertencia: La detención forzada del módulo puede provocar daños en los datos, pérdida de cambios no guardados o una finalización incorrecta de procesos. Utilice esta configuración con precaución.
Tamaño máximo del archivo de registro
Tamaño máximo del archivo de registro en megabytes. Al superar el valor indicado, el archivo de log se volverá a crear en el siguiente inicio del módulo.

Establezca el valor 0 para limpiar los registros en cada inicio del módulo.

Establezca el valor 100 MB para desactivar por completo la limpieza de registros.
Codificación del terminal
Codificación del terminal al trabajar con el entorno del módulo.

Valores especiales:
- system: Se utiliza la codificación del sistema.
Zona horaria
Determina la zona horaria del módulo en el formato Etc/GMT (por ejemplo, Etc/GMT-3).

Valores especiales:
- system: Se utiliza la zona horaria del sistema.

Importante: El formato Etc/GMT tiene un desplazamiento inverso con respecto a UTC (por ejemplo, Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Entornos de complementos utilizados
Determina la lista de complementos (se indican separados por espacios) cuyos entornos (si los hay) se anexan al entorno del módulo. Los indicadores informativos en el terminal no muestran estos entornos adicionales.

Advertencia: Utilice esta opción solo si entiende completamente su propósito.
Variables del sistema permitidas
Determina la lista de variables de entorno de Windows (se indican separadas por espacios) que se transfieren al entorno del módulo.

Propósito: Permite aislar el entorno de trabajo del módulo del software similar instalado en el sistema.

Advertencia: Cambiar esta lista sin comprender completamente su impacto puede provocar un funcionamiento inestable del módulo.
