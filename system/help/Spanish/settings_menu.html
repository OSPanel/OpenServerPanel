Configuración del menú

Tema de diseño
Tema de diseño para los iconos del menú.
Tamaño de fuente
Tamaño de fuente del menú en píxeles. Esta opción permite establecer el tamaño de fuente del menú independientemente de la configuración del sistema.

Establezca el deslizador en el valor mínimo de 12px para desactivar la función de control del tamaño de fuente (se utilizará el tamaño del sistema).
Mostrar icono en el área de notificaciones
Mostrar el icono del programa en el área de notificaciones de Windows.

Desactivación: Desactive esta opción si ejecuta Open Server Panel en un entorno Windows Server Core o utiliza un tipo de inicio automático que no requiere inicio de sesión de usuario de Windows (Programador de tareas de Windows→Inicio al arrancar el ordenador).
Mostrar iconos para elementos del menú
Mostrar iconos en el menú del programa. Los iconos no se muestran si está activado el renderizado del sistema.
Activar renderizado del sistema
Active esta opción solo cuando sea necesario garantizar la compatibilidad con programas de acceso por pantalla (lectores de pantalla).
Mostrar separador vertical
Cuando esta opción está activada, los iconos en el menú del programa estarán separados por un separador vertical.
No agrupar listas de un solo elemento
No agrupar listas que contienen solo un elemento.
