Creación de elementos de menú personalizados

  1. Añada una nueva sección con un identificador único [ID]
  2. Organice las secciones en el orden deseado — esto determinará el orden de los elementos en el menú
  3. Guarde los cambios y reinicie Open Server Panel para aplicar los cambios

Información importante

Al crear elementos de menú personalizados, asegúrese de que los identificadores de sección no se repitan. Esto puede provocar conflictos en la funcionalidad del menú.

Configuración de elementos de menú

Orden de clasificación: Los elementos del menú se ordenan en el mismo orden que sus secciones correspondientes en la plantilla.

caption Título del elemento de menú. Admite constantes de idioma en formato {lang_xxx}.

Por defecto: no establecido
category

Determina la posición del elemento en la jerarquía del menú. Admite un nivel de anidamiento (por ejemplo, "Mis Marcadores\Trabajo").

Categorías especiales:

  • projects, modules, addons - añade el elemento al menú de acciones correspondiente
  • projects\, modules\, addons\ - añade un elemento para un elemento específico

Si no se especifica la categoría, el elemento se crea en el menú raíz.

Variables de plantilla

Las siguientes variables de plantilla se pueden usar en los parámetros "command" y "work_directory":

Variables generales

Variable Descripción
{root_dir} Directorio raíz de Open Server Panel (ruta completa)
{root_drive} Unidad del directorio raíz
{root_path} Ruta al directorio raíz de Open Server Panel
{web_panel_url} URL de la interfaz web

Variables especiales (solo para projects y projects\<nombre_dominio>)

Variable Descripción
{base_dir} Directorio base del proyecto
{host} Nombre de dominio (Punycode)
{host_decoded} Nombre de dominio visible (sin Punycode)
{host_scheme} Esquema de solicitud del proyecto ("http" o "https", depende del parámetro SSL en la configuración del proyecto)
{http_port} Puerto de solicitud del protocolo HTTP para el proyecto
{https_port} Puerto de solicitud del protocolo HTTPS para el proyecto
{menu_caption} Título del elemento de menú (solo para la categoría projects con need_alias=ON)
{nginx_engine} Motor Nginx
{node_engine} Motor Node.js
{php_engine} Motor PHP
{project_dir} Directorio raíz del proyecto
{project_url} URL del proyecto
{public_dir} Directorio público del proyecto
{scheme_port} Puerto de solicitud del proyecto (":{http_port}" o ":{https_port}", depende del parámetro SSL en la configuración del proyecto). Si {http_port} o {https_port} tiene un valor estándar de 80 o 443, entonces {scheme_port} estará vacío.
{start_command} Comando de inicio del proyecto (si está configurado)
{terminal_codepage} Codificación de la consola

Variables especiales (solo para addons y addons\<nombre_complemento>)

Variable Descripción
{addon_name} Nombre del complemento
{terminal_codepage} Codificación de la consola

Variables especiales (solo para modules y modules\<nombre_módulo>)

Variable Descripción
{ip} Dirección IP del módulo
{log_level} Nivel de registro de errores
{module_name} Nombre del módulo
{port} Puerto del módulo
{profile_name} Nombre del perfil de configuración actual del módulo
{query_log_level} Nivel de registro de consultas
{shell_command} Comando de inicio de shell/cli del módulo (si está configurado)
{terminal_codepage} Codificación de la consola
{time_zone} Zona horaria

Valores especiales de comandos

Comando Descripción
command_open_logs_viewer Abrir ventana del visor de registros
command_open_idn_converter Abrir conversor IDN
command_open_options Abrir ventana de configuración del programa

Además de las variables de plantilla, puede utilizar cualquier variable de entorno de Windows, como: %COMSPEC%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, etc.

Ejemplos de uso

[21]

caption  = Abrir en PhpStorm
category = projects
command  = "%COMSPEC%" /c "osp project {host_decoded} & start "" "C:\chrome.exe" "{project_dir}""
hide     = on
icon     = code

[22]

caption  = Google
category = Mis Marcadores\Motores de búsqueda
command  = "%COMSPEC%" /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opciones de `cmd.exe`

  • /c: Ejecutar el comando y cerrar el terminal.
  • /k: Ejecutar el comando y mantener el terminal abierto.
