Creación de elementos de menú personalizados

  1. Agregue una nueva sección con un identificador único [ID]
  2. Coloque las secciones en el orden deseado: esto determinará el orden de los elementos en el menú
  3. Guarde los cambios y reinicie Open Server Panel para aplicar los cambios

Información importante

Al crear elementos de menú personalizados, asegúrese de que los identificadores de las secciones no se repitan. Esto puede provocar conflictos en el funcionamiento del menú.

Configuración de los elementos del menú

Orden de clasificación: Los elementos del menú se ordenan en el mismo orden en que se ubican las secciones correspondientes en la plantilla.

caption Título del elemento del menú. Admite constantes de idioma en el formato {lang_xxx}.

Por defecto: no establecido
category

Determina la ubicación del elemento del menú en la jerarquía. Admite un nivel de anidación (por ejemplo, "Mis Marcadores\Trabajo").

Categorías especiales:

  • projects, modules, addons: agrega el elemento al menú de acciones correspondiente
  • projects\, modules\, addons\: agrega el elemento para un elemento específico

Si no se especifica la categoría, el elemento se crea en el menú raíz.

Por defecto: no establecido
command Comando para ejecutar al activar el elemento del menú. Los elementos sin comando se ignoran.

Por defecto: no establecido
enabled Habilita/deshabilita la visualización del elemento del menú.

Por defecto: on | Valores: on, off
hide Controla la visibilidad de la ventana de la aplicación llamada. No afecta a los procesos secundarios.

Por defecto: off | Valores: on, off
hr_after Agrega un separador horizontal después del elemento del menú.

Por defecto: off | Valores: on, off
hr_before Agrega un separador horizontal antes del elemento del menú.

Por defecto: off | Valores: on, off
icon Icono del conjunto Font Awesome Free (Solid/Regular/Brands).

Por defecto: no establecido
need_alias Muestra el elemento del menú solo para el alias de dominio. ¡En la plantilla del menú solo puede haber un elemento con need_alias=on!
Aplicable para categorías: projects

Por defecto: no establecido | Valores: on, off
need_category

Restringe la visualización del elemento del menú a módulos/complementos de una categoría específica.

Formatos admitidos:

  • modules, addons
  • modules\, addons\
Por defecto: no establecido
need_module_shell Muestra el elemento del menú en función de la disponibilidad de shell/cli del módulo principal.
Aplicable para categorías: modules, modules\

Por defecto: no establecido | Valores: on, off
need_state Muestra el elemento del menú según el estado del módulo principal.
Aplicable para categorías: modules, modules\

Por defecto: no establecido | Valores: on, off
need_start_cmd Muestra el elemento del menú si hay un comando de inicio en la configuración del proyecto.
Aplicable para categorías: projects, projects\

Por defecto: no establecido | Valores: on, off
need_use_wt Muestra el elemento del menú según la configuración de uso de Windows Terminal en Open Server Panel.

Por defecto: no establecido | Valores: on, off
work_directory Directorio de trabajo para la ejecución del comando. Puede cambiar durante la ejecución de los comandos.

Por defecto: {root_dir}

Variables de plantilla

En los parámetros "command" y "work_directory" se pueden utilizar las siguientes variables de plantilla:

Variables generales

Variable Descripción
{date_time} Fecha/hora actual (la variable solo está disponible para el parámetro "command")
{root_dir} Directorio raíz de Open Server Panel (ruta completa)
{root_drive} Unidad del directorio raíz
{root_path} Ruta al directorio raíz de Open Server Panel
{web_panel_url} URL de la interfaz web

Variables especiales (solo para projects y projects\<nombre_de_dominio>)

Variable Descripción
{base_dir} Directorio base del proyecto
{host} Nombre de dominio (Punycode)
{host_decoded} Nombre de dominio visible (sin Punycode)
{host_scheme} Esquema de la solicitud al proyecto ("http" o "https", depende del parámetro TLS en la configuración del proyecto)
{http_port} Puerto de la solicitud al proyecto por el protocolo HTTP
{https_port} Puerto de la solicitud al proyecto por el protocolo HTTPS
{menu_caption} Título del elemento del menú (solo para la categoría projects con need_alias=ON)
{http_engine} Motor HTTP
{node_engine} Motor Node.js
{php_engine} Motor PHP
{project_root} Directorio raíz del proyecto
{base_url} URL del proyecto
{web_root} Directorio público del proyecto
{scheme_port} Puerto de la solicitud al proyecto (":{http_port}" o ":{https_port}", depende del parámetro TLS en la configuración del proyecto). Si {http_port} o {https_port} tiene el valor estándar 80 o 443, entonces {scheme_port} estará vacío.
{app_start_command} Comando de inicio de la aplicación del proyecto (si está configurado)
{terminal_codepage} Codificación de la consola

Variables especiales (solo para addons y addons\<nombre_del_complemento>)

Variable Descripción
{addon_name} Nombre del complemento
{terminal_codepage} Codificación de la consola

Variables especiales (solo para modules y modules\<nombre_del_módulo>)

Variable Descripción
{ip} Dirección IP del módulo
{log_level} Nivel de registro de errores
{module_name} Nombre del módulo
{port} Puerto del módulo
{profile_name} Nombre del perfil actual de configuración del módulo
{query_log_level} Nivel de registro de consultas
{shell_command} Comando para iniciar la shell/cli del módulo (si está configurado)
{terminal_codepage} Codificación de la consola
{time_zone} Zona horaria

Valores especiales de comandos

Comando Descripción
command_open_logs_viewer Abrir la ventana del visor de registros
command_open_idn_converter Abrir el convertidor IDN
command_open_options Abrir la ventana de configuración del programa

Además de las variables de plantilla, se pueden usar cualquier variable de entorno de Windows, por ejemplo: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, etc.

Ejemplo de uso

[bookmark_1]

caption  = Google
category = Mis Marcadores\Motores de búsqueda
command  = cmd.exe /c "start "" "https://google.com""
hide     = on
icon     = bookmark

Opciones de CMD.EXE

  • /c: Ejecutar el comando y cerrar la terminal.
  • /k: Ejecutar el comando y dejar la terminal abierta.
