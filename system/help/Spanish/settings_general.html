Configuración del programa

Iniciar junto con Windows
Habilitar el inicio automático de Open Server Panel al cargar el sistema operativo.
Retardo
Retardo del inicio del programa (en segundos, de 0 a 60).

Permite posponer el inicio de la aplicación durante el arranque junto con Windows para reducir la carga general del sistema. Es especialmente útil si es necesario esperar la completa inicialización de servicios de terceros o interfaces de red.
Comprobar la disponibilidad de nuevas versiones
Activar la comprobación de actualizaciones de Open Server Panel (se requiere conexión a Internet).
Habilitar el planificador de tareas
Activar el planificador de tareas integrado. Si el parámetro está desactivado, no se ejecutará ninguna tarea programada, independientemente de su estado.
Usar el archivo HOSTS
Habilitar el registro de nombres de dominio en el archivo HOSTS.

Recomendaciones cuando el acceso al archivo HOSTS está limitado en la organización:

1. Configure todos los módulos y proyectos necesarios.
2. Contacte con el administrador del sistema para desbloquear HOSTS y fijar su estado.
3. Después de que el administrador fije los cambios, se puede desactivar esta opción.

Importante: ¡No desactive este parámetro si no está seguro de las consecuencias!
Iniciar módulos con el perfil del proyecto
Iniciar los módulos con la activación simultánea del perfil que coincida con el nombre del proyecto.

Se utiliza al seleccionar el elemento del menú «Habilitar módulos del proyecto», para activar automáticamente el perfil con el mismo nombre que el proyecto actual, si existe.
No apagar los módulos de proyectos ocultos
No apagar los módulos de proyectos ocultos al seleccionar el elemento del menú «Apagar todos los módulos». Por "ocultos" se entienden aquellos proyectos para los que se ha establecido la categoría "hidden".

De forma predeterminada, el comando «Apagar todos los módulos» detiene el funcionamiento de absolutamente todos los módulos, incluidos los que utilizan los proyectos de servicio ocultos (por ejemplo, PHPMyAdmin). Esta opción permite mantener la operatividad de los proyectos de servicio ocultos sin desactivar los módulos necesarios para ellos, mientras que todos los demás módulos se apagarán.
Idioma de la interfaz
Idioma de la interfaz de usuario de Open Server Panel.

Si falta el archivo de localización o contiene errores, se utilizará el idioma inglés.
Dominio del API
Dominio local para el API y la interfaz web (en desarrollo)

Recomendación: Si se utiliza VPN o proxy, añada este dominio a las excepciones.
Dirección IP del API
Dirección IPv4 para el API y la interfaz web (en desarrollo).

Recomendación: Si se utiliza VPN o proxy, añada esta dirección IP a las excepciones.
Puerto del API
Puerto utilizado para el API y la interfaz web (en desarrollo). Open Server Panel no podrá iniciarse si el puerto indicado ya está siendo utilizado por otra aplicación.
Usar Windows Terminal
Habilitar el uso de Windows Terminal en lugar de la interfaz de comandos estándar.

Requisitos: Windows Terminal debe estar instalado en el sistema y añadido a la variable de entorno PATH.

Windows Terminal como cmd.exe: Windows Terminal puede reemplazar a cmd.exe y estar establecido en la variable de entorno %COMSPEC% en las nuevas versiones de Windows. Si es así, deje esta opción habilitada.

Nuevas instancias de Windows Terminal: Si Windows Terminal abre nuevas ventanas en lugar de pestañas, configúrelo así: Configuración→Inicio→Comportamiento de nueva instancia→Adjuntar a la última ventana utilizada.
Título corto del proyecto
Al activar esta opción, en el título de la ventana del terminal se mostrará solo el nombre del proyecto en lugar de la descripción detallada del entorno.
Incluir el entorno del sistema en el entorno del proyecto
Usar el entorno del sistema (System) en el terminal, incluso si no está definido en la configuración del proyecto. El entorno del sistema permite usar programas instalados en el sistema (por ejemplo, git.exe o ssh.exe).

Desactive esta opción solo si se producen conflictos con el software del sistema.
Soporte ANSI
Habilitar el soporte de códigos ANSI para controlar los colores en el terminal.

Modo "Automático" (por defecto):
- La corrección se aplica solo a Windows 10 hasta la versión 1903 inclusive. En versiones más recientes de Windows, el soporte de códigos ANSI ya está incorporado.
- La corrección no se aplica a los terminales que admiten ANSI de forma predeterminada (por ejemplo, Windows Terminal).
Directorios para buscar proyectos
Lista de directorios en los que Open Server Panel buscará proyectos. Separe las rutas con punto y coma (;).

Excepciones: Se ignoran los subdirectorios node_modules y vendor.
Profundidad
Profundidad máxima de anidamiento de directorios al buscar proyectos.

Aumentar este valor puede ralentizar el inicio de Open Server Panel si en los directorios indicados hay una gran cantidad de subdirectorios.
Tamaño máximo del archivo de registro
Tamaño máximo del archivo de registro en megabytes. Al exceder el valor indicado, el archivo de log se volverá a crear en el próximo inicio del programa.

Establezca el valor 0 para limpiar los registros en cada inicio del programa.

Establezca el valor 100 MB para desactivar por completo la limpieza de registros.
