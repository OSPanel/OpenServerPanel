Configuración del programa

Iniciar con Windows
Activar el inicio automático de Open Server Panel al cargar el sistema operativo.
Comprobar nuevas versiones
Activar la comprobación de actualizaciones de Open Server Panel (requiere conexión a Internet).
Activar el programador de tareas
Activar el programador de tareas integrado. Si este parámetro está desactivado, no se ejecutará ninguna tarea programada, independientemente de su estado.
Usar archivo HOSTS
Activar la escritura de nombres de dominio en el archivo HOSTS.

Recomendaciones para acceso limitado al archivo HOSTS en una organización:

1. Configure todos los módulos y proyectos necesarios.
2. Contacte con el administrador del sistema para desbloquear HOSTS y fijar su estado.
3. Después de que el administrador fije los cambios, puede desactivar esta opción.

Importante: ¡No desactive este parámetro si no está seguro de las consecuencias!
Idioma de la interfaz
Idioma de la interfaz de usuario de Open Server Panel.

Si el archivo de localización está ausente o contiene errores, se utilizará el idioma inglés.
Dominio API
Dominio local para API e interfaz web (en desarrollo)

Recomendación: Si utiliza VPN o proxy, añada este dominio a las exclusiones.
Dirección IP API
Dirección IPv4 para API e interfaz web (en desarrollo).

Recomendación: Si utiliza VPN o proxy, añada esta dirección IP a las exclusiones.
Puerto API
Puerto utilizado para API e interfaz web (en desarrollo). Open Server Panel no se iniciará si el puerto especificado ya está ocupado.
Usar Windows Terminal
Activar el uso de Windows Terminal en lugar de la interfaz de comandos estándar.

Requisitos: Windows Terminal debe estar instalado en el sistema y estar en la variable de entorno PATH.

Windows Terminal como cmd.exe: En las nuevas versiones de Windows, Windows Terminal puede reemplazar cmd.exe y estar en la variable de entorno %COMSPEC%. Si es así, mantenga esta opción activada.

Nuevas instancias de Windows Terminal: Si Windows Terminal abre nuevas ventanas en lugar de pestañas, configúrelo así: Configuración→Inicio→Comportamiento de nueva instancia→Adjuntar a la última ventana usada.
Título corto del proyecto
Al activar esta opción, en el título de la ventana de terminal solo se mostrará el nombre del proyecto en lugar de una descripción detallada.
Usar entorno del sistema con entorno de proyectos
Usar el entorno del sistema (System) en la terminal, incluso si no está especificado en la configuración del proyecto. El entorno del sistema permite utilizar programas instalados en el sistema (por ejemplo, git.exe o ssh.exe).

Desactive esta opción solo si hay conflictos con software del sistema.
Soporte ANSI
Activar el soporte de códigos ANSI para el control de colores en la terminal.

Modo "Automático" (por defecto):
- La corrección se aplica solo a Windows 7, 8 y Windows 10 (hasta la versión 1903 inclusive). En versiones más recientes de Windows, el soporte de códigos ANSI ya está integrado.
- La corrección no se aplica a terminales que soportan ANSI por defecto (por ejemplo, Windows Terminal).
Directorios para buscar proyectos
Lista de directorios donde Open Server Panel buscará proyectos. Separe las rutas con punto y coma (;).

Exclusiones: Los subdirectorios node_modules y vendor son ignorados.
Profundidad
Profundidad máxima de anidamiento de directorios al buscar proyectos.

Aumentar este valor puede ralentizar el inicio de Open Server Panel si los directorios especificados contienen un gran número de subdirectorios.
Tamaño máximo del archivo de registro
Tamaño máximo del archivo de registro en megabytes. Si se excede el valor especificado, el archivo de registro se recreará en el próximo inicio del programa.

Establezca el valor 0 para limpiar los archivos de registro en cada inicio del programa.

Establezca el valor 100 MB para desactivar completamente la limpieza de archivos de registro.
