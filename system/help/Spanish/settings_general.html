Configuración del programa

Iniciar con Windows
Habilitar el inicio automático de Open Server Panel al cargar el sistema operativo.
Retraso
Retraso de inicio del programa (en segundos, de 0 a 60).

Permite posponer el lanzamiento de la aplicación para reducir la carga del sistema durante el inicio. Esto es especialmente útil si necesita esperar la inicialización completa de servicios de terceros o interfaces de red.
Comprobar nuevas versiones
Habilitar la comprobación de actualizaciones para Open Server Panel (se requiere conexión a Internet).
Habilitar programador de tareas
Activar el programador de tareas integrado. Si este parámetro está desactivado, no se ejecutará ninguna tarea programada independientemente de su estado.
Usar archivo HOSTS
Habilitar la escritura de nombres de dominio en el archivo HOSTS.

Recomendaciones para acceso restringido al archivo HOSTS en organizaciones:

1. Configure todos los módulos y proyectos necesarios.
2. Contacte a su administrador de sistemas para desbloquear HOSTS y fijar su estado.
3. Después de que el administrador haya fijado los cambios, puede desactivar esta opción.

Importante: ¡No desactive este parámetro si no está seguro de las consecuencias!
Iniciar módulos con perfil de proyecto
Iniciar módulos con la activación simultánea de un perfil que coincida con el nombre del proyecto.

Se utiliza al seleccionar la opción de menú "Habilitar módulos del proyecto" para activar automáticamente un perfil con el mismo nombre que el proyecto actual, si existe.
Idioma de la interfaz
Idioma de la interfaz de usuario para Open Server Panel.

Si el archivo de localización falta o contiene errores, se utilizará el inglés.
Dominio de API
Dominio local para API e interfaz web (en desarrollo)

Recomendación: Si usa VPN o proxy, añada este dominio a las excepciones.
Dirección IP de API
Dirección IPv4 para API e interfaz web (en desarrollo).

Recomendación: Si usa VPN o proxy, añada esta dirección IP a las excepciones.
Puerto de API
Puerto utilizado para API e interfaz web (en desarrollo). Open Server Panel no podrá iniciarse si el puerto especificado ya está siendo utilizado por otra aplicación.
Usar Windows Terminal
Habilitar el uso de Windows Terminal en lugar de la interfaz de comandos estándar.

Requisitos: Windows Terminal debe estar instalado en el sistema y definido en la variable de entorno PATH.

Windows Terminal como cmd.exe: Windows Terminal puede reemplazar a cmd.exe y estar definido en la variable de entorno %COMSPEC% en versiones más recientes de Windows. Si este es el caso, mantenga esta opción habilitada.

Nuevas instancias de Windows Terminal: Si Windows Terminal abre nuevas ventanas en lugar de pestañas, configúrelo de la siguiente manera: Configuración→Inicio→Comportamiento de nueva instancia→Adjuntar a la ventana usada más recientemente.
Título corto del proyecto
Cuando esta opción está activada, solo se mostrará el nombre del proyecto en el título de la ventana del terminal en lugar de una descripción detallada.
Incluir entorno del sistema en el entorno del proyecto
Usar el entorno del sistema (System) en el terminal incluso si no está especificado en la configuración del proyecto. El entorno del sistema permite el uso de programas instalados en el sistema (como git.exe o ssh.exe).

Desactive esta opción solo si se producen conflictos con el software del sistema.
Soporte ANSI
Habilitar soporte para códigos ANSI para controlar los colores en el terminal.

Modo "Automático" (predeterminado):
- La corrección se aplica solo a Windows 7, 8 y Windows 10 (hasta la versión 1903 inclusive). En versiones más recientes de Windows, el soporte para códigos ANSI ya está integrado.
- La corrección no se aplica a terminales que soportan ANSI por defecto (por ejemplo, Windows Terminal).
Directorios de búsqueda de proyectos
Lista de directorios donde Open Server Panel buscará proyectos. Separe las rutas con punto y coma (;).

Exclusiones: Se ignoran los subdirectorios node_modules y vendor.
Profundidad
Profundidad máxima de anidamiento de directorios al buscar proyectos.

Aumentar este valor puede ralentizar el inicio de Open Server Panel si los directorios especificados contienen un gran número de subdirectorios.
Tamaño máximo del archivo de registro
Tamaño máximo del archivo de registro en megabytes. Cuando se supera el valor especificado, el archivo de registro se recreará la próxima vez que se inicie el programa.

Establezca el valor en 0 para limpiar los archivos de registro en cada inicio del programa.

Establezca el valor en 100 MB para desactivar completamente la limpieza de archivos de registro.
