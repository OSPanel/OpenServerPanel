Configuraciones globales de proyectos

Los parámetros establecidos en esta sección se utilizan en caso de que en la configuración del proyecto no se especifiquen otros valores.

HTTP
Determina el módulo del servidor web utilizado para los proyectos.
NODE
Indica el motor Node.js para ejecutar aplicaciones Node.js.

Instalación de Node.js: Preinstale la versión necesaria de Node.js con el comando osp node <latest|lts|номер>.
PHP
Determina el módulo PHP utilizado para procesar archivos PHP.
Habilitar
Determina el estado predeterminado del proyecto (activado o desactivado).
Codificación del terminal
Codificación del terminal al trabajar con el entorno del proyecto.

Valores especiales:
- system: Se utiliza la codificación del sistema.

Importante: Si no se especifica un valor, al formar el entorno final del proyecto la codificación del terminal será establecida por el último entorno conectado en el que esté definida, por ejemplo, el entorno del módulo PHP.
IP
Establece la(s) dirección(es) IP utilizada(s) por todos los proyectos sin configuraciones individuales.

Limitación: Los proyectos que utilizan la misma dirección IP deben ejecutarse en una misma versión de PHP.

Soporte de múltiples IP: Se pueden especificar varias direcciones IP separadas por un espacio, incluyendo IPv6. En el archivo HOSTS a los dominios se les asignará la primera IP indicada.

Asignación automática: Si deja el campo vacío, la dirección IP se asignará automáticamente.

Recomendaciones:
  • La gestión automática de direcciones IP es recomendable para la mayoría de los usuarios.
  • La asignación manual de IP debe usarse solo con requisitos específicos de configuración de red.
HTTP
Determina el puerto para conexiones HTTP.
HTTPS
Determina el puerto para conexiones HTTPS.
TLS
Activa o desactiva el soporte de TLS.
Archivo de certificado
Indica la ruta al archivo del certificado TLS. Se pueden usar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:

Recomendación: Deje el campo vacío para la generación automática de certificados.
Archivo de clave
Indica la ruta al archivo de la clave TLS. Se pueden usar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:

Recomendación: Deje el campo vacío para la generación automática de la clave.
Dirección IP (backend)
Indica la dirección IP a través de la cual se realiza la conexión a la parte del servidor (Backend).
Puerto (backend)
Determina el número de puerto para la conexión a la parte del servidor (Backend).
Habilitar (backend)
Permite redirigir automáticamente todo el tráfico entrante (HTTP y HTTPS) del proyecto a la parte del servidor (Backend). Es útil para pruebas o desarrollo cuando el frontend y el backend están separados.
Directorio del proyecto
Indica el directorio raíz del proyecto. La transición a este directorio se realiza con el comando osp project <DOMAIN> simultáneamente con la activación del entorno del proyecto. Se pueden usar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:
Directorio público
Determina el directorio público del proyecto. Se pueden usar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:
Alias
Indica nombres de dominio adicionales (alias) para el proyecto (separados por un espacio). Se pueden usar variables de plantilla.

Limitación: El símbolo "*" no es compatible con el archivo HOSTS en Windows y requiere configuración de DNS.
Entorno del proyecto
Lista de complementos y módulos (separados por un espacio) que forman el entorno del proyecto.

HTTP, NODE y PHP: Los entornos de estos motores se conectan siempre (si están definidos para el dominio) y no requieren indicarse en este parámetro.
Comando de inicio del proyecto
Determina el comando para iniciar el proyecto (por ejemplo, nodemon app.js). Se pueden usar variables de plantilla.
URL del proyecto
URL utilizada al abrir el proyecto Menú→Proyecto→Abrir en el navegador, así como al abrir los alias de dominio del proyecto. Se pueden usar variables de plantilla.

Aplicación: Puede establecer la URL del panel de administración de la CMS.

Variables de plantilla

Variable Descripción
{backend_ip} Dirección IP de conexión a la parte del servidor (Backend)
{backend_port} Puerto de conexión a la parte del servidor (Backend)
{base_dir} Directorio raíz del proyecto (donde se encuentra el directorio .osp)
{date_time} Fecha/hora actual (la variable solo está disponible para el comando de inicio de la aplicación del proyecto)
{host} Nombre de dominio (para dominios internacionalizados se utiliza Punycode)
{host_decoded} Nombre de dominio visible (sin Punycode)
{host_scheme} Esquema de la solicitud al proyecto ("http" o "https", depende del parámetro TLS en la configuración del proyecto)
{http_port} Puerto de solicitud al proyecto por el protocolo HTTP
{https_port} Puerto de solicitud al proyecto por el protocolo HTTPS
{http_engine} Motor HTTP
{node_engine} Motor NODE
{php_engine} Motor PHP
{project_root} Directorio raíz del proyecto
{web_root} Directorio público del proyecto
{scheme_port} Puerto de solicitud al proyecto (":{http_port}" o ":{https_port}", depende del parámetro TLS en la configuración del proyecto).

Si {http_port} o {https_port} tiene el valor estándar 80 o 443, entonces {scheme_port} estará vacío.
{root_dir} Directorio raíz de Open Server Panel (ruta completa)
{root_drive} Unidad del directorio raíz
{root_path} Ruta al directorio raíz de Open Server Panel
{terminal_codepage} Codificación de la consola
