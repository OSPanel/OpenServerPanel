Configuración global de proyectos

Los parámetros especificados en esta sección se utilizan si no se indican otros valores en la configuración del proyecto.

Activar
Define el estado predeterminado del proyecto (activado o desactivado).
Codificación de terminal
Codificación de la terminal al trabajar con el entorno del proyecto.

Valores especiales:
- system: Se utiliza la codificación del sistema.
- (valor vacío): La codificación de la terminal permanece sin cambios.

Importante: Si no se especifica un valor, al formar el entorno final del proyecto, la codificación de la terminal será establecida por el último entorno conectado donde esté definida, por ejemplo, el entorno del módulo PHP.
Nginx
Define la versión del servidor web Nginx utilizada para los proyectos.
Node
Especifica el motor Node.js para ejecutar aplicaciones Node.js.

Instalación de Node.js: Instale previamente la versión necesaria de Node.js usando el complemento NVM.
PHP
Define el motor PHP utilizado para procesar archivos PHP.

Importante: Los módulos PHP sin el prefijo FCGI son módulos integrados de Apache+PHP.
IP
Establece la(s) dirección(es) IP utilizada(s) por todos los proyectos sin configuración individual.

Limitación: Los proyectos que utilizan la misma dirección IP deben funcionar con la misma versión de PHP.

Soporte para múltiples IP: Se pueden especificar varias direcciones IP separadas por espacios, incluyendo IPv6. En el archivo HOSTS, a los dominios se les asignará la primera IP especificada.

Asignación automática: Si deja el campo vacío, la dirección IP se asignará automáticamente.

Recomendaciones:
  • La gestión automática de direcciones IP se recomienda para la mayoría de los usuarios.
  • La asignación manual de direcciones IP solo debe utilizarse cuando existan requisitos específicos de configuración de red.
HTTP
Define el puerto para conexiones HTTP.
HTTPS
Define el puerto para conexiones HTTPS.
SSL
Activa o desactiva el soporte SSL para proyectos sin configuración individual.
Archivo de certificado
Especifica la ruta al archivo del certificado SSL. Se pueden utilizar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:

Recomendación: Deje el campo vacío para la generación automática de certificados.
Archivo de clave
Especifica la ruta al archivo de clave SSL. Se pueden utilizar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:

Recomendación: Deje el campo vacío para la generación automática de la clave.
Directorio del proyecto
Especifica el directorio raíz del proyecto. La transición a este directorio se realiza mediante el comando osp project <DOMAIN> simultáneamente con la activación del entorno del proyecto. Se pueden utilizar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:
Directorio público
Define el directorio público del proyecto. Se pueden utilizar variables de plantilla.

Caracteres permitidos: A-Za-z0-9-+_.\:
Alias
Especifica nombres de dominio adicionales (alias) para el proyecto (separados por espacios). Se pueden utilizar variables de plantilla.

Subdominios: Si un alias no contiene un punto, se considera un subdominio (por ejemplo, "www" -> "www.test.local").

Limitación: El carácter "*" no es compatible con el archivo HOSTS de Windows y requiere configuración DNS.
Entorno del proyecto
Lista de complementos y módulos (separados por espacios) que forman el entorno del proyecto.

Módulos PHP/Nginx/Node.js: Los entornos de estos módulos se conectan siempre (si están configurados para el dominio) y no requieren especificación en este parámetro.
Comando de inicio del proyecto
Define el comando para iniciar el proyecto (por ejemplo, nodemon app.js). Se pueden utilizar variables de plantilla.
URL del proyecto
URL que se abre al seleccionar Abrir proyecto en el navegador en Open Server Panel. Se pueden utilizar variables de plantilla.

Aplicación: Se puede establecer la URL del panel de administración del CMS.

Variables de plantilla

Variable Descripción
{base_dir} Directorio raíz del proyecto (donde se encuentra el directorio .osp)
{host} Nombre de dominio (para dominios internacionalizados se utiliza Punycode)
{host_decoded} Nombre de dominio visible (sin Punycode)
{root_dir} Directorio raíz de Open Server Panel (ruta completa)
{root_drive} Unidad del directorio raíz
{root_path} Ruta al directorio raíz de Open Server Panel
