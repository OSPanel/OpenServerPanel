Variables de entorno globales de los módulos

En esta sección se pueden establecer variables de entorno globales para los módulos.

Estas variables solo funcionan en el entorno de los módulos y no afectan a las variables del sistema ni al entorno de los proyectos.

En los valores se permite el uso de variables de plantilla.

Si una variable está presente en el entorno del sistema pero no debe usarse en el entorno de los módulos, utilice el filtro especial (ver Módulos→Variables del sistema permitidas) o elimine la variable del entorno asignándole un valor vacío.

Variables de plantilla

Variable Descripción
{root_dir} Directorio raíz de Open Server Panel (ruta completa)
{root_drive} Unidad del directorio raíz
{root_path} Ruta al directorio raíz de Open Server Panel
{terminal_codepage} Codificación en la terminal (ver Módulos→Codificación en la terminal)
{time_zone} Zona horaria en formato Etc/GMT (ver Módulos→Zona horaria)

Además de las variables de plantilla, se pueden utilizar cualquier variable de entorno de Windows, por ejemplo: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH%, etc.
