Programma-instellingen

Starten met Windows
Schakel automatisch starten van Open Server Panel in bij het opstarten van het besturingssysteem.
Vertraging
Opstartvertraging van het programma (in seconden, van 0 tot 60).

Maakt het mogelijk om de start van de applicatie bij het opstarten met Windows uit te stellen om de algehele systeembelasting te verminderen. Dit is vooral nuttig als u wilt wachten op de volledige initialisatie van externe services of netwerkinterfaces.
Controleren op nieuwe versies
Schakel controle op updates van Open Server Panel in (internetverbinding vereist).
Taakplanner inschakelen
Activeer de ingebouwde taakplanner. Als de instelling is uitgeschakeld, worden er geen geplande taken uitgevoerd, ongeacht hun status.
HOSTS-bestand gebruiken
Schakel het wegschrijven van domeinnamen naar het HOSTS-bestand in.

Aanbevelingen bij beperkte toegang tot het HOSTS-bestand binnen een organisatie:

1. Configureer alle benodigde modules en projecten.
2. Neem contact op met de systeembeheerder om HOSTS te deblokkeren en de status vast te zetten.
3. Na het vastzetten van de wijzigingen door de beheerder kunt u deze optie uitschakelen.

Belangrijk: Schakel deze instelling niet uit als u niet zeker bent van de gevolgen!
Modules starten met projectprofiel
Start modules met gelijktijdige activatie van een profiel dat overeenkomt met de projectnaam.

Wordt gebruikt bij het kiezen van het menu-item «Modules van het project inschakelen» om automatisch het profiel met dezelfde naam als het huidige project te activeren, indien aanwezig.
Modules van verborgen projecten niet uitschakelen
Schakel modules van verborgen projecten niet uit wanneer het menu-item «Alle modules uitschakelen» wordt gekozen. Met "verborgen" worden projecten bedoeld waarvoor de categorie "hidden" is ingesteld.

Standaard stopt de opdracht «Alle modules uitschakelen» absoluut alle modules, inclusief die gebruikt worden door verborgen serviceprojecten (bijvoorbeeld PHPMyAdmin). Met deze optie kunt u de werking van verborgen serviceprojecten behouden zonder de daarvoor benodigde modules uit te schakelen, terwijl alle andere modules worden uitgeschakeld.
Interfacetaal
De taal van de gebruikersinterface van Open Server Panel.

Als het localisatiebestand ontbreekt of fouten bevat, wordt Engels gebruikt.
API-domein
Lokaal domein voor API en webinterface (in ontwikkeling)

Aanbeveling: Als u een VPN of proxy gebruikt, voeg dit domein dan toe aan de uitzonderingen.
API IP-adres
IPv4-adres voor API en webinterface (in ontwikkeling).

Aanbeveling: Als u een VPN of proxy gebruikt, voeg dit IP-adres dan toe aan de uitzonderingen.
API-poort
De poort die wordt gebruikt voor API en webinterface (in ontwikkeling). Open Server Panel kan niet starten als de opgegeven poort al door een andere applicatie wordt gebruikt.
Windows Terminal gebruiken
Schakel het gebruik van Windows Terminal in plaats van de standaard command-interface in.

Vereisten: Windows Terminal moet in het systeem zijn geïnstalleerd en opgenomen zijn in de omgevingsvariabele PATH.

Windows Terminal als cmd.exe: Windows Terminal kan cmd.exe vervangen en opgenomen zijn in de omgevingsvariabele %COMSPEC% in nieuwere versies van Windows. Als dit zo is, laat deze optie ingeschakeld.

Nieuwe instanties van Windows Terminal: Als Windows Terminal nieuwe vensters opent in plaats van tabbladen, stel het dan als volgt in: Instellingen→Opstarten→Gedrag van nieuw exemplaar→Aan laatste gebruikte venster toevoegen.
Korte projecttitel
Wanneer deze optie is ingeschakeld, wordt in de titel van het terminalvenster alleen de projectnaam weergegeven in plaats van de gedetailleerde beschrijving van de omgeving.
Systeemomgeving opnemen in de projectomgeving
Gebruik de systeemomgeving (System) in de terminal, zelfs als deze niet in de projectinstellingen is opgegeven. De systeemomgeving maakt het mogelijk om programma’s te gebruiken die in het systeem zijn geïnstalleerd (bijvoorbeeld git.exe of ssh.exe).

Schakel deze optie alleen uit als er conflicten optreden met systeemsoftware.
ANSI-ondersteuning
Schakel ondersteuning voor ANSI-codes in voor kleurbeheer in de terminal.

Modus "Automatisch" (standaard):
- De fix wordt alleen toegepast op Windows 10 tot en met versie 1903. In nieuwere versies van Windows is ondersteuning voor ANSI-codes al ingebouwd.
- De fix wordt niet toegepast op terminals die standaard ANSI ondersteunen (bijvoorbeeld Windows Terminal).
Mappen voor het zoeken naar projecten
Lijst met mappen waarin Open Server Panel naar projecten zoekt. Scheid paden met een puntkomma (;).

Uitzonderingen: Submappen node_modules en vendor worden genegeerd.
Diepte
Maximale diepte van mapnesten bij het zoeken naar projecten.

Het verhogen van deze waarde kan het starten van Open Server Panel vertragen als de opgegeven mappen veel submappen bevatten.
Maximale logbestandsgrootte
Maximale grootte van het logbestand in megabytes. Wanneer de opgegeven waarde wordt overschreden, wordt het logbestand opnieuw aangemaakt bij de volgende start van het programma.

Stel de waarde 0 in om logs bij elke start van het programma te wissen.

Stel de waarde 100 MB in om het wissen van logs volledig uit te schakelen.
