Algemene module-instellingen

De parameters die in deze sectie zijn opgegeven, worden toegepast wanneer in de instellingen van een specifieke module voor de betreffende optie de waarde auto (standaard) is ingesteld.

Stille modus
Schakelt pop-up foutmeldingen uit van Windows Error Reporting en van de module zelf.

Aanbeveling: Schakel deze modus alleen uit wanneer diagnose van moduleproblemen nodig is.
Kop toevoegen aan logbestand
Schakelt het automatisch toevoegen van een kop in het logbestand in bij elke start van de module. Handig wanneer automatische logopschoning is uitgeschakeld om werksessies te scheiden.
Maximaal aantal mislukte starts
Bepaalt hoeveel opeenvolgende mislukte starts van de module zijn toegestaan voordat deze naar de status "Fout" gaat.
Tijdsduur voor healthcheck van de module
Bepaalt de periode voor het testen van de werking van de module na een succesvolle start.

Start van de telling: Vanaf het moment van succesvolle start van de module.

Overgang naar status "Fout": Als de module binnen de proeftijd onverwacht wordt beëindigd, wordt hij niet automatisch opnieuw gestart en gaat hij naar de status "Fout". Dit geldt ook wanneer de module niet op systeemniveau kan worden gestart.

Healthcheck uitschakelen: Waarde 0 schakelt de proeftijd uit en de module wordt altijd opnieuw gestart bij een crash.

Aanbeveling: Stel geen waarde 0 of een te korte periode (minder dan 30 seconden) in, omdat dit kan leiden tot oneindige herstartloops.
Wachttijd voor het beëindigen van de module
Bepaalt de maximale tijd waarbinnen de module zijn werk mag beëindigen.

Geforceerde beëindiging: Als de module binnen de opgegeven tijd niet stopt, wordt deze geforceerd gestopt.

Wachttijd uitschakelen: Waarde 0 schakelt de wachttijd uit. Het programma wacht onbeperkt op het beëindigen van de module.

Waarschuwing: Geforceerd stoppen van de module kan leiden tot gegevensbeschadiging, verlies van niet-opgeslagen wijzigingen of onjuiste beëindiging van processen. Gebruik deze instelling voorzichtig.
Maximale grootte van het logbestand
Maximale grootte van het logbestand in megabytes. Bij overschrijding van de opgegeven waarde wordt het logbestand bij de volgende start van de module opnieuw aangemaakt.

Stel de waarde 0 in om logs bij elke start van de module te wissen.

Stel de waarde 100 MB in om het wissen van logs volledig uit te schakelen.
Terminalcodering
Terminalcodering bij het werken met de omgeving van de module.

Speciale waarden:
- system: De systeemcodering wordt gebruikt.
Tijdzone
Bepaalt de tijdzone van de module in het formaat Etc/GMT (bijvoorbeeld Etc/GMT-3).

Speciale waarden:
- system: De systeemtijdzone wordt gebruikt.

Belangrijk: Het Etc/GMT-formaat heeft een omgekeerde offset ten opzichte van UTC (bijvoorbeeld Etc/GMT-3 = UTC/GMT+3 = UTC+03:00 = Europe/Moscow).
Gebruikte add-on omgevingen
Bepaalt de lijst met add-ons (opgegeven gescheiden door spaties) waarvan de omgevingen (indien aanwezig) worden gekoppeld aan de omgeving van de module. Informatieve indicatoren in de terminal tonen deze extra omgevingen niet.

Waarschuwing: Gebruik deze optie alleen als u het doel volledig begrijpt.
Toegestane systeemvariabelen
Bepaalt de lijst met Windows-omgevingsvariabelen (opgegeven gescheiden door spaties) die worden doorgegeven aan de omgeving van de module.

Doel: Hiermee kunt u de werkomgeving van de module isoleren van vergelijkbare software die in het systeem is geïnstalleerd.

Waarschuwing: Het wijzigen van deze lijst zonder volledig begrip van de gevolgen kan leiden tot instabiele werking van de module.
