პროგრამის პარამეტრები

გაშვება Windows-თან ერთად
ჩართეთ Open Server Panel-ის ავტოგაშვება ოპერაციული სისტემის ჩატვირთვისას.
დაყოვნება
პროგრამის გაშვების დაყოვნება (წამებში, 0-დან 60-მდე).

საშუალებას აძლევს გადადო აპლიკაციის გაშვება Windows-თან ერთად ჩატვირთვისას, რათა შემცირდეს სისტემაზე საერთო დატვირთვა. ეს განსაკუთრებით სასარგებლოა, თუ საჭიროა დაელოდოთ საგარეო სერვისების ან ქსელური ინტერფეისების სრულ ინიციალიზაციას.
ახალი ვერსიების შემოწმება
ჩართეთ Open Server Panel-ის განახლებების შემოწმება (საჭიროა ინტერნეტთან კავშირი).
ამოცანების დამგეგმავის ჩართვა
ჩართეთ ჩაშენებული ამოცანების დამგეგმავი. თუ პარამეტრი გამორთულია, żadna დაგეგმილი ამოცანა არ შესრულდება, მათი სტატუსის მიუხედავად.
ფაილის HOSTS გამოყენება
ჩართეთ დომენური სახელების ჩაწერა ფაილში HOSTS.

რეკომენდაციები ორგანიზაციაში HOSTS ფაილზე შეზღუდული წვდომისას:

1. დააყენეთ ყველა საჭირო მოდული და პროექტი.
2. მიმართეთ სისტემურ ადმინისტრატორს HOSTS-ის განბლოკვისა და მისი მდგომარეობის ფიქსაციისთვის.
3. ცვლილებების ადმინისტრატორის მიერ დაფიქსირების შემდეგ შეგიძლიათ გამორთოთ ეს ოპცია.

მნიშვნელოვანია: ნუ გამორთავთ ამ პარამეტრს, თუ შედეგებში დარწმუნებული არ ხართ!
მოდულების გაშვება პროექტის პროფილით
მოდულების გაშვება ერთდროულად იმ პროფილის აქტივაციით, რომელიც ემთხვევა პროექტის სახელს.

იყენება მენიუს პუნქტის „პროექტის მოდულების ჩართვა“ არჩევისას, რათა ავტომატურად გააქტიურდეს პროფილი იმავე სახელით, როგორიც არის მიმდინარე პროექტი, თუ ასეთი არსებობს.
დამალული პროექტების მოდულების არ გათიშვა
არ გათიშოთ დამალული პროექტების მოდულები მენიუს პუნქტის „ყველა მოდულის გათიშვა“ არჩევისას. „დამალული“ იგულისხმება ის პროექტები, რომლებშიც მითითებულია კატეგორია „hidden“.

ნაგულისხმევად, ბრძანება „ყველა მოდულის გათიშვა“ აჩერებს აბსოლუტურად ყველა მოდულის მუშაობას, მათ შორის იმათსაც, რომლებსაც იყენებენ დამალული სამსახურებრივი პროექტები (მაგალითად, PHPMyAdmin). ეს ოპცია საშუალებას იძლევა შენარჩუნდეს დამალული სამსახურებრივი პროექტების სამუშაოუნარიანობა, მათთვის საჭირო მოდულების გამორთვის გარეშე, მაშინ როცა დანარჩენი მოდულები გაითიშება.
ინტერფეისის ენა
Open Server Panel-ის მომხმარებლის ინტერფეისის ენა.

თუ ლოკალიზაციის ფაილი არ არსებობს ან შეიცავს შეცდომებს, გამოყენებული იქნება ინგლისური ენა.
API დომენი
ლოკალური დომენი API-სა და ვებ-ინტერფეისისთვის (მუშავდება)

რეკომენდაცია: თუ გამოიყენება VPN ან პროქსი, დაამატეთ ეს დომენი გამონაკლისებში.
API IP-მისამართი
IPv4 მისამართი API-სა და ვებ-ინტერფეისისთვის (მუშავდება).

რეკომენდაცია: თუ გამოიყენება VPN ან პროქსი, დაამატეთ ეს IP-მისამართი გამონაკლისებში.
API პორტი
პორტი, რომელიც გამოიყენება API-სა და ვებ-ინტერფეისისთვის (მუშავდება). Open Server Panel ვერ გაიშვება, თუ მითითებული პორტი უკვე გამოიყენება სხვა აპლიკაციის მიერ.
Windows Terminal-ის გამოყენება
ჩართეთ Windows Terminal-ის გამოყენება სტანდარტული საკომანდო ინტერფეისის ნაცვლად.

მოთხოვნები: Windows Terminal უნდა იყოს დაყენებული სისტემაში და прописан იყოს გარემოს ცვლადში PATH.

Windows Terminal როგორც cmd.exe: Windows Terminal-ს შეუძლია ჩაანაცვლოს cmd.exe და იყოს მითითებული გარემოს ცვლადში %COMSPEC% Windows-ის ახალ ვერსიებში. თუ ასეა, დატოვეთ ეს ოპცია ჩართული.

Windows Terminal-ის ახალი ეგზემპლარები: თუ Windows Terminal ხსნის ახალ ფანჯრებს ჩანართების ნაცვლად, დააყენეთ ასე: პარამეტრები→გაშვება→ახალი ეგზემპლარის ქცევა→მიმაგრება ბოლოს გამოყენებულ ფანჯარაზე.
პროექტის მოკლე სათაური
ამ ოპციის აქტივაციისას ტერმინალის ფანჯრის სათაურში გამოჩნდება მხოლოდ პროექტის სახელი გარემოს დეტალური აღწერის ნაცვლად.
სისტემური გარემოს ჩართვა პროექტის გარემოში
სისტემური გარემოს (System) გამოყენება ტერმინალში, მაშინაც კი, თუ ის არ არის მითითებული პროექტის პარამეტრებში. სისტემური გარემო საშუალებას გაძლევთ გამოიყენოთ სისტემაში დაყენებული პროგრამები (მაგალითად, git.exe ან ssh.exe).

გამორთეთ ეს ოპცია მხოლოდ სისტემურ პროგრამულ უზრუნველყოფასთან კონფლიქტების შემთხვევაში.
ANSI-ის მხარდაჭერა
ჩართეთ ANSI-კოდების მხარდაჭერა ტერმინალში ფერების სამართავად.

რეჟიმი „ავტომატურად“ (ნაგულისხმევად):
- გამოსწორება გამოიყენება მხოლოდ Windows 10-ზე, ვერსია 1903-მდე ჩათვლით. Windows-ის უფრო ახალი ვერსიებში ANSI-კოდების მხარდაჭერა უკვე ჩართულია.
- გამოსწორება არ გამოიყენება ტერმინალებისთვის, რომლებიც ნაგულისხმევად უჭერენ მხარს ANSI-ს (მაგალითად, Windows Terminal).
კატალოგები პროექტების მოსაძებნად
კატალოგების სია, სადაც Open Server Panel მოძებნის პროექტებს. გამოყავით ბილიკები წერტილ-მძიმით (;).

გამონაკლისები: ქვეკატალოგები node_modules და vendor იგნორირდება.
სიღრმე
მაქსიმალური ჩადგმის სიღრმე კატალოგების ძებნისას პროექტებისთვის.

ამ მნიშვნელობის გაზრდამ შეიძლება შეანელოს Open Server Panel-ის გაშვება, თუ მითითებულ კატალოგებში დიდი რაოდენობით ქვეკატალოგებია.
ჟურნალის ფაილის მაქსიმალური ზომა
ჟურნალის ფაილის მაქსიმალური ზომა მეგაბაიტებში. მითითებული მნიშვნელობის გადაჭარბებისას ლოგ-ფაილი თავიდან შეიქმნება პროგრამის შემდეგ გაშვებისას.

დააყენეთ მნიშვნელობა 0, რომ გაიწმინდოს ჟურნალები პროგრამის ყოველ გაშვებაზე.

დააყენეთ მნიშვნელობა 100 MB, რომ სრულად გამორთოთ ჟურნალების გასუფთავება.
