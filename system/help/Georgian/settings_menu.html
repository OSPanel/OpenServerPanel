მენიუს პარამეტრები

ოფორმების თემა
მენიუს ხატულებისათვის ოფორმების თემა.
შრიფტის ზომა
მენიუს შრიფტის ზომა პიქსელებში. ოპცია საშუალებას გაძლევთ დააყენოთ მენიუს შრიფტის ზომა სისტემური პარამეტრებისგან დამოუკიდებლად.

გადააყენეთ სლაიდერი მინიმალურ მნიშვნელობაზე 12px შრიფტის ზომის კონტროლის ფუნქციის გასათიშად (გამოიყენება სისტემური ზომა).
ხატულის ჩვენება შეტყობინებების ზონაში
პროგრამის ხატულის ჩვენება Windows-ის შეტყობინებების ზონაში.

გამორთვა: გამორთეთ ეს ოპცია, თუ იყენებთ ავტოწყების ტიპს, რომელიც არ მოითხოვს Windows მომხმარებლის შესვლას (Windows Task Scheduler→კომპიუტერის ჩატვირთვისას გაშვება).
ხატულების ჩვენება მენიუს პუნქტებისთვის
პროგრამის მენიუში ხატულების ჩვენება. ხატულები არ გამოდის, თუ ჩართულია სისტემური რენდერინგი.
სისტემური რენდერინგის ჩართვა
ჩართეთ ეს ოპცია მხოლოდ მაშინ, როდესაც საჭიროა თავსებადობის უზრუნველყოფა ეკრანზე წვდომის პროგრამებთან (스크린-რიდერები).

ყურადღება! მენიუში ხატულები არ გამოდის, თუ ჩართულია სისტემური რენდერინგი.
ვერტიკალური გამყოფის ჩვენება
ამ ოპციის ჩართვისას პროგრამის მენიუში ხატულები გამოყოფილი იქნება ვერტიკალური გამყოფით.
არ დააჯგუფო ერთი ელემენტის სიები
არ დააჯგუფო სიები, რომლებიც შეიცავს მხოლოდ ერთ ელემენტს.
პროექტები: ჩვენება
პროექტების მართვის მენიუს ჩვენება.
პროექტები: დაჯგუფება
პროექტების დაჯგუფება დომენის ზონის მიხედვით მენიუში.
პროექტები: ჩადგმული მენიუ
პროექტების მენიუს ჩვენება ცალკე ქვემენიუში.
პროექტები: გამყოფის ჩვენება
გამყოფი ხაზის ჩვენება პროექტების მენიუს შემდეგ.
