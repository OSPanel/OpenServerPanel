მოდულების გარემოს გლობალური ცვლადები

ამ განყოფილებაში შეგიძლიათ მიუთითოთ მოდულებისთვის გარემოს გლობალური ცვლადები.

ეს ცვლადები მოქმედებს მხოლოდ მოდულების გარემოში და არ ახდენს გავლენას სისტემურ ცვლადებზე ან პროექტების გარემოზე.

მნიშვნელობებში დაშვებულია შაბლონური ცვლადების გამოყენება.

თუ ცვლადი არსებობს სისტემურ გარემოში, მაგრამ არ უნდა იქნას გამოყენებული მოდულების გარემოში, გამოიყენეთ სპეციალური ფილტრი (იხ. მოდულები→ნებართვად სისტემური ცვლადები) ან წაშალეთ ცვლადი გარემოდან, მიანიჭეთ მას ცარიელი მნიშვნელობა.

შაბლონური ცვლადები

ცვლადი აღწერა
{root_dir} Open Server Panel-ის ფესვიური კატალოგი (სრული ბილიკი)
{root_drive} ფესვიური კატალოგის დისკი
{root_path} ბილიკი Open Server Panel-ის ფესვიურ კატალოგამდე
{terminal_codepage} კოდირება ტერმინალში (იხ. მოდულები→კოდირება ტერმინალში)
{time_zone} დროის სარტყელი Etc/GMT ფორმატში (იხ. მოდულები→დროის სარტყელი)

შაბლონური ცვლადების გარდა, შეგიძლიათ გამოიყენოთ Windows-ის ნებისმიერი გარემოს ცვლადი, მაგალითად: %SYSTEMROOT%, %SYSTEMDRIVE%, %USERNAME%, %PATH% და ა.შ.
