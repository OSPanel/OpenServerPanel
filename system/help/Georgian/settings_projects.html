პროექტების გლობალური პარამეტრები

ამ განყოფილებაში მითითებული პარამეტრები გამოიყენება იმ შემთხვევაში, თუ პროექტის პარამეტრებში სხვა მნიშვნელობები არ არის მითითებული.

HTTP
განსაზღვრავს ვებ-სერვერის გამოყენებულ მოდულს პროექტებისთვის.
NODE
მიუთითებს Node.js ძრავას Node.js-აპლიკაციების გასაშვებად.

Node.js-ის ინსტალაცია: წინასწარ დააყენეთ საჭირო ვერსია ბრძანებით osp node <latest|lts|номер>.
PHP
განსაზღვრავს PHP-ფაილების დასამუშავებლად გამოყენებულ PHP მოდულს.
ჩართვა
განსაზღვრავს პროექტის ნაგულისხმევ მდგომარეობას (ჩართული ან გამორთული).
ტერმინალის კოდირება
ტერმინალის კოდირება პროექტის გარემოში მუშაობისას.

სპეციალური მნიშვნელობები:
- system: გამოიყენება სისტემური კოდირება.

მნიშვნელოვანი: თუ მნიშვნელობა არ არის მითითებული, პროექტის საბოლოო გარემოს ფორმირებისას ტერმინალის კოდირება დაყენდება ბოლო მიერთებული გარემოს მიხედვით, სადაც ის მითითებულია, მაგალითად, PHP მოდულის გარემოში.
IP
განსაზღვრავს IP-მისამართ(ებ)ს, რომელიც გამოიყენება ყველა პროექტში ინდივიდუალური პარამეტრების გარეშე.

შეზღუდვა: პროექტები, რომლებიც იყენებენ ერთსა და იმავე IP-მისამართს, უნდა მუშაობდნენ ერთი და იმავე PHP ვერსიაზე.

რამდენიმე IP-ის მხარდაჭერა: შესაძლებელია რამდენიმე IP-მისამართის მითითება გამოტოვებით, მათ შორის IPv6. HOSTS ფაილში დომენებს მიენიჭება პირველი მითითებული IP.

ავტომატური მინიჭება: თუ ველი ცარიელად დარჩება, IP-მისამართი მიენიჭება ავტომატურად.

რეკომენდაციები:
  • IP-მისამართების ავტომატური მართვა რეკომენდებულია მომხმარებელთა უმრავლესობისათვის.
  • IP-მისამართის ხელით მითითება სასურველია მხოლოდ სპეციფიკური ქსელური კონფიგურაციის მოთხოვნების შემთხვევაში.
HTTP
განსაზღვრავს პორტს HTTP შეერთებებისთვის.
HTTPS
განსაზღვრავს პორტს HTTPS შეერთებებისთვის.
TLS
რთავს ან თიშავს TLS მხარდაჭერას.
სერტიფიკატის ფაილი
მიუთითებს TLS-სერტიფიკატის ფაილის ბილიკს. შესაძლებელია შაბლონური ცვლადების გამოყენება.

დაშვებული სიმბოლოები: A-Za-z0-9-+_.\:

რეკომენდაცია: დატოვეთ ველი ცარიელი სერტიფიკატების ავტომატური გენერაციისათვის.
გასაღების ფაილი
მიუთითებს TLS-გასაღების ფაილის ბილიკს. შესაძლებელია შაბლონური ცვლადების გამოყენება.

დაშვებული სიმბოლოები: A-Za-z0-9-+_.\:

რეკომენდაცია: დატოვეთ ველი ცარიელი გასაღების ავტომატური გენერაციისათვის.
IP-მისამართი (backend)
მიუთითებს IP-მისამართს, რომლის საშუალებითაც ხორციელდება მიერთება Backend-სერვერთან.
პორტი (backend)
განსაზღვრავს პორტის ნომერს Backend-სერვერთან მიერთებისთვის.
ჩართვა (backend)
აძლევს საშუალებას ავტომატურად მიმართოს პროექტის მთლიანი შემომავალი ტრეფიკი (HTTP და HTTPS) Backend-ზე. სასარგებლოა ტესტირებისა ან განვითარებისას, როდესაც ფრონტენდი და ბექენდი განცალკევებულია.
პროექტის კატალოგი
მიუთითებს პროექტის ფესვურ კატალოგს. ამ კატალოგში გადასვლა ხორციელდება ბრძანებით osp project <DOMAIN> ერთდროულად პროექტის გარემოს აქტივაციასთან. შესაძლებელია შაბლონური ცვლადების გამოყენება.

დაშვებული სიმბოლოები: A-Za-z0-9-+_.\:
საჯარო კატალოგი
განსაზღვრავს პროექტის საჯარო კატალოგს. შესაძლებელია შაბლონური ცვლადების გამოყენება.

დაშვებული სიმბოლოები: A-Za-z0-9-+_.\:
ფსევდონიმები
მიუთითებს დამატებით დომენურ სახელებს (ელიასებს) პროექტისთვის (გამოტოვებით). შესაძლებელია შაბლონური ცვლადების გამოყენება.

შეზღუდვა: სიმბოლო "*" არ არის მხარდაჭერილი Windows-ის HOSTS ფაილში და მოითხოვს DNS-ის კონფიგურაციას.
პროექტის გარემო
დამატებებისა და მოდულების სია (გამოტოვებით), რომლებიც ფორმირებენ პროექტის გარემოს.

HTTP, NODE და PHP: ამ ძრავების გარემოები ყოველთვის ერთიანდება (თუ მითითებულია დომენისთვის) და არ საჭიროებს ამ პარამეტრში მითითებას.
პროექტის გაშვების ბრძანება
განსაზღვრავს პროექტის გასაშვებ ბრძანებას (მაგალითად, nodemon app.js). შესაძლებელია შაბლონური ცვლადების გამოყენება.
პროექტის URL
URL, რომელიც გამოიყენება პროექტის გასახსნელად მენიუ→პროექტი→გახსნა ბრაუზერში, ასევე პროექტის დომენური ფსევდონიმების (ალიასების) გასახსნელად. შესაძლებელია შაბლონური ცვლადების გამოყენება.

გამოყენება: შესაძლებელია CMS ადმინისტრირების პანელის URL-ის მითითება.

შაბლონური ცვლადები

ცვლადი აღწერა
{backend_ip} მიერთების IP-მისამართი Backend-სერვერთან
{backend_port} მიერთების პორტი Backend-სერვერთან
{base_dir} პროექტის ფესვური კატალოგი (სადაც მდებარეობს .osp კატალოგი)
{date_time} მიმდინარე თარიღი/დრო (ცვლადი ხელმისაწვდომია მხოლოდ პროექტის აპლიკაციის გაშვების ბრძანებისთვის)
{host} დომენის სახელი (ინტერნაციონალიზებული დომენებისთვის გამოიყენება Punycode)
{host_decoded} ხილული დომენის სახელი (Punycode-ის გარეშე)
{host_scheme} პროექტის მოთხოვნის სქემა ("http" ან "https", დამოკიდებულია TLS პარამეტრზე პროექტის პარამეტრებში)
{http_port} პროექტის მოთხოვნის პორტი HTTP პროტოკოლით
{https_port} პროექტის მოთხოვნის პორტი HTTPS პროტოკოლით
{http_engine} HTTP ძრავა
{node_engine} NODE ძრავა
{php_engine} PHP ძრავა
{project_root} პროექტის ფესვური კატალოგი
{web_root} პროექტის საჯარო კატალოგი
{scheme_port} პროექტის მოთხოვნის პორტი (":{http_port}" ან ":{https_port}", დამოკიდებულია TLS პარამეტრზე პროექტის პარამეტრებში).

თუ {http_port} ან {https_port} აქვს სტანდარტული მნიშვნელობა 80 ან 443, მაშინ {scheme_port} იქნება ცარიელი.
{root_dir} Open Server Panel-ის ფესვური კატალოგი (სრული ბილიკი)
{root_drive} ფესვური კატალოგის დისკი
{root_path} Open Server Panel-ის ფესვური კატალოგის ბილიკი
{terminal_codepage} კონსოლის კოდირება
